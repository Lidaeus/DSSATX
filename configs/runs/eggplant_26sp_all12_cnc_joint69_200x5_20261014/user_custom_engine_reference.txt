  ### 二、底层 Fortran 机理核心修改说明

  本版本针对茄子/番茄水氮试验中原版 CROPGRO (TMGRO048) 模型的生理缺陷进行了底层重构，主要修改集中在以下模块：

  #### 1. 临界氮动态稀释与 F1 条件分支加固 (DEMAND.for)

  • 连续渐近稀释曲线:

                                                                      -CNC_B
                                                   ⎡max⎛CNC_W0, W   ⎞⎤
                                                   ⎢   ⎝         eff⎠⎥
    N ⎛W   ⎞ = CNC_NC_INF + (CNC_A - CNC_NC_INF) · ⎢─────────────────⎥
     c⎝ eff⎠                                       ⎣     CNC_W0      ⎦

  在封垄阈值 W_{eff} = CNC_W0 处满足严格 C⁰ 连续，消除任何跨阈值台阶突变。

  • 根除 F1 倒置死锁:
  在顶端新生幼叶与茎秆需氮上确立结构性下界：
               ⎛                   ⎛                        1.05 × N ⎞⎞
               ⎜                   ⎜                                c⎟⎟
    FNINL = min⎜PROLFI × 0.16,  max⎜PROLFG × 0.16 + 0.002,  ─────────⎟⎟
               ⎝                   ⎝                          100.0  ⎠⎠
    FNINS = max(PROSTG × 0.16 + 0.001,  min(PROSTI × 0.16,  FNINS))
  结构性保证 FNINL > FNINLG 且 FNINS > FNINSG，使 VEGGR.for 中的 NGRVEG > NGRVGG
  恒成立，杜绝了分支误判与氮素数值泄漏。
  • 老组织补氮需求解耦: 老叶回补目标 NVSTL 随有效生物量异速稀释，打破高氮处理全季叶氮“一条平线”的非生理现象。

  #### 2. 液泡缓冲氮与化学计量学对称 (GROW.for 与 MOBIL.for)

  • 安全缓冲动员: 将叶片动员解耦为“液泡安全缓冲氮（c_{opt,L} = PROLFG × 0.16
  以上）”与“代谢功能蛋白”。安全缓冲动员扣减干物质 β_{sol} = 4.4 g DM/g
  N（游离硝酸盐/氨基酸溶质化学计量比），且不扣减叶面积。
  • 对称回注: 根系吸氮充裕时优先回填功能蛋白亏缺（增加 6.25 × NADLF_{func} 并恢复叶面积），饱和后回补安全缓冲（增加
  4.4 × NADLF_{buf} 且不膨胀叶面积），彻底消除质量滞后与虚假干物质漂移。
  • Bug 修正: 修正第 783 行累计种子氮计算误用果壳氮浓度 PCNSH 的拼写错误，更正为种子氮 PCNSD。

  #### 3. 净化光合作用模块 (PHOTO.for)

  • 清除 0.675 毒乘子: 完全剔除日冠层光合中的冗余 S_{NNI} 乘子，避免在 NNI = 1.0 时强加 32.5%
  的非生理光合抑制；光合由功能叶比叶氮 SLN（g N/m²）平滑驱动。

  #### 4. 原生保持不变的模块

  • 土壤氮吸收函数 (NUPTAK.for): 经阶段 3
  严格审计，在地上部缓冲与化学计量对称建立后，低氮处理（N0）生长平稳无早衰，因此严格维持原生官方代码未动，确保土壤水
  氮扩散模块 100% 官方兼容。

  ### 四、PEST-IES 模板与控制文件定制规范

  在定制 PEST-IES 时，请注意以下关键规范：

  #### 1. SPE 模板文件 (TMGRO048.SPE.tpl) 格式规范
  DSSAT 的 Fortran 读取函数采用 4F6.0 定宽格式。每一列必须严格占用 6 个字符宽度（含负号或小数点）：
    ptf ~
    ... (上方常规参数省略)
    !*CRITICAL NITROGEN DILUTION PARAMETERS
    @ CNC_A  CNC_B CNC_W0 CNC_NC_INF
    ~ cnc_a~~ cnc_b~~cnc_w0~~cnc_inf~
    !*NITROGEN FIXATION PARAMETERS
    ...

  注：请确保每个 ~param~ 占位符展开后的实际字符宽度恰好为 6 列。若使用 Python 的 _format_to_width(val,
  6)，会自动格式化为如   4.85  0.38  1.00  1.70。

  #### 2. PEST 控制文件 (.pst) 参数块配置参考

    *parameter groups
    pargpnme        inctyp          derinc          derinlnd        forcen          derincmul       dermthd
    spe_nitrogen    relative        0.01            0.0             switch          2.0             parabolic

    *parameter data
    # parnme        partrans  parchglim  parval1   parlbnd   parubnd  pargp         scale  offset  dercom
    cnc_a           none      factor     4.8500    4.2000    5.2000   spe_nitrogen  1.0    0.0     1
    cnc_b           none      factor     0.3800    0.3000    0.4500   spe_nitrogen  1.0    0.0     1
    cnc_w0          none      factor     1.0000    0.8000    1.5000   spe_nitrogen  1.0    0.0     1
    cnc_nc_inf      none      factor     1.7000    1.4000    2.0000   spe_nitrogen  1.0    0.0     1

  #### 3. 模型执行命令（Model Command Line）配置

  在 PEST 控制文件中的 *model command line 块，或者并行代理调度脚本中，黑盒调用命令直接指向自定义执行体：

    # 格式：<自定义执行体路径> B <批处理文件名>
    D:\Tomato_Cal\subprojects\critical_n\bin\dscsm048_cnc.exe B DSSBatch.v48

  #### 4. 输出提取文件推荐（Instruction Files）

  • 鲜产提取: FreshWt.OUT（变量 CHFPW）
  • 干物质与 LAI 提取: PlantGro.OUT（变量 LAID, CWAD, LWAD, SWAD）
  • 组织氮浓度提取: PlantN.OUT（变量 LN%D, SN%D）
