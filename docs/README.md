## 开发与科研证据

- [开发/运行报告索引](reports/README.md)：P0–P2、SA、IES、code review 和图表接入证据。
- `workspace/runs/<run_id>/run_manifest.yaml`：单次运行配置与来源。
- `workspace/runs/<run_id>/calibration_finalize/`：率定核心产物清单及唯一科研状态授权。

报告记录“当时发生了什么”，不自动成为当前操作规范。报告中的旧参数范围、审批状态和命令必须与当前规范及实际 CLI 重新核对。

## 已淘汰文档

[archive/README.md](archive/README.md) 收录早期设计、已完成计划、迁移输入材料、旧教程和被替代的分析方案。归档内容保留 Git 历史和原始文件名，供开发者追溯；其中的路径、参数、边界、算法和科研结论均不可直接用于新运行。

## 文档维护规则

- 新用户操作只写入根 README 或用户指南，避免出现第二套入口。
- 科学和技术约定只保留一份当前专题规范；计划完成后移入 archive。
- 每个阶段的运行/code review 记录进入 `docs/reports/`，不混入用户入口。
- 文档移动后必须检查当前文档的 Markdown 链接。
- `docs/archive/` 中的文件原则上只做归档标注，不继续维护其正文。
