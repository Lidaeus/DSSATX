## 已淘汰文档

[archive/README.md](archive/README.md) 收录早期设计、已完成计划、论文旧底稿、工程审查、运行历史、决策快照、迁移输入材料、旧教程和被替代的分析方案。归档内容保留 Git 历史和原始文件名，供开发者追溯；其中的路径、参数、边界、算法和科研结论均不可直接用于新运行。

## 文档维护规则

- 新用户操作只写入根 README 或用户指南，避免出现第二套入口。
- 科学和技术约定只保留一份当前专题规范；计划完成后移入 archive。
- 每个阶段的运行/code review 记录进入 `docs/reports/`，不混入用户入口。
- 文档移动后必须检查当前文档的 Markdown 链接。
- `docs/archive/` 中的文件原则上只做归档标注，不继续维护其正文。
- 过期临时文档只有在内部无可沉淀知识或配置时才可删除，且删除前须征得项目所有者同意并说明理由。
