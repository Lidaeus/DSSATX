## 核心判断

你遇到的现象与当前 CROPGRO 氮素模块的结构高度一致：

> **低氮处理长期低于氮供应阈值，受到多个氮限制过程叠加；中氮处理一旦越过阈值，`NSTRES` 很快变为1；高氮即使增加土壤矿质氮，也可能因作物氮需求已经满足而不再增加吸收。**

因此，低氮—中氮之间会出现很大的产量跳变，而中氮—高氮进入平台。

这通常不是仅靠修改一个 `NSTFAC` 就能解决的问题。更有效的做法是同时检查四个环节：

1. 土壤氮是否正确转化为根区矿质氮；
2. 根系吸氮函数是否过早饱和；
3. 作物计算的氮需求上限是否过低；
4. 低叶氮对光合作用和生长的惩罚是否过强。

---

# 一、CROPGRO氮素胁迫的完整计算链

## 1. 作物首先计算潜在氮需求

在 `DEMAND.for` 中，当日总氮需求由三部分构成：

[
NDMTOT=NDMREP+NDMVEG+NDMOLD
]

其中：

* `NDMREP`：果实、种子和果实外部组织的新生长氮需求；
* `NDMVEG`：叶、茎、根新生长氮需求；
* `NDMOLD`：已有组织恢复到目标氮浓度所需的氮。

用于计算即时胁迫的主要是新生长氮需求：

[
NDMNEW=NDMREP+NDMVEG
]

营养器官氮需求由当日可用于营养生长的碳量、叶茎根分配比例及其目标氮浓度共同决定。

这意味着，只要器官目标氮浓度、潜在生物量或果实氮需求偏低，模型就会低估 `NDMNEW` 和 `NDMTOT`。中等施氮量随后很容易满足全部需求，导致中氮和高氮没有差异。

---

## 2. 土壤矿质氮被转换为潜在吸收能力

`NUPTAK.for` 中，各土层硝态氮和铵态氮的可利用系数分别为：

[
F_{\mathrm{NO3}}=1-\exp(-0.08,NO_3)
]

[
F_{\mathrm{NH4}}=1-\exp(-0.08,NH_4)
]

其中 `NO3` 和 `NH4` 在该子程序中的单位是土壤质量浓度，即：

[
\mu g\ N\ g^{-1}\ soil
]

近似可理解为 ppm N。

例如：

| 土壤NO₃⁻-N浓度 |  FNO3 |
| ---------: | ----: |
|      2 ppm | 0.148 |
|      5 ppm | 0.330 |
|     10 ppm | 0.551 |
|     20 ppm | 0.798 |
|     40 ppm | 0.959 |

所以，这个函数在较低至中等矿质氮浓度范围内快速增加，之后迅速接近饱和。

各层潜在吸氮量还受到以下变量控制：

[
RNO3U=RLV\times \sqrt{SMDFR}\times DLAYR\times100
\times FNO3\times RTNO3
]

铵态氮采用同样形式。其中：

* `RLV`：根长密度；
* `SMDFR`：土壤水分因子；
* `DLAYR`：土层厚度；
* `RTNO3、RTNH4`：单位根长最大吸收能力。

但实际吸氮量还被当日作物氮需求封顶：

[
ANDEM=(NDMTOT-NDMSDR)\times10
]

如果潜在吸氮量大于 `ANDEM`，模型只吸收满足需求的部分。因此一旦中氮已经满足 `NDMTOT`，高氮增加的矿质氮只会留在土壤中，不会继续增加植株吸氮或产量。

---

## 3. 当根系吸氮不足时，模型动员植株内部氮

如果：

[
TRNU<NDMNEW
]

模型从叶、茎、根和果实外部组织中动员可再转运氮：

[
NMINEA=\min(NDMNEW-TRNU,\ NMINEP)
]

`NMINEP` 由 `NMOBMX`、`NVSMOB`、发育阶段和各器官可动员氮库决定。

因此当天用于新生长的总氮供应为：

[
SUPPN=TRNU+NMINEA+NFIXN
]

对于茄子这种非豆科作物：

[
NFIXN=0
]

---

## 4. NSTFAC将氮供需关系转换为NSTRES

当前 CROPGRO 代码采用：

[
r_N=\frac{SUPPN}{NDMNEW}
]

当：

[
SUPPN<NSTFAC\times NDMNEW
]

则：

[
XNSTRES=
\frac{SUPPN}{NSTFAC\times NDMNEW}
=================================

\frac{r_N}{NSTFAC}
]

否则：

[
XNSTRES=1
]

最后采用当前值和前一天瞬时值的平均：

[
NSTRES_t=0.5XNSTRES_t+0.5XNSTRES_{t-1}
]

代码还将 `NSTFAC` 限制在0.1～1.0。

Tomato默认：

[
NSTFAC=0.70
]

因此其瞬时响应为：

| 氮供应/新生长需求 (r_N) | XNSTRES |
| --------------: | ------: |
|            0.20 |   0.286 |
|            0.30 |   0.429 |
|            0.40 |   0.571 |
|            0.50 |   0.714 |
|            0.60 |   0.857 |
|           ≥0.70 |   1.000 |

这正是中氮—高氮几乎没有差异的一个直接原因：

> 只要中氮处理的日氮供需比达到0.70，`NSTRES` 就与高氮完全相同。

---

## 5. 低氮还会触发第二个生长限制

`NSTRES` 并不是低氮影响生长的唯一途径。

在 `VEGGR.for` 中，模型还计算新生叶、茎和根所允许的最低氮需求：

[
NGRVGG=NGRLFG+NGRSTG+NGRRTG
]

其中：

[
FNINLG=PROLFG\times0.16
]

[
FNINSG=PROSTG\times0.16
]

[
FNINRG=PRORTG\times0.16
]

如果当天真正可用于营养生长的氮 `NAVL` 小于这个最低需求：

[
NAVL<NGRVGG
]

则叶、茎、根生长全部乘以：

[
NRATIO=\frac{NAVL}{NGRVGG}
]

因此，在低氮处理下，模型不仅产生较低的 `NSTRES`，还可能直接按最低组织氮需求缩减叶、茎和根生长。

如果你沿用Tomato的 `PROLFG、PROSTG、PRORTG`，而茄子实际上能够在更低组织氮浓度下继续生长，就会造成低氮产量被严重低估。

---

## 6. 叶片氮还会直接降低光合作用

模型计算真实叶片氮浓度：

[
RNITP=
100\frac{WTNLF}{WTLF-WCRLF}
]

随后在光合作用模块中：

[
AGEMXL=
\frac{CURV(FNPGN,RNITP)}
{CURV(FNPGN,LNREF)}
]

并直接进入：

[
LFMAX\propto AGEMXL
]

同时量子效率也随 `AGEMXL` 下降。

Tomato默认：

* `FNPGN=[2.0,4.5,20,20]`
* `TYPPGN=QDR`
* `LNREF=4.5`

其低氮区近似为：

[
AGEMXL=
1-\left(\frac{4.5-RNITP}{2.5}\right)^2
\qquad 2<RNITP<4.5
]

对应：

| 叶片N浓度 | 光合氮因子AGEMXL |
| ----: | ----------: |
|  2.0% |        0.00 |
|  2.5% |        0.36 |
|  3.0% |        0.64 |
|  3.5% |        0.84 |
|  4.0% |        0.96 |
| ≥4.5% |        1.00 |

这条曲线的低氮惩罚很强，而一旦达到4.5%叶片N，继续增加氮完全不提高该光合因子。

---

# 二、为什么100 kg N/ha会产生突变

施氮量与作物氮胁迫之间不是线性关系。模型实际经历的是：

[
施肥量
\rightarrow 土壤NO_3/NH_4
\rightarrow 根系潜在吸收
\rightarrow 当日需求封顶
\rightarrow SUPPN/NDMNEW
\rightarrow NSTRES
\rightarrow 叶面积、光合和果实生长
]

如果低氮处理的供需比约为0.3～0.5，而增加100 kg N/ha后变为0.7以上，那么：

* 低氮：`NSTRES`约0.4～0.7；
* 中氮：`NSTRES=1`；
* 高氮：仍为1。

而低氮还可能同时出现：

* 叶片氮低于FNPGN的陡峭响应区；
* `NAVL<NGRVGG`，营养生长直接缩减；
* LAI下降；
* 根系生长和后续吸氮下降；
* 果实库建立减少。

这些过程形成正反馈，所以最终产量差异远大于当天氮供应差异。

# 五、最有效的参数调整方向

## 方案一：先拓宽“允许的组织氮浓度范围”

这是在不修改代码的情况下，最可能同时缓解两个问题的方案。

你的目标是：

* 低氮时，植株能够在较低组织氮浓度下继续维持一定生长；
* 高氮时，模型仍允许植株形成更高的氮需求和吸氮量。

这要求将“最低生长氮浓度”和“最高或目标氮浓度”分开调整。

### 1. 低氮端：检查并可能降低G类蛋白参数

重点参数：

* `PROLFG`；
* `PROSTG`；
* `PRORTG`；
* 必要时 `PROSHG`。

这些参数定义低氮条件下新生组织维持生长所需的最低氮浓度。若其值过高，低氮处理会频繁触发：

[
NRATIO=\frac{NAVL}{NGRVGG}
]

造成叶、茎、根同步大幅下降。

调整方向：

* `PROLFG`降低：叶片能够在更低N浓度下生长；
* `PROSTG`降低：茎生长低氮敏感性下降；
* `PRORTG`降低：根生长在低氮下不至于过早停止。

但必须依据低氮处理中实测叶、茎、根氮浓度设置。不能单纯为了提高低氮产量而任意降低。

### 2. 中高氮端：检查I类目标氮参数是否偏低

重点参数：

* `PROLFI`；
* `PROSTI`；
* `PRORTI`；
* `PROSHI`；
* `SDPRO`。

这些参数参与新生组织的潜在氮需求。如果它们过低，中等施氮量很快就能满足全部需求。

可考虑在实测支持下：

* 维持或适当提高I类目标氮浓度；
* 同时降低G类最低生长氮浓度。

这实际上拓宽了模型允许的氮浓度区间：

[
N_{\min}\downarrow
\qquad
N_{\max}\uparrow
]

结果是：

* 低氮端不再过度崩溃；
* 中氮仍可能存在一定氮缺口；
* 高氮可以产生更高吸氮和组织氮浓度；
* 氮响应曲线不再集中在很窄的施氮区间。

这是比单调调整NSTFAC更合理的方向。

---

## 方案二：重新率定FNPGN，而不是直接沿用Tomato

如果实测显示低氮茄子叶片在2.5%～3.5% N时仍具有较高光合能力，那么Tomato曲线过于敏感。

### 当前问题

Tomato曲线从：

* 2.0%叶N时光合因子0；
* 4.5%叶N时光合因子1。

其有效响应区只有2.5个百分点。

### 推荐调整思路

不是把四个FNPGN值整体增大或减小，而是：

* **适当降低FNPGN1**：降低零光合或严重失活阈值；
* **适当提高FNPGN2**：推迟完全无氮限制的饱和点。

即把响应区间拓宽。

示意上可由：

[
[2.0,\ 4.5,\ 20,\ 20]
]

改为更宽的先验范围，例如：

[
FNPGN1=1.3\sim2.0
]

[
FNPGN2=4.5\sim5.5
]

这不是最终推荐值，而是敏感性分析边界。最终应使用实测叶片N浓度—净光合速率关系确定。

这种改变可以同时实现：

* 在很低叶N时，光合作用不至于下降过快；
* 在中等叶N时，光合作用仍未完全饱和；
* 高氮处理仍可能高于中氮处理。

同时应联合检查：

* `LNREF`；
* `NSLOPE`。

因为模型先按 `NSLOPE` 将平均叶N分配到冠层上、下层，再通过FNPGN计算光合。

---

## 方案三：NSTFAC只能作为辅助调整

### 调低NSTFAC

例如从0.70降到0.55：

优点：

* 同一供需比下NSTRES提高；
* 低氮产量会上升。

缺点：

* 当供需比达到0.55后即完全无胁迫；
* 中氮—高氮平台会更严重。

因此不适合单独解决你的问题。

### 调高NSTFAC

例如从0.70提高到0.85：

优点：

* 中氮处理更可能继续受到氮胁迫；
* 中氮—高氮差异可能增加。

缺点：

* 低氮NSTRES进一步降低；
* 低氮产量会更低。

因此也无法单独解决两端问题。

### 建议用途

先完成：

1. 土壤氮供应；
2. 植株氮需求；
3. 组织氮参数；
4. FNPGN；

之后，再在以下范围对NSTFAC做小幅率定：

[
0.60\sim0.85
]

不建议仅根据最终产量率定它。

---

# 六、如果允许修改源码，建议改变NSTRES函数形状

你当前的问题本质上要求一种新的响应形状：

* 低供需比时，惩罚比当前轻；
* 中等供需比时，不要过早达到1；
* 高供需比时，逐步接近1。

现有单阈值线性函数无法同时满足。

## 推荐方法：查表函数

在SPE文件增加：

* `XNSTN(1:n)`：氮供应/需求比；
* `YNSTN(1:n)`：对应氮生长因子。

然后用：

```fortran
RNNEW = MIN(1.0, MAX(0.0, SUPPN / MAX(NDMNEW, 1.E-8)))
XNSTRES = TABEX(YNSTN, XNSTN, RNNEW, NNST)
NSTRES = 0.5 * XNSTRES + 0.5 * PNSTRES
```

可先用以下曲线进行结构测试：

| XNSTN：供应/需求比 | YNSTN：氮因子 |
| -----------: | --------: |
|         0.00 |      0.00 |
|         0.20 |      0.40 |
|         0.40 |      0.65 |
|         0.60 |      0.82 |
|         0.80 |      0.94 |
|         1.00 |      1.00 |

与当前NSTFAC=0.70相比：

* 供需比0.2：当前0.286，新曲线0.40；
* 供需比0.4：当前0.571，新曲线0.65；
* 供需比0.6：当前0.857，新曲线0.82；
* 供需比0.8：当前1.00，新曲线0.94。

这正好实现：

* 减轻严重低氮惩罚；
* 保留中氮到高氮的渐进响应；
* 消除0.70处的突然饱和。

但这些数值只能作为初始测试曲线，最终应使用不同氮处理的植株吸氮、叶N、LAI和生物量进行率定。

---

## 备选：平滑函数

也可采用：

[
f_N(r)=
\frac{r}
{r+K_N(1-r)}
]

其中：

[
r=\min\left(1,\frac{SUPPN}{NDMNEW}\right)
]

例如 (K_N=0.5) 时：

|   r | (f_N(r)) |
| --: | -------: |
| 0.2 |    0.333 |
| 0.4 |    0.571 |
| 0.6 |    0.750 |
| 0.8 |    0.889 |
| 1.0 |    1.000 |

该函数不会在0.70处突然变为1。

不过查表函数更方便：

* 与DSSAT现有参数体系一致；
* 容易施加单调约束；
* 可以根据茄子试验数据直接率定；
* 不必假定固定数学形状。

---

# 七、吸氮函数需要修改吗

## 1. 不要首先调整RTNO3和RTNH4

提高 `RTNO3/RTNH4` 会提高根系单位长度吸收能力，但有两个限制：

1. 中氮和高氮如果已经被需求封顶，提高RT参数不会产生差异；
2. 提高吸收能力可能进一步加速中氮达到完全无胁迫。

只有出现以下情况才调整：

> 低氮或中氮土壤中仍有明显可利用NO₃⁻/NH₄⁺，但模拟植株吸氮显著低于实测。

这时应联合检查：

* RLV；
* RTDEPI；
* XRTFAC/YRTFAC；
* RTNO3；
* RTNH4；
* 土壤水分SMDFR。

## 2. 现有浓度响应函数本身可能过窄

当前：

[
F_N=1-\exp(-0.08C)
]

只有一个形状参数，无法同时做到：

* 提高低浓度下的吸收；
* 延缓中高浓度下的饱和。

若试验明确显示低氮下根系仍具有较高吸收效率，而高氮下吸收能力仍继续增加，可考虑改为两参数函数：

[
F_N=
F_{\min}+
(1-F_{\min})
\frac{C}{K_m+C}
]

其中：

* `Fmin`：低浓度下的基础吸收能力；
* `Km`：达到半饱和响应的矿质氮浓度。

这比单纯修改0.08更有能力拓宽响应区间。但只有在土壤矿质氮和植株吸氮动态数据支持时才建议修改。

---

# 八、建议实施的具体试验矩阵

## 第一步：构建细施氮梯度

不要只比较间隔100 kg N/ha的几个水平。保持其他管理不变，运行：

[
0,\ 25,\ 50,\ 75,\ 100,\ 125,\ldots,300
\quad kg\ N\ ha^{-1}
]

对每个水平提取：

* 产量；
* 果实干重；
* 最大LAI；
* 总生物量；
* 累计植株吸氮；
* 收获期土壤残留氮；
* 生育期平均NSTRES；
* `NSTRES<0.9`的天数；
* `Rnew≥NSTFAC`的天数；
* 平均RNITP；
* 平均AGEMXL。

这样能够准确确定模型的“跳变点”位于哪个施氮区间。

---

## 第二步：运行五组机制敏感性试验

### 试验A：NSTFAC

[
0.55,\ 0.65,\ 0.70,\ 0.80,\ 0.90
]

目的：确认产量跳变是否主要来自NSTFAC阈值。

### 试验B：最低生长氮浓度

对以下参数同步乘以：

[
0.75,\ 0.85,\ 1.00,\ 1.15
]

参数：

* PROLFG；
* PROSTG；
* PRORTG。

目的：判断低氮产量过低是否由最低组织N要求过高导致。

### 试验C：最大或目标氮浓度

对以下参数乘以：

[
0.90,\ 1.00,\ 1.10,\ 1.20
]

参数：

* PROLFI；
* PROSTI；
* PRORTI；
* 必要时PROSHI。

目的：判断中氮和高氮相同是否由于NDMTOT过低。

### 试验D：FNPGN响应范围

设置若干组合：

| 方案       | FNPGN1 | FNPGN2 |
| -------- | -----: | -----: |
| Tomato原值 |    2.0 |    4.5 |
| 扩宽1      |    1.7 |    5.0 |
| 扩宽2      |    1.5 |    5.0 |
| 扩宽3      |    1.5 |    5.5 |

目的：判断低氮光合惩罚和中高氮平台是否来自叶N—光合函数。

### 试验E：吸氮能力

分别改变：

* RTNO3；
* RTNH4；
* 根长密度或根系分布尺度。

范围建议先为：

[
0.75,\ 1.00,\ 1.25
]

目的：判断低氮是否主要受到吸收动力学限制。

# 九、推荐的实际调整顺序

## 阶段1：先固定土壤氮供应

使用：

* 播前或移栽前分层NO₃⁻、NH₄⁺；
* 生育期分层矿质氮；
* 施肥时间、肥料形态和施肥深度；
* 土壤有机碳、全氮；
* 灌溉及淋失资料。

先保证低、中、高氮处理的土壤氮动态合理。

特别注意：

* FileX初始NO₃⁻和NH₄⁺不是直接按kg N/ha输入，而是按土壤质量浓度处理；
* 肥料施用量通常按kg N/ha；
* 不要把硝酸盐质量或肥料产品质量误当作纯N质量。

---

## 阶段2：率定植株氮需求

使用实测：

* 叶N浓度；
* 茎N浓度；
* 根N浓度；
* 果实N浓度；
* 各器官生物量；
* 累计植株吸氮。

重点率定或赋值：

* PROLFI、PROLFG、PROLFF；
* PROSTI、PROSTG、PROSTF；
* PRORTI、PRORTG、PRORTF；
* PROSHI、PROSHG、PROSHF；
* SDPRO；
* NRCVR。

这一阶段的主要目标不是产量，而是：

[
模拟器官N浓度\approx实测器官N浓度
]

[
模拟植株总吸氮\approx实测总吸氮
]

---

## 阶段3：率定叶氮对光合作用的影响

使用：

* 叶片N浓度；
* SPAD或叶绿素；
* 净光合速率；
* LAI；
* 地上部生物量。

重点参数：

* FNPGN1；
* FNPGN2；
* LNREF；
* NSLOPE。

先拟合叶N—光合关系，再拟合产量。

---

## 阶段4：最后处理NSTRES形状

如果前面三步完成后仍出现明显台阶：

* 不再依赖单一NSTFAC；
* 改为XNSTN–YNSTN查表；
* 用低、中、高氮处理的生物量增量和LAI增量率定曲线；
* 不要只用最终鲜产量率定。

---

# 十、最推荐的解决组合

根据你描述的症状，我建议优先测试以下组合，而不是单独修改NSTFAC：

### 不修改源码的优先方案

1. 核验中氮和高氮是否都被 `NDMTOT` 封顶；
2. 根据实测器官N，适当提高I类目标氮参数；
3. 根据低氮器官N和生长数据，适当降低G类最低生长氮参数；
4. 将FNPGN低氮端向左移、完全饱和点向右移；
5. NSTFAC保持0.65～0.80范围内小幅率定；
6. 最后检查RTNO3、RTNH4和根系参数。

### 允许修改源码的优先方案

1. 完成土壤氮和器官氮参数率定；
2. 将单阈值NSTFAC函数替换为XNSTN–YNSTN查表；
3. 保留SUPPN/NDMNEW作为自变量；
4. 使曲线在低氮区高于原函数，在0.6～0.9区低于原函数；
5. 用植株吸氮、叶N、LAI、生物量和产量联合率定。

---

# 十一、不建议采用的方法

不要直接采取以下操作：

* 只降低NSTFAC来抬高低氮产量；
* 只提高NSTFAC来增加中高氮差异；
* 只提高RTNO3或RTNH4；
* 只根据最终产量调整器官蛋白浓度；
* 用高氮产量调整LFMAX；
* 在没有器官N数据时同时率定NSTFAC、FNPGN、PROLFG和RTNO3；
* 通过改变施肥日期或分次比例拟合数据，除非田间实际管理确实如此。

这些做法容易得到正确产量，但错误的植株吸氮、叶N浓度和土壤残留氮。

---

## 最终结论

你的问题很可能是四个过程叠加造成的：

1. `NSTFAC=0.70`造成明确的饱和阈值；
2. `FNO3/FNH4`随土壤矿质氮快速饱和；
3. 实际吸氮量被 `NDMTOT` 封顶；
4. Tomato的最低组织氮和FNPGN曲线可能对Eggplant低氮过于严格。

最有效的解决方向不是简单改变氮敏感性，而是：

> **降低低氮条件下维持生长所需的最低组织氮浓度，提高或校正中高氮条件下的潜在氮需求，拓宽叶N—光合响应范围，并将当前单阈值NSTRES函数改成渐进查表函数。**

其中第一步应检查中、高氮处理的 `TRNU` 是否都等于 `NDMTOT`。如果是，问题首先在“氮需求上限”，而不是土壤供氮或NSTFAC。
