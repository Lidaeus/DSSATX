# 番茄 ECO 参数解析 (一)：发育与物候参数详细定义

本报告详细解析了 `TMGRO048.ECO` 中控制番茄生长发育阶段及物候响应的关键参数。这些参数主要在 `IPPHENOL.for` (通过 `PHENOL` 模块调用) 中读入，并直接影响 `PHTHRS` 数组的构建。

## 1. 基础发育阶段参数 (Thermal/Photothermal Days)

这些参数定义了植物从一个发育阶段转换到下一个阶段所需的累积度数（积温或光温时）。

| 参数名称 | 源代码对应 | 定义与作用 |
| :--- | :--- | :--- |
| **PL-EM** | `PHTHRS(1)` | **播种到出苗**。在土壤水分充足的情况下，种子从播种到子叶展开所需的热量单位（积温）。 |
| **EM-V1** | `PHTHRS(2)` | **出苗到第一片真叶**。出苗（V0）到第一片真叶（V1）完全展开所需的热量单位。 |
| **V1-JU** | `PHTHRS(3)` | **第一片真叶到幼年期结束**。决定了植物对光周期产生敏感性之前的最短营养生长阶段。 |
| **JU-R0** | `PHTHRS(4)` | **花芽诱导期**。在最适温度和光照条件下，完成诱导所需的最小光温积。 |
| **R7-R8** | `PHTHRS(11)` | **生理成熟到收获成熟**。定义了果实达到生理成熟后，到可以进行田间采收（干缩或商用成熟）的时间间隔。 |

> [!NOTE]
> 在番茄模型中，**开花时间 (`PHTHRS(6)`)** 通常由品种文件 (`.CUL`) 中的 `PH2T5` (幼年期结束到开花) 间接决定。`IPPHENOL` 会计算：
> `PHTHRS(5) = MAX(0., PH2T5 - PHTHRS(3) - PHTHRS(4))`

---

## 2. 发育修正与时序比例参数

这些参数不直接代表积温，而是作为比例因子或修正量来微调发育关键点。

### PM06 (Proportion to First Pod)
- **作用**：定义了从**第一朵花 (R1)** 到**第一个果实 (R2)** 出现的时间占比。
- **公式**：`PHTHRS(7) = PHTHRS(6) + MAX(0., (PHTHRS(8) - PHTHRS(6)) * PM06)`
- **逻辑**：它将 `PHTHRS(6)` (开花) 和 `PHTHRS(8)` (第一颗种子) 之间的时间分配给果实（角果/荚/浆果）的形成。

### PM09 (Proportion to End Pod Set)
- **作用**：定义了**最后果实形成**（停止座果）的时间点相对于生理成熟的比例。
- **公式**：`PHTHRS(9) = MAX(0., PHTHRS(10) * PM09)`
- **逻辑**：番茄是无限生长型，该参数控制了模型停止分配资源给新果实的时机，以确保现有果实能达到成熟。

### FL-VS (Flowering to Last Node)
- **源代码对应**：`PHTHRS(12)`
- **定义**：从开花到主茎出现最后一片叶片的光温积。
- **重要性**：对于番茄这类趋于无限生长的作物，该参数设定了一个理论上的营养生长终点，防止模拟中叶片无限增加。

## 3. 光周期与环境敏感性

### THVAR (Minimum Development Rate)
- **定义**：在长日照（非最优光周期）和最适温度下，生殖发育的最小相对速率。
- **逻辑**：用于计算临界日长 `CLDVAR`。如果 `THVAR` 为 1.0，表示作物品种对光周期不敏感。

### R1PPO (Daylength Sensitivity Change after R1)
- **作用**：开花后光周期敏感性的改变值（小时）。
- **逻辑**：在开花后，临界日长 `CSDVAR` 和 `CLDVAR` 会同时加上该修正量，反映作物在进入生殖生长阶段后对光周期反应强度的变化。

### OPTBI & SLOBI (Temperature Inhibition)
- **OPTBI**：发育不受低温抑制的最低日温度 (°C)。
- **SLOBI**：当最低气温低于 `OPTBI` 时，发育速率下降的斜率。
- **适用阶段**：主要影响从出苗到开花的发育进度。

---

## 4. 营养生长速率控制

### TRIFL (Rate of Leaf Appearance)
- **源代码变量**：`TRIFOL`
- **定义**：每热量单位（degree day）主茎上出现的连带叶片数（V 阶段形成速率）。
- **影响**：直接控制 `VSTAGE` 的累积，进而影响冠层扩展、截获的光合产物总量以及节点的资源竞争。

---

> [!TIP]
> **校准建议**：
> 在番茄生产中，如果模拟的始花期准确但始采收期（R2/R5阶段）偏晚，应优先检查 `PM06`；如果模拟的后期叶面积指数（LAI）过高，应调整 `FL-VS` 或 `TRIFL`。
