# 番茄 SPE 参数解析 (二)：组分构成与呼吸作用机制

本报告解析了 `TMGRO048.SPE` 中定义的植物构建基础组件及其代谢消耗。这部分参数决定了番茄干物质如何转化为具有生理功能的器官（如蛋白质、脂类、木质部等）。

## 1. 组建呼吸 (Synthesis Respiration)

组建呼吸是指将碳水化合物（CH2O）转化为各种生化组分所需的代谢成本倍数。这些参数在 `IPPLNT.for` 中读入。

| 组分类型 | 参数名 | 值 (g[CH2O]/g) | 说明 |
| :--- | :--- | :--- | :--- |
| **碳水化合物结构** | `RCH2O` | 1.242 | 合成结构性碳水化合物基本框架。 |
| **脂类** | `RLIP` | 3.106 | 合成膜脂和储藏脂。成本极高，体现了脂类的高能量密度。 |
| **木质素** | `RLIG` | 2.174 | 用于加固细胞壁。番茄作为草本，木质化程度适中。 |
| **有机酸** | `ROA` | 0.929 | 合成常见的苹果酸、柠檬酸等（果实风味核心）。 |
| **矿物质** | `RMIN` | 0.050 | 矿物元素吸收与转运的代谢成本。 |

---

## 2. 氮素同化与蛋白质合成

由于氮是番茄光合作用和果实品质的驱动力，模型细化了不同氮源的同化成本。

| 过程 | 参数名 | 值 | 逻辑解析 |
| :--- | :--- | :--- | :--- |
| **硝态氮还原** | `RNO3C` | 2.556 | 将 NO3- 还原并合成蛋白质。成本最高。 |
| **铵态氮同化** | `RNH4C` | 2.478 | 直接利用 NH4+ 的成本。略低于 `RNO3C`。 |
| **蛋白质再利用** | `RPRO` | 0.280 | 从衰老组织动员的 N 再合成蛋白质的成本（较低）。 |

---

## 3. 维持呼吸 (Maintenance Respiration)

维持呼吸保证了活细胞在不生长时也能生存（更新蛋白质、维持离子梯度）。

| 参数名 | 典型值 | 功能 |
| :--- | :--- | :--- |
| **RES30C** | 3.2E-04 | **基础维持效率**。在 30°C 下，每克总干重每小时消耗的 CH2O 量。 |
| **R30C2** | 0.0028 | **光合关联维持**。与每日日光合总量相关的额外维持成本。 |

> [!TIP]
> **温度效应**：在 `RESPIR.for` 中，`RES30C` 会根据每日温度修正因子 `TRSFAC` 进行非线性放大。这意味着高温条件下番茄的碳消耗会剧增，可能导致夜温过高时的“净积累骤降”。

---

## 4. 各器官初始组分比例 (Plant Composition)

这些参数（如 `PROLF`, `PLIPLF`, `PCARLF`）通过行映射定义了叶（LF）、茎（ST）、根（RT）、壳（SH）、种（SD）的生理基础。

| 组分 (L-叶/S-壳) | 蛋白质 (PRO) | 碳水 (PCAR) | 脂类 (PLIP) | 木质素 (PLIG) |
| :--- | :--- | :--- | :--- | :--- |
| **番茄叶 (Initial)** | 0.270 | 0.491 | 0.025 | 0.070 |
| **番茄果壳 (Initial)** | 0.210 | 0.490 | 0.020 | 0.050 |

### 逻辑解析：为什么这样取值？
- **高蛋白质 (`PROLFI=0.27`)**: 番茄叶片为了匹配极高的光合能力 (`PGREF`)，必须含有高比例的 Rubisco 酶（蛋白质）。
- **果实的高碳水比例**: 果肉（壳部分）的 `PCARSH` (0.49) 反映了番茄作为浆果以糖分积累为主的生理特征。

---

## 5. 碳/氮动员潜力 (Mining Parameters)

这些参数定义了植物在逆境或果实膨大期，可以从老叶、老茎中“借用”多少资源。
- **CMOBMX (0.022)**: 每日最大碳动员比例。
- **NMOBMX (0.090)**: 每日最大氮动员比例。
- **NRCVR (0.150)**: 动员过程中的不可回收损失率。

> [!IMPORTANT]
> **番茄的“早衰”风险**：如果 `NMOBMX` 设置过高，模型中番茄老叶的氮会迅速流向果实，导致 LAI 崩塌（早衰）。TM048 的设定平衡了果实需求与冠层维持。
