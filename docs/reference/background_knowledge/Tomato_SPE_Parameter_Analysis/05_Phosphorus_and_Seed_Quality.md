# 番茄 SPE 参数解析 (五)：磷素模拟与种子品质

本报告解析了 `TMGRO048.SPE` 中定义的磷（P）素营养临界值及其对生长的影响，以及种子内营养组分（脂类、碳水）合成的温度响应参数。

## 1. 磷 (P) 素需求阈值

CROPGRO 模型的 P 模块模拟了不同发育阶段器官内 P 浓度的盈亏。定义了“最适（Optimum）”和“最小（Minimum）”两个梯度，跨越出苗 (EM)、首花 (FF) 和全实 (FS) 三个关键期。

| 器官类型 | 最佳浓度范围 (OPT...P) | 最小浓度范围 (MIN...P) | 逻辑解析 |
| :--- | :--- | :--- | :--- |
| **叶片 (Leaf)** | 0.0038 - 0.0022 | 0.0027 - 0.017 | P 需求最高，用于支持高效的能量转化（ATP/NADPH）。 |
| **茎秆 (Stem)** | 0.0028 - 0.0019 | 0.0017 - 0.010 | 较低。主要在成熟过程中因木质化和纤维化而被稀释。 |
| **种子 (Seed)** | 0.0040 - 0.0044 | 0.0033 - 0.033 | **最高值**。番茄种子需要储备充足的磷以保证下一代的发芽势。 |

---

## 2. 磷素响应与动员逻辑

| 参数名称 | 值 | 功能说明 |
| :--- | :--- | :--- |
| **SRATPHOTO** | 0.63 | **P 亏缺对光合的敏感因子**。当叶片 P 降至临界值以下时，光合速率受抑程度。0.63 表明中等偏高的敏感性。 |
| **SRATPART** | 0.83 | **P 亏缺对干物质分配的影响**。亏磷会将更多产物分配向根系以寻求更多养分（避逆反应）。 |
| **FracPMobil** | 0.20 | **最大日动员比例**。由于 P 在植物体内移动性极强，番茄老叶的 20% 磷素可每日动员给果实。 |

---

## 3. 种子品质与生化合成温度

这部分参数通过定义种子内脂类和碳水化合物合成对温度的响应，间接模拟了番茄种子的千粒重和活力积累。

### 3.1 脂类合成 (LIP...)
- **LIPTB (7.168)**: 脂类合成的基点温度。低于此温度种子脂质停止积累。
- **LIPOPT (23.65)**: 最适温度。在此温度下脂类合成速率最快。

### 3.2 碳水化合物
- **CARMIN (0.180)**: 种子中碳水化合物占据的最小比例（即使在极端环境下也会存留的基准糖分）。

## 4. 环境保护与土壤 P 提取

| 参数名称 | 值 | 逻辑解析 |
| :--- | :--- | :--- |
| **ROOTRAD** | 0.0025 | **根际提取半径** (m)。定义了单根能够从周围多远的土壤圆柱体中提取 P 元素。番茄微细根系发达，此值属于标准范畴。 |

---

## 总结：番茄 SPE 设计的全局视野
1. **高磷需求逻辑**：番茄作为园艺作物，对其生产效率的追求反映在了极高的叶片和种子 `OPTP` 设定上。
2. **敏感的反馈机制**：通过 `SRATPHOTO` (0.63)，模型能灵敏捕捉到磷肥不足导致的“僵苗”现象。
3. **精准的生化时序**：通过 `LIPOPT` 等参数，将果实品质（种子饱满度）与气候（温度）深度耦合，支持了对不同产地风味多样性的底层解释。
