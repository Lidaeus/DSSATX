# 番茄 SPE 参数解析 (四)：冠层几何与水分利用

本报告解析了 `TMGRO048.SPE` 中定义主茎发育与植株几何形状映射关系的模板参数，以及蒸散发（ET）计算中的作物特征参数。

## 1. 冠层形状模板 (XVSHT, YVSHT, YVSWH)

这些参数构成了番茄生长的“形态骨架”。在 `CANOPY.for` 中，它们作为 `TABEX` 的查询源，定义了每增加一个 V 阶段（节点），植株高度和宽度的理论增量。

| V 节点数 (XVSHT) | 节间长度增量 (YVSHT, m) | 冠层宽度增量 (YVSWH, m) | 形态意义 |
| :--- | :--- | :--- | :--- |
| **0.0 - 6.12** | 0.025 | 0.025 - 0.035 | **苗期**。生长紧凑，高度和宽度按 1:1 左右比例协调增加。 |
| **14.6 - 17.2** | 0.076 | 0.059 | **旺长期**。节间显著拉长，高度增加速度快于宽度，形成直立的冠层结构。 |
| **23.2 - 43.0** | 0.048 - 0.015 | 0.022 - 0.010 | **后期**。生长速度极剧放缓，接近封顶或受生殖负载抑制。 |

---

## 2. 形态扩展的环境修正

即使有了上述模板，实际每日的高度/宽度增加仍受温度和光照的实时修正。

### 2.1 温度修正 (XHWTEM / YHWTEM)
- **26.0°C**：效应因子为 1.00（最佳温）。
- **11.0°C**：效应因子降至 0.40。低温会显著抑制番茄的细胞伸长，使植株变矮、变厚。

### 2.2 光照修正 (XHWPAR / YHWPAR)
- **光照越弱，节间越长**：这是一个模拟“避荫反应（Shade Avoidance）”的逻辑。
- 在 low PAR (5.0) 时，效应倍数为 2.0；在 high PAR (20.0+) 时，倍数降至标准位 1.0。这解释了温室番茄在连阴天会出现徒长（Leggy）的现象。

## 3. 水分利用与蒸散发参数

这些参数在 `IPPLNT.for` 中读取，用于 `SPAM` 或 `WATBAL` 模块计算水分亏缺。

| 参数名称 | 典型值 | 功能与逻辑 |
| :--- | :--- | :--- |
| **KEP** | 0.70 | **潜在蒸腾系数** (Energy partitioning for soil vs plant)。用于将总能量分配给土壤蒸发和植株蒸腾。 |
| **EORATIO** | 1.00 | **冠层阻力调节比**。用于平衡空气潜热平衡。 |

### ASCE 双作物系数标准 (SSKC & TSKC)
番茄 SPE 中包含了基于 ASCE 标准的作物系数。
- **SSKC (0.50 - 1.10)**: 针对短草（12cm）参考蒸散发的修正系数。1.10 代表番茄全覆盖期的水分需求高于参考短草。
- **TSKC (0.50 - 0.92)**: 针对高草（50cm 苜蓿）参考蒸散发的修正系数。

## 4. 根系发育基准

| 参数名称 | 值 | 逻辑解析 |
| :--- | :--- | :--- |
| **RTDEPI** | 10.0 | **初始根深** (cm)。出苗时的基础深度。 |
| **RWUMX** | 0.04 | **最大单层根系吸水率** (cm3 water / cm3 soil / day)。限制了番茄根系从单层土壤中吸水的最大能力。 |
| **PORMIN** | 0.02 | **组织气体扩散所需最小孔隙度**。这反映了番茄对土壤通气性的敏感性（忌积水）。 |

---

## 总结：番茄冠层设计的巧思
1. **非线性的节间生长**：YVSHT 的 0.025 到 0.076 的起伏，完美捕捉了番茄“后期发力”的伸长逻辑。
2. **光温协同**：通过 YHWTEM 和 YHWPAR，模型不需要复杂的生理方程就能模拟出徒长和僵苗两种极端的形态表型。
3. **水分冗余设计**：ASCE 系数的设定确保了在全覆盖期，模型能反映番茄叶片高强度蒸腾带来的水分高需求。
