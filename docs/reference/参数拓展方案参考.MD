# CROPGRO-Eggplant 候选参数扩充实施方案

## 一、扩充原则

建议不要简单地把更多参数全部放进同一次率定，而是建立三个层次：

* **结构必备参数**：决定茄子模型能否正确描述连续开花、果实形成、多次采收和鲜重，应立即补入候选参数表。
* **敏感性筛选参数**：可能影响结果，但只有在相应观测或处理条件下才具有可识别性。
* **实测或先验固定参数**：虽然属于茄子物种参数，但不宜用最终产量反演，应通过器官分析、果实测定或文献确定。

建议将现有参数模块调整为以下十一个模块：

1. 物候与发育温度响应；
2. 叶片发生与叶面积扩展；
3. 冠层结构、光合作用与辐射截获；
4. 叶片衰老；
5. 营养器官干物质分配；
6. 开花、坐果与果实数量形成；
7. 果实干物质增长与库强；
8. 果实鲜重换算与多次采收；
9. 根系生长与水氮吸收；
10. 水分胁迫；
11. 氮素需求、再转运及碳储备动员。

其中，第4、第6和第8模块是当前候选参数体系中最需要补齐的部分。

# 二、第一批：应立即补入候选参数集的参数

这些参数建议直接列入表2或补充表S1。是否最终进入优化，可在敏感性分析后决定。

## 2.1 物候与持续营养生长

| 新增参数   | 文件层级 | 建议状态    | 主要作用                 | 加入原因                              | 主要观测           |
| ------ | ---- | ------- | -------------------- | --------------------------------- | -------------- |
| LNGSH  | ECO  | 优先活动    | 单个果实外部组织的潜在生长持续时间    | 茄子商品器官主要是果肉和果皮，比SFDUR更直接控制果实干物质增长 | 开花至采收时间、单果干重动态 |
| XMPAGE | SPE  | 敏感性分析   | 果实队列继续增厚和种子生长的最大生理年龄 | 防止果实队列无限增长，并与XMAGE区分              | 老果干重、延迟采收处理    |
| XMAGE  | ECO  | 已有，重新定位 | 达到可采收状态所需的果实光温年龄     | 应与LNGSH、XMPAGE和SD-PM分别率定          | 各队列开花日期、采收日期   |

Tomato 的 CUL 文件本身包含 ，ECO 文件包含 FL-VS、LNGSH 和 XMAGE；Strawberry 的 ECO 文件进一步加入了 XFPHT 和 XFINT。

### 实施注意

应建立以下时间顺序约束：

[
FL!-!SH < FL!-!SD
]

[
LNGSH \leq XMPAGE
]

对于商品成熟早于生理成熟的茄子，通常还应满足：

[
XMAGE \leq XMPAGE
]

但最终约束需要根据你实际修改后的程序判据确认。

不要用 SD-PM 替代 XMAGE。SD-PM 描述种子形成至生理成熟的作物发育阶段，而 XMAGE 是果实队列的商品采收年龄。

## 2.2 叶片发生与潜在叶面积轨迹

| 新增参数组         | 文件层级 | 建议状态       | 主要作用                | 加入原因                          |
| ------------- | ---- | ---------- | ------------------- | ----------------------------- |
| XVGROW–YVREF  | SPE  | 优先活动，降维后使用 | 定义不同V-stage下潜在叶面积   | 仅调整SIZLF和VSSINK不足以改变叶面积增长曲线形状 |
| XLEAF–YLEAF   | SPE  | 优先活动，降维后使用 | 不同发育阶段营养生长中分配给叶片的比例 | 决定叶、茎、根竞争关系                   |
| XLEAF–YSTEM   | SPE  | 优先活动，降维后使用 | 不同发育阶段分配给茎的比例       | 茄子茎秆和分枝生物量通常不同于番茄             |
| FRLFMX        | SPE  | 敏感性分析      | 叶片分配比例上限            | 防止叶片分配曲线出现不合理峰值               |
| SLAMAX、SLAMIN | SPE  | 条件活动       | 新叶SLA的上下限           | 多水氮和季节处理下仅用SLAVR难以描述SLA变化     |
| SLAPAR        | SPE  | 条件活动       | 辐射对SLA的影响           | 温室、露地或季节辐射差异较大时需要             |
| TURSLA        | SPE  | 水分试验活动     | 水分或膨压胁迫对SLA的影响      | 用于区分叶片面积下降来自分配变化还是叶片变厚        |
| NSLA          | SPE  | 氮试验活动      | 氮胁迫对SLA的影响          | 氮肥梯度下影响叶面积形成                  |
| XSLATM–YSLATM | SPE  | 多季节条件活动    | 温度对SLA的影响           | 低温或高温季节下叶片厚度可能发生系统变化          |

源码中先利用 `SLAVR/SLAREF` 缩放SLA，再利用 `SIZLF/SIZREF` 缩放 YVREF；XLEAF、YLEAF、YSTEM 则决定叶、茎分配，根分配为剩余比例。

### 不建议直接率定全部数组节点

建议将 XVGROW–YVREF 简化为三个尺度参数：

* `LAREA_EARLY`：早期叶面积尺度；
* `LAREA_MID`：开花前后叶面积尺度；
* `LAREA_LATE`：持续营养生长期叶面积尺度。

中间节点通过线性插值生成。

XLEAF–YLEAF–YSTEM 同样建议只释放以下锚点：

* 营养早期叶分配；
* 开花期叶分配；
* 生殖后期叶分配；
* 营养早期茎分配；
* 生殖后期茎分配。

其余节点保持平滑插值，并强制：

[
0\leq YLEAF_i\leq1
]

[
0\leq YSTEM_i\leq1
]

[
YLEAF_i+YSTEM_i\leq1
]

这样才能保证根分配比例非负。

## 2.3 叶片衰老模块

建议在现有“冠层结构与叶面积扩展”之外，单独增加“叶片衰老”模块。

| 新增参数          | 文件层级 | 第一轮处理       | 主要作用        | 主要约束数据        |
| ------------- | ---- | ----------- | ----------- | ------------- |
| SENRTE        | SPE  | 优先活动        | 基础衰老速率      | 绿叶面积和衰老叶面积    |
| SENDAY        | SPE  | 优先活动        | 叶龄驱动的衰老     | 叶片寿命、不同叶位黄化日期 |
| SENRT2        | SPE  | 第二轮敏感性分析    | 补充衰老速率项     | 后期LAI下降       |
| XSTAGE–SENPOR | SPE  | 只释放1–2个后期锚点 | 不同阶段的衰老比例   | 开花后和采收期LAI    |
| XSENMX–SENMAX | SPE  | 条件活动        | 衰老强度上限      | 严重胁迫或生育后期     |
| ICMP、TCMP     | SPE  | 高密度或弱光条件活动  | 冠层弱光引起的叶片衰老 | 下层叶黄化、冠层透光率   |

Tomato SPE 已包含完整的基础衰老、叶龄衰老、阶段响应和弱光竞争衰老参数。

### 推荐第一轮活动参数

第一轮只加入：

* SENRTE；
* SENDAY；
* 一个生殖后期 SENPOR 锚点。

若模型仍无法描述后期绿叶面积，再增加 ICMP 或 SENMAX。不要一开始释放整套衰老曲线。

### 为什么必须加入

连续采收茄子的后期产量不仅由 XFRT 控制，还取决于采收后是否仍保有足够绿叶面积。若没有率定衰老过程，模型可能通过以下错误补偿拟合产量：

* 降低LFMAX来补偿LAI过高；
* 提高XFRT来补偿后期叶片过早衰老；
* 延长FL-LF来补偿衰老过快。

因此叶片扩展和叶片衰老必须分开约束。

# 三、第二批：果数形成和单果增长参数

建议将目前的“器官分配与果实库强”拆成两个独立模块：

* 开花、坐果与果实数量形成；
* 果实干物质增长和单果库强。

这样可以避免用一个 XFRT 同时补偿果数和单果重量。

---

## 3.1 开花、坐果与果实数量形成

| 新增参数        | 文件层级 | 建议状态    | 主要作用                   | 为什么需要              |
| ----------- | ---- | ------- | ---------------------- | ------------------ |
| SETMAX      | SPE  | 优先敏感性分析 | 当供应低于需求时果实队列的最大保留比例    | 决定低同化物条件下能坐住多少果    |
| RFLWAB      | SPE  | 优先敏感性分析 | 花败育速率，并与不适宜环境和水分状态共同作用 | 用于区分花形成与坐果失败       |
| FNPDT(1:4)  | SPE  | 优先活动    | 温度对花果添加和坐果的响应曲线        | 茄子坐果温度范围不能直接沿用番茄   |
| TYPPDT      | SPE  | 结构选择    | FNPDT函数类型              | 不作为普通连续参数率定        |
| PODUR       | CUL  | 已有，保留   | 达到最终果实负载所需时间           | 控制果实添加时间尺度         |
| SDPDV       | CUL  | 实测固定为主  | 每果种子数                  | 影响种子需求和果实队列组成      |
| DETACH及脱落曲线 | SPE  | 条件加入    | 果实或果柄脱落                | 仅在观测到明显幼果或商品果脱落时使用 |

源码中 `PODUR` 影响每日潜在果实添加速率；`SETMAX`、供应需求关系、温度因子、水分因子和叶片氮状态共同影响新果实队列的建立。

### FNPDT的率定方式

不建议自由率定四个温度节点和函数类型。建议：

* TYPPDT先固定为QDR或LIN；
* 低温归零点依据文献或控温试验固定；
* 高温归零点依据高温试验或文献固定；
* 只率定最适温度区间的两个节点。

强制约束：

[
T_{min}<T_{opt1}\leq T_{opt2}<T_{max}
]

### 所需观测

至少需要按日期记录：

* 开花数；
* 幼果数；
* 保留果数；
* 采收果数；
* 落花、落果数量；
* 各时期坐果率。

只有分次产量而没有果数时，SETMAX、RFLWAB和FNPDT会与XFRT高度相关，不宜同时完全自由。

## 3.2 果实干物质增长与单果库强

| 新增参数          | 文件层级 | 建议状态       | 主要作用                   |
| ------------- | ---- | ---------- | ---------------------- |
| FNSDT(1:4)    | SPE  | 优先活动       | 温度对果实或种子潜在增长速率的影响      |
| TYPSDT        | SPE  | 结构选择       | FNSDT函数类型              |
| XXFTEM–YXFTEM | SPE  | 多季节优先活动    | 温度对每日生殖分配比例的修正         |
| SHLAG         | SPE  | 有幼果动态时活动   | 幼果早期慢速生长阶段相对于快速生长期的比例  |
| SRMAX         | SPE  | 多光周期环境条件活动 | 生殖生长对光周期的敏感程度          |
| XMPAGE        | SPE  | 优先敏感性分析    | 队列停止继续增长的最大生理年龄        |
| WTPSD         | CUL  | 实测固定为主     | 单粒种子最大干重               |
| SDPDV         | CUL  | 实测固定为主     | 每果种子数                  |
| THRSH         | CUL  | 实测固定为主     | 种子干重占种子和果实外部组织总干重的最大比例 |
| SFDUR         | CUL  | 保留，次要活动    | 种子填充持续期                |
| LNGSH         | ECO  | 优先活动       | 果实外部组织增长持续期            |

在当前源码中，果实外部组织的潜在增长持续到 `PAGE ≤ LNGSH`，种子潜在增长受 FNSDT、SFDUR、WTPSD、SDPDV 和 THRSH 等约束；温度还通过 XXFTEM–YXFTEM 修正生殖分配。

### 参数优先顺序

对于商品茄子，建议按以下顺序处理：

1. LNGSH；
2. SHLAG；
3. FNSDT；
4. XMPAGE；
5. SFDUR；
6. WTPSD、SDPDV和THRSH。

原因是茄子商品果鲜重主要来自果皮和果肉，而不是成熟种子。若有实测种子数据，应直接确定 WTPSD、SDPDV 和 THRSH，不宜依赖产量率定。

# 五、第四批：建议补充但需满足数据条件的参数

## 5.1 光合作用温度响应

你目前已有 LFMAX、PARMAX、PHTMAX、KCAN 和 KC_SLOPE。建议再把以下参数加入候选池，但不必全部进入优化：

| 参数组           | 加入条件            | 作用            |
| ------------- | --------------- | ------------- |
| XLMAXT–YLMAXT | 跨季节或控温试验        | 最大叶片光合速率的温度响应 |
| FNPGT–TYPPGT  | 使用冠层光合路径且参数实际生效 | 冠层光合温度响应      |
| FNPGL–TYPPGL  | 存在低夜温处理         | 前一夜低温对次日光合的影响 |
| PGEFF         | 有光响应曲线          | 量子效率          |
| KDIF、LFANGB   | 有辐射截获或冠层透光资料    | 漫射光消光和叶角分布    |

Tomato SPE 同时包含冠层光合、叶片光合温度响应和低夜温响应参数。

### 实施要求

在正式加入前做一次“实际生效审计”：

* 每个参数增加10%；
* 在无胁迫条件下运行；
* 检查光合速率、日生物量和产量是否变化；
* 没有变化的参数不进入当前模型路径的率定；
* 输出高度相似的参数只保留一个潜在光合尺度参数。

---

## 5.2 冠层高度与冠幅基础曲线

现有候选集中有 RWDTH 和 RHGHT，但这两个参数只是相对于 SPE 基础曲线的比例因子。

建议新增：

* XVSHT–YVSHT；
* XVSHT–YVSWH；
* 必要时 XHWTEM–YHWTEM；
* 必要时 XHWPAR–YHWPAR；
* NHGT。

Tomato 和 Pepper 的基础高度、冠幅曲线有明显差别。

### 推荐实施方式

如果当前只构建一个砧穗组合：

* 根据株高和冠幅动态确定 Eggplant 基础曲线；
* 将RWDTH、RHGHT固定为1。

如果未来要模拟多个品种：

* 固定Eggplant基础曲线；
* 用RWDTH、RHGHT表示品种相对差异。

不要同时自由率定基础曲线和比例因子。

# 六、第五批：水分胁迫参数的扩充

## 6.1 应增加 DSWBAR

| 参数            | 文件层级 | 建议状态       | 作用                  |
| ------------- | ---- | ---------- | ------------------- |
| DSWBAR        | SPE  | 有水分处理时优先活动 | 定义计算SWBAR的表层土壤深度    |
| XFRMAX        | SPE  | 条件活动       | 膨压胁迫对生殖分配比例的附加修正    |
| XTRFAC–YTRFAC | SPE  | 条件活动       | TURFAC对生殖增长和果实添加的修正 |

模型先在0–DSWBAR深度内计算相对可提取水分SWBAR，再通过 XSWBAR–YSWBAR 计算生殖生长限制因子。

因此率定 XSWBAR–YSWBAR 而固定错误的 DSWBAR，会把“水分感知深度错误”误认为“作物耐旱阈值错误”。

## 6.2 水分模块推荐活动参数

第一轮只释放：

* DSWBAR；
* XSWBAR中“恢复至无胁迫”的关键阈值；
* 一个中间YSWBAR响应值；
* XSWFAC中“恢复至无胁迫”的关键阈值。

其余节点固定，且保证：

[
0=X_1<X_2<\cdots<X_n=1
]

[
0\leq Y_i\leq1
]

不要自由率定全部X、Y节点。

## 6.3 进入条件

只有同时具备以下资料时才率定：

* 灌溉梯度；
* 分层土壤含水量；
* 花数或坐果率；
* LAI和生物量；
* 分次产量。

没有水分处理时，这些参数保留在候选数据库中，但不进入活动集。

# 七、第六批：氮素模块的补充

## 7.1 建议增加 LNREF 和 NSLOPE

| 参数     | 作用               | 加入原因                 |
| ------ | ---------------- | -------------------- |
| LNREF  | 参考叶片氮浓度          | FNPGN响应需要相对于参考氮水平归一化 |
| NSLOPE | 冠层内叶氮随LAI深度变化的梯度 | 决定上层和下层叶片光合能力差异      |

源码先根据 RNITP 和 NSLOPE 计算不同冠层层次的叶片氮浓度，再通过 FNPGN 调节最大光合能力。

## 7.2 将“器官蛋白浓度参数”展开记录

不要只在参数表中写“器官蛋白浓度参数”，建议明确列出：

* PROLFI、PROLFG、PROLFF；
* PROSTI、PROSTG、PROSTF；
* PRORTI、PRORTG、PRORTF；
* PROSHI、PROSHG、PROSHF；
* SDPRO。

其中：

* I：组织形成初期或高氮状态；
* G：正常生长状态；
* F：氮再转运后的最低或终末状态。

这些参数决定器官氮需求和可再转运氮库。Tomato和Pepper的器官组成参数并不相同。

## 7.3 推荐处理方式

* 器官蛋白参数：根据实测器官氮浓度换算，尽量固定；
* LNREF、NSLOPE：有叶氮和光合数据时率定；
* NSTFAC：有氮肥梯度时活动；
* FNPGN：有叶氮—光合关系数据时活动；
* NMOBMX、NVSMOB、NRCVR：有器官氮动态时活动。

NMOBMX和NVSMOB控制氮库再转运速率，而不是简单的缺氮敏感性参数。

# 八、根系模块建议增加的参数

建议补入：

| 参数组           | 建议状态           | 作用                |
| ------------- | -------------- | ----------------- |
| XRTFAC–YRTFAC | 优先敏感性分析        | 根系生长或根系形成随发育阶段的变化 |
| PORMIN        | 条件固定或敏感性分析     | 根系生长受土壤通气孔隙限制的阈值  |
| 根系深度分布缩放参数    | 建议自定义或通过SRGF表示 | 描述托鲁巴姆砧木的深层根系优势   |

由于使用托鲁巴姆砧木，根系参数应定义为“砧木—接穗—环境组合的有效参数”，你的原文对此解释是正确的。

### 推荐第一轮根系活动集

只选：

* RTDEPI；
* RWUMX；
* 一个XRTFAC/YRTFAC尺度参数；
* 必要时RTEXF。

RTNO3和RTNH4只有在具备分层土壤NO₃⁻、NH₄⁺及植株吸氮量时才进入活动集。

在根系参数率定前，应先固定或核验：

* LL；
* DUL；
* SAT；
* SRGF；
* 灌溉量和灌溉深度；
* 土壤蒸发参数。

否则根系吸水参数会吸收土壤参数误差。

# 十一、参数加入后的分阶段率定顺序

## 阶段0：源码和参数读取核验

在任何优化之前完成：

1. 建立 Eggplant SPE、ECO、CUL 文件；
2. 确认每个参数由哪个子程序读取；
3. 对每个候选参数实施单参数±10%扰动；
4. 记录受影响的输出变量；
5. 删除不在当前模型路径中生效的参数；
6. 检查 XFPHT、XFINT、XMAGE 和采收事件的运行逻辑；
7. 检查新增Eggplant DMC参数是否被读取；
8. 确认采收前后干物质守恒。

当前源码对 XFPHT 和 XFINT 有明确读取和范围检查，并在 DEMAND 中动态修改 XFRUIT。

---

## 阶段1：直接测定参数赋值

优先通过实测或文献固定：

* WTPSD；
* SDPDV；
* THRSH；
* 器官蛋白浓度；
* 果实DMC参数；
* 最低、最高致死或归零温度；
* 基础冠层高度和宽度曲线；
* 果实脱落比例；
* 根系最大深度的先验边界。

这些参数不应首先通过最终产量优化。

---

## 阶段2：无胁迫条件下的物候率定

活动参数建议不超过8个：

* EM-FL；
* FL-SH；
* FL-SD；
* FL-LF；
* FL-VS；
* LNGSH；
* XMAGE；
* 1–2个温度响应节点。

目标变量：

* 第一花日期；
* 第一坐果日期；
* 第一采收日期；
* 各采收队列开花至采收时间；
* 叶片扩展结束日期；
* 主茎叶片停止出现日期。

---

## 阶段3：冠层、叶面积和总生物量率定

活动参数建议8–12个：

* TRIFL；
* SLAVR；
* SIZLF或YVREF尺度；
* VSSINK；
* FL-LF；
* SENRTE；
* SENDAY；
* LFMAX；
* 一个主要辐射截获参数；
* 株高和冠幅尺度参数。

目标变量：

* 叶数；
* 绿叶面积；
* LAI；
* 株高；
* 冠幅；
* 叶、茎、根干物质；
* 地上部总生物量。

此阶段暂时固定XFRT、XFPHT、XFINT和果数参数，避免果实库强反向补偿冠层错误。

---

## 阶段4：营养器官分配率定

活动参数建议6–8个：

* XLEAF–YLEAF的三个锚点；
* XLEAF–YSTEM的两个锚点；
* FRLFF；
* FRSTMF；
* ATOP；
* 必要时FRLFMX。

目标变量：

* 叶、茎、根干物质比例；
* 开花前后器官增量；
* 各器官生物量时间序列。

---

## 阶段5：果数形成率定

活动参数建议5–8个：

* PODUR；
* SETMAX；
* RFLWAB；
* FNPDT的两个最适温度节点；
* 必要时XSWBAR或XSWFAC关键阈值；
* 必要时果实脱落参数。

目标变量：

* 每日或每周开花数；
* 坐果数；
* 幼果数；
* 落花落果数；
* 分次采收果数；
* 累积果数。

这一阶段尽量不使用鲜重作为主要目标，避免果数和单果重量混淆。

---

## 阶段6：单果干重与生殖分配率定

活动参数建议8–10个：

* XFRT；
* XFPHT；
* XFINT；
* LNGSH；
* SHLAG；
* FNSDT关键节点；
* XXFTEM/YXFTEM关键节点；
* XMPAGE；
* 有必要时SFDUR。

目标变量：

* 单果干重；
* 果实干物质增长曲线；
* 分次果实干产量；
* 果实总干物质；
* 叶、茎和果实之间的干物质竞争。

---

## 阶段7：鲜重与多次采收率定

先固定阶段6得到的所有干物质参数，再活动：

* XMAGE；
* DMC0；
* DMCH；
* KDMC；
* 必要的商品成熟判据或收获移除比例。

目标变量：

* 各次采收日期；
* 各次采收鲜重；
* 平均单果鲜重；
* 平均果实干物质比例；
* 累积鲜产量。

---

## 阶段8：水分和氮素胁迫率定

只使用有明确水、氮处理的数据。

水分活动参数可包括：

* DSWBAR；
* XSWBAR关键节点；
* YSWBAR中间响应；
* XSWFAC关键节点；
* RWUMX；
* 必要时XTRFAC/YTRFAC。

氮素活动参数可包括：

* NSTFAC；
* LNREF；
* NSLOPE；
* FNPGN低氮端节点；
* NMOBMX；
* NVSMOB；
* NRCVR；
* 必要时RTNO3和RTNH4。

每次只释放一个过程链。例如先率定土壤水分和吸水，再率定坐果水分响应，不能一次同时释放根系、水分胁迫曲线和XFRT。

# 十二、参数筛选与活动参数数量控制

## 12.1 推荐筛选流程

每个阶段采用：

1. Morris或局部扰动筛选；
2. 对敏感参数进行Sobol或其他全局敏感性分析；
3. 检查参数相关性和等效性；
4. 只保留能够被现有观测独立约束的参数；
5. 最后进入集合反演或贝叶斯率定。

## 12.2 每阶段参数数量

建议：

* 初始候选参数：可较多；
* 每个模块敏感性分析：10–20个参数；
* 每次正式联合率定：通常不超过8–12个；
* 最终全模型联合微调：不超过15个，并使用强先验。

---

# 十三、必须执行的参数约束

## 13.1 不同时自由率定的参数对

以下参数只能选择一侧作为活动参数：

* SLAVR 与 SLAREF；
* SIZLF 与 SIZREF；
* RWDTH 与基础YVSWH曲线；
* RHGHT 与基础YVSHT曲线；
* XFRT文件参数与内部XFRUIT状态量；
* LFMAX与其他纯尺度型光合参数中的多个参数；
* 全套DMC参数与XFRT、LNGSH同时首次自由率定。

## 13.2 曲线约束

温度节点：

[
TB<TO1\leq TO2<TM
]

所有X轴查表参数严格递增。

比例响应：

[
0\leq Y_i\leq1
]

动态果实分配：

[
0\leq XFINT\leq1
]

[
0\leq XFRT\leq1
]

[
XFPHT>0
]

采收参数：

[
XMAGE\geq1
]

营养器官分配：

[
FRLF+FRSTM+FRRT=1
]

[
FRRT\geq0
]

果实干物质比例：

[
0<DMC<1
]

且DMC曲线应符合实测随果龄变化趋势，不能仅依靠数学边界。

# 十四、建议立即执行的工作清单

按实施顺序，建议现在完成以下工作：

1. 在候选参数表中新建“叶片衰老”“果数形成”“鲜重换算”三个模块。
2. 加入 LNGSH、XMPAGE。
3. 加入 XLEAF–YLEAF–YSTEM、XVGROW–YVREF 和 FRLFMX。
4. 加入 SENRTE、SENDAY 和一个后期SENPOR锚点。
5. 加入 SETMAX、RFLWAB、FNPDT/TYPPDT。
6. 加入 FNSDT/TYPSDT、XXFTEM/YXFTEM、SHLAG。
7. 将 WTPSD、SDPDV、THRSH 列入候选表，但标记为“优先实测固定”。
8. 增加 DSWBAR，并将 XFRMAX、XTRFAC/YTRFAC列为条件参数。
9. 在氮素模块增加 LNREF、NSLOPE，并展开器官蛋白参数。
10. 在根系模块增加 XRTFAC/YRTFAC。
11. 修改FreshWt程序，加入Eggplant专用DMC参数和作物代码。
12. 对新增参数执行±10%扰动测试，建立“参数—受影响输出”映射表。
13. 按物候、冠层、果数、单果干重、鲜重、水氮胁迫的顺序逐阶段率定。
14. 每阶段保存固定参数版本，避免后续率定破坏前一阶段已经验证的过程。

按这个方案扩充后，你的参数体系不仅能够拟合累计产量，还能够分别解释：**何时开花、形成多少果、每个果实积累多少干物质、果实含水量如何变化、何时达到采收条件，以及采收后植株是否仍能维持新的叶片和果实生长。**
