
# 参数率定沟通模板（简版）

```text
【本次目的】
例如：探索历史最优拟合是否适合两个春季试验联合率定

【参与率定的数据】
季节：25春 + 26春
处理：两个春季试验的高水高氮、低水高氮、高水低氮、低水低氮处理（25春trno2、5、10、13；26春trno1、3、9、12）

【观测指标】
默认进入率定：
物候、LAI、叶干重、茎干重、株高、SNAM、LNAM、
土壤水分、累积干产量 CHPDT、单次干产量 HPODW、累积鲜重产量、单次鲜重产量。

默认不进入率定：
ADAP、MDAP、CNAM

数据变换：
CHPDT、HPODW、累积鲜重产量、单次鲜重产量 使用 ln(y+1)，其他指标保持原尺度。

【目标族权重】
物候：0.10
冠层：1.00
器官生物量：1.00
植株氮：1.00
土壤水分：0.5
绝对干产量：1.25
绝对鲜重产量：1.25
氮响应：0.75
鲜重与干重产量相关总预算：2.50

【参数设置】
本次使用stage4_full_v12_best_parameters_fixed 率定过程文件中记录的参数取值范围
特别的：FL-VS 固定为 120。
SLPF 参与率定，范围 0.90–0.96。

【FileX 设置】
初始硝态氮 SNO3：1.0
初始铵态氮 SNH4：0.5
PAGE：25 天
SPRL：-99
其他管理条件保持 FileX 不变。

【运行规模】
默认：150×5，7 个并行 agents


【本次重点报告】
默认报告最佳成员的分季和总体 RRMSE、NSE、R²、Bias，
参数后验触边比例，以及高、低水下 N3−N0、N2−N0、N1−N0。

其他要求：

【启动方式】通过smoke测试后，生成脚本由我一键启动
```
