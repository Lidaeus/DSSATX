# 最小用户流程与入口

> 状态：当前规范（P2-MVP），更新：2026-07-18

普通研究者只需要理解以下三类流程；其余 Python 文件是内部实现，不构成稳定公共 API。

## 1. 敏感性分析

1. 准备并冻结参数边界与输入包；
2. 构建并运行 Morris 或 Sobol case；
3. 使用对应 audit/quality 输出检查运行完整性、跨 seed 稳定性和响应是否有生理学意义；
4. 只有通过 SA 质量门的冻结数据才进入论文数据导出。

SA 不需要观测值作为敏感性指标的目标函数；指标应是预先选择的、有生理或生产意义的 DSSAT 响应。观测数据仅用于后续率定和验证。

## 2. 分阶段参数率定

核心入口按以下顺序使用：

```text
build_pest.py --design-config <design.json> --stage S1|S2|S3|S4
        ↓
tools/parallel/run_parallel.py
        ↓
src/calibration/finalize_calibration.py
```

分阶段只释放 2–4 个活动参数。正式率定默认关闭分布自适应的相对 2σ 筛除，仅排除真实运行失败或预先定义的无效模拟；若显式启用统计筛除，必须同时提供 no-cull 对照和成员流失报告。

IES 质量报告只描述工程完整性。是否达到 `science_validated` 只由运行目录中的 `calibration_finalize/calibration_finalize.json` 决定。

## 3. 后验、异参同效与论文图表

率定 finalize 通过后，才允许执行：

- 先验—条件参数集合边际分布、参数收缩和边界命中；
- Spearman 相关矩阵；
- 2–3 对 Phi 接近但参数距离较远的候选解及确定性复跑；
- `export_paper_data.py` → `paper/R/make_all.R` 的正式图表流程。

正式导出必须绑定同一 run 的 manifest、工程质量报告和 `calibration_finalize.json`。没有 finalize 的结果只能作为带 DEMO 标识的版式预览，不能用于论文结论。

## 暂停的能力

在最小科研闭环完成前，不开发新 SA 算法、14 参数联合率定、pwtadj1、自动聚类/t-SNE、代理模型、管理优化、品质预测或新的 Fig/FigS 模块。历史探索脚本应归档，不再作为公共入口。
