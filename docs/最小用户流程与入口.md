# 最小用户流程与入口

> 状态：当前规范（P2-MVP），更新：2026-07-18

普通研究者只需要理解以下三类流程；其余 Python 文件是内部实现，不构成稳定公共 API。

## 1. 敏感性分析

1. 准备并冻结参数边界与输入包；
2. 构建并运行 Morris 或 Sobol case；
3. 使用对应 audit/quality 输出检查运行完整性、跨 seed 稳定性和响应是否有生理学意义；
4. 只有通过 SA 质量门的冻结数据才进入论文数据导出。

SA 不需要观测值作为敏感性指标的目标函数；指标应是预先选择的、有生理或生产意义的 DSSAT 响应。观测数据仅用于后续率定和验证。

## 2. 分阶段参数率定

核心入口按以下顺序使用：

```text
build_pest.py --design-config <design.json> --stage S1|S2|S3|S4
        ↓
tools/parallel/run_parallel.py
        ↓
src/calibration/finalize_calibration.py
```

分阶段只释放 2–4 个活动参数。正式率定默认关闭分布自适应的相对 2σ 筛除，仅排除真实运行失败或预先定义的无效模拟；若显式启用统计筛除，必须同时提供 no-cull 对照和成员流失报告。

IES 质量报告只描述工程完整性。是否达到 `science_validated` 只由运行目录中的 `calibration_finalize/calibration_finalize.json` 决定。

## 3. 后验、异参同效与论文图表

率定 finalize 通过后，才允许执行：

- 先验—条件参数集合边际分布、参数收缩和边界命中；
- Spearman 相关矩阵；
- 2–3 对 Phi 接近但参数距离较远的候选解及确定性复跑；
- `export_paper_data.py` → `paper/R/make_all.R` 的正式图表流程。

正式导出必须绑定同一 run 的 manifest、工程质量报告和 `calibration_finalize.json`。没有 finalize 的结果只能作为带 DEMO 标识的版式预览，不能用于论文结论。

当前稳定的 T4 数据接口为：

```powershell
# 独立处理角色指标；science_pending 仅允许显式 demo QA
python -m src.reporting.validation_metrics `
  --run-dir workspace/runs/<run_id> --case <case> `
  --out-dir workspace/runs/<run_id>/validation_results `
  --allow-unvalidated-demo

# 最小条件集合摘要与 2–3 对候选解
python -m src.reporting.posterior_summary `
  --run-dir workspace/runs/<run_id> --case <case> `
  --out-dir workspace/runs/<run_id>/posterior_results `
  --max-pairs 3 --allow-unvalidated-demo

# 候选解 prediction distance（≤6 次隔离确定性 DSSAT 复跑）
python -m src.reporting.candidate_predictions `
  --run-dir workspace/runs/<run_id> --case <case> `
  --posterior-manifest workspace/runs/<run_id>/posterior_results/posterior_results_manifest.json `
  --out-dir workspace/runs/<run_id>/candidate_predictions `
  --observation-policy-csv configs/runs/<policy>.csv `
  --allow-unvalidated-demo
```

三个入口都会先逐项验证 `calibration_artifacts_manifest.json`。validation 指标不会回写 Phi，也不能用于重新选择 S4 参数；候选解 prediction distance 在 tooling_demo 上游下只能标记为 `demo_prediction_similar`/`demo_prediction_divergent`/`prediction_incomplete`，**不得**称为功能异参同效。prediction distance 只消费 validation + diagnostic 角色，calibration 行永不进入距离计算；sigma_eff 用 raw 尺寸（不含 group_multiplier）。

## 暂停的能力

在最小科研闭环完成前，不开发新 SA 算法、14 参数联合率定、pwtadj1、自动聚类/t-SNE、代理模型、管理优化、品质预测或新的 Fig/FigS 模块。历史探索脚本应归档，不再作为公共入口。
