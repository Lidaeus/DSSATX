## 7. prediction distance 的冻结定义

### 7.1 行对齐

解 A/B 按下列科学键一对一合并，禁止按 CSV 行号拼接：

```text
dataset_role, variable, treatment, date_code, harvest_number
```

`date_code/harvest_number` 的缺失值需使用稳定 sentinel 后再校验 `one_to_one`。任一解缺行、多行或变量集合不同均硬失败。

### 7.2 sigma 映射

使用 S4 manifest 绑定的 observation policy，并按当前 raw-scale 定义计算：

```text
sigma_eff = sqrt(sigma² + model_sigma² + sigma_floor²)
```

变量映射固定为：

| comparison variable | policy group |
|---|---|
| ADAP | ADAPM |
| LAIX | LAIXM |
| CNAM | CNAMM |
| LAID | LAIDM |
| LWAD | LWADM |
| SWAD | SWADM |
| DRY_INC | PWAIM |
| DRY_CUM | PWADM |

prediction distance 衡量预测差异，不重算 Phi，因此不应用 `group_multiplier`。缺少 sigma、非 raw transform 或 sigma 非有限/非正时硬失败；不要增加静默数值 fallback。

### 7.3 聚合

对每个 role × variable 分层计算：

```text
d(role, variable) = RMS[(sim_A - sim_B) / sigma_eff(variable)]
```

然后：

```text
d_validation = 各 validation variable 的等权平均
d_diagnostic = 各 diagnostic variable 的等权平均
prediction_distance = mean(d_validation, d_diagnostic)
```

按变量等权，避免 11 次采收事件因行数多而自动支配距离。必须同时保留逐 role-variable 分量，不能只输出一个总数。

### 7.4 分类

预声明阈值为 `1.0 sigma_eff`：

- validation 和 diagnostic 均 `<= 1.0`：预测在当前假设误差尺度内接近；
- 任一 `> 1.0`：预测分化；
- 任一缺失或复跑失败：`prediction_incomplete`。

当前上游是 `tooling_demo/science_pending`，输出标签只能是：

- `demo_prediction_similar`；
- `demo_prediction_divergent`；
- `prediction_incomplete`。

不得输出 `functional_equifinality` 或 `science_validated`。未来只有 science-use 上游、独立证据门和相同计算定义均通过后，才可使用“功能异参同效得到支持”的表述。
