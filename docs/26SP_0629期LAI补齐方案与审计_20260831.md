## 六、缺失值与有符号差值的安全处理

先在原始单位识别缺失值（−99附近容差1e−6，NaN/Inf），再换单位。状态量使用有限且非负校验；响应差值允许任意有限负数。先把参与相减的原始缺失值置NaN，不能在差值形成后把合法−99误判为缺失。

```python
from src.reporting.metrics import valid_pair_mask
mask = valid_pair_mask(obs_raw, sim_raw, value_kind="state")
obs = obs_raw[mask] * unit_factor
sim = sim_raw[mask] * unit_factor
# 已由有效状态值生成的差值：value_kind="signed"
```
