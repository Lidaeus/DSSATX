## 1. P1 目标

P1 只回答“哪些参数在当前试验、参数范围和输出定义下稳定地影响 DSSAT 响应”。它不直接率定参数，也不把一次 Morris 排名当作最终生理结论。

预期产物包括：

- 多随机种子 Morris 原始 elementary effects、单输出排名和稳定性报告；
- 参数—输出矩阵及过程分组结果；
- 经人工审核的 Top-K proposal；
- Top-K Sobol 一阶/总效应、置信区间或样本收敛证据；
- 可用于后续 P2 分阶段率定的参数选择依据。

## 3. 正式 P1 前置质量门

正式运行必须同时满足：

1. bounds 共享 validator 无 error；
2. `review_status=approved`，proposal 经 `freeze_bounds.py` 生成新且唯一的 frozen ID，且 CSV 哈希与 metadata 完全一致；
3. active 参数数量不超过本轮预算，SOIL/IC 没有未经批准的 active 项；
4. 处理集合、输出变量、缺失规则及聚合方式已冻结；
5. 基线和至少一个扰动 DSSAT 运行通过非陈旧、有限值和非零响应门；
6. 随机种子、Morris `r/p/delta`、并行度和软件版本进入 manifest；
7. 任一 seed 出现全零 elementary effects、主要输出为 `-99` 或有效运行率不足时整批失败，不生成正式排名。

当前基线预检发现 `MDAPS` 在 TN2、TN3 及均值中均为 `-99`，因此已从本案例默认输出契约移除；未来只有在成熟期输出有效且研究问题需要时才显式加入。

正式门禁命令：

```powershell
python tools/check_p1_readiness.py `
  --bounds data/parameter_registry/bounds_frozen/eggplant/<approved_id>.csv
```

当前 pending proposal 在 `--technical-only` 下通过；不加该开关时必须失败，这是防止误启动的设计行为。

## 4. 推荐的分级计算方案

### P1-A：多种子 Morris 试运行

- 参数：审核后的最多 60 个 active 参数；
- 输出：物候、冠层、器官/总生物量、增量采收分别保留，不先压成单一总分；
- 处理：使用经审核的代表性处理覆盖水氮梯度，保持完整处理而非随机拆行；
- 建议配置：3 个固定种子，每个 seed `r=8`、`p=6`；
- 用途：估计失败率、耗时、输出方差和排名稳定性，不作为正式最终排名。

### P1-B：正式 Morris

- 在 P1-A 无退化后，提高到每 seed `r=20`，仍使用至少 3 个种子；
- 报告每个参数—输出组合的 `mu*`、`sigma`、有效轨迹数和失败率；
- 建议稳定性诊断：Top-K Jaccard、排名 Spearman、跨种子变异系数；阈值先由 P1-A 分布确认，不为通过门禁事后放宽；
- 只生成 Top-K proposal，不自动进入 Sobol 或率定。

### P1-C：Top-K Sobol

- Top-K 建议不超过 12，并覆盖物候、冠层、生物量和结实/采收过程；
- 至少比较两个样本量层级，报告 `S1/ST` 变化和重采样区间；
- 若 `ST-S1` 较大，保留为交互候选，不因一阶效应低而自动删除。
