## 3. 受控水氮处理与输出设计

### 3.1 为什么不再只用 TN2/TN3

TN2/TN3 的 `MI` 都为1，仅覆盖 `MF=1/2`，不能代表水氮响应。正式 v4 使用 `2,3,4,5,10,11,12,13`：TN2–5 为 W3 下四个氮水平，TN10–13 为 W1 下四个氮水平。TN9 和 TN14 不构成完整配对，不进入正式水氮主效应/交互排名；以后可作为外部情景诊断。

实际灌溉总量为 W3=481.4 mm、W1=283.1 mm；实际施氮量为0、130、271、399 kg N ha-1。氮响应按实际剂量计算线性斜率，不把 N0–N3 编码为等距等级。每一个参数向量必须成对运行全部8个处理，再计算水分差值、两条氮响应斜率及其斜率差交互。

### 3.2 v4 的164项响应

配置由 `configs/sa/eggplant_p1_outputs.json` 固定。每个 TN 包含13个端点/曲线特征和4个 LAI 观测对齐点，共 `8×17=136` 项；另对 LAI AUC、季末地上生物量、最终累计果实干重、累计果实干重 DAP50 分别生成4个水分差值、2个氮响应斜率和1个水×氮交互，共28项，总计164项。

LAI 的4个 DAP 为45、67、95、119，并作为一个 `LAI_DAP` 特征族汇总。所有固定 DAP 的累计果实干重均删除；采收进程改用最终累计干重和达到最终累计量50%的插值日期 DAP50。旧的 `HIAMS`、`HI_END_HIAD`、`LAI_TPEAK` 结构性零方差/冗余响应和累计曲线 AUC 也不再进入正式契约。

- 覆盖完整2×4核心水氮子设计，不再让不成对的 TN9/TN14 稀释交互解释；
- 删除跨处理 `MEAN_*`，避免处理值与其均值重复进入综合排名；
- LAI 固定 DAP 点只作为一个观测对齐特征族，不按4份独立证据加权；
- 删除 DAP67/95/119 累计果实干重，保留生理/生产意义更明确的最终累计量和 DAP50；
- 最大 LAI 明确读取 DSSAT 模拟字段 `LAIXS`，不再把 FileA 实测 `LAIXM` 当作模型输出；
- 直接对成对水差、氮响应斜率和水×氮斜率差执行 Morris/Sobol，而不是比较处理排名后间接推断；
- `MDAPS` 在基线为 DSSAT 缺失哨兵，继续排除。

164 是 SA 响应维度，不是 PEST 率定观测。`general_genetic` 与 `water_nitrogen_response` 是两个独立排名域，禁止平均成一个综合分数。旧 v3 的正式 Morris、Top16 与 Sobol 结果保留为历史证据，但其输入/输出哈希不适用于 v4；v4 必须重新完成 Morris、跨 seed 稳定性和 Top-K 审批后才能开展新 Sobol。

## 4. 正式 Morris 规模与完成结果

P1-R1 取代了原“预先固定运行 5 个 seed”的设计。批准后的自适应正式规模为：

- 57 个 active 参数；
- 先运行 2 个独立随机种子；候选 seed 仍为 `20260715, 20260729, 20260812, 20260826, 20260909`，但 seed 20260715 的现有失败案例只用于诊断，不得计入正式结果；
- 每个 seed `r=30`，`p=6`；
- 每个 seed 理论运行数 `30×(57+1)=1740`；初始预算 3480 次 DSSAT，只有跨 seed 稳定性不足时才依次扩展，最多 8700 次；
- 每个 seed 独立运行目录和 manifest，建议每个案例 6 个并行 agent。

每个 seed 必须先通过 P1-R1 进程、模型、轨迹和 elementary-effect 完整性门禁。两个有效 seed 的总体 Spearman ≥ 0.90 且 Top-15 Jaccard ≥ 0.80 时停止扩展；否则逐个增加第 3–5 个 seed，并记录扩展理由。不得将多个 seed 合并成一个伪大样本；必须先分别审计，再计算跨 seed 稳定性。

跨 seed 排名不直接平均不同量纲的 `mu*`。先在每个响应内归一化为相对贡献，再在特征族和过程组内汇总。一般遗传影响只在物候、冠层、生物量、产量/采收四组内汇总；水氮响应只在水分差值、氮斜率、水×氮交互三组内汇总。两个排名域分别审核稳定性和 Top-K，禁止跨域平均。

正式 seed 不再接受“有效轨迹达到 90%”作为充分条件：30条轨迹必须全部完整有效，每个参数必须具有完整的30个 elementary effects，且 `.mio` 有限性、整体非退化和逐响应非退化质量门全部通过。任一模型失败、运行时失败、未完成设计点或声明响应全零都会使该 seed 失败；原因解决前不得发布排名。

本轮实际执行三个 seed：`20260729` 出现1/1740个可重复模型失败，按预声明门禁整 seed 排除；替换 seed `20260812`、`20260826` 均为1740/1740成功、30/30完整轨迹和1710/1710有效 effects。两个有效 seed 的总体 Spearman 为0.9962、Top-15 Jaccard为0.875，达到判停阈值，因此不再增加第4/5个 seed。完整证据见 [P1-R4 正式 Morris 与跨 seed 稳定性报告](reports/P1_R4_正式Morris与跨seed稳定性.md)。

Top-15稳定交集为14个参数：`TRIFL, XFRT, TB2, RTNO3, FRLFF, LFMAX, EM-FL, XFINT, TO12, TO22, PM06, FRSTMF, TM2, NMOBMX`。边界并集另含 `FL-SD, RTNH4`。用户已批准该16参数保守并集，版本化配置位于 `configs/sa/approved_topk/eggplant_p1_sobol_top16_20260716.*`。

## 5. 执行顺序

1. 在干净提交上重新运行输入、边界、依赖和测试门禁；
2. 基线与至少一个参数扰动实跑，要求164项全部有限且非陈旧；基线已通过；
3. 先生成并运行 2 个 seed 的独立控制文件与 manifest；
4. 每个 seed 完成后执行 P1-R1 Morris 审计，任何不完整 seed 均从干净案例重跑，不用部分恢复结果替代；
5. 两个 seed 均通过后计算 Spearman 与 Top-15 Jaccard，未达到门槛时才依次扩展到最多 5 个 seed；
6. 输出每个参数—响应的 `mu*`、`sigma`、有效轨迹数和失败率；
7. 报告 Top-K Jaccard、Spearman、名次范围与跨 seed 变异；
8. 生成并审批 Top-K proposal；该步骤已完成；
9. 分别生成 `general_genetic` 与 `water_nitrogen_response` 的 Top-K proposal，由领域审核决定新 Sobol 参数并集；
10. 新 Top-K 审批后先用小 N 验证完整矩阵和 bootstrap 复算，再单独审批正式自适应预算。

深层缺失 `SSKS`、`SLCL/SLSI` 不参与 SA，保留 warning 并在论文中披露；不得把 DSSAT 默认纹理视为实测值。旧 v3 的 r=8/正式 Morris/Sobol 报告只用于历史追溯。v4 受控输入与164项契约已经批准，下一步是独立小样本扰动预检和正式 Morris。

预检 manifest 已写入 `run_type: sensitivity_preflight_case`；全部质量门通过只说明候选域可进入正式 Morris，不得把预检 `.mio` 用作正式参数排名。

构建示例：

```powershell

  --morris-r 8 --morris-p 6 --random-seed 20260716 `
  --run-type sensitivity_preflight_case
```
