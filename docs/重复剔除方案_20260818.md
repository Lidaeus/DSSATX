# 源数据异常重复剔除方案（2026-08-18，待审核）

## 判据设计（预先设定、双向对称、与趋势无关）

对每个 小区×日期 的 3 个重复（每重复 = 1 株 destructive 样株）：

- **C1 离散判据**：|rep − 中位(rep)| / 中位 > 30%
- **一致性分类**（同一株的 株高/茎干重/叶干重/LAI 相对各自重复中位数的偏差 d）：
  - `single_var_anomaly`：仅 1 个变量 |d|>30%，其余 |d|<15% → **测量可疑**（该株其他量正常，单变量孤立异常，指向称量/记录/处理差错）
  - `uniform_plant`：≥3 个变量同向 |d|>15% → **整株偏大/偏小**（真实株间异质性，非差错）
  - `mixed`：其余

**两条剔除通道**：
- **通道 1（统计）**：`single_var_anomaly` → 剔除**该株的该变量值**（自动有资格）
- **通道 2（田间佐证）**：`uniform_plant`/`mixed` → 剔除**整株**（全部变量），但**必须附田间/记录佐证**（该株矮化、病虫害、损伤、取样位置异常等），由实验者逐株确认

**红线**：任何剔除不得以"修正后趋势变好"为理由——趋势效果仅作信息披露，不作剔除依据。

## 关键算术（必须先看懂再决策）

1. **你的案例（25SP 小区2 叶干重剔 39.5）**：39.5 相对重复中位 43.5 仅偏差 9.2%，**不触发任何判据**（属正常离散）。即使按田间知识剔除：−21.6% → −18.1%，**仍远超 10%**——因为三个重复整体都降了（打叶是真实的）。
2. **剔除是零和的**：同一个"偏大株在早期"——剔除它会缩小叶干重降幅（如 26SP 小区2 →−7.1%），但会**放大**同一小区其他变量的增幅（25SP 小区13 → +48%/+70%）。不存在让所有序列同时回到 ±10% 的剔除组合。
3. **无法达成的目标**：±10% 约束在数学上不可达——株高/茎干重的 +30~50% 是 24 天真实生长，叶干重的 −15~20% 是真实打叶，均非取样噪声。
