# 观测误差与权重设计规范

> 文档状态：当前专题规范
> 更新日期：2026-07-15
> 实施状态：原始尺度基线及显式 log/均值 sigma 策略已实现；相关误差模型和 pwtadj1 留待后续审批

本文取代旧版“权重设计方案改进提案”。旧版中将 `1/sigma²` 直接写入 PEST 权重、强制 Min–Max 归一化及对组权重静默回退等设计不再采用。

## 1. 目标

权重设计需要同时做到：

- 反映观测误差和量纲差异；
- 防止高频或大数值观测组无依据地主导目标函数；
- 保留清晰的统计解释和完整审计记录；
- 在观测不足时诚实表达假设，不伪造精确性；
- 支持敏感性分析、率定、验证和论文方法描述使用同一观测定义。

权重不能修复错误的模型输出、变量映射或数据质量。所有权重计算都必须在观测预检通过后进行。

## 2. PEST 权重的数学语义

PEST/PEST++ 的加权最小二乘目标函数按下式理解：

```text
Phi = Σ_i [w_i × r_i]²
r_i = observed_i - simulated_i
```

若假设独立高斯观测误差，且 `sigma_i` 是观测误差的标准差，则：

```text
w_i = 1 / sigma_i
```

这样每项贡献才是 `(r_i / sigma_i)²`。将 `1/sigma_i²` 直接写入 PEST 的 weight 列会得到 `r_i²/sigma_i⁴`，造成过度加权，禁止使用。

系统中必须区分：

- `sigma_i`：统计或工程上估计的观测误差标准差；
- `base_weight_i = 1 / sigma_i`：由误差模型产生的基础权重；
- `group_multiplier_g`：研究目标层面的显式组倍率；
- `final_weight_i = base_weight_i × group_multiplier_g`：写入 PEST 的最终权重。

四者都应出现在审计表中，不能只保留最终数字。

## 3. 观测误差标准差

### 3.1 来源优先级

`sigma_i` 的来源按以下优先级选择：

1. 同一处理与时点的独立重复测量，可估计标准差；
2. 试验仪器精度、取样方案或公开方法提供的误差；
3. 跨重复/相似试验的稳健误差模型；
4. 经用户审核的变量级绝对误差或变异系数假设。

每个变量必须记录 `sigma_source`。如果使用第 4 类假设，论文中应作为假设或敏感性分析项报告。

### 3.2 异方差

对误差随观测量级增加的变量，可使用预声明的绝对误差加相对误差模型：

```text
sigma_i = sqrt(sigma0_g² + (cv_g × abs(observed_i))²)
```

其中 `sigma0_g` 防止零值附近权重发散，`cv_g` 表示相对误差。二者都必须按变量组配置、记录单位并通过下限检查。

禁止直接从某次候选模拟的残差反推该次运行的权重；这会使目标函数随候选解改变定义。

### 3.3 标准误与标准差

若观测值是重复样本均值，是否使用均值标准误取决于研究问题和重复的独立性。不能机械地用 `SD/sqrt(n)` 获得极高权重。原始重复、均值、样本量及所选误差定义必须可追溯。

### 3.4 当前 FileA/FileT 为处理均值时的规则

FileA/FileT 继续保存处理均值，不把多个重复伪装成多个独立 DSSAT 处理。确定性 DSSAT 对一个处理给出一个期望响应；若把同一处理的多个重复分别与同一个模拟值配对，既会人为放大该处理的权重，也会忽略区组与同株时序相关性，构成伪重复。

推荐另存一张不参与 DSSAT 解析的长表保存原始重复，至少包含 `experiment/treatment/block_or_plot/replicate/variable/date_or_stage/value/unit/qc`。率定观测仍为处理均值，重复用于估计均值的不确定性：

```text
sigma_eff = sqrt(replicate_sd² / n_eff + sigma_model² + sigma_floor²)
0 < n_eff <= n_replicates
```

- `replicate_sd` 描述小区/样本离散；`replicate_sd / sqrt(n_eff)` 描述均值抽样不确定性；
- `sigma_model` 表达模型结构与尺度不匹配，防止仅凭重复数把权重推得过高；
- `sigma_floor` 防止零方差或极小样本方差产生无限权重；
- 同一小区跨日期重复测量或空间上不独立时，`n_eff` 应小于物理重复数；
- 重复数很少、组内 SD 极不稳定时，优先使用变量级 pooled SD/CV，并保留变量/处理敏感性分析。

若目前只有均值、无法找回重复，不能从均值反推出 SD。临时使用相似试验、仪器精度、文献 CV 或经审核的变量级 sigma，并把 `sigma_source` 标为 `pooled`、`instrument`、`literature` 或 `assumed`；正式论文结果需要报告该假设并做权重敏感性比较。

## 4. 残差尺度与变换

### 4.1 默认原始物理尺度

默认在原始单位上计算残差，并用同单位的 `sigma_i` 标准化。这保留最直接的物理解释。

### 4.2 可选变换

仅在误差结构和研究问题有明确依据时采用对数等变换。变换必须：

- 在运行前写入 Observation Spec；
- 同时作用于观测和模拟；
- 明确零值/负值处理和逆变换；
- 在变换尺度上定义或传播 `sigma`；
- 在图表和论文方法中说明。

本项目批准的第一版 log 定义为自然对数：

```text
z_i = ln((y_i + offset_g) / reference_g)
sigma_log_i = sqrt(ln(1 + [sigma_raw_i / (y_i + offset_g)]²))
weight_log_i = 1 / sigma_log_i
```

`reference_g` 只使对数参数无量纲，不改变观测—模拟残差；默认值为 `1`，必须为正。观测与模拟使用同一 `offset_g/reference_g`。不自动使用 `log1p`，因为 `log1p(y)` 隐含单位为 1 的零点修正；只有显式配置 `offset=1` 时才与其等价。任何 `y + offset <= 0` 直接失败，不静默截断、取绝对值或增加机器 epsilon。

FileA、FileT、Evaluate.OUT、FreshWt.OUT、PlantGro.OUT、常规指标和论文主图继续使用实际物理尺度。构建器把观测变换后写入 `.pst`，DSSAT runner 只在 PEST 专用的 tagged `Pest*.OUT` 中变换对应模拟 token，因此 `.ins` 读取的是变换后模拟值。权重审计表同时保留 `raw_obsval/raw_sigma` 与变换后的 `obsval/sigma`。目标函数诊断可显示变换尺度，拟合优度与论文结果图默认回到实际尺度并明确误差带定义。

若重复原始值可用，log 误差最好在重复层检查；需要区分 `log(处理均值)` 与 `mean(log(重复值))`。当前率定响应定义为前者，因为它对应 DSSAT 的处理期望值；重复层只用于估计离散性和检查乘性误差假设。

### 4.3 不采用动态 Min–Max

禁止用“当前观测 + 当前候选模拟”的最小值和最大值对残差归一化。该做法会使同一残差在不同候选解下具有不同尺度，破坏目标函数的一致性。

如绘图需要 0–1 标度，只能使用预先冻结的物理范围或训练数据统计量，并且该标度不自动进入率定目标函数。

## 5. 观测组倍率

### 5.1 用途

在基础误差权重之外，`group_multiplier_g` 只用于表达预先声明的研究目标，例如确保物候、冠层和产量均有合理贡献。默认值为 `1.0`。

组倍率不得用于掩盖：

- 错误单位或变量映射；
- 极端异常值；
- 参数对某观测完全不敏感；
- 某组模拟全部失败；
- 观测误差缺少依据。

### 5.2 设置与审计

任何非 1 倍率都需要记录：组名、理由、批准人、配置版本和敏感性比较。系统必须输出初始及最终的组 `Phi` 贡献。

PEST++ 的 `pwtadj1` 本轮明确停用。以后若重新审批，只允许基于冻结的 `noptmax=0` 基线平衡“各组总 Phi”，并在启用前同时审核各组观测数量、累计/时序相关性和基线残差异常；不得把它解释为观测误差估计，也不得在缺少基线或组名不匹配时回退。

当前物候、冠层、生物量和增量采收四类研究目标默认等权，即组倍率均为 `1.0`。可在预声明的对照实验中把增量采收倍率小幅提高（示例 `1.1`），但必须同时报告倍率为 `1.0` 的结果；不得根据最终拟合效果反向调权。

### 5.3 频次平衡

同一变量的高频采样可能仅因数量多而主导目标函数。优先根据重复测量相关性建模；在暂不支持协方差的 P0/P1 阶段，可使用明确记录的组频次修正作为近似，并做有/无修正敏感性对比。

## 6. 相关观测和多次采收

累计采收量共享此前采收误差，相邻累计值不是独立观测。默认设计为：

- 各次增量鲜重/干重进入率定；
- 季末累计量用于诊断或验证；
- 不同时将全套增量和全套累计量以独立权重重复计入。

若研究必须率定累计曲线，应使用显式协方差/白化残差，或采用经说明的降权近似，并报告其限制。

类似地，同一植株或小区的 LAI、生物量时间序列存在相关性。当前最低要求是按处理保留完整时间序列，报告相关性假设，并避免把验证行随机混入率定集。

## 7. Observation Spec 最小字段

建议每行对应一个观测：

| 字段 | 含义 |
|---|---|
| `obs_id` | 全局唯一观测标识 |
| `variable` / `group` | 变量及 PEST 观测组 |
| `treatment` / `date_or_stage` | 处理与时间定位 |
| `value` / `unit` | 原始处理均值与单位 |
| `replicate_n` / `n_effective` | 物理重复数与有效独立样本数 |
| `replicate_sd` / `sigma_model` / `sigma_floor` | 均值误差的可追溯组成 |
| `use` | calibration / validation / diagnostic |
| `transform` | raw / log / 其他已批准变换 |
| `sigma` / `sigma_source` | 误差标准差及依据 |
| `group_multiplier` | 显式组倍率 |
| `final_weight` | 写入 PEST 的权重 |
| `correlation_block` | 重复测量或累计序列分组 |
| `simulated_source` | DSSAT 输出文件、变量和解析键 |

生成 `.pst` 前必须验证单位、正 sigma、有限权重、唯一映射和用途互斥。

## 8. 推荐运行模式

### 基线模式

`raw residual + sigma-based weight + group_multiplier=1`。这是首个可信基线，也是 P0 必须实现和测试的模式。

### 研究目标平衡模式

在基线通过后，只对少数组增加预声明倍率，并比较组贡献、参数变化和验证性能。任何倍率不得从最终结果反向调到“看起来更好”。

### 显式 log 模式

使用 `--observation-policy-csv` 按组配置；全局 `--apply-log-transform` 已停用。配置必须使同一模拟 token 的 `transform/offset/reference` 唯一，且 log 组必须有原始尺度 sigma。示例文件位于 `configs/runs/observation_policy_example.csv`，默认仍为原始尺度，仅演示增量采收 `1.1` 倍率，使用前应复制并按本次试验审核。

### 相关误差模式

当重复测量/累计数据成为主要研究问题时，再实现协方差或白化残差。该能力不属于 P0 的必要范围，避免过度设计。

## 9. 质量检查与验收

P0 至少覆盖以下自动检查：

1. 已知 `sigma` 的示例中，写入权重严格等于 `1/sigma`；
2. 残差扩大一倍时，单项 `Phi` 扩大四倍；
3. 非正、缺失或非有限 `sigma/weight` 直接失败；
4. 变换只作用一侧、组名拼错或配置静默回退直接失败；
5. 权重计算不依赖候选模拟的 Min–Max；
6. 增量和累计重复进入目标函数时触发错误或显式警告；
7. 输出权重审计表和按组 `Phi` 分解；
8. 微型 PEST 案例的手算 `Phi` 与程序结果一致。

## 10. 后续审批点

P0 可以先用小型合成数据验证数学语义，不需要立即决定真实试验的全部误差参数。进入正式率定前需由用户审批：

- 各变量/处理的 `sigma` 来源和估计值；
- 是否采用异方差模型及其 `sigma0/cv`；
- 是否需要非 1 的组倍率；
- 多次采收采用增量、累计协方差还是其他方案；
- 是否对特定变量采用预声明变换。
