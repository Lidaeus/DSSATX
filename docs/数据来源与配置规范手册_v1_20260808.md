## 2. FileT 干重换算规范

### 2.1 DMFR（干物质率）计算

```python
DMFR = 1.0 - 果含水率   # 含水率单位 0-1
HARVEST_DRY = HARVEST_FRESH × DMFR
```

### 2.2 异常重复剔除规则（2026-08-07 修正）

在 `build_trial_observations_v2_20260726.py` 中，对每个 `(TRNO, 日期)` 组：
- 计算 DMFR 中位数
- **剔除与中位数偏差 > 0.05 的重复**（如 TN13 rep3 含水率 0.7848、TN5 rep2 含水率 0.8936）
- 剔除后再取平均

修正后各处理 DMFR（CHPDT/CHFPW）：

| TN2 | 4.86% | 95.1% |
| TN13 | **3.21%** | 96.8%（修正前 9.31%） |
| TN5 | **4.20%** | 95.8%（修正前 6.35%） |
| 全部范围 | 3.2%–4.9% | 95.1%–96.8% |

## 4. 目标函数权重（Group Policy）

### 4.1 权重计算公式（T8 §7.2）

```
weight = (1 / sigma) × sqrt(phi_budget / n_obs)
```

- `phi_budget`：group policy CSV 中的 `phi_budget` 列
- `n_obs`：该 family 在该季节的 active 观测数
- `sigma`：来自 observation_registry 的每观测标准差

|---|---|---|---|
| **nresp** | `windows/windows_nresp_20260806/` | 原生吸收 + 连续 NR 响应 | NREXP, NRMIN |

> 历史版本（windows_nresp_20260803, windows_a3_20260804/05, windows_a4_* 等）保留在 `windows/` 中，不再用于新率定。

### 6.2 SPE 行格式

每个版本的 `Genotype/TMGRO048.SPE` 含自定义行：
- `XPODF, NSTFAC,NREXP,NRMIN`（N 响应行，所有版本共享）
- `NUPK50,NUPCMN`（A3 系列）或 `NUPK50,NUPQ`（nresp/nni 系列）

### 6.3 SPE 替换机制

率定时通过 `run_custom_nresp_calibration.py` 或 `launch_*.py`：
1. `workspace/DSCSM048.EXE` → 备份，替换为版本 exe
2. `data/templates/genotype/TMGRO048.SPE.base` → 备份，替换为版本 SPE
3. 跑完 IES → 还原

## 8. 拟合评价规范

### 8.1 评价指标

| 指标 | 公式 | 合格标准 |
|---|---|---|
| RMSE | √(mean((sim−obs)²)) | — |
| RRMSE% | RMSE / mean(|obs|) × 100 | <30% 良好 |
| NSE | 1 − Σ(sim−obs)² / Σ(obs−mean)² | >0.5 良好 |
| d-index | 1 − Σ(sim−obs)² / Σ(|sim−mean|+|obs−mean|)² | >0.7 良好 |
| R² | corr(obs,sim)² | >0.7 良好 |

### 8.2 确定性模拟流程

1. 提取 best member 参数（min-Phi realization）
2. 用对应版本 exe + SPE 跑确定性模拟（`run_multiseason.py`）
3. 用 `deterministic_harvest_compare` + `deterministic_process_compare` 生成 compare CSV
4. 计算指标 + 绘图

### 8.3 图表输出规范

- **路径**：`figture/{batch_name}/`
- **图表类型**：scatter（obs-vs-sim）、residual、metrics_heatmap、metrics_bar、timeseries_by_WxN
- **数据 CSV**：metrics_comparison.csv、mse_decomposition.csv
- **manifest**：diagnostic_manifest.json（含 bundle sha + exe sha + 参数 sha）
- **注意**：这些是 Python run-diagnostics（非论文 Fig/FigS），论文图表走 `paper/R/` 管线

## 9. 版本变更流程

1. **修改 bundle** → 同步到所有活跃 bundle + 更新 input_manifest.json sha
2. **修改 policy/bounds** → 新建文件（不覆盖旧版）+ 更新 design json 引用
3. **新增 DSSAT 版本** → 在 `windows/` 新建目录 + README + SPE + 构建脚本
4. **重建率定批次** → 新前缀（新日期）+ 新 design json（更新 bundle sha）+ 构建 + smoke + launcher
5. **更新本手册** → 记录变更 + 版本号递增
