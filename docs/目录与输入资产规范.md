# 目录与输入资产规范

本项目只有 `data/` 保存可追溯输入资产；`workspace/` 只保存可再生运行产物。不要把 FileX、观测文件或模型模板放在仓库根目录或 `workspace/` 根目录。

| 资产 | 唯一推荐位置 | 写入规则 |
|---|---|---|
| FileX | `data/user/experiments/<bundle_id>/<name>.TMX` | 原始实验输入；修改后创建新 bundle，不覆盖旧版本 |
| FileA | `data/user/experiments/<bundle_id>/<name>.TMA` | 同上 |
| FileT | `data/user/experiments/<bundle_id>/<name>.TMT` | 同上 |
| 气象、土壤、批处理文件 | 同一 `<bundle_id>/` 下的 `.WTH`、`SOIL.SOL`、`DSSBatch.v48` | 同一输入清单的一部分 |
| 输入清单 | `data/user/experiments/<bundle_id>/input_manifest.json` | 由导入工具生成；用于 SHA-256 与处理一致性核验 |
| CUL/ECO/SPE 基线模板 | `data/templates/genotype/TMGRO048.CUL.base`、`TMGRO048.ECO.base`、`TMGRO048.SPE.base` | 项目版本化模板；经审查后修改并提交，不在运行目录手改 |
| 参数范围 | `data/parameter_registry/bounds_proposals/` → `bounds_frozen/eggplant/` | proposal 经审核后冻结；率定只能读取 frozen 层 |
| 单次运行 | `workspace/runs/<run_id>/` | 生成物；运行目录隔离，不能作为下一次输入目录手工复用 |
| 论文数据与图 | `workspace/runs/<run_id>/paper_data/`、`paper_figures/` | 由冻结数据接口生成；R 只读 `paper_data` |
| 临时/废弃归档 | `workspace/trash/` | 仅短期人工归档；确认无审计价值后再手工清空 |

## 运行时副本

构建器会把基线模板与实验输入复制到 `workspace/runs/<run_id>/` 及各 agent 沙箱，并在其中写入候选参数后的 `.CUL/.ECO/.SPE`。这些文件是临时副本，即使文件名与模板一致也不是新基线，运行完成后只保留必要的 manifest/审计证据。

## 新一轮正式分析的准备顺序

1. 为新 FileX/FileA/FileT 及配套土壤、气象文件建立新的 `data/user/experiments/<bundle_id>/`；
2. 生成并核验 `input_manifest.json`；
3. 如需调整模型基线，审查并更新 `data/templates/genotype/*.base`；
4. 从新的参数 proposal 冻结为新的 bounds ID；
5. 用 `--input-dir`、`--bounds-id` 和新的 `workspace/runs/<run_id>` 显式启动。

旧的 `Workspace/`/`workspace/` 根目录文件不是稳定输入接口。清理脚本和日常运行不得从那里隐式取 FileA、FileT、FileX 或 CUL/ECO/SPE。

`Evaluate.OUT` 以及 `Pest*.OUT` 同样不是构建输入。staged builder 从输入包内的 FileA/FileT 冻结实测值和观测结构；这些 OUT 文件只能由本次候选运行在隔离目录中重新生成。

## 多季试验目录规则

每个季节必须使用独立 `<bundle_id>`，不得把两季 FileA/FileT 覆盖到同一目录。建议命名包含试验号、季节和审核日期，例如：

```text
data/user/experiments/
  <spring_1_bundle>/
  <spring_2_bundle>/
  <autumn_1_bundle>/
```

每个目录都应自包含 FileX、FileA、FileT、WTH、SOIL、`DSSBatch.v48` 和 `input_manifest.json`。所有被处理引用的 FileX simulation OPTIONS 统一为 `SYMBI=N` 并配套 `POTAS=N`（非豆科政策；早期误用 `SYMBI=Y`，已于 2026-07-20/21 统一修正，见 `docs/CHANGELOG.md`）。`FRCNOD` 在 `src/common/param_registry.py` 中保留 (0, 1) 物理域作为窄幅 SA 探测，不作为固定排除参数。来源修订必须创建新 bundle，并通过 `derived_from_bundle` 与 `derived_from_manifest_sha256` 保留证据链。
