# E02 三季默认初始氮率定重规划与协作交接

## 技术摘要

新的正式研究分支统一使用三季 FileX 初始矿质氮 `SNO3=1.0`、`SNH4=0.5`，
但不重复此前“只改初始氮、不显式约束氮响应”的方案。新配置采用 62 个可调参数
（55 个三季共享参数、7 个 25FA 有效偏移量），将干重采收总预算 2.50 拆分为
绝对产量 1.75 和同水分水平氮响应 0.75，并使用修正后的
`ln(CHPDT+1)_Nk - ln(CHPDT+1)_N0` 作为氮响应目标。

当前唯一有效配置为：

- 输入权威清单：
  `configs/runs/e02_three_season_defaultn_input_authority_v1_20260730.json`
- 多季设计：
  `configs/runs/eggplant_e02_joint62_three_season_defaultn_nresponse_v2_20260730.json`
- 冻结参数域：
  `eggplant_e02_joint62_defaultn_replan_v1_20260730`
- 启动器：
  `tools/calibration/run_e02_three_season_defaultn_replan.py`
- 一键正式运行：
  `tools/calibration/start_e02_three_season_defaultn_replan_150x5.cmd`

20×1 实际并行烟雾率定已通过工程门：三季共 34 个 DSSAT treatment-run、
62 个可调参数、1,448 个进入 Phi 的观测，其中 114 个为氮响应对比；最小 Phi
从第 0 轮 5801.53 降至第 1 轮 2409.94。该结果证明输入、参数、观测、权重和
并行执行契约能够闭环；小样本结果不用于评价正式拟合能力。

## 历史证据支持“默认氮 + 显式响应约束”，而不是再次照搬旧默认氮版

| 历史批次 | 关键设置 | 结果或启示 | 对新配置的影响 |
|---|---|---|---|
| `e02_joint62_m1_offsets_plantn_slpf_150x5_20260729_v6` | 25SP+25FA；Plant-N、SLPF、秋季偏移 | 为多目标联合率定提供了较稳定的 55+7 参数骨架 | 保留 62 参数结构与秋季有效偏移 |
| `e02_joint62_moisturefix_touchrelax_harvest250_150x5_20260729` | 修正 25SP 果实含水率；干采收预算 2.5 | 证明修正观测和提高干产量预算有效 | 继续使用修正后的 25SP TMT，干采收总预算保持 2.5 |
| `e02_joint62_three_season_nstfac050_rhght035_150x5_20260730` | `NSTFAC` 下界 0.5；`RHGHT` 下界 0.35 | 产量可拟合，但水氮响应仍弱；单独抬高 NSTFAC 不足以解决问题 | `RHGHT` 保留 0.35；`NSTFAC` 恢复 0.10 |
| `e02_joint62_three_season_defaultn_150x5_20260730` | 三季默认初始氮；没有显式 N-response 目标 | 最佳 Phi 1558.10；累积干产量 RRMSE 58.54%、NSE 0.096；RTNO3 100% 上触边、NSTFAC 97.3% 上触边 | 旧版仅作为反事实压力测试，不再作为正式模板 |
| `e02_spring_pair_histbest_4corner_150x5_20260730_v4` | 两春季四角处理；RTNO3/RTNH4 下界放宽；修正后的 N-response | 工程和科学实现正确，但最优解 N3−N0 仍接近零 | 保留 RTNO3/RTNH4 下界 0.003/0.001，同时必须让响应目标进入 Phi |
| NSTFAC 10 点剖面 | 最佳参数组上只改变 NSTFAC | N3−N0 对 NSTFAC 变化很小 | 不再用提高 NSTFAC 下界替代目标函数设计 |

旧的两个三季 N-response 对比版本生成于模拟响应尺度实现仍不正确的阶段。审计发现
`PestHarvest.OUT` 中 CHPDT 已按策略写成 `ln(y+1)`，响应模块却又执行了一次
`log1p`，形成双重变换；现已改为对两个已变换 token 直接相减。该尺度错误已在
`src/calibration/nitrogen_response.py` 修复并由专门单元测试锁定。修复前的响应目标结果只能保留作工程历史，
不能用于判断“观测形状”和“无过量氮减产”哪一个科学假设更好。

## 正式率定详细配置

### 试验与参数结构

| 项目 | 正式配置 |
|---|---|
| 季节 | 25SP、25FA、26SP 均为 calibration |
| 处理 | 25SP：2、3、4、5、9、10、11、12、13、14；25FA/26SP：1–12 |
| 规模 | 150 realizations × 5 IES iterations |
| 并行 | 6 agents |
| 随机种子 | 20260730 |
| 共享参数 | 55 个遗传、生理、根系氮水过程及 `SOIL_SLPF` 参数 |
| 秋季偏移 | `DLFMAX_AUT`、`DSLAVR_AUT`、`DXFRT_AUT`、`DSFDUR_AUT`、`DTB1_AUT`、`DTB2_AUT`、`DTB3_AUT` |
| 固定项目约束 | `FL-VS=100`；ADAP 永久 diagnostic-only；MDAP diagnostic-only |
| SLPF | 0.90–0.96 |
| 关键放宽 | `RHGHT=0.35–2.20`；`RTNO3=0.003–0.05`；`RTNH4=0.001–0.05` |
| NSTFAC | 0.10–1.00，不再强制下界 0.50 |

秋季偏移量是 25FA 的有效环境/季节修正，不解释为茄子品种遗传系数。报告结果时，
必须同时给出共享遗传参数和经偏移投影后的 25FA 有效参数。

### 观测、变换与目标族

| 目标族 | 内容 | 预算 |
|---|---|---:|
| PHENO | PDAP；ADAP、MDAP 仅诊断 | 0.10 |
| CANOPY | LAID、LAIX | 1.00 |
| BIOMASS | LWAD、SWAD | 1.00 |
| PLANT_N | SNAM、LNAM；不计算 CNAM | 1.00 |
| SOIL_WATER | 初始日期之后的审计土壤体积含水率 | 1.00 |
| HARVEST_DRY | `ln(CHPDT+1)` 与 `ln(HPODW+1)` 的绝对拟合 | 1.75 |
| N_RESPONSE | 同水分水平 N1/N2/N3 相对 N0 的 `ln(CHPDT+1)` 差值 | 0.75 |

HARVEST_DRY 与 N_RESPONSE 合计仍为批准的 2.50，不因增加采收日期或对比数而线性
扩大总权重。每个季节、目标族的预算在构建时按有效观测数静态归一，IES 全程不做
动态重平衡。

正式主版本使用 `response_target=observed_shape`，即保留实测 N1/N2/N3 相对 N0
的差值，不预设过量氮必然减产。若后续比较“DSSAT 不能模拟氮富裕抑制”的假设，
只需用同一启动器切换为 `--response-target monotone_plateau`；其余输入、参数域、
随机种子和权重必须保持不变，才能构成有效对照。

### PEST++ IES 设置

- `ies_use_approx = false`
- `ies_lambda_mults = 0.5,1.0,10.0`
- `lambda_scale_fac = 0.9,1.0`
- `ies_enforce_bounds = true`
- `bad_phi_sigma = 1e300`
- `noptmax = 5`
- `ies_num_reals = 150`

## 工程门和科研判据

构建门要求：

1. 三季 manifest、FileX、TMA、TMT 哈希与输入权威清单完全一致；
2. 每个 FileX 初始矿质氮行均为 `SNO3=1`、`SNH4=0.5`；
3. 可调参数恰为 62，ADAP/MDAP 不得进入 Phi；
4. N-response 有 114 条有效对比，三季各自共享 0.75 静态预算；
5. 绝对干采收三季各自共享 1.75 静态预算；
6. 所有 DSSAT runs 成功，PEST++ 结束状态为 `engineering_validated`。

正式结果不能只报告最小 Phi。至少必须输出：

- 最优实际 Phi 成员和末轮中位数代表解；
- 三季分层及总体的 RMSE、RRMSE、NSE、R²、Bias；
- CHPDT、HPODW、LAID、LWAD、SWAD、CHTD、SNAM、LNAM、SOIL_WATER；
- 高水和低水下 N3−N0、N2−N0、N1−N0 的实测/模拟对比；
- 参数后验中位数、5%–95% 区间和上下触边比例；
- `PlantN.OUT`/`SoilNi.OUT` 的 NSTD 持续时间、植株吸氮、土壤矿质氮消耗工程门。

如果绝对产量改善而氮响应仍接近零，不应继续通过扩大一般生长参数边界来追 Phi；
应先检查 RTNO3、RTNH4、RTEXF、NSTFAC、NMOBMX、NVSMOB、NRCVR 和 SLPF 的后验
移动及 NSTD 过程，再决定是否进入小型氮子空间率定。

## TMA/TMT 清理决定

已删除：

- `xxql2502_actual_trial_calibration_v3_page25_20260728/XXQL2502.TMA`
- `xxql2502_actual_trial_calibration_v3_page25_20260728/XXQL2502.TMT`

这两份文件生成于 25FA 完整生长观测补入之前；旧 TMT 只有 6,481 bytes，
缺少后续测定日期和处理，旧 TMA 的终点 LAI、叶干重和茎干重也不是当前权威值。
同目录保留 `SUPERSEDED_OBSERVATIONS_DO_NOT_USE.md`，而历史 PAGE=25 FileX 仍作为
管理修订证据保留。

其他旧 bundle 的 TMA/TMT 暂不物理删除，因为已有历史运行清单和脚本引用它们，
删除会破坏历史复现。它们被定义为“历史快照”，不是当前真值。新率定只能从输入
权威清单解析三份 `special_defaultn` bundle；这在不破坏证据链的同时实现了运行时
唯一真值。

## 局限与后续问题

统一默认初始氮是一个明确的模型假设，不是对三季实测初始氮的恢复。它会把更多
差异交给施肥管理、根系吸收、土壤供氮和 SLPF 解释，因此可能增强参数代偿。
上一默认氮版本已经显示 RTNO3、NSTFAC 的强触边风险。新目标函数能让“氮响应形状”
进入优化流形，但不能保证 DSSAT 的结构足以同时描述氮亏缺和氮富裕抑制。

正式 150×5 完成后优先回答三个问题：

1. N-response 预算是否使模拟 N3−N0/N2−N0 明显接近实测，而没有显著牺牲三季绝对产量？
2. RTNO3、RTNH4、SLPF、NSTFAC 是否仍发生集中触边，提示默认初始氮与模型供氮过程冲突？
3. 25FA 七个偏移量是否承担了不属于季节效应的氮过程补偿？

只有在这三项审查完成后，才适合冻结下一版参数域或扩大正式运行规模。
