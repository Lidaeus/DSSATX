# E02 v37 氮响应多臂试验结果与 v38 正式率定设计（2026-08-29）

## 1. 结论先行

五个局部 PEST-IES 臂 A–E 均正常完成，但**没有任何成员通过预先声明的全部科学门槛**，因此不满足构建组合 F 臂的条件，也不应把任何一臂直接晋级为正式率定起点。配置审计还发现：实际 C/D/E 错误沿用了 λ=2，而原设计只有 B 应把 λ 从 1 提高到 2；因此 C/D/E 是“参数族 + 权重”的混合对照，其机理归因只能作为探索性证据。

最关键的否决证据有三项：

1. 五臂最终集合共 300 个成员，`25SP` 两个末次 `N3-N0` 同时为正的成员数为 **0**；
2. `26SP` 全部氮响应收获节点的绝对误差（SAE）相对 v37 第 3 轮成员 137 降低至少 30% 的成员数为 **0**；
3. C、D 臂虽能明显改善部分氮响应层，却以累计鲜产量尺度退化为代价；E 臂能保持产量、LAI 和水分响应，但几乎不能改善氮响应。

因此，本轮证明的不是“某个氮参数族已经解决问题”，而是：**仅靠局部氮参数或提高 N_RESPONSE 权重，无法同时纠正 25SP 氮响应方向、26SP 氮响应幅度和总体产量尺度。** 25SP N0 处理的供氮/胁迫链必须先完成输入与机理审计。

### 2.2 指标复算口径

- N_RESPONSE：按“季节 × 水分层”分别计算 NSE，四层分别为 `25SP-W3`、`25SP-W1`、`26SP-W3`、`26SP-W1`；
- W_RESPONSE：按“季节 × 氮水平”分别计算 NSE；
- `26SP` 绝对误差降低率：对两个水分层、全部收获节点的 `|SIM-OBS|` 求和后，相对锚点计算；
- 末次氮响应：按数值收获序号确定末次，不能按字符串排序 `H1/H10/.../H9`；
- 响应差值允许为任意负值，不能把小于 -99 的合法差值误判为 DSSAT 缺测值；
- 全 22 处理确定性复跑使用“成员 137 完整参数向量 + 本臂后验参数覆盖”。PEST 的 `.par.csv` 只含本臂激活参数，不能单独作为完整复跑参数集。

最后一项是本次复核发现并已在分析脚本中修正的重要复现陷阱。未合并完整锚点的首轮复跑结果已弃用，正式引用目录带有 `fullanchor` 标识。

### 2.3 发现的试验配置偏差

原始设计是 A 使用 λ=1、B 仅改变权重为 λ=2、C/D/E 分别只改变参数族并保持 λ=1。实际生成器 `setup_v37_nitrogen_multiarm_20260829.py` 却把 B/C/D/E 全部设成 λ=2，且运行注册表证实实际值确为 2。因此：

- A 与 B 仍是有效的权重对照；
- C/D/E 不能与 A 做严格单因素因果比较；
- C/D/E 的“能力上限”和“未通过硬门槛”仍然有效，但不能把变化量全部归因于相应参数族；
- 历史配置和运行目录保持不改，以保护溯源；生成器已修为未来 C/D/E 使用 λ=1；
- 正式率定前应以 λ=1 纠正重跑 C′/D′/E′，仍按 60×3、6 agents 即可，不需要重跑 A/B。

## 5. 因果解释

1. **局部参数并非完全无效。** C/D 能让 3–4 个 N_RESPONSE 层改善，说明吸收触发、蛋白需求和氮动员确实控制响应形状。
2. **但 25SP 方向错误不是局部曲率问题。** 300 个最终成员均不能使两个末次差值为正，表明当前输入下 N0 处理没有形成足够氮限制，或者氮限制被土壤供氮、残体矿化、根区供氮或源库补偿抵消。
3. **权重不是主因。** B 把 λ 加倍后没有成员达到 30% 误差降低，反而累计鲜产量下降。
4. **存在明确目标冲突。** C/D 的最佳氮响应候选让 25SP 校准累计鲜产量 NSE 从 0.778 降至约 0.68，验证 NSE 从 0.732 降至约 0.62；这类候选不能晋级。
5. **需要源库容量共同缓冲，但不能未经诊断直接组合。** E 证明叶氮—光合曲线可以维持尺度；早期边界诊断又提示 `WTFSD`、`SFDUR`、`PARMAX`、`XFRMAX` 等可能限制尺度补偿。正式设计应保留这些参数的合理自由度，但在 25SP 供氮链解释清楚前不启动。
