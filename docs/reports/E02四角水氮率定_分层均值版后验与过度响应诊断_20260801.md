# E02 四角水氮率定：分层均值版后验与过度水氮响应诊断

日期：2026-08-01  
比较对象：

- 原始初始条件版：`e02_wnstress_fourcorner_formal_200x5_20260801_080700`
- 分层均值版：`e02_wnstress_fourcorner_layermeanic_formal_200x5_20260801_114300`

## 结论先行

分层均值版确实恢复了明显的水氮响应，但当前响应偏强，且后验显示模型通过多组边界代偿实现该响应。分层均值版末轮最小实际 Phi 为 375.390（成员 78），原始初始条件版为 153.202（成员 179）；两者 Phi 不能作为严格同口径优劣比较，因为前一版实际运行存在 FileX 路径回退风险，后一版使用了反事实初始条件。

本轮不建议继续放宽边界，也不建议把分层均值版直接作为正式遗传参数结果。建议下一轮先使用修复后的运行链，以处理特异初始条件重新率定，并对 RTNO3、RTNH4、RWUMX、NSTFAC 等过强方向实施阻尼边界。

## FileX 初始氮核查

核查了分层均值 bundle、正式运行 agent-01 沙箱 FileX 以及 bundle manifest。两季均正确写入 5 个土层、每层所有 IC 组相同的固定宽度值：

| 季节 | 20 cm | 40 cm | 60 cm | 80 cm | 100 cm |
|---|---|---|---|---|---|
| 25SP | SH2O 0.21871；SNH4 1.6357；SNO3 47.30 | 0.26786；1.0857；18.771 | 0.30121；0.9357；7.9571 | 0.31371；0.5；1.0 | 0.30129；0.5；1.0 |
| 26SP | SH2O 0.20885；SNH4 3.1692；SNO3 33.531 | 0.26315；1.8000；29.023 | 0.27223；1.4692；11.108 | 0.31400；0.5；1.0 | 0.30462；0.5；1.0 |

每季分别为 25SP 70 行、26SP 65 行，正式运行沙箱 FileX 与输入 bundle 的逐字节哈希一致。固定宽度切片读取后，`SH2O/SNH4/SNO3` 与 manifest 层均值完全一致。因此本轮过度响应不是“均值没有写入”或“氮字段错位”造成的。

需要注意：均值是对该季节 FileX 中**全部 IC 组**计算的，不仅是四个参与率定的处理。25SP 20 cm 的高值受 IC15 原始 SNO3=196.0 影响，均值升至 47.30；这使该版本是反事实敏感性试验，而不是实际处理特异初始条件。

## 建议的下一轮方向（待批准）

### 推荐方案：修复路径后的实际初始条件版

1. 使用原始处理特异 FileX，不再使用分层均值版作为正式参数来源。
2. 保留修复后的 `run_multiseason.py` 输入物化与 FileX 哈希审计。
3. 不再放宽非水氮参数；若仍出现高触边，再考虑固定 `ATOP、KC_SLOPE、NSLOPE、SIZREF、TO13、TB1、PARMAX` 中的代偿参数。
4. 对水氮参数采用阻尼边界：

| 参数 | 建议下一轮范围 | 目的 |
|---|---:|---|
| RTNO3 | 0.005–0.030 | 保留历史 v24 高响应方向，但阻止本轮上界堆积 |
| RTNH4 | 0.003–0.030 | 保留铵态氮响应，避免过强吸收 |
| RTEXF | 0.030–0.200 | 保留当前有效区间，不再扩大 |
| RWUMX | 0.020–0.080 | 压回本轮过高吸水方向 |
| NSTFAC | 0.30–0.80 | 避免固定因子直接触及 1.0 |
| DSWBAR | 15–30 | 避免水分感知深度贴近表层下界 |
| PORMIN | 0.010–0.060 | 恢复原下界，减少根系低孔隙补偿 |
| SENDAY | 0.005–0.080 | 恢复原下界，避免极慢衰老放大冠层 |
| CMOBMX | 0.005–0.040 | 减少碳储备对产量的代偿 |
| SOIL_SLPF | 0.90–0.96 | 暂不改变，当前最佳值位于内部且非主导触边 |

### 运行判据

- 首先检查 N3−N0 与 W1−W3 的响应方向和幅度是否同时合理；
- 其次看 `RTNO3、RWUMX、NSTFAC` 是否不再大比例贴上界；
- 若仍过度，优先收紧 NSTFAC/RWUMX，而不是继续调整源库或冠层参数；
- 若响应消失，再单独放宽 RTNO3 或 NSTFAC，避免多参数同时释放。

本建议尚未执行新的边界修改或率定。
