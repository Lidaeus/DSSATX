## TN2 与土壤风险

TN2 使用 FileX 中的 `IC=2、MI=1、MF=1` 组合；其中 MI=1 与 TN3 共享，但 IC2 和 MF1 对当前批次是 TN2 特有组合。尚不能区分初始条件、施肥、灌溉/采收状态或其交互贡献，禁止据此修改真实试验数据。

DSSAT 失败工件还持续报告：

- 145、175、203 cm 层 `SSKS` 缺失；
- 同三层 `SLCL/SLSI` 缺失；
- DSSAT 对缺失纹理采用默认 30%黏粒、30%粉粒、40%砂粒，并提示可能产生错误结果。

这些缺失不是 TN2 专属，也不能单独解释崩溃，但会影响水氮过程与论文方法可追溯性。输入校验现将其作为显式 warning；在正式 P1 前应由数据负责人决定补充实测/有依据的推定值，或明确接受并记录 DSSAT 默认假设。
