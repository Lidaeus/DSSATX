## 1. 审查结论

T6 可以作为当前候选池，但不能把其中 23 个参数直接全部释放到率定。敏感性回答“参数变化是否会影响输出”，不能单独证明参数能被现有观测辨识；春秋敏感性比值较大也不能推出“必须率定”，尤其当分母接近零时，比值会被放大。

本方案建议：

1. 敏感性筛选先排除模型定义明确不适用于茄子/番茄的 `PM06`，再分别在 `general_genetic` 与 `water_nitrogen_response` 域内累计到 90%，最后取并集；当前得到 17 个主率定候选；
2. 17 参数全部进入正式联合主率定，但按物候温度、冠层分配、根水氮三个块先做低成本工程诊断；分块结果不作为正式后验，也不自动缩界；
3. XXQL2501 与 XXQL2502 使用实际初始水分、矿质氮和实际管理进行联合率定；XXQL2601 整季封存为独立验证；
4. S1–S3 只做小规模分块工程诊断，正式条件参数集合来自一次全新、联合的 S4，不继承分块后验，避免重复使用数据和丢失跨过程参数协方差；
5. 正式 S4 默认关闭相对高 Phi 剔除，只排除可追溯的模型/解析失败；
6. 后验分析坚持“最小充分集”：边际收缩和边界、prior/posterior Spearman、2–3 对候选解的确定性预测距离，以及只生成、不自动应用的边界/约束审查建议；不扩建自动聚类、t-SNE 或通用 PCA/VIF 平台。

## 3. T6 的采用与修正

### 3.1 保留的结论

- 三季受控反事实 Morris 可用于筛选跨季敏感候选；
- `TRIFL, RTNO3, XFRT, LFMAX, XFINT` 是当前最稳定、最值得优先审查的参数；
- `FL-VS, KC_SLOPE, PARMAX, PHTMAX, PL-EM, PM09, RTEXF, WTFSD` 在当前试验期输出上结构性零敏感，应固定；
- `SOIL_*` 与 `IC_*` 在遗传参数主率定中固定为实测值；
- 结构约束、安全边界和非豆科 `FRCNOD=0.05` 继续保留。

### 3.2 不采用的结论

| T6 结论 | 评估 | 本方案处理 |
|---|---|---|
| 23 个参数全部进入率定 | 不成立；其中含模型定义不适用或贡献不足的参数 | 按适用参数池的双域 90% 规则选 17 个 |
| 春秋敏感性比 >2 或 >3 即必须率定 | 不成立；比值可能由近零分母、季节混杂或间接效应造成 | 只作为 G×E/稳健性讨论证据 |

| 水氮敏感参数都应进入遗传率定 | 不成立；必须同时满足参数适用性和域内累计贡献规则 | 仅纳入双域 90% 并集，并对弱观测参数增加先验约束 |

### 3.3 当前证据限制

T6 记录“9/9 case、0 失败、5,017 次运行”，但本轮可见工作区中只有 XXQL2501 `r=10` 的部分 raw/audit 结果；XXQL2502、XXQL2601 的 `r=10–40` 目录目前主要是构建 manifest，尚不足以独立复算 T6 的汇总数字。因此，本方案尊重用户意见，把 T6 当作“当前可用候选证据”，但不把它标记为最终冻结的 SA 结论。

### 4.2 处理选择

所有处理角色必须按 `experiment_code + treatment` 冻结，不能仅按 TN 编号跨季推断。

## 5. 参数方案

### 5.1 双域 90% 选择规则

使用冻结的跨季 Morris 汇总，先剔除明确不适用于当前作物模块用途的参数，再分别在两个域内按归一化贡献由高到低累计至 0.90，最后取并集。禁止先混合两个域再排序，因为二者回答的问题不同。

`PM06` 在本项目 DSSAT 模板中明确标注为 `first peg (peanut only)`，故从茄子适用参数池排除。当前证据状态仍为 `science_pending`，生成结果是率定提案而不是已冻结科研结论：

| 域 | 最小参数数 | 适用池内累计贡献 |
|---|---:|---:|
| general_genetic | 14 | 0.9048 |
| water_nitrogen_response | 10 | 0.9018 |
| 两域并集 | 17 | — |

17 参数为：`TRIFL, XFRT, RTNO3, LFMAX, XFINT, FRLFF, NMOBMX, EM-FL, EM-V1, FL-SD, TB2, TO11, TO12, TO22, RTNH4, FRSTMF, NVSMOB`。机器可读清单位于 `configs/calibration/t7_90pct_candidate_20260721/`。

### 5.2 参数块与证据强度

| 参数块 | active 参数 | 主要约束 | 风险处理 |
|---|---|---|---|
| P 物候/温度 | `EM-FL, EM-V1, FL-SD, TRIFL, TB2, TO11, TO12, TO22` | ADAT、LAI 时序、跨季温度；温度响应文献 | 温度系数保持阶段内严格有序；缺少直接阶段观测者使用较强先验 |
| C 冠层/分配/根水 | `LFMAX, XFRT, XFINT, FRLFF, FRSTMF` | LAID、LWAD、SWAD、增量采收、水分处理响应 | FRLFF/FRSTMF 无根系直接观测，不能把后验收缩单独解释为真实根系参数 |
| N 吸收/再分配 | `RTNO3, RTNH4, NMOBMX, NVSMOB` | 四氮水平响应、XXQL2501 CNAM、XXQL2502 SNAD/LNAD diagnostic | RTNH4/NMOBMX/NVSMOB 使用外部/模型先验，重点审查补偿和边界堆积 |

当前 v3 边界只是已批准的安全候选起点。尤其 `LFMAX` 初值位于候选下界、`XFRT` 初值位于候选上界，正式 S4 必须使用独立受界先验样本并单独保存原始 base realization，不能让边界位置被误读为数据支持。

### 5.3 外部证据与边界规则

文献可以支持过程方向、物理温度包络和弱先验，但多数 DSSAT 内部系数没有可从实测量直接换算的茄子专属范围。采用三级证据：A 为茄子直接生理/物候证据，B 为 DSSAT/CROPGRO 参数定义与同模块作物范围，C 为当前模型安全边界。只有 A/B 与 C 的交集可形成新的数值边界提案；仅有敏感性或后验形状不得自动缩界。

温度参数必须满足：固定的 `TB1 < TO11 < TO21 < TM1`，以及 `TB2 < TO12 < TO22 < TM2`。其余弱观测参数优先使用独立先验或固定较低证据参数，不增加人为伪观测。具体证据、当前范围和限制见《T7 参数先验与观测审计》。

### 5.4 明确不纳入

- `PM06`：模板明示 peanut only；其非零敏感性作为模型适用性警报，不作为茄子率定依据；
- 适用池内未达到双域 90% 并集的参数：保持 fixed，保留诊断，不因单季比值或漂亮后验图临时释放；
- 土壤和初始条件：主遗传参数率定中使用逐处理实测值，不与遗传参数共同补偿。

## 6. 观测、sigma 与 Phi 契约

### 6.1 进入 Phi 的最小观测集

| 组 | 主观测 | 规则 |
|---|---|---|
| phenology | ADAT | 若同一季所有处理只是复制同一个日期，只计一个季节级观测；有独立处理观测证据时才逐处理计入 |
| canopy_biomass | LAID、LWAD、SWAD | 使用 FileT 的 DAP45/67/95/119；DAP0 作为初始状态诊断，不进入 Phi |
| plant_n | CNAM | 使用 FileT 多时点总植株氮；LNAM/SNAM 暂作 diagnostic，只有扩展 NMOBMX 时再进入正式设计 |
| harvest_increment | HPODW | 以每次增量干物重为正式采收目标 |

DAP67/95/119 不进入此前的 SA 点目标，是为了避免任意日期主导敏感性结论；它们作为真实、稀疏的过程观测，对率定生长轨迹仍有价值。SA 与 calibration 的目标定义不应混为一谈。

### 6.2 不进入 Phi 的派生/重复量

- FileA 的 LAIX：若由 FileT LAID 最大值派生，只作 diagnostic；
- FileA 的 CNAM：若等于 FileT 末次 CNAM，只作 diagnostic；
- FileA 的 HWAM 与 FileT 累计干重 CHPDT：由增量采收求和或近似派生，只作 diagnostic；
- CHPDT 累计采收：用于曲线和守恒检查，不与 HPODW 同时计权；
- MDAT/HDAT：在定义和实测来源未审计前不作为物候率定目标。

### 6.3 处理均值与 sigma

FileA/FileT 继续保存处理均值，不必把重复逐行塞入 DSSAT 文件。重复原始数据应保存在独立、版本化的原始表中，并为每个 `season+treatment+date+variable` 冻结：`n_rep, observed_sd, observed_se, sigma_source`。

正式权重继续使用：

```text
sigma_eff = sqrt(observed_se^2 + model_sigma^2 + sigma_floor^2)
weight = group_multiplier / sigma_eff
```

- 有重复时：`observed_se = observed_sd / sqrt(n_rep)`；
- 无重复时：使用预先批准的 assumption-based sigma，并明确标记，另做一次 sigma 稳健性运行；
- 各主要组 `group_multiplier=1.0`，不启用 pwtadj1，不按运行后的组 Phi 回调权重；
- 若用户希望适度强调增量采收，只做预先登记的 `harvest_increment=1.25` 稳健性对照，不替代主结果；
- 观测与模拟均保持原始尺度，暂不启用 log 或动态 Min–Max。

## 7. 率定运行设计

### 7.1 E0：输入与基线门

1. 构建两个 calibration 季节和一个 validation 季节的实际输入包；
2. 冻结 FileX/FileA/FileT、天气、土壤、批处理、处理角色、sigma 和哈希；
3. 逐季逐处理确定性基线运行；
4. 检查观测唯一键、单位、日期、累计=增量求和、NO3≤100、无 `-99/NaN/Inf` 泄漏；
5. 生成水、氮及 W×N 的实测/模拟处理对比基线。

E0 未通过时不构建正式 PST。

### 7.2 E1：S1–S3 分块工程诊断

| 阶段 | active | 观测 | 建议规模 |
|---|---|---|---|
| S1 | EM-FL, TRIFL | ADAT、LAID | 60 reals，2 iterations |
| S2 | LFMAX, RTNO3 | LAID、LWAD、SWAD、CNAM | 60 reals，2 iterations |
| S3 | XFRT, XFINT | HPODW | 60 reals，2 iterations |

这些运行只检查参数注入、响应方向、先验覆盖、模型失败和组 Phi，不产生正式后验，也不据其后验自动缩界。它们可使用相同 observation ensemble 以便比较，但结果不继承到正式 S4。

### 7.3 F1：正式联合 S4

- active：6 个主参数全部联合释放；
- calibration 数据：XXQL2501+XXQL2502 的预注册处理与观测；
- prior：独立、受界的 100 个参数 realization，固定 seed；参数间默认无先验相关；另保存原始基线 realization；
- observation ensemble：100 个 realization，独立固定 seed，并绑定 sigma 哈希；
- `noptmax=4`；先看逐轮 Phi 和参数稳定性，不因达到最大轮次自动宣称收敛；
- `ies_bad_phi_sigma=1e300`，关闭相对 Phi 筛除；
- `pwtadj1`、自动 localization、MDA、动态变换和自动参数扩展均关闭；
- 真实 DSSAT/解析失败单独记为 `model_failed`，成功但 Phi 高的成员保留为 `phi_outlier` 诊断标签。

正式 S4 必须从冻结先验重新开始，不读取 S1–S3 代表值或后验作为先验中心。这样最终 ensemble 才能用于 6 个参数的联合协方差、共线性和异参同效分析。

### 7.4 F2：独立 seed 确认

保持输入、边界、sigma、observation ensemble 和选项完全相同，只更换参数 prior seed，再运行一次 100-real S4。主运行用于报告，第二次运行只评价算法/采样稳定性，不把两个后验直接拼接。

## 8. 率定后分析

### 8.1 拟合与水氮响应

必须同时报告：

- calibration 与 validation 分开的 RMSE、MAE、bias、NRMSE；
- season×process group 的 Phi，不只报告 total Phi；
- 逐水水平的 `N3-N0, N2-N0, N1-N0` 响应差；
- 逐氮水平的高水−低水响应差；
- 在设计单元完整时报告差分中的差分 W×N 交互；不完整设计不强算交互；
- 基线、率定代表解和 validation 结果并列，避免只展示改善后的结果。

### 8.2 条件参数集合/近似后验

PEST-IES 末轮结果称为“条件参数集合”或“近似后验”，不声称严格 Bayesian posterior。对每个参数输出：

- prior/posterior mean、median、SD、IQR、5%–95%；
- IQR/方差收缩率；
- 近上下界成员比例；
- collapsed 与简单多峰提示；
- 两个 prior seed 运行的中位数和 IQR 对比。

### 8.3 参数共线性/补偿

稳定工作流只增加以下内容：

1. prior 与 posterior Spearman 相关并列；
2. `|rho|>=0.8` 标记为强经验补偿，配对散点图人工审查；
3. collapsed 或边界堆积参数先单独标记，不用其虚假相关解释可辨识性；
4. 相关性只表述为“在当前先验、观测和 IES 更新条件下的补偿”，不解释为模型全参数空间中的结构性共线性。

VIF/PCA 代码可保留为专家诊断，但不进入首轮正式用户流程；除非 Spearman 已发现难以解释的多参数补偿，否则不新增平台化功能。

### 8.4 异参同效

沿用现有、预先声明的最小接口：

1. 从末轮中筛选 Phi 位于 best+5% 内、标准化参数距离大于全体配对中位数的候选；
2. 选最多 3 对且 realization 不复用；
3. 逐 realization 用其真实 ensemble 行参数确定性复跑，不用参数中位数替代；
4. 在 validation/diagnostic 观测上按 `sigma_eff` 计算 prediction distance；
5. 只有 Phi 接近、参数远且 validation/diagnostic 预测也接近时，才支持“功能性异参同效”；否则只是 calibration 补偿解。

不进行自动聚类，也不为了得到漂亮分群而删除高 Phi 成员。

## 9. 科研质量门

正式结果进入后验和论文出图前，至少满足：

1. 所有输入、边界、处理角色、sigma、随机 seed 和命令均有哈希；
2. 无未解释的 DSSAT/解析失败；任何成员退出均有唯一原因；
3. prior predictive 覆盖、逐组 Phi 和逐季残差已经审查；
4. calibration 与 validation 指标严格分开；validation 未参与参数选择、权重修改或停止判断；
5. 关键水氮处理对比相对基线改善，且没有以牺牲物候/冠层过程为代价换取产量拟合；
6. 边界堆积、坍缩、强相关、多峰和 seed 敏感性全部披露；
7. 代表解确定性复跑可复现，候选异参同效解复跑完成；
8. 只有机器证据齐全后才允许 `science_validated`，否则保持 `science_pending`。

边界比例、相关阈值和收缩率首先是预警，不机械充当“通过/失败”结论。最终科研判断应结合参数含义、观测支撑和 validation 表现。
