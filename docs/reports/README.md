## 新报告规则

- 新运行报告可先写入本目录，但阶段结束后必须归档。
- 文件名中的“正式”不等于 `science_validated`；科研状态以 manifest、质量门和决策记录为准。
- 报告记录当时发生了什么，不自动成为当前配置、参数范围或运行命令的权威入口。
- 对论文有长期价值的方法定义应合并到根目录的材料与方法、讨论或图表规范，不能长期散落在运行报告中。
