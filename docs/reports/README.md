- 文件名中的“正式”只描述当时的运行命名；最终状态以报告更正、run manifest 和 finalize 为准。
- 失败报告和早期审查保留原文，便于定位为什么形成当前门禁。
- 当前 T3/T4 产物仍为 `tooling_development / science_pending`，不得因为存在完整报告而升级为科研结论。
