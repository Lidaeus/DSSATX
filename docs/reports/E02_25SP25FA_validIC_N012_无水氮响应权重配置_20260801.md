# E02 25SP+25FA 有效 IC、N0–N2、无水氮响应权重配置

## 配置结论

- 率定季节：25SP（XXQL2501）与 25FA（XXQL2502）；26SP 仅同步生成有效 IC 包，暂不进入本轮率定。
- 处理筛选：25SP 保留 TN3、TN4、TN5、TN9、TN11、TN12、TN13、TN14；25FA 保留 TN4、TN5、TN6、TN7、TN8、TN9、TN10、TN11、TN12。上述处理均为 N0、N1 或 N2；N3 处理不进入观测目标。
- 处理映射核对：25SP 的保留集合对应 W3-N2/1/0、W2-N0、W1-N2/1/0 与 CK-N2；25FA 的保留集合对应 W3/W2/W1 的 N2、N1、N0 组合。该映射来自各季 FileX 的 MI/MF 因子，不按跨季 TN 编号推断。
- 初始条件：25SP 以 IC2–IC13 计算各层 SH2O、SNH4、SNO3 均值，删除错误的 IC15；保留 IC14 但使用同一有效子集均值。25FA 与 26SP 仅保留 IC1–IC12，超过 IC12 的 IC 块不使用。
- 目标函数：保留物候、冠层、生物量、植株氮、累积/单次干重采收和土壤水分；不生成 NRESP/N_RESPONSE 派生观测，不分配水氮响应预算。ADAP 继续永久排除，MDAP/CNAM/鲜重仅诊断。
- 采收变换：CHPDT 与 HPODW 使用 `ln(y+1)`；结果报告必须回到原尺度。
- 初始集合：Sobol；正式规模 200 realizations × 5 IES iterations；6 个并行 agent。
- 参数范围：使用冻结边界 `eggplant_e02_wnstress_fourcorner_layermeanic_v1_20260801`。该边界包含 64 个共享参数与 7 个 25FA 偏移参数，共 71 个可调参数；设计文件名中的历史 `joint61` 不代表实际可调参数数目。
