原表全氮mg/g转换为百分数时除以10，例如20 mg N/g干物质=2.0%，不能当成20%。观测均值取各原始样品浓度的平均，不由“平均器官氮量÷平均器官干重”反推，以免改变均值的统计定义。处理均值只建立一条模型观测，原重复用于估计离散性。

茎叶器官氮量满足N量=干物质量×氮浓度，若再与两项基础观测一起独立加权，会重复利用同一测量并忽略误差相关性。因此SNAM/LNAM保持可追溯的诊断目标；可以审核选择“器官N量＋干重”作为替代方案，但不要同时再加入相同日期的浓度。缺少根氮量与枯落物氮不能把茎叶和采收果氮的简单和称为全株累计吸氮量。

果实干物质量采用**采收事件增量**而非在株PWAD，更不能拿累计采收CHPDT配当天果实浓度。春季HPODW仍是鲜产量×实测含水率插值所得的派生观测，包含插值和端点保持误差。秋季干产量是鲜产量×5%的条件估算，跨季验证必须同时报告鲜产量实测指标，并注明干产量并非独立直接称量。

累计CHPDT/CHFPW、单次鲜产量HFPOW、直接干物质比例PDMCD和氮量保留作诊断。当前主方案只对单次干产量加权，累计终值和累计轨迹不再重复进入Phi。若更关注实测鲜产量，可审核选择“单次鲜产量＋直接测定干物质比例”为另一套目标；不把两套不加说明地叠加。

水氮效应由9个完整处理的原始目标共同识别。N2–N0、N1–N0、W3–W1差值及N2/N1比值作为结果诊断，不另建独立目标，避免重复计权。定植初始水分只用于输入，2026年10月2日秋季土样继续排除在当季验证之外。

## 3. 果实氮目标：已确认取样口径与模型对应

2026-10-11用户补充：“果实全氮测定使用的是测定果实品质时采摘成熟果实，切去一半测定品质，剩下一半烘干后磨粉称样测定。”已记录到`fruit_sampling_definition.json`。据此采用成熟采摘果、干样浓度的口径。取样说明未提去皮或去籽，本方案将剩余半果作为成熟果组织的代表样品；这一代表性是观察算子的假设，不是已证明两半在氮浓度上完全相同。若实际另有去皮/去籽等步骤，应再修正。

**浓度不乘2。** 原表mg N/g干样仍除以10转换为干基百分数。取半果影响样品覆盖和代表性，不改变浓度单位；也不把该浓度乘累计产量构造累计果氮。果实干物质量目标继续来自实际采收产量和干物质比例。

本机实际使用DSSAT 4.8.5.000。最新输入完整试运行中，PlantN.OUT包含LN%D、SN%D、CNAD、VNAD、GNAD、GN%D和SHND，**没有FRN%D/FRNAD**。新版官方源码虽增加了这些列，本机可执行程序的实际表头才是本次可用接口。SHND输出的是果壳组织氮浓度PCNSH，**不是kg/ha的果实氮量**。GNAD/GN%D是种子组织，不能直接代表完整茄子果实。

官方[OPGROW源码](https://github.com/DSSAT/dssat-csm-os/blob/25c93b9a2f73f8ec45bf441b198dac5fb7b22849/Plant/CROPGRO/Opgrow.for)显示，在株全果氮量由CNAD−VNAD得到，并按果实干重计算全果浓度。公式

`c_fruit_live(%) = 100 × (CNAD − VNAD) / PWAD`。

给的是**全部在株果龄**的平均浓度，不能直接对应本次成熟采摘果样。本方案不再用它作为果实氮率定的模拟值，仅保留用于区分输出语义。两个0.1 kg/ha精度的氮量相减还会放大低果实量时的舍入误差。

本次推荐按实际品质/氮取样日对应**商品成熟果**，使用模型成熟果种子/果壳干重MTDSD、MTDSH，与相应组织氮浓度配对：

`c_fruit_mature_proxy(%) = (GN%D × MTDSD + SHND × MTDSH) / (MTDSD + MTDSH)`。

这是模型组织平均浓度假设下的成熟果代理，**不是每个果龄cohort独立的氮浓度**。[GROW源码](https://github.com/DSSAT/dssat-csm-os/blob/25c93b9a2f73f8ec45bf441b198dac5fb7b22849/Plant/CROPGRO/GROW.for)对采收氮移除也使用种子/果壳组织平均浓度；[FreshWt源码](https://github.com/DSSAT/dssat-csm-os/blob/25c93b9a2f73f8ec45bf441b198dac5fb7b22849/Plant/CROPGRO/FreshWt.for)用达到XMAGE的果龄组组成成熟果库。本次采样日为6月3日、6月24日、7月2日，与产量表的批量采收日不完全一致，按真实采样日取值，不替换成最近采收日、不增加无产量测量的采收事件。

现有基线输出中27条记录的真实日期均有成熟果干重和上述代理值；`nitrogen_output_readback.csv`已改为这个成熟果代理。前一版采用全部在株果实平均浓度，仅证明输出可读取，不能代表本样品的拟合目标。`fruit_semantics_candidates.csv`保留前一天数值作相位诊断，`selected_for_review_proxy`仅选择真实采样日。这次更新不宣称已经完成最终输出相位验证：正式adapter还须验证跨文件状态时点、打印精度、XMAGE成熟标准与商品成熟样品的对应，并在任何候选参数导致采样日没有成熟果时明确报错或记录模型失败，不能跳过该观测、改用全部在株果或自动移动日期。

用户的补充已经解决本轮果实取样定义问题，**无需重复询问成熟度或干基**。27条成熟果浓度现在作为草案主要目标分配建议权重，合计423条；整套设计仍为`awaiting_user_review / executable=false`。若正式前无法验证这个代理，应提交果实氮暂作诊断或增加所需模型输出的替代方案，由用户审核后选择，不能静默删除。

## 5. 误差、权重和运行阶段

全部主要目标采用原始物理尺度。暂建议：

`sigma_eff = sqrt(SD²/n_eff + floor² + (CV_model × |observed|)²)`。

采用保守的n_eff=1，不把3个样品立即当成3个独立小区以获得过小SE；秋季4个编号样品仍只描述离散性。SD来自当前重复，floor及CV_model是**待审核的误差假设**，不是检测仪器证书或从某次残差反推的权重。

|目标族|相对预算B|绝对误差floor|模型/尺度CV|
|---|---:|---:|---:|
|LAI|1.00|0.05|10%|
|叶干重|0.75|20 kg/ha|15%|
|茎干重|0.75|25 kg/ha|15%|
|株高|0.25|0.03 m|10%|
|叶氮浓度|1.00|0.15个百分点|10%|
|茎氮浓度|1.00|0.15个百分点|10%|
|成熟果氮浓度代理（待预检）|0.75|0.15个百分点|20%|
|单次干采收|2.00|25 kg/ha|20%|
|土壤含水量|0.50|0.01 cm³/cm³|8%|

每个目标族内9个处理等预算，处理内各日期/层段平均分配：

`w_i = sqrt(B_family / (n_treatments × n_obs_in_treatment_family)) / sigma_eff_i`。

这把135条土样与36条器官浓度的数量差异显式平衡，也避免过去鲜产量高倍率默认压制新氮目标。预算不是运行后的实际Phi比例。它是平衡后的复合损失，存在同株时序及浓度/干重相关性，不能据此宣称独立卡方似然或无条件概率置信区间。审核时可选择更多保留检测误差而更少目标平衡，但须预声明。

推荐200成员、6个并行工作进程（每次模型成员只跑9个2026率定处理），分阶段用仅率定集的目标更新：

1. S1冠层/生长：25项候选参数，3次更新。其他模块暂固定，仍检查氮及采收是否退化。
2. S2吸氮、动员、茎叶蛋白组成：16项，3次更新。继承S1通过门检的代表值。
3. S3水分与果实形成/果氮：12项，3次更新。成熟果氮代理需先通过审核和输出相位预检。
4. 联合精修：最多使用已通过识别与注入门检的53项，6次更新。每阶段需同时在完整主目标集上复核，防止局部阶段破坏另一目标。预声明种子20261011/12/13/14，不启动随机seed竞赛后挑选验证最优者。

这只是运行设计；迭代数不等于所有模型调用总数，IES线搜索会增加调用。不能通过增加成员、自动放宽范围、自动再平衡Phi或用验证集选择迭代制造拟合改善。最终代表参数依据率定集的预声明完整复合目标选取；验证RMSE/NRMSE/d-index、分水分/氮梯度偏差与预测区间覆盖率最后报告。
