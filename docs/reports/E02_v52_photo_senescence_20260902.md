# v52：有效光合 × 冠层衰老配对试验

## 目的与预设设计（结果计算前冻结）

验证PGEFF提高有效光合后的产量增益，是否可以由适当的衰老/冠层参数调整保留，同时不明显损害两季LAI。不是氮响应问题已经解决的假设，也不启动新的大型IES。

共同对照是v49 A第3轮成员47。两季ICNS固定为0.531622、0.726747，均在用户指定0.4–0.8内；倍率作用于已有bundle，26SP bundle此前已×0.34，并保留原下限截断。所有土壤、水分、种苗、氮吸收、源库、天气、管理、观测、目标权重固定。沿用官方DSCSM048.EXE、PHOTO=L和原1432条观测指令。

第一阶段25组参数向量；根据其结果追加15组末节点微调（见下节）。每组25SP 10处理、26SP 12处理，两阶段共40组、80个季节模拟/880个处理运行。全部为确定性单向量模拟，不是后验集合，也不能视作独立验证。

| 分支 | 变化 | 各自搭配的PGEFF |
|---|---|---|
| 对照 | 不改冠层 | 0.0574852、0.0589、0.0604 |
| 氮动员相关衰老 | SENRTE=3.75、4.5，对照3.03654 | 同上 |
| 发育阶段衰老 | SENPOR_LATE=1/3、0.5、2/3 | 同上 |
| 配对衰老 | SENPOR_LATE=1/3且SENRTE=3.75 | 同上 |
| 遗传冠层参考 | 仅移植E第2轮成员3的SLAVR、LFMAX、FRLFF、SENRTE | 同上 |
| 水胁迫衰老对照 | SENDAY=0.02 | 0.0604 |

E冠层分支不移植其初始氮系数；不能与旧E2/3的总体结果直接混为同一配置。SENRTE/SENDAY等采用物理硬界内的局部探针；SENPOR用现有注入器支持的[0,1]比例锚点，没有修改冻结率定边界。

## 机制与注入注意事项

机制参考为官方开源[SENES.for](https://github.com/DSSAT/dssat-csm-os/blob/develop/Plant/CROPGRO/SENES.for)，develop不等同于本地官方4.8.5，需结合实际二进制试验判断。

- SENRTE控制与叶片氮动员量相关的衰老；它不是独立的日期阈值。
- SENDAY作用于水胁迫引起的叶片损失。当前26SP近乎无水胁迫，预计不能独自控制26SP偏高LAI。
- SENRT2只在R7后作用。当前长SD-PM设定和既有OVERVIEW显示模拟期未达生理成熟，不将其作为本轮主要自由度；现有参数注入也没有开放该字段。
- 现有SENPOR_LATE扩展器在XSTAGE=0、5、14、30写入`[0,0,0.36×late,late]`。原模板为`[0,0,0.12,0.16]`，所以SENPOR_LATE=0.16并不复现原模板，本轮对照不写入此参数。1/3对应约`[0,0,0.12,0.33]`，仅提升末节点；0.5及2/3同时提升第三、四节点。这里“晚期”按发育叶龄而非观测日历定义，不保证只影响最后两次LAI。
- 实际PGEFF精度约1e-4，SENRTE约0.01；SENPOR本轮可写至0.001，逐组记录实际值。每季读取最终SPE/CUL验证请求与实际值，并检查未授权字符不变。现有数组扩展器会重新格式化SENMAX的前导零，单独核对其数值完全不变。

## 预设候选保护规则

相对于共同A47对照，候选需同时满足：

1. 两季累积鲜产NSE各提高至少0.01。
2. 两季LAI NSE各下降不超过0.03。
3. 两季末期鲜产RRMSE≤25%，且各自不劣于对照。不用末期处理间NSE判优。
4. 两季早期、后两次有效LAI观测的RMSE各上升不超过10%。
5. 每个N_RESPONSE/W_RESPONSE分层的RMSE上升不超过10%。
6. 另列相对v48第4轮成员55的原尺度/LAI保护门槛；不将低Phi自动等同于科学晋级。

分阶段指标沿用现有比较代码：early为第一个有效观测日期，late为最后两个有效日期。26SP缺失的26180 LAI不插补，late实际包括26153和26198；若需严格“最后一次”，必须另外按日期审查。全体22处理均为现有拟合/诊断范围，不称作独立验证。

## 结果

### 1. 完成情况与补充试验

40组全部完成，官方模型正常退出、各组1432条接口观测完整。共80个季节的累积鲜产NSE及末期RRMSE另用独立公式复算，全部与汇总一致。原v49封存代码/输入哈希核验不变。

第一阶段较强SENPOR扩展导致产量明显下降，而PGEFF+2.5%与E冠层组合出现合格候选。随后冻结`refinement_plan.json`：围绕三个PGEFF对照和两个提高PGEFF的E冠层组合，分别将SENPOR第四节点从0.16小幅改为0.17、0.18、0.20；其余前三节点保持`0,0,0.12`。增加15组，不改变验收门槛。此为根据已见结果设计的自适应小试，不是预注册独立验证。

补充试验只在每组隔离SPE副本更改末节点，通过`DSSAT_SPE_BASE`指向该副本；原模板和bundle未改。**这里的SENPOR4不是现有SENPOR_LATE：复用结果时必须携带`task.json`和`senpor_last_node.SPE.base`，仅复制params.csv不能复现0.17候选。**

复现全部：`python tools/experiments/run_v52_photo_senescence_20260902.py --run --refine`，再运行`python tools/analysis/analyze_v52_photo_senescence_20260902.py`。已完成任务核验计划后跳过，不覆盖旧运行。

### 3. 分日期核查：26SP改善，但两季偏差仍未消除

0.17候选相对共同对照：

- 26SP最后实测日26198：LAI RMSE从0.9081降至0.7921（降低12.8%），平均模拟LAI从3.3368降至3.2670，实测均值2.7232。平均高估仍为0.5438，不能宣称末期LAI问题已经完全解决。
- 26SP后两个有效日期RMSE从0.6759降至0.5973；初期RMSE从0.1742升至0.1814（约4.1%），在预设保护门槛内。
- 25SP初期RMSE从0.3998升至0.4102（约2.6%）；后两次RMSE从1.0069降至1.0044，总体基本持平。最后日期均值仍低估，Bias从−0.7418变为−0.7822；RMSE则从1.0427降至1.0312，说明均值偏差与处理间离散误差不能混为同一结论。
- `date_metrics.csv`保存每季×日期×器官的观测/模拟均值、RMSE、Bias等；无缺失值插补或平滑值参与计分。

### 4. 不能忽略的代价

**Phi没有降低。** 0.17候选为573.51，比567.02高6.49（约1.15%）。主要增量：25SP末期茎状态SWETS +10.08、25SP单次鲜采收HFPOWS +6.66；主要改善包括26SP累计鲜产−3.96、25SP累计鲜产−1.96、26SP末期LAI−1.97、26SP末期叶重−1.96。详见`phi_family_comparison.csv`。本轮没有暗改权重来制造低Phi。

对应的实值退化也存在：25SP茎重NSE从0.6462降至0.5667，后两次茎重RMSE从588.81升至655.73 kg/ha（约11.4%）；25SP单次鲜采收NSE从0.0882降至0.0356。26SP单次鲜采收NSE则从0.3558改善到0.4068。因此这里只能称为符合本次“产量—LAI”目标的改进候选，不应直接替代所有目标的最佳成员。

**非N0氮响应仍未解决。** 0.17候选各N/W分层RMSE恶化均未超过10%，但26SP各N响应NSE依然为负；26SP末次N3−N1模拟差值为W1 −475.5、W2 +288.8、W3 +266.8 kg/ha，对应实测为+4815、+16111、+6915。非N0末期模拟CV仅0.37%、0.22%、0.20%，远小于实测7.35%、9.21%、4.68%。增加总体光合并未形成足够的氮处理差异，W1方向仍错误。

### 5. 应保留与放弃的改动

保留：小幅PGEFF提高、E冠层遗传组合、SENPOR第四节点0.16→0.17的窄幅探索作为两个备选锚点。初始氮、土壤、水分、源库和权重继续固定，保持归因清晰。

暂不保留：

- PGEFF直接提高约5%：部分组合总体产量更好，但初期LAI、N/W响应或26SP LAI保护失败。
- SENRTE普遍上调至3.75–4.5：本次没有合格候选，25SP LAI明显受损。
- SENPOR_LATE直接扩至1/3–2/3：最轻探针已严重损害产量，更强者累积产量NSE为负。不能使用该联动参数代替末节点微调。
- SENDAY增至0.02：26SP鲜产和LAI与相同PGEFF对照完全一致，未解决目标问题。

### 6. 下一步建议

1. 保留两个合格候选，不立刻启动200×4全参数率定或改权重。优先0.17候选作为冠层受保护的产量尺度锚点；它不等于氮响应晋级候选。
2. 如继续局部探索，先固定E冠层其余参数，在PGEFF约0.0585–0.0592、SENPOR第四节点约0.165–0.175附近小网格细化；加入25SP末期/晚期茎重RMSE不增超过10%的新保护条款，并单列单次采收过程。这些范围是后续建议，未冻结为正式率定边界、未执行。
3. SENPOR4进入IES前须增加一个**只改变末节点、默认准确复现模板**的明确参数映射及冻结边界；不能把现有SENPOR_LATE设成0.17冒充相同配置。当前隔离SPE探针足以验证思路，无须为小试重构生产引擎。
4. N1–N3响应差异仍应作为另一机制分支处理，不以继续提高PGEFF代替氮响应诊断，不机械加权迫使模拟单调。
