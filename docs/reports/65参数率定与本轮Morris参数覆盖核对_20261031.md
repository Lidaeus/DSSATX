# 65参数率定与本轮Morris参数覆盖核对

日期：2026-10-31。这里只核对参数身份、历史采样范围并记录用户决定，未重新运行敏感性分析或率定。原待审方案的41参数建议、200×6规模及SLPF=.933/.933建议由本次用户决定替代；其他方案内容尚未获准执行。

## 已确认的三项决定

- 正式联合率定规模为 **100成员×5次更新**。
- **FL-LF固定400，不参与率定**。FL-LF是首次开花R1至叶面积扩展结束所需的光温生理时间（photothermal days），不是单片叶展开至死亡的寿命，也不能直接当作400个日历天。项目当前CUL模板第17–18行有相同定义。此前“叶片寿命”的表述及据此增加第41项的建议撤回。
- **SLPF_25SP=0.93，SLPF_26SP=0.89**。两季分别固定，不再推荐.933/.933。

本轮没有将以上范围决定当成启动授权；等待用户进一步决策敏感性范围及正式方案。

## 65参数版是否有本轮未分析的作物参数：有，两项

主核对对象为 `eggplant_26sp_all12_robust_joint65_200x5_20261012` 的实际 `joint/joint.pst` 自由参数，与对应冻结bounds逐项一致；本轮则读取Morris实际采样矩阵列名，而不只根据文件名判断。

|此前65版参数|文件/性质|此前冻结工作范围|本轮Morris86是否采样|本次决定/解释|
|---|---|---|---|---|
|FL-LF|CUL，冠层叶面积扩展的发育时间参数|45–220 PTD|**否**|用户已决定固定400；本轮没有其μ*、σ或低敏感结论|
|KEP|SPE，潜在蒸散分配的能量消光系数|0.76–0.90|**否**|按CUL/ECO/SPE广义作物过程口径属于遗漏项；按严格品种遗传口径更适合称过程系数，不能因存于SPE就声称是实测遗传性状|
|SOIL_SLDR|SOIL，土壤排水参数|0.75–0.93|**否**|非遗传参数，不应当作遗传筛查遗漏；本次率定固定环境条件|

KEP的准确本地源码说明为“Energy extinction coefficient for partitioning EO to EP”，即潜在蒸散向潜在蒸腾分配的能量消光系数。此前仅称“土壤蒸发系数”不够完整。原65参数执行链对KEP与SOIL_SLDR有专门注入逻辑；以后若将KEP补进Morris，需要核验本轮SA入口的注入与原生回读，不能只往CSV加一行。

数量关系：**65=64项作物文件参数+1项土壤参数**；64项中，**62项参与本轮SA、2项未参与**。因此不能把“65项都已由86项SA覆盖”作为前提。

同时检查了10/12的N012水氮65版、N012 RMSE65版、N012稳健65版及全12处理稳健65版。四份design指向的冻结活跃参数清单得到相同未覆盖结果：FL-LF、KEP和非遗传的SOIL_SLDR。

## 已参与、但没有进入前98%的参数要另行区分

此前65版的62项已采样作物参数中，36项进入本轮前40，26项没有进入。例如KCAN、RWUMX、RTNO3、RTNH4、NSLOPE、NVSMOB、ICMP、TCMP、PROLFF等，**均已参与本轮Morris**，不是未分析参数。

本轮前40另有4项不在此前65版的自由参数中：TO21、TO22、XFPHT、XFINT。它们的激活建议来自本次筛查，而不是旧65版的激活状态。

前98%仅指已复核的物候、LAI积分、累计干采收三项输出等权的累计相对μ*份额；不说明这26项对所有N浓度、水氮响应或其他输出都不重要。

已核到 `sa_wnp_phase1_20260914/26SP`：实际Morris PST有138个自由参数，4170行采样矩阵中的138列均发生变化，对应30×(138+1)设计；冻结bounds按文件位置拆分如下：

因此“历史达到近百个遗传参数”的记忆有实际文件支持：该批为105项广义作物参数，但不能把全部138项称为遗传参数。本次仅核对其采样身份、数量和范围，未重新验收历史每个参数的数值注入、有效输出或统计结论。

历史105项中，74项在本轮86项中，**31项未纳入本轮**；本轮86项也有12项不在该历史105项中，所以86不是105的简单子集或超集。上述历史105项本身亦不包含FL-LF和KEP。

31项差异包括：

- **19项器官P浓度参数**：OPTLFP_EM、OPTLFP_FF、OPTSTP_EM、OPTSTP_FF、OPTRTP_EM、OPTRTP_FF、OPTRTP_FS、OPTSDP_FF，以及MINLFP_EM/FF/FS、MINSTP_EM/FF/FS、MINRTP_EM/FF/FS、MINSDP_FF/FS。
- **12项其他参数**：CSDL、PORMIN、SIZREF、SLAREF、THRSH、XFRMAX、NREXP、NRMIN、ROOTRAD、FRACPMOBIL、SRATPHOTO、SRATPART。

这说明当前86项不能代表历史所有可调作物参数。本次未声称31项都应恢复：今后扩充应先核对参数含义、模型开关、注入/回读支持及对应输出。尤其CSDL需要光周期辨识依据，THRSH涉及种子/果实定义，P参数需要P过程和输出证据，不能单纯为了凑到100项而全部激活。当前SA包的PHOSP=Y也不自动证明每个组织P参数都被正确扰动并可被当前目标识别。

针对“是否需要扩大范围”的直接判断：若目标是覆盖此前65版的全部作物过程，至少还需正视KEP未分析的问题；FL-LF已按用户本次决定固定。若目标是恢复历史更完整的养分/生理筛查，则应再审核这31项差异，而不仅比较86和65两个总数。没有本轮敏感性结果的参数不能按“低敏感”处理。
