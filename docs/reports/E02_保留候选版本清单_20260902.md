- 官方DSSAT 4.8.5，PHOTO=L；25SP 10处理、26SP 12处理。两季累积产量对数分别90、60；LAI有效对数40、36。25FA不属于本次筛选结果，不能据此声称三季验证通过。
- 四者沿用同一v49 A设计、PEST目标及变换配置，1432条接口观测；土壤、天气、管理、TMA/TMT/TMX输入一致。本次重新逐字节比对四者已落盘的TMX/TMA/TMT/SOL/WTH，未发现差异，并从采收配对表独立复算四者两季累积鲜产NSE，与汇总一致。
- 初始氮系数均为`ICNS_25SP=0.531622`、`ICNS_26SP=0.726747`，在0.4–0.8范围内。它们相对于既有bundle；26SP bundle此前已×0.34，且存在浓度下限截断，不能直接解释为原实测剖面的同名倍率。
- C01/C02通过v52预设提产、LAI、分阶段LAI、水氮响应保护规则，也通过相对v48的尺度/LAI保护。C03/C04保留作替代参考和基线，**不是**通过“每季鲜产NSE必须提高0.01”的新晋级者。四者均通过原v48尺度/LAI保护。
- C01/C02/C03各N/W分层相对C04的最大RMSE增幅分别约7.58%、7.59%、5.37%，均小于10%；这是“不明显退化”，不是“水氮响应已经拟合良好”。完整分层NSE、RMSE见下方源表。
- 使用原日期配对、原始模拟值计算；缺失观测不插补，末期处理间产量采用RRMSE，不用NSE。26SP有效LAI日期为26122、26153、26198，26180缺失；“后两次”不等同于两个连续晚期采样日期。

## 4. 后续使用的边界

1. **总体比较/人工审图**：先看C01，同时保留C02、C03、C04作为透明对照，不根据单张图临时换成员。
2. **论文结果**：可用此清单组织已完成结果和折中讨论；这些22处理的拟合不是独立验证。未核查25FA结果，不宣称外推能力或氮响应机制已验证。
3. **共同未解决项**：非N0氮响应仍偏弱，部分差值方向错误；26SP末期LAI仍高估；25SP单次采收过程拟合弱。C01/C02的25SP茎重退化必须与其产量收益一并披露。
4. **工程限定**：v52相关测试56项通过；历史安全测试另有6项失败，详见v52报告。保留候选不等于全仓测试通过。既有土壤质地默认假设也未在此清单中消除。
5. **不继续扩展工作**：本次按用户要求归档即可，不启动新的敏感性分析、率定、重绘或自动监控；不删除未入选的版本。
