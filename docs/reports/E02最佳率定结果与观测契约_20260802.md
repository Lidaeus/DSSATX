# E02 最佳率定结果与观测契约（2026-08-02）

## 当前标记

`e02_joint62_softn_response_95pct_dmc5_formal_200x5_20260802` 标记为当前最佳结果候选之一（`engineering_validated`，末轮最优成员 `real_name=99`，actual Phi=371.815）。该 Phi 与未加入水氮响应目标的历史批次不宜直接横向排序；本批次的优势是使用 95% 果实含水率（DMC=5%）唯一真值，并显式加入软水氮响应目标。

## 该批次实际进入 Phi 的观测

三季均参与：25SP、25FA、26SP。正权重观测共 1,448 个，目标族如下：

- 物候：PDAP；ADAP 仅保留为诊断，不进入 Phi；MDAP 不进入 Phi。
- 冠层/生长过程：LAID、LAIX、LWAD、SWAD、CHTD。
- 干物质采收：CHPDT 累积干重采收序列（在 Phi 中按既定 log 变换处理）；HPODW 单次采收干重序列（同一干重口径）。
- 植株氮：SNAM、LNAM；CNAM 保留为诊断，不进入 Phi。
- 土壤水分：SOIL_WATER 全部正权重时序观测。
- 水氮响应：每季 NRESP 组，使用高/低水分下的 N3−N0、N2−N0、N1−N0 对比目标（共 114 条对比观测，沿用当前响应目标和权重）。

明确不进入 Phi：ADAP、MDAP、CHFPW（鲜重采收）、鲜重累计/单次采收旧组，以及 CNAM 诊断组。观测登记原件见当前批次的 `*_observation_registry.csv`。
