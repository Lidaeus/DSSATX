# 双季水氮梯度单因素扰动结果

采用双季率定代表解 `global_0062`，固定两季最终版 bundle 和其余参数。基线与 10 个扰动情景全部完成，每个情景分别运行两季，共 22 次模拟。基线逐项复现已存的确定性输出。PODUR 30 和 38 属于探索点，超出上一轮冻结上限 22。 [试验清单](D:/Tomato_Cal/workspace/runs/both_springs_wn_perturbation_20261106/experiment_manifest.json) · [逐情景状态](D:/Tomato_Cal/workspace/runs/both_springs_wn_perturbation_20261106/scenario_status.csv)

- **CMOBMX** 降至 0.015–0.060 时，两季氮梯度误差均低于基线，0.015 的鲜、干产氮梯度均为试验最低。2025 春 W1 鲜产 N2−N0 从 +1.34 改善至 +5.04 t/ha，实测 +5.52。W3 仍为 −2.27，实测 +5.46。2026 春三个水分水平模拟仍为负。0.015 的 2026 春季末鲜产 NRMSE 从 11.13% 降至 9.25%，干产 NRMSE 从 14.64% 升至 15.82%。0.022 对 2025 春整体季末鲜、干产 NRMSE 最有利，分别为 6.31% 和 5.41%。因此 0.015–0.040 可优先作为下一轮候选区间，0.022 可作起始参考。
- **ATOP** 从 1.581 调至 0.80 或 1.10 后，2025 春氮梯度误差扩大，2026 春无实质改善。本次结果支持保留现有范围。
- **PODUR** 从 7.932 上调后，2026 春氮梯度误差持续扩大。38 虽改善 2026 春水梯度，2025 春季末鲜、干产 NRMSE 分别升到 24.29% 和 24.53%。本次结果支持保留原上限 22。
- **水分梯度** 仍普遍低估。2026 春实测各氮水平 W2−W1 鲜产差为 4.96–10.80 t/ha，基线仅 1.90–2.40，CMOBMX 0.015 时为 2.19–2.56。方向命中与幅度误差应同时报告。
