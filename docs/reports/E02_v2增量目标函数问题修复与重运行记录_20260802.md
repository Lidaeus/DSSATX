# E02 V2 增量目标函数问题修复与重运行记录（2026-08-02）

## 结论

`e02_v2_formal25sp_allincrement_terminal_200x5_20260802` 变差并非单纯由“增量目标理论不适用”造成，而是理论选择与实现错误叠加：

1. NRESP 观测端计算 `ln(CHPDT+1)` 差值，模拟端却直接对原尺度 CHPDT 相减，导致尺度不一致；
2. NRESP 观测和模拟使用不同排序键，66 条模拟差值中有 60 条被绑定到错误观测；
3. NRESP 的 0.75 是标准化残差预算，不是 Phi 硬上限；前两项错误使该族贡献约 11166 Phi，占最佳成员总 Phi 的 95.7%；
4. LAID、LWAD、SWAD 是状态观测，并非累积采收量。相邻状态差分会引入共享测量误差和残差相关性，但当前观测集合仍按独立误差生成；
5. 累积采收原基线已采用误差标准化和静态族预算，不能把“默认等权累计量的后期支配”直接当作本项目当前实现；
6. FileT 采收观测日期对应 FileX 前一日的采收管理事件，FreshWt.OUT 应精确读取 FileT 日期，不应使用 `日期+1` 或邻日回退。

因此，本轮不再对所有时序变量统一差分。采用“状态变量原尺度 + 实测事件增量 + 终值锚点 + 严格配对处理差值”的目标函数。
