## 2. 关键设计决策

### 2.1 OLS MSE 分解（§4.1）

按 Robeson & Willmott (2023) 定义：`sim_hat = a + b·observed`（带截距 OLS），`MSE_s = mean((sim_hat−O)²)`，`MSE_u = mean((sim−sim_hat)²)`。

- **数值闭合**：`compute_metrics` 内以 1e-9 容差断言 `MSE = MSE_s + MSE_u`，否则 `AssertionError`。手算验证：obs=[1,2,3,4] sim=[1.1,1.9,3.2,3.8] → a=0.15, b=0.94, MSE_s=0.0045, MSE_u=0.0205, MSE=0.025（精确闭合）。
- **OLS 手算**：用正规方程实现（numpy），不引入 statsmodels 依赖。
- `MSE_s/MSE > 0.5` 在结果表输出但仅作诊断标记，不作"模型结构错误证明"。

### 2.2 残差证据链（§4.2）

- **游程检验**：按 `season×treatment×variable` 真实时序执行；零残差剔除并记录；n<8 → `not_tested`（不用大样本近似）；n≥8 用正态近似 z/p。手算：交替符号 n=8 → p=0.022；聚类 n=10 → p=0.0073。
- **处理级 bootstrap MBE**：**以处理为重抽样单位**，禁止对累计采收每个时间点做独立 t 检验。小样本（<8 处理）额外给符号置换检验。默认 2000 次 percentile 95% CI。
- **累计非独立标签**：同一 treatment 的多 harvest 累计事件标 `is_cumulative_non_independent=True`（变量名含 'cum'，匹配 DRY_CUM/FRESH_CUM/cumulative）。

### 2.3 article_rawscale_v1 profile 门

- **拒绝** HWAM/PWAD/PWAI 进入正式指标表（`_enforce_profile` 抛 ValueError）。
- CHFPW 计算指标但标 `is_diagnostic_only=True`，不进论文主汇总。
- 允许变量：CHPDT/CHFPW/LAID/LWAD/SWAD/ADAP/CNAM/LAIX/DRY_CUM/DRY_INC。
