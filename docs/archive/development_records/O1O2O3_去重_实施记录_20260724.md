## 2. 方案

### O2: `_compute_harvest_sigmas(df_harvest, args) -> dict`

提取收获事件 sigma 计算：
```
sigma = (sigma0² + (cv * |median|)²)^0.5 * sigma_factor * early_scale
```
含 PWADM（累积）/ PWAIM（增量）双变量和 `harvest_early_*` 早期加权逻辑。三处调用统一为单行调用。

### O3: `_compute_process_sigmas(df_process, var_specs, defaults, sigma_factors=None) -> dict`

提取过程点 sigma 计算：
```
sigma = (sigma0² + (cv * |median|)²)^0.5 * sigma_factors.get(var, 1.0)
```
- `var_specs`: `(var_name, sigma0, cv)` 元组列表，支持不同变量集（stage2 三变量、v13 四变量、process 三变量）
- `sigma_factors`: 可选逐变量因子（stage2 使用 `laidm/lwadm/swadm_sigma_factor`；v13/process 传 None）
- `defaults`: 默认 sigma 值（如 `{"LAIDM": 2.0, ...}`），因子非空时自动乘以

### O1: `create_ins_and_pst` 委托给提取函数

将 `create_ins_and_pst` 内联的 ~110 行 INS/obs 构建（含 `obs_cols` 过滤、`is_tagged_output` 判断、逐行 INS/obs 循环）替换为调用 `_build_ins_and_obs`；将 ~16 行 PST 参数/观测填充替换为调用 `_populate_pst_from_par_obs`。两个提取函数此前已被 `create_ins_and_pst_multi` 使用，现在遗留构建器也统一委托。
