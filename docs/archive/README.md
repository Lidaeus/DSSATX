# 已淘汰与历史文档

本目录保存已完成、被替代或仅作为迁移输入的文档。它们保留原始文件名和 Git 历史，供开发人员追溯设计演变。

## 使用限制

- 不得直接复制其中的参数范围、Top-K、权重、运行规模或审批状态到新试验；
- 不得把旧命令视为当前稳定入口；
- 不得引用历史失败运行、DEMO 或工程预检作为科研结论；
- 如果历史内容仍有价值，应将核验后的结论合并到当前权威规范，而不是恢复旧文档为入口。

## 分类

- [designs/](designs/)：早期产品、聚类、绘图和率定方案；
- [completed_plans/](completed_plans/)：已经实施或已被后续阶段替代的 P0/P1/P2/T4 计划；
- [research_inputs/](research_inputs/)：相似项目迁移材料、前沿方法评估和早期领域方案；
- [sa_project/](sa_project/)：旧 SA 教程、分组和结果解释；
- [handoffs/](handoffs/)：阶段性交接材料；
- [misc/](misc/)：其他已淘汰内容。
