## 0. 复审后的定位与成熟化方向

这份文档第一版已经把“有什么”整理出来；下一步更重要的是回答“哪些值得写进研究，哪些只是支撑材料”。复审后建议把本项目的论文主线收束为：

> 面向设施连续采收作物的 DSSAT-PEST 参数率定中，如何用敏感性筛选、分阶段约束和异参同效诊断，避免把拟合改善误读为参数真实性，并进一步把模型输出转化为可解释的水氮管理与品质代理变量分析。

这里最值得强化的不是工程系统本身，而是三个研究问题：

| 研究问题 | 为什么有价值 | 当前证据 | 还缺什么 |
|---|---|---|---|
| 高维遗传/生态/物种参数如何筛选并分阶段释放？ | DSSAT 参数多、观测少，直接全参数率定容易不可识别 | Morris/Sobol 漏斗、Stage 1-4 框架 | 把筛选规则写成可复现方法，并给出最终参数清单 |
| 率定后的“好拟合”是否来自生理合理参数，还是来自参数代偿？ | 这是作物模型率定论文中最容易被质疑、也最有讨论价值的部分 | PCA 长轴/短轴比、代偿轴参数、v6-v12 比较 | 共线性矩阵、后验分布、边界命中和分组 Φ |
| 连续采收作物的结果是否应从终产量转向动态与策略规则？ | 番茄/茄子/草莓等连续采收作物用单一总产量描述管理效果不够 | HFPOW/CHFPW、策略家族、S1-S4 规则、鲁棒性筛选 | 用最终茄子参数重跑并替换先导数值 |

需要有意弱化的内容：

- 不把“大量脚本重构”作为研究目标。工程只服务于可复现图表和结果。
- 不把品质预测包装成成熟预测模型。当前更适合作为 DSSAT 代理变量与采收时间混杂的探索性分析。
- 不把水氮优化先导数值当作最终结论。可保留方法链，数值必须在茄子正式参数上重算。
- 不追求完整贝叶斯/全自动平台。除非论文必须，否则后验诊断用 IES ensemble 足够支撑讨论。

比较有创新性、值得强化的部分：

1. **把异参同效作为研究结果，而不是率定失败的附注**。PCA 代偿轴可以解释“哪些生理过程在互相替代”，这比只报告 RMSE 更有学术味道。
2. **把水氮响应差异写成 relational/directional constraints**。例如 W1/W3 比值、N response、处理间方向惩罚，本质上是把农学先验转成目标函数约束。
3. **把连续采收优化从 Pareto 点转译为阶段管理规则**。S1-S4 的规则提取、HFPOW/CHFPW 动态验证和鲁棒性筛选，比单个最优解更适合论文表达。
4. **品质模型引入 time-baseline 守门人**。这能防止“漂亮散点图”掩盖采收时间效应，是一个很好的方法学警示。

## 1. 总体判断

近一个月的工作可以归纳为五条主线：

1. **DSSAT-PEST 率定流程升级**：从直接全参数联合率定，逐步转向敏感性筛选、分阶段释放、权重策略、观测注册和决策日志化。
2. **参数代偿与异参同效诊断**：已有 PCA 椭圆几何、代偿方向参数识别、跨版本长短轴比比较；但尚未形成完整的参数共线性和后验分布分析闭环。
3. **论文级图表体系**：形成了从 Morris/Sobol、率定收敛、验证时序、采收动态、水氮响应、机制诊断到策略优化的图表骨架。
4. **品质预测与机理代理变量探索**：从 263/274 个 DSSAT 变量筛选出与 DMC、Brix、Vc 强相关的过程变量，并建立了多个经验/半机理模型；同时发现高 R2 可能主要来自采收时间效应。
5. **连续采收作物水氮策略优化链条**：草莓先导/茄子迁移路径中，形成了“全局探索-局部加密/NSGA-II-策略分类-阶段规则-采收动态-鲁棒性筛选”的方法链。

对另一分支最值得重写的不是所有临时脚本，而是以下四个层次：

- **方法层**：敏感性筛选漏斗、分阶段率定、目标函数权重、异参同效诊断、策略优化后处理。
- **证据层**：关键 CSV/诊断文本/图表输出，用来支撑论文方法和讨论。
- **经验层**：土壤/初始条件固定、防数据漂移、温度三基点约束、N response 约束设计、采收时间混杂诊断。
- **工程层**：配置化入口、策略快照、决策日志、可复现输出目录。

### 4.3 需要补做：参数共线性分析

当前项目还没有完成参数共线性分析。下一版建议新增一个独立章节或补充材料：

**输入数据**

- IES 后验 ensemble 参数矩阵：每行 realization，每列参数。
- 可选：每个 realization 对应的 Φ、分组 Φ 和主要输出误差。

**分析指标**

| 分析 | 目的 | 输出 |
|---|---|---|
| Pearson/Spearman 参数相关矩阵 | 找出线性/单调相关参数对 | heatmap + Top correlated pairs |
| VIF 或条件数 | 判断多参数线性依赖强度 | 参数 VIF 表、condition number |
| Graph clustering | 把 `abs(r)>0.7` 或 `abs(r)>0.8` 的参数连边，识别参数团簇 | 参数共线性网络 |
| 分组相关 | 检查土壤-根系-氮素-温度跨组代偿 | block correlation heatmap |
| 与输出残差相关 | 判断相关参数团是否对应某类观测缺口 | 参数团簇 vs 观测组误差 |

**建议阈值**

- `abs(r) >= 0.7`：进入候选代偿对。
- `abs(r) >= 0.85`：强共线性，重写时考虑固定其中一个、收紧边界或增加观测约束。
- VIF > 5：中等风险；VIF > 10：高风险。

**优先检查参数对**

- 温度三基点：`TB*`, `TO*`, `TM*`
- 根系水分：`RWDTH`, `RTDEPI`, `RWUEP1`, `RWUMX`, `RTSDF`
- 氮素吸收/调动：`RTNO3`, `RTNH4`, `NMOBMX`, `NVSMOB`, `FNPGN*`
- 源库分配：`XFRT`, `VSSINK`, `FRSTMF`, `FRLFF`, `PRO*`
- 土壤/初始条件：`SOIL_SBDM_*`, `IC_SH2O_*`, `IC_SNO3_*`, `IC_SNH4_*`

### 4.4 需要补做：后验分布分析

当前已有 `compensation_pairs_ranges.csv` 这种后验范围输出，但尚未系统化。建议下一版增加：

| 图/表 | 内容 | 用途 |
|---|---|---|
| Prior vs posterior density/ridge plot | 每个关键参数的先验范围、初始值、后验分布 | 判断参数是否被数据约束 |
| Boundary hit table | 后验样本靠近上下界的比例 | 判断是否边界驱动 |
| Posterior shrinkage | `(prior_width - posterior_width) / prior_width` | 量化可识别性 |
| Posterior pair plot | 关键代偿参数二维散点 | 展示异参同效方向 |
| Parameter-phi scatter | 参数值 vs 总 Φ/分组 Φ | 区分“等价好解”和“坏解混入” |

建议判据：

- 后验仍接近先验且 Φ 差异小：参数未被有效识别，可固定或降权。
- 后验贴边：优先检查边界是否生理合理，不要直接扩大边界。
- 后验多峰：可能存在多个机制路径，需要分情景或分阶段约束。
- 后验窄但与其他参数强相关：看似可识别，实际可能是组合可识别。

### 4.5 论文写法建议

可以写成：

> Ensemble calibration revealed an elongated posterior cloud in the principal-component space, indicating that multiple parameter combinations can generate comparable model performance. The dominant compensation axis involved temperature response, soil bulk density/initial water, root water uptake, nitrogen remobilization, and source-sink allocation parameters. Subsequent boundary tightening and response constraints reduced the terminal ellipse axis ratio, suggesting improved identifiability, but parameter collinearity and posterior distribution diagnostics are still required before claiming robust parameter uniqueness.

中文讨论可写：

> 率定并未得到唯一参数解，而是暴露出一组生理过程之间的代偿通道。该结果提示：模型拟合优度改善不应被直接解释为单个参数的生理真实性，必须结合后验分布、边界命中、共线性和独立观测约束进行判读。

## 5. 率定参数经验与失败模式

### 5.1 土壤/初始条件不要轻易放开

来源：`CHANGELOG.md`, `DEVELOPER_GUIDE.md`, `Workspace/decision_log.md`

经验：

- v6 中 `IC_SH2O` 被率定后偏离实测值 36-68%，`SOIL_SBDM`、`SOIL_SALB/SLDR/SLPF` 也发生偏移。
- 土壤/IC 参数放开后，遗传参数会通过非生理变化来补偿，例如 `PARMAX` 提高、`FINREF` 降低。
- v7 将 20 个土壤/IC 参数固定后，Phi 从 16241 降至 14276，下降约 12.1%，收敛更稳定。

重写建议：

- 默认固定实测土壤和初始条件。
- 只有在有对应观测约束时才作为 nuisance 参数小范围释放。
- 如果释放，必须单独报告土壤/IC 参数偏离实测值的幅度。

### 5.2 用 `.bak` 防止数据漂移

经验：

- 多轮率定会把参数写回 DSSAT 输入文件。
- 如果下一轮从已修改文件读取初始值，初始条件会逐轮漂移。

重写建议：

- 构建 PST 时始终从 `XXQL2501.TMX.bak` 和 `SOIL.SOL.bak` 读取实测基准。
- 每次率定输出应写入 run directory，不应覆盖基准输入。
- 在运行清单中记录基准文件 hash。

### 5.3 温度三基点需要生理边界

经验：

- v6 中 `TM1/TM3` 接近 38.9°C，`TO23` 接近 `TM3`，导致温度响应函数的最适平台几乎消失。
- 这是“通过提高高温上限来无视高温胁迫”的典型参数代偿。

重写建议：

- 收紧 `TM*` upper bound，例如从 40°C 降至 35°C，或根据文献/本地试验固定。
- 对 `TB/TO/TM` 做单独的 posterior/boundary hit 图。
- 不要只用总产量判断温度参数是否合理，应检查 LAI 高温期下降、花期偏差和胁迫曲线。

### 5.4 水氮响应需要显式目标，不应只依赖终产量

来源：v13-v24 未提交配置和 `.adjusted.obs_data.csv`

目标函数演化：

| 版本 | 核心思路 |
|---|---|
| v13 | 加入 N response 约束 |
| v14 | 引入 v5/N prior |
| v15-v18 | 根系-水分-N 交互和边界试验 |
| v19 | `w3nresp`, `w1nresp`, `w1n3n2`, `w1n2n0` 轻量权重 |
| v20 | 强化 response penalty |
| v21 | 加入 W1/W3 ratio 约束 |
| v22 | SLPF + sink guard |
| v23 | low-water N release |
| v24 | W1 only + SLPF=0.95 方向试验 |

重写建议：

- 把水氮响应目标作为单独 obs group，如 `wn_response`。
- 目标不宜只约束单个处理产量，还应约束处理差异、比例和方向。
- 对响应约束做敏感性：权重过低无效，权重过高会牺牲 LAI/物候/采收拟合。

### 5.5 分阶段率定比直接全参数更适合论文叙事

建议保留的阶段框架：

| 阶段 | 目的 | 参数组 |
|---|---|---|
| S0 | 土壤/初始条件审计 | 土壤水分、容重、N 初值 |
| Stage 1 | 时间轴锚定 | `TB/TO/TM`, `EM-FL`, `FL-SH/SD` |
| Stage 2 | 冠层与源端 | `TRIFL`, `RWDTH`, `RHGHT`, `LFMAX`, `SLAVR`, `KCAN` |
| Stage 3 | 库端与采收 | `XFRT`, `PODUR`, `SFDUR`, `SDPDV`, `WTPSD` |
| Stage 4 | 全局联合 | 全部已筛选 active 参数 |

论文中可以强调：分阶段不是为了机械降低 Φ，而是为了减少早期错误通过后期参数代偿。

## 6. 品质模型：可保留结论与谨慎点

### 6.1 可保留的变量发现

来源：

- `Workspace/quality/outputs/correlation_analysis_v3.md`
- `Workspace/quality/outputs/all_models_reassessment.csv`
- `Workspace/quality/outputs/quality_treatment_signal_report.md`

关键发现：

- DMC 与 `GN%D_h`、`PWAD_wm/ws`、`HIPD_ws`、`PWAD_growth_rate`、`harvest_interval_d` 强相关。
- Brix 与 `HIPD_ws`、`PWAD_ws`、`harvest_interval_d`、`GN%D_h`、`PWAD_growth_rate` 强相关。
- Vc 与 `PWAD_ws/wm`、`HIPD_ws`、`GN%D_h`、`PWAD_growth_rate` 呈相反方向关系。

可以概括为：

> DSSAT 的果实干重/鲜重、收获指数、果实含氮和采收进度变量，可以作为连续采收作物品质形成的代理变量。

### 6.2 模型表现

`all_models_reassessment.csv` 中较有价值的结果：

| 指标 | 模型 | Full R2 | CV R2 | 判断 |
|---|---|---:|---:|---|
| DMC | `G6_fix2_fd_ratio` | 0.727 | 0.657 | 可作为当前 DMC 定稿候选，但需处理采收时间混杂 |
| Brix | `M4_complete` | 0.631 | 0.501 | 中等可信 |
| Vc | `V1_carbon_source` | 0.705 | 0.667 | 简洁模型反而优于复杂模型 |
| Vc | `V23b_four_process` | 0.693 | 0.662 | 机制解释更强，但参数更多 |

### 6.3 重要警示：采收时间效应

`quality_treatment_signal_report.md` 显示：

- Brix `pool_mixed` raw R2=0.811，但 time baseline R2=0.767，增量只有约 0.044。
- DMC raw R2 约 0.10，而 time baseline R2 约 0.775，说明当前模型没有学到处理差异。
- Vc 在 cohort3 模式 raw R2 约 0.467，但 time baseline R2 约 0.588，仍弱于时间基线。

重写建议：

- 品质模型必须同时报告 raw R2、time baseline R2、within-harvest anomaly R2、处理对比方向准确率。
- 不能只报告散点图好看。
- 若数据主要由采收时间驱动，应把品质章节定位为“代理变量探索/机制假设生成”，而不是最终预测模型。

## 7. 水氮管理优化：可迁移方法链

### 7.1 建议保留的流程

来源：

- `Workspace/SimResult_Eggplant/Strawberry_Pilot/Optimization/lhs_local_v1/publication_results/方法学章节_水氮策略优化草稿_v1.md`
- `Workspace/SimResult_Eggplant/Strawberry_Pilot/Optimization/nsga2_3obj_formal_rainzero_v1/formal_postprocess/formal_postprocess_methods_results.md`

方法链：

1. 参数化 DSSAT 模型。
2. 全局 LHS 或 NSGA-II 生成候选解。
3. 构建 Pareto + 近优候选集。
4. 对生产、资源效率、环境风险、采收稳定性和管理变量进行标准化。
5. KMeans 聚类形成策略亚型。
6. 提取 S1-S4 阶段水氮规则。
7. 用 HFPOW/CHFPW 验证采收动态。
8. 做价格、水价、氮价、环境惩罚扰动的鲁棒性筛选。

### 7.2 可保留的论文叙事

核心观点：

- 连续采收作物不能只优化最终总产量。
- 需要同时考虑采收峰值、采收稳定性、资源效率和策略可解释性。
- Pareto 解集应被转译为“策略家族”和“阶段规则”，而不是只报告一个最优点。

当前 formal rain-zero 结果中：

- 产量优先型产量最高但总氮/补灌也高。
- 节水高产型 WUE 高且鲁棒性最好。
- 综合效率均衡型是低风险折中方案。
- 采收稳定型 CV 最低，但可能依赖较高补灌。

迁移到茄子时必须重跑，不应沿用草莓/先导实验的数值阈值、聚类标签和代表解。

## 9. 可直接写入论文的经验性结论

1. **敏感性筛选应兼顾主效应和交互效应**：Morris 初筛若只按 μ* 排名，会遗漏 σ/μ* 高的非线性/交互参数；交互捞回能提高后续 Sobol 和率定的机制覆盖。
2. **全参数率定容易产生生理代偿**：土壤/IC、温度基点、根系吸水、氮调动和源库分配可共同形成等价解通道。
3. **固定实测土壤/初始条件通常比放开更稳健**：除非有独立土壤水氮观测，否则放开土壤/IC 会把遗传参数推向非生理补偿。
4. **温度响应参数需要生理边界**：过高的 `TM*` 会让模型绕开高温胁迫，改善拟合但破坏机制真实性。
5. **连续采收作物需要采收动态指标**：最终产量不能反映 HFPOW 峰值、CHFPW 累积速度和供应稳定性。
6. **品质预测必须拆解采收时间效应**：高 raw R2 可能来自采收期进程，而非水氮处理信号。
7. **优化结果应转译为策略家族和阶段规则**：比单个最优解更适合论文表达和生产解释。

## 11. 结论

本月最有价值的成果不是某一个“最佳参数集”，而是一套逐渐成型的判断框架：

- 用敏感性分析决定哪些参数值得放开；
- 用分阶段率定减少早期过程错误向后期参数转移；
- 用 PCA/共线性/后验分析识别异参同效；
- 用目标函数设计显式约束水氮响应方向；
- 用采收动态和鲁棒性把优化结果转成可解释策略；
- 用 time baseline 和 anomaly 诊断避免把采收时间效应误当成品质预测能力。

另一分支重写时，应围绕这套框架重建工程和论文材料，而不是迁移所有探索脚本。
