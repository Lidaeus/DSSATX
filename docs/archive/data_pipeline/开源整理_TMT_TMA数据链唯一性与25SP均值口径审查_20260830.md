- canonical 根 bundle **按设计**保留剔除前数值（apply_repfilter 文档串明确"without modifying their parent bundles"），父目录本就无 input_manifest.json。

## 五、25SP 加权平均专项结论（用户问题直答）

> **⚠️ 2026-08-31 口径更新**：协作者 08-30 全链条重构（CHANGELOG「25SP 观测数据全链条重构」条目）已**废除"加权小区产量"口径**，25SP 鲜产量现行改为小区内各行实测产量直接算术平均，采收截止统一为 25192，品质集升级为 3 次全小区测定。以下 1-3 描述的是重构前（HEAD 提交状态）的历史口径，供追溯；现行口径以重构后产物为准。

1. **重复之间：无加权平均**。生长指标对每 (TRNO,日期) 组直接 `np.mean`（build_trial_observations_v2_20260726.py:568-582）；DMFR 为中位数离群剔除后算术平均（:519-521）；SWAD/LWAD 乘 DENSITY/1000=27 是线性单位换算非加权。
2. **历史加权点（已废除）：25SP 鲜产量**。HEAD 口径为 `weighted_val = float(grp["加权小区产量"].iloc[0])`（:450）——权重是**小区内行位置**（边行产量×0.5 + 中间行均值×0.5），值在源 xlsx 预计算，代码直取。权重不来自重复数、面积或株数。
3. **均值与 SD 不同源（25SP 产量专属，历史口径）**：均值 = 加权组合，fresh_sd 用 3 个行位置"产量"值的 hybrid_sd（算术离散）。
4. **跨季口径分化（历史）**：HEAD 上 25SP=行位置加权值，25FA/26SP=`np.mean(小区产量)` 算术平均（:703/:906）；08-30 重构后 25SP 已改为算术平均，三季趋同。
5. **重复剔除后（已批准、HEAD 已落实）**：均值 = 剩余重复（n=2）算术平均（apply_repfilter_v1_20260818.py:93-95），单位换算系数精确继承，SD 按剩余重复重算（min CV 5%）。产量链路从未被 repfilter 触碰。**注意：08-30 重构是否复现 REMOVALS 剔除修正尚待协作者确认（见《待协作者确认》问题 1）。**
6. **率定合成 sigma**：`sigma_eff = sqrt(SD²/n_eff + sigma_model² + sigma_floor²)`（src/calibration/observation_policy.py:64、build_pest_multiseason.py:285），土壤水分路径用 SD/√n（:162）。
