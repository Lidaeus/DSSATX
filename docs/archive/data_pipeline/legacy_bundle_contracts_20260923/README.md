# Historical bundle contracts (retired 2026-09-23)

The 21 experiment specs, 129 run/management/SA designs, five entry scripts/matrix
files, and 34 test files in this directory were tied to input manifests and observed values from the
pre-2026-09-23 bundles. Those bundles were moved to
`D:/Tomato_Cal_Cold_Storage/input_bundles_20260923/` after the source workbooks
were corrected. These contracts are preserved for provenance only and are not
part of the current test collection or executable calibration workflow.

New analyses must use the three inputs listed in
`configs/experiments/current_bundles.json` and create new specs with their
manifest hashes and observation policies. Historical metrics and approvals do
not transfer to corrected inputs.
