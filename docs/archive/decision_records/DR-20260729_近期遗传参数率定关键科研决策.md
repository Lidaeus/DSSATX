# DR-20260729：近期遗传参数率定关键科研决策

> 状态：2026-07-29 决策快照  
> 范围：E01 预率定、E02 单季/联合率定、25FA 秋季偏移、25SP+26SP 春季联合率定  
> 目的：冻结近期已经由项目负责人明确批准、且会改变论文方法或结果解释的口径  
> 限制：本记录不替代机器可执行配置、冻结边界和运行 manifest

## 1. 研究推进原则

科研进度优先。不会实质改变输入、目标函数、模拟—观测配对、参数后验或论文结论的工程问题，可以记录后延；以下问题必须停止并修复后再授权结果：

- 原始观测丢失、单位错误或日期错误；
- 观测角色、变换、sigma、目标族预算与审批不一致；
- FileX 初始条件或管理信息被错误替换；
- 模拟日期与观测日期静默错配；
- 原尺度反变换错误；
- 参数集、冻结边界或活动参数数与运行声明不一致。

“通过工程门”只说明执行链完整，不自动升级为论文可用的 `science_validated` 结果。

## 2. 作物与管理权威口径

1. 茄子继续使用 DSSAT v4.8 的番茄/CRGRO048 模型文件；参数解释必须结合无限生长型、连续开花坐果和分批采收特性。
2. `FL-VS` 固定为 100，不参与率定。
3. 25SP 的 `ADAP` 观测权威值为移栽后 21 d。
4. 三季移栽苗龄 `PAGE` 均为 25 d。
5. 三季 `SPRL=-99`，使用 DSSAT 缺省解释。
6. 已完成运行和旧输入包保持不变；未来运行只使用带 manifest 的权威版本化输入包。

机器权威文件：

- `configs/experiments/management_authority_20260728.json`

## 3. 物候与观测角色

1. `MDAP` 不进入参数率定。无限生长型茄子没有适合作为本研究约束的真正生理成熟日，`MDAP` 只保留诊断。
2. `PDAP`、有效 `ADAP`、`LAIX`、`LAID`、`LWAD`、`SWAD`、`CHTD`、存在实测时的植株含氮指标、干重采收和土壤水分按试验 profile 进入率定。
3. 鲜重 `CHFPW` 不进入 Phi，只用于鲜干比和实用产量诊断。
4. 叶干重和茎干重已经参与近期 E02 率定。
5. 2025 春、秋虽有茎叶全氮浓度原始记录，但当前 FileT 没有完成从 mg/g 到器官氮量的日期、干重和面积换算，因此茎叶含氮量尚未进入 Phi；不能把浓度直接写入 `SNAM/LNAM`。
6. `CHTD` 使用 m，历史 cm 观测写入问题已经修复；不得恢复旧单位。

## 4. 干重采收与异方差处理

1. 正式 E02 多目标口径中的采收目标为：
   - 累积干重 `CHPDT`；
   - 单次干重 `HPODW`。
2. 鲜重不进入率定。
3. 当前正式比较基线保留“仅 `CHPDT` 使用 `ln(y+1)` 变换”；指标报告必须反变换回原始尺度。
4. 全时序统一 `ln(y+1)` 版本不作为正式结果。
5. 选择性变换试验允许比较：
   - A：原尺度基线；
   - B：仅 `CHPDT` 变换；
   - C：`CHPDT + CHTD` 变换。
6. `LAID` 暂不变换；优先通过观测误差模型处理量级相关异方差。
7. `LWAD`、`SWAD` 保持原尺度；如需评估，只单独试验 `SWAD`，不能将全部过程变量同时变换后直接替换正式基线。
8. 原尺度指标必须显式读取 `transform` 列并进行反变换，禁止属性式访问导致字段名与 pandas 方法冲突。

注意：仓库中的 `direct_chpdt_log_v1.json` 是早期“只有 CHPDT 活跃”的论文合同，不代表近期多目标 E02 的完整观测合同。近期运行必须以设计 JSON 实际引用的 observation policy、PST 和 observation registry 为准。

## 5. 目标族、sigma 与静态预算

目标族预算冻结为：

| 目标族 | 内容 | 预算 |
|---|---|---:|
| `PHENO` | `PDAP`、有效 `ADAP`；不含 `MDAP` | 0.10 |
| `CANOPY` | `LAIX`、`LAID`、`CHTD` | 1.00 |
| `BIOMASS` | `LWAD`、`SWAD` | 1.00 |
| `PLANT_N` | 有效植株氮观测；无观测时不激活 | 1.00 |
| `HARVEST_DRY` | `CHPDT` 与 `HPODW` 共享 | 1.25 |
| `SOIL_WATER` | 非初始土壤水分过程观测 | 1.00 |

执行规则：

1. 多批次采收共享一个 `HARVEST_DRY` 预算；增加采收频次只增加时间分辨率，不线性增加权重。
2. 组权重在构建 PST 时静态计算，率定过程中不动态重平衡。
3. 权重优先使用逐观测重复方差、有效重复数、静态模型误差项和误差下限形成的 `sigma_eff`。
4. 土壤水分历史错误倍率 0.8 已更正为 `sqrt(1/80)=0.111803`。
5. 25FA 提供的单次土壤测量不是初始条件；25FA 真正初始条件以 FileX 为权威。该次测量若进入 Phi，应作为过程观测，不得覆盖 FileX 初始水氮状态。

## 6. 参数边界与季节偏移

1. 预率定结果用于经验初始化和边界提案，不是独立先验。
2. 参数触边不自动扩边。每次调整需区分：
   - 有生理意义且多个成员共同触边：可适度放宽；
   - 物理极限、温度顺序或代偿风险：保持或收紧；
   - 仅最优成员触边：不作为扩边依据。
3. 正式运行只读取 frozen bounds；不得从 proposal 或“最新文件”自动回退。
4. 25SP+26SP 春季联合率定使用 54 个共享参数，`FL-VS=100`，无季节偏移：
   - 参数集：`highdim54_joint_v2_20260729`
   - 边界：`eggplant_e02_joint54_v2_20260729`
5. 25SP+25FA 的 M1 模型使用 54 个共享参数和 7 个仅作用于 25FA 的有效偏移：
   - `DLFMAX_AUT`
   - `DSLAVR_AUT`
   - `DXFRT_AUT`
   - `DSFDUR_AUT`
   - `DTB1_AUT`
   - `DTB2_AUT`
   - `DTB3_AUT`
6. 秋季偏移是季节条件下的有效过程修正，不解释为第二套遗传参数。

## 7. 25FA 数据与日期决定

1. 25FA 新 FileA/FileT 已恢复三个生长测定日期：
   - 2025-10-02（`25275`）；
   - 2025-12-08（`25342`）；
   - 2026-01-10（`26010`）。
2. 25FA 原始 LAI 均值随日期递增；不存在首期 LAI 高于后期的观测错误。
3. 旧三季动态图把 `26010` 因跨年和轨迹外日期保留为 `DOY=10`，与 DAP 50、117 混排，属于绘图数据契约错误。
4. 更重要的是，25FA DSSAT 日轨迹止于 2026-01-06，过程读取器将 2026-01-10 的观测与 1 月 6 日模拟值配对。
5. 在 `e02_joint61_m1_offsets_150x6_20260729_084500` 最优成员 85 中，末次 LAID/LWAD/SWAD/CHTD 共 32 点贡献 Phi 64.419，占 actual Phi 的 22.26%。
6. 因此：
   - 25FA 原始观测和 FileT 数值不修改；
   - 旧 25FA 动态图时间轴失效；
   - 含 25FA 的秋季联合率定后验在延长模拟期并同日配对重跑前，不升级为权威论文结果。

## 9. 最优成员与报告规则

1. “最佳参数组”默认指最终 IES ensemble 中 actual Phi 最小成员，不是末轮参数中位数。
2. 报告同时保留：
   - 最佳成员；
   - 最终 ensemble 中位数/分位数；
   - 参数触边比例；
   - 分季节、分变量的原尺度 RMSE、RRMSE、NSE、R² 和 MBE。
3. 原尺度评价不能跨单位合并。
4. `R²` 高但 `NSE` 低通常表示时序或处理排序可解释、尺度/偏差较差，不能只报告 `R²`。
5. 率定内拟合、参与结构选择的数据和真正独立验证必须明确分开。
