### 关键观察

1. **25FA 季 CHPDT 拟合优秀**（single_25fa 与 joint 的 25FA 部分）：点紧贴 1:1 线，量级覆盖 4.7–8.7（log）即 ~100–6200 kg/ha，无系统偏差。这是去掉 CHFPW 后干重作为唯一采收目标的最佳证据。

2. **25SP 季 CHPDT 系统性低估**：点群整体位于 1:1 线下方。这不是去掉 CHFPW 引入的问题——v4（含 CHFPW）的 25SP 同样存在该季拟合弱（见后验对比中 25SP 生物量偏差）。25SP 春季早期叶/茎/果发育速率与模型结构不匹配是参数集已知的 science_pending 限制。

3. **偏差是系统性的（整体平移），非随机散布**：25SP 的 ME=−1.84 远大于 MAE 的离散，说明可通过对数尺度偏置修正大幅改善，提示存在季节性系统误差（如移栽日/起始生物量），而非参数不可识别。

## ③ dry-only vs v4（CHFPW+CHPDT）后验对比（joint）

对照运行：
- **dry-only joint**：`eggplant_t10_dryonly_20260723_202942_joint`（194 reals）
- **v4 joint**：`eggplant_t10_joint_20260723_000453`（196 reals，CHFPW+CHPDT 均活跃，engineering_validated）
- 两者共享相同 64 参数列（41 active + 23 fixed）、相同冻结边界、相同 IES 数值 profile。

### 总体统计

| 指标 | 数值 |
|---|---|
| 对比参数总数 | 64 |
| 中位数偏移 \|shift%\| > 50% | **9 个** |
| 中位数偏移 \|shift%\| > 20% | **19 个** |
| 中位数偏移 \|shift%\| ≤ 10%（基本不变） | **36 个**（56%） |

**结论：去掉 CHFPW 后，过半参数（56%）后验中位数基本不变（≤10%），后验无任何参数变宽，6 个参数反而收紧。** 这说明去掉鲜重目标后，率定整体稳定，未引入新的不确定性膨胀。

### 解读

1. **果实/叶尺寸类参数（SIZREF/SIZLF/FINREF）整体下移**：去掉鲜重约束后，模型不再需要同时匹配鲜重的绝对量级（鲜重含水量高、量级是干重的 ~20 倍），转而只拟合干重，因此尺寸标定参数系统性减小。**这是去掉 CHFPW 的预期直接效应**，符合物理逻辑。

2. **氮代谢类参数（NMOBMX/NVSMOB/NSTFAC/NRCVR/RTNO3）显著偏移**：这些参数原本部分由鲜重（含氮稀释）间接约束。去掉鲜重后，氮相关约束来源减少，后验向边界漂移。偏移方向需结合 CHPDT 拟合质量判断——由于 CHPDT 的 R 仍达 0.90，这些偏移未破坏干重拟合。

3. **PHTMAX/PARMAX 上移**：光合上限参数在只拟合干重时上移，可能因干物质累积对光合响应更敏感。

4. **异参同效信号**：NMOBMX、KC_SLOPE 等 shift%>100% 但 IQR 不变，提示存在补偿效应（多参数联合达到相近 CHPDT 拟合）。这与本项目已记录的异参同效审查方向一致。

## 综合结论

| 维度 | 结论 |
|---|---|
| **CHPDT 拟合质量** | 25FA 优秀（R=0.97，无系统偏差）；25SP 系统低估（季节性初始条件问题，非去 CHFPW 所致） |
| **去掉 CHFPW 的影响** | 果实/叶尺寸标定参数系统性下移（预期效应）；56% 参数后验基本不变 |
| **后验稳定性** | 无参数 IQR 变宽，6 个收紧——去 CHFPW 未引入不确定性膨胀 |
| **风险点** | 氮代谢参数（NMOBMX/NSTFAC 等）漂移较大，shift%>100%，提示鲜重曾是这些参数的隐式约束；建议后续重点审查这几个参数的异参同效 |
