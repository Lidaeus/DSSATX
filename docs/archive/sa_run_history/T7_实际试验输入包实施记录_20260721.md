- 原 XXQL2502、XXQL2601 FileX 的 OPTIONS 行保持固定宽度，仅将 `SYMBI` 从 Y 改为非豆科适用的 N；`POTAS=N` 保持不变。

- 用户确认 plot 1–12 与 TN1–TN12 一一对应。FileA/FileT 标题改为 DSSAT `*EXP.DATA (A/T)`，TRNO 注释改为 `DSSAT treatment number`；数据行和观测数值没有改变。

观测粒度仍是 `experiment + treatment + date + variable` 的处理/小区均值。标准化 TRNO 语义只修复键的定义，不把均值扩展成不存在的重复观测。

## 4. 剩余警告不会被静默填补

| 警告 | 影响 | 当前处理 |
|---|---|---|
| SOIL.SOL 在 145/175/203 cm 的 SSKS 与 SLCL/SLSI 缺失 | DSSAT 可能使用缺省深层水力/质地信息 | 保留 warning；不凭空补值。主要根区敏感性需披露此限制 |
| XXQL2502 无 CNAM，仅有 SNAD/LNAD | 不能直接形成总植株氮观测 | 器官 N 与模拟定义审核前只作 diagnostic |
| XXQL2601 无植株 N | 不能独立验证 N 再分配系数 | 仅验证冠层、产量和水氮处理响应 |
| FileA/FileT 为处理均值且无独立重复统计表 | 不能从当前文件估计 observed SE | 后续冻结 assumption-based sigma，并在获得 n/SD/SE 后替换；不伪造重复 |

## 5. 构建方法与可复现入口

`tools/import_experiment_bundle.py` 新增：

- `--observation-source-dir`：FileX 来自已修复 source candidate，FileA/FileT 来自已确认的原观测目录；
- `--scenario-role calibration|validation`：冻结用途并对 validation 加禁止率定条款；
- `--actual-trial-reference-filex`：比较逐处理 IC/SA/MI/MF 和两个实测区段，发现池化或改值立即失败。

回归测试位于 `tests/test_actual_trial_bundles.py`，覆盖 manifest 完整性、用途门、实测 IC/SA 保留、标准 TRNO、观测审计及原 FileX `SYMBI=N`。

## 6. 下一步只剩率定配置门

输入格式和 actual-trial 保留不再是阻塞项。正式 PEST-IES 前仍需：

1. 冻结 XXQL2501+XXQL2502 的多季处理角色与唯一观测名；
