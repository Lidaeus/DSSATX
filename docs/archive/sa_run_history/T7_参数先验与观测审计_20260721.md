## 2. 文献证据如何使用

### 2.1 证据层级

| 层级 | 内容 | 可用于什么 | 不能用于什么 |
|---|---|---|---|
| A | 茄子温度、开花、光合、水氮响应和氮吸收的直接试验 | 物理包络、响应方向、排序约束、先验强弱 | 直接等同于 DSSAT 内部系数 |
| B | DSSAT/CROPGRO 官方参数定义、同模块作物系数和模型文献 | 参数含义、单位、同模块合理范围 | 证明本品种参数已被识别 |
| C | 当前模型安全测试和物理硬边界 | 防止数值崩溃、保证温度有序 | 作为生物学最佳值 |

DSSAT 的 CROPGRO 模板本来就要求综合田间试验、品种试验和论文证据建立遗传参数，而不是只凭一次优化结果定值；PEST++-IES 的 bounds/covariance 定义的是先验可访问空间，也不自动赋予边界生物学真实性。

### 2.2 当前范围与约束建议

下表的数值是现有 v3 候选边界，文献用于审核其物理合理性和先验强度；本轮不自动创建新的 frozen bounds。

| 参数 | 当前范围 | 直接观测支持 | 本轮先验/约束 |
|---|---:|---|---|
| TRIFL | 0.20–0.85 | LAI 时序，间接 | 中等先验；与 EM-V1/温度参数审查补偿 |
| EM-FL | 23–31 | XXQL2501 ADAT，但日期在处理间重复 | 中等偏强；不得把重复日期当 10 个独立观测 |
| EM-V1 | 10–40 | 无第一真叶日期 | 较强模型先验 |
| FL-SD | 7–21 | 无第一种子/坐果日期 | 较强模型先验 |
| TB2 | 8–12 °C | 无控温观测 | `TB2 < TO12`；A+B 级温度包络 |
| TO11 | 20–27.5 °C | 无控温观测 | 固定 TB1/TO21 之间，保持阶段 1 有序 |
| TO12 | 20–27.5 °C | 无控温观测 | `TB2 < TO12 < TO22` |
| TO22 | 28–33 °C | 无控温观测 | `TO12 < TO22 < TM2` |
| LFMAX | 1.27–1.36 | LAI/生物量，间接 | 初值在下界；需无边界堆积的先验采样 |
| XFRT | 0.73–0.99 | 增量采收，较强间接 | 初值在上界；保存 base realization |
| XFINT | 0.12–0.35 | 多次采收时序，间接 | 中等先验，继续遵守数值安全下限 |
| FRLFF | 0.26–0.48 | 无根观测 | 强先验；不可据后验收缩声称根分配已验证 |
| FRSTMF | 0.37–0.69 | 无根观测 | 强先验；与 FRLFF 联合审查 |
| RTNO3 | 0.008–0.05 | N 处理响应；XXQL2501 CNAM | 中等先验；重点报告水氮响应差而非只看 Phi |
| RTNH4 | 0.01–0.05 | 无 NH4 动态 | 强先验；若与 RTNO3 强补偿，优先固定 RTNH4 |
| NMOBMX | 0.08–0.40 | XXQL2501 CNAM；XXQL2502 器官 N diagnostic | 强先验；审查坍缩和边界 |
| NVSMOB | 0.20–0.50 | 无直接再分配观测 | 强先验；若与 NMOBMX 补偿，优先固定/收紧较弱者 |

茄子温度研究覆盖约 12–28 °C 并观察到开花、果实生长和产量的非线性温度响应，支持温度包络和有序约束，但不足以单独识别四个 DSSAT cardinal-temperature coefficients。茄子水氮试验和氮代谢研究支持把水×氮响应、植株氮和产量共同用于核验 `RTNO3/RTNH4/NMOBMX/NVSMOB`，但没有给出可直接转换的 DSSAT 系数值。因此 N 参数的数值边界主要仍来自 CROPGRO 同模块范围和当前安全审计，文献只改变先验强弱与约束优先级。

## 4. 异参同效如何反馈到下一轮边界

反馈是“提案—人工审批—新确认轮”，不是自动在线调参：

1. 先并列 prior/posterior Spearman、边界比例、IQR 收缩和多峰提示；
2. 从 best Phi +5% 内选参数距离大的最多 3 对，逐 realization 确定性复跑；
3. validation/diagnostic prediction distance 也接近才标记功能性异参同效；
4. 对强补偿对，优先约束外部证据等级较低、缺少直接观测的一方；温度参数只加有序/文献包络约束，N/根参数优先收紧弱先验或固定，而不是增加伪观测；
5. 边界堆积先检查边界错误和模型结构偏差，不能机械缩界；
6. 所有建议写入新的 bounds proposal，记录依据、旧范围、新建议和预期可区分观测。不得修改原 run 的 frozen bounds，也不得使用 XXQL2601 validation 结果挑选更好看的范围。

首轮重点审查对：`RTNO3–RTNH4`、`NMOBMX–NVSMOB`、`FRLFF–FRSTMF`、`EM-V1/TRIFL–温度系数`、`XFRT–XFINT`。这只是预注册的审查优先级，不预判它们一定共线。
