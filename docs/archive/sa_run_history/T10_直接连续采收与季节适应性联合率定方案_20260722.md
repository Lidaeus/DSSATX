# T10 直接连续采收与季节适应性联合率定方案

> 状态：待执行的技术方案（2026-07-22）  
> 目标：将 CHFPW、CHPDT 作为连续采收的直接率定证据，取消 PWAD/PWAI 率定；以 200 个集合成员、4 次 IES 更新完成 2025 春—2025 秋联合率定，并用最小必要结构检验季节适应性。  
> 正式率定季节：XXQL2501（25SP）＋XXQL2502（25FA）  
> 封存验证季节：XXQL2601（26SP）

本方案的季节性假设、三阶段基温结构和失败域处理分别依据：

- [`data/user/ref/春秋季节参数适应性参数率定参考方案.md`](../../../data/user/ref/春秋季节参数适应性参数率定参考方案.md)；
- [`data/user/ref/率定三基点温度.md`](../../../data/user/ref/率定三基点温度.md)；
- [`data/user/ref/部分情况下运行失败的问题。.md`](../../../data/user/ref/部分情况下运行失败的问题。.md)。

上述文档中的文献依据支持“共享参数优先、季节偏移强约束、SLA 比值去冗余”；具体 Phi 契约、参数数量和运行门禁则由本项目 T9 代码与运行证据确定。

连续采收的误差尺度采用 Hopf et al. (2022) *Development and improvement of the CROPGRO-Strawberry model*（DOI: [10.1016/j.scienta.2021.110538](https://doi.org/10.1016/j.scienta.2021.110538)）所启发的累计序列对数处理：在模型输出与观测均为正值、且方差随累计量增加的前提下，使用同尺度 log 残差缓解异方差。该选择只适用于 T10 的 CHFPW/CHPDT 累计序列，不自动外推到 LAI、器官干物质或其他变量。

## 技术结论

T10 不应在 T9 上简单改两个变量名后重跑。当前 T9 的真实行为是：`--harvest-var CHPDT` 从 FileT 读取累计干重 `CHPDT`，将其改名为 `PWADM`，再差分得到 `PWAIM`；模拟端从 `FreshWt.OUT:CHPDT` 做同样处理。因此，T9 **没有用 DSSAT 默认 PWAD 拟合，但使用了容易误解的 PWAD/PWAI 命名和人为差分；CHFPW 没有进入 Phi**。

T10 作如下冻结决策：

1. 直接使用 FileT 的 `CHPDT` 和 `CHFPW` 累计连续采收序列，模拟值分别来自 `FreshWt.OUT` 的同名列；二者同时进入 Phi。
2. 从正式率定契约中删除 `PWAD`、`PWAI`、`PWADM`、`PWAIM`。不再由累计值差分构造率定观测，也不使用 DSSAT 默认 PWAD。
3. CHFPW、CHPDT 在 PEST 专用输出和观测表中统一应用预登记自然对数变换；FileT、FreshWt.OUT、常规指标、论文图和导出的物理量始终保留原始尺度。
4. 同一品种首先使用跨季共享参数 M0。季节偏移只能作为 M0 之后的受约束结构检验，不能直接建立两套春秋遗传参数。
5. 固定 `SLAREF=300`，只率定 `SLAVR`，消除 DSSAT 内部 `SLAVR/SLAREF` 比值造成的冗余。主率定前必须达到先验集合双季 DSSAT 零失败。
6. T10 的 `XFPHT` 候选范围调整为 `31–70`；仍严格保持 `upper(XMAGE)=30 < lower(XFPHT)=31`，不使用采样后裁剪。
7. 正式 M0 使用 `ies_num_reals=200`、`noptmax=4`。200 是集合大小，输出应包含第 0 轮和第 1–4 轮；不得把“4 轮”解释为总共只保存 4 个状态。
8. T9 结果仅作为诊断证据。它存在 30/600 个非随机 DSSAT 失败、25FA 近零生长响应和大量参数贴边，不能作为 T10 的后验先验直接复用。

## 当前事实与 T9 证据

### 收获指标的现状

当前多季构建器一次只接受一个 `--harvest-var`。T9 固定选择 `CHPDT`：

```text
FileT: CHPDT -> PWADM -> 差分 -> PWAIM
FreshWt.OUT: CHPDT -> PWADS -> 差分 -> PWAIS
```

因此对用户问题的直接回答是：

- `CHPDT`：实际参与了 T9，但被伪装成 PWAD/PWAI 观测；
- `CHFPW`：未参与 T9 Phi；
- DSSAT 默认 `PWAD`：当前主链路并未用它作为首选值，但旧命名、回退分支和报告映射仍有混淆风险；
- T10：同时直接率定 `CHPDT`、`CHFPW`，彻底移除 PWAD/PWAI 的率定语义。

### 当前 Phi 预算实现会随采收次数膨胀

`build_pest_multiseason.py::_apply_t8_weights` 当前对每个 `obgnme` 分别应用一次家庭预算。`25SP_PWAIM_H1` 至 `H11` 因而各得到一次 `INCREMENTAL_HARVEST` 预算，而不是 11 轮共同分享一次预算。结果是采收轮次越多，收获家庭的总预期 Phi 越大。

T10 必须改为“家庭—季节—变量”三级预算，预算只能分配一次，不能按 H1、H2……重复生成。

### 贴边与失败不支持继续机械扩边

T9 第 2 轮保留 570 个成员，最佳成员为 realization 164，Phi=273.924。按参数跨度 2% 定义近边界，最明显的末轮聚集为：

| 参数 | T9 范围 | 近下界 | 近上界 | 最佳成员 | T10 处置 |
|---|---:|---:|---:|---:|---|
| PODUR | 25–60 | 70.9% | 0.0% | 25 | 暂不扩边；更换直接收获目标后复核 |
| XFRT | 0.70–1.00 | 0.0% | 67.5% | 1.00 | 保留物理上限，不允许超过 1 |
| EM-FL | 23–42 | 65.8% | 0.0% | 23 | 物候低优先级，M0 固定为基线值 |
| XFPHT | 35–70 | 54.7% | 0.0% | 35 | T10 放宽为 31–70；仍保证 `XMAGE < XFPHT` |
| RTNH4 | 0.008–0.05 | 39.8% | 0.0% | 0.00890 | 保留但检查 N 观测支持度 |
| PM09 | 0.60–1.00 | 0.0% | 37.4% | 1.00 | 不越过比例物理上限 |
| SDPDV | 80–300 | 32.1% | 0.0% | 229.7 | 不因边界频率单独扩边 |

这些聚集可能同时来自错误的收获目标、季节运行异常、参数代偿和模型结构不足。只有在 T10 工程门禁通过、直接指标残差仍沿同一方向、且文献或独立观测支持时，才允许提出新边界。

## T10 观测与误差契约

### FileA/FileT 保持 DSSAT 兼容，标准差使用旁车表

FileA/FileT 继续保存实际尺度上的处理均值，不加入代码内部变换值，也不破坏 DSSAT 默认格式。标准差、重复数和误差来源写入旁车文件：

```text
observation_uncertainty.csv
season_id,treatment,date,variable,mean,sd,n_rep,n_eff,source,note
25SP,2,25140,CHFPW,4710,...,...,...,measured_replicates,...
25SP,2,25140,CHPDT,235,...,...,...,propagated_or_measured,...
```

主键必须是 `(season_id, treatment, date, variable)`。`variable` 至少允许 `CHFPW`、`CHPDT`、`LAID`、`LWAD`、`SWAD`、`CNAM`。FileT 中的均值与旁车表 `mean` 必须在写入精度内一致，否则构建失败。

若有重复观测，均值的观测误差使用：

\[
\sigma_{\mathrm{eff}}=
\sqrt{\frac{s^2}{n_{\mathrm{eff}}}+\sigma_{\mathrm{model}}^2+\sigma_{\mathrm{floor}}^2},
\qquad w_0=1/\sigma_{\mathrm{eff}}.
\]

其中 `n_eff <= n_rep`；重复之间存在空间或时间相关时降低 `n_eff`。不能把重复的标准差 `s` 直接当作均值的标准误，也不能在缺少重复数据时伪造 `n_rep`。

25FA 的 CHPDT 由鲜重和果实干物质比例计算时，与 CHFPW 并非独立。若原始重复可用，应在重复层面先计算干重再汇总；否则按误差传播：

\[
\sigma_D^2 \approx p^2\sigma_F^2+F^2\sigma_p^2+\sigma_{D,\mathrm{model}}^2,
\]

并把 `source=propagated_from_fresh_and_dm_fraction` 写入旁车表。缺少可审核 SD 时，可使用预先登记的 CV＋误差下限完成工程试跑，但该运行不得标记为 `science_validated`。

### 累计采收的 log Phi 定义

CHFPW、CHPDT 的累计量在 PEST 专用观测和模拟 token 中使用自然对数；其他变量仍使用原始尺度。固定定义为：

\[
z=\ln\left(\frac{y+c}{r}\right),\qquad c=r=1\ \mathrm{kg\ ha^{-1}}.
\]

`c=1 kg ha⁻¹` 是预先冻结、具有单位意义的零点修正；它使零累计量可定义，同时相对于现有收获量级可忽略。观测与模拟必须使用同一个 `c` 和 `r`，`y+c<=0` 直接失败。实现时不得调用没有单位说明的 `log1p`，尽管在这里数值上等价于 `ln(y+1 kg ha⁻¹)`。

原始尺度的 `sigma_raw` 依照重复/误差传播获得，再转换为：

\[
\sigma_{\log}=\sqrt{\ln\left[1+\left(\frac{\sigma_{\mathrm{raw}}}{y+c}\right)^2\right]},
\qquad w_0=1/\sigma_{\log}.
\]

`observation_registry.csv` 和 weights audit 必须同时保存 `raw_obsval`、`raw_sigma`、`transform=log`、`transform_offset=1`、`transform_reference=1` 与写入 PST 的 `obsval/sigma`。Phi、组 Phi 和 IES 更新使用 `z`；RMSE、MAE、RRMSE、NSE、bias、1:1 图、采收轨迹与论文文字只使用原始 kg ha⁻¹。log 缓解异方差，不消除累计序列的时间相关性，故仍须执行本方案的家庭总预算控制。

### 直接收获输出契约

每个处理、每个实测采收日期只写一行。runner 先从 `FreshWt.OUT` 读取原始 `CHFPW`、`CHPDT`，把原始值写入 audit/配对表和 `PestHarvest.OUT`；随后由与观测端共用的 observation-transform 配置就地转换 tagged 输出。该顺序保证 log 只执行一次，且 FileT、FreshWt、常规指标与图表始终保持原始尺度。

```text
RUN 1 TN 2 HNO 1 DATE 25140 @CHFPWS_LOG@ 8.458 @CHPDTS_LOG@ 5.476
```

PEST 观测命名建议为：

```text
25SP_CHFPWM_LOG_T02_D25140
25SP_CHPDTM_LOG_T02_D25140
25FA_CHFPWM_LOG_T03_D25325
25FA_CHPDTM_LOG_T03_D25325
```

模拟 token 分别为 `CHFPWS_LOG`、`CHPDTS_LOG`。注册表必须保留：季节、试验代码、TN、全局 RUN、日期、HNO、原始变量名、原始 kg ha⁻¹ 值、变换定义、单位、sigma 来源和 Phi 角色。常规 comparison、metrics 和论文数据只能使用原始变量名与原始值，不能误把 `_LOG` token 导出为物理量。

不再生成或读取：

```text
PWADM PWAIM PWADS PWAIS
```

旧接口可为历史结果读取保留适配器，但 T10 design 一旦出现上述任一活动变量就立即失败。

### 采收日历、虚拟末次事件与有界就近读取

DSSAT 的采收量在采收日完成日更新后才写入输出。若最后一次真实采收日同时是模拟结束日，最后一笔真实采收量不会出现在可读取输出中；同一日历语义也使模型管理采收应比真实采收日早 1 天，才能与真实事件对应。

T10 对每个处理采用下列固定规则：

| 对象 | 日期规则 | 是否进入 Phi |
|---|---|---|
| 真实 FileT 观测 | 实测采收日 `d` | 是 |
| 本地 FileX 的真实模型采收 | `d-1` | 间接用于对应真实观测 |
| 本地 FileX 的虚拟末次采收 | 最后一个真实模型采收日后的 1 天 | 否，仅促使最后真实采收量写出 |
| 模拟结束日 | 不早于虚拟末次事件后的 1 天 | 否 |

虚拟事件只能写入每个 worker 的本地 FileX 副本，绝不能回写 input bundle；它不得生成观测、权重、图表点或管理结论。构建 manifest 需记录真实事件数、虚拟事件日期、实际模拟结束日和 FileX 副本哈希。

提取 CHFPW/CHPDT 时，以真实 FileT 日期 `d` 为中心，在 `[d-1,d+1]` 内从 FreshWt.OUT 选择绝对日期差最小的有限值；同距离时选较晚日期，以匹配“日更新后可见”的 DSSAT 写出语义。窗口内无值、候选值不唯一且无法按上述规则决出、或选择结果跨越 1 天，均为提取失败。registry 必须记录 `observation_date`、`scheduled_harvest_date`、`selected_simulation_date`、`date_distance_days`、`is_virtual_terminal_event` 和候选日期数。此为**有界且可审计的就近读取**，不是无约束 nearest-on-or-before。

Smoke 必须逐行比较 25SP、25FA 的首个、一个中间和最后真实采收事件，并确认最后一个 Phi 观测由虚拟末次事件后可用的输出正确取得。

### 输入质量门禁

每季每个 TN 分别检查：

1. CHFPW、CHPDT 非负且随采收日期单调不减；
2. 同日 `0 <= CHPDT <= CHFPW`；
3. `CHPDT/CHFPW` 位于预先审核的果实干物质比例范围，异常只报告，不自动删除；
4. 日期严格递增，重复日期必须合并或解释；
5. 一个变量为 `-99` 时仅跳过该变量，不能删除同日另一有效变量；
6. 构建出的活动观测数必须与 registry、PST、instruction file 完全一致。

## Phi 预算：让两季和两种收获量真正可比

T10 使用分层预算，建议初值如下：

| 家庭 | 总预算 | 子变量 |
|---|---:|---|
| PHENOLOGY | 0.10 | ADAP；低优先级 |
| CANOPY | 1.00 | LAID；LAIX 仅诊断 |
| BIOMASS | 1.00 | LWAD、SWAD，各分 0.50 |
| PLANT_N | 1.00 | CNAM；仅有观测的季节参与 |
| HARVEST_FRESH | 1.25 | CHFPW 全累计序列；log Phi |
| HARVEST_DRY | 1.25 | CHPDT 全累计序列；log Phi |

鲜、干收获合计预算为 2.50，植株氮预算为 1.00，反映连续采收和水氮响应均为本研究核心目标。鲜、干收获仍共享来源且相关，因此不因新增采收日期或虚拟末次事件再次增加预算；后续可根据真实重复 SD 调整 sigma，不得为改善拟合而事后调整预算。

对家庭 `f`、季节 `s`、子变量 `v` 中的第 `i` 个观测：

\[
w_i=\frac{1}{\sigma_i}
\sqrt{\frac{B_f\,a_{s|f}\,a_{v|f}}{n_{fsv}}},
\]

其中同一家庭内季节份额默认相等，子变量份额按上表分配，`n_fsv` 是该季节—变量单元内的活动观测数。关键约束是所有 H1…Hn **共同**分享一次变量预算。审计文件应验证每个单元的 `sum((w_i*sigma_i)^2)` 等于其分配预算。

累计序列存在时间相关性。T10 先通过固定家庭总预算防止采收次数支配 Phi，并在报告中明确采用对角误差模型；不在本轮引入完整时序协方差矩阵。论文中的“后验”应表述为“在已声明对角误差模型条件下的 IES 条件集合”。

## 春秋季节差异：先共享，再一次只检验一个机制

### M0 是正式主模型

同一品种的遗传参数跨 25SP、25FA 共享。三个生育时期允许不同的基础温度：

```text
TB1 = 营养阶段基温
TB2 = 早期生殖阶段基温
TB3 = 晚期生殖阶段基温
```

M0 中三者跨季共享。为了避免基温与生理日数等效：

- `TB1/TB2/TB3` 活动，暂保留 6–14 ℃物理候选范围；
- `TO11–TO23`、`TM1–TM3` 在本轮固定到经审核基线，不与三个 TB 同时自由率定；
- `EM-FL` 固定到当前基线 23.3；
- `EM-V1` 固定为已接受的旧 EM-V1 基线 22；
- `FL-VS` 本轮固定为 120，其 100–140 范围保留给后续敏感性/稳健性试验；
- 物候只分配 0.10 预算，不允许用低解释力 ADAP 强迫温度参数贴边。

### 25FA 近零输出首先按工程或输入问题处理

T9 中 25SP 多个冠层/生物量指标可拟合，而 25FA 集合模拟大面积接近零。如此量级的跨季断裂不能先用“秋季遗传参数”解释。M0 构建前必须对同一共享参数集完成双季确定性核对：

- 作物建立、LAI、LWAD、SWAD、CHFPW、CHPDT 均产生非缺失且非结构性近零输出；
- 逐季核对天气、温室温度、辐射、移栽日期、模拟终止日期、FileX 模块开关、土壤/初始水氮和管理事件；
- 确认各季写入的是各自隔离的 CUL/ECO/SPE 文件副本；
- 若旧 25SP 最佳参数导致 25FA 近零，报告触发的阶段/胁迫过程，而不是立刻放开季节偏移。

### M1：共享参数＋逐参数秋季偏移（2026-07-23 批准替换）

M1 仍不是第二套春、秋遗传参数。PEST++ 只率定一组共享参数 \(\theta\)；25SP 和
26SP 均注入 \(\theta\)，25FA 只对预先登记的、具有季节生理依据的参数施加各自偏移。
这样任何秋季结果都可复算为“共享值＋偏移量”，并能与共享参数和偏移后验一起进行
共线性、异参同效和模型评价。

| 参数 | 25FA 投影 | 偏移范围 | 保留理由 |
|---|---|---|
| `TB1/TB2/TB3` | `TBj_aut=TBj_shared+DTBj_AUT` | 每项 -2～2 ℃ | 分阶段温度响应的待检验季节修正；`TO/TM` 仍固定 |
| `LFMAX` | `LFMAX_aut=LFMAX_shared*exp(DLFMAX_AUT)` | 0.85–1.15 倍 | 温度、DLI、叶氮与叶龄对有效光合能力的影响 |
| `SLAVR` | `SLAVR_aut=SLAVR_shared*exp(DSLAVR_AUT)` | 0.85–1.15 倍 | 光温氮环境造成的叶片厚度和面积—质量关系变化 |
| `XFRT` | `logit(XFRT_aut)=logit(XFRT_shared)+DXFRT_AUT` | logit ±0.35 | 源库与果实负载的有效季节差异；变换天然保持 \(0<XFRT<1\) |
| `SFDUR` | `SFDUR_aut=SFDUR_shared*exp(DSFDUR_AUT)` | 0.85–1.15 倍 | 已有逐次采收数据，允许检验果实生长时长的有效修正 |

`DTB1_AUT`、`DTB2_AUT`、`DTB3_AUT` 是三个不同参数，不使用共同 `DTB_AUT` 掩盖阶段差异。
为保证任何独立抽样都符合 DSSAT 的 4–15 ℃物理边界，共享 `TB1/TB2/TB3`
冻结为 6–13 ℃，偏移为 -2～2 ℃；构建器会在创建 PST 前验证完整参数矩形域。
`XFRT` 的共享上界改为 0.98，避免 logit 变换在 1.0 处无定义。

#### M1 数值稳定性修复（2026-07-23）

首次 M1 运行的 23 个成员丢失均发生在 PEST++ 的 lambda/line-search **试算更新**阶段；初始 200 个成员均给出了有限 Phi，且失败季节为 25SP，故不能归因为秋季偏移投影。默认 `ies_lambda_mults=0.1,1,10` 与 `lambda_scale_fac=0.75,1,1.1` 会试探过于激进的 0.075 倍更新；对于 48 个活动参数的非线性 DSSAT 响应，该试算可触发原生程序崩溃，并使 PEST++ 删除相应成员。

修复后的 M1 保持观测、权重、参数边界、偏移定义和 `ies_bad_phi_sigma=1e300` 不变，仅冻结数值更新配置：

```text
ies_use_approx      = false     # 使用包含先验约束的完整 IES 更新
ies_lambda_mults    = 0.5,1,10 # 不再试探 0.1 倍的激进阻尼
lambda_scale_fac    = 0.9,1.0  # 不再试探 0.75 倍步长
ies_enforce_bounds  = true
```

这不是用高 Phi 筛除或运行器安全阈值冻结成员；正常运行的高 Phi 成员仍完整保留。重跑仍须满足：DSSAT 工程失败不超过 2%、末轮保留率至少 98%、偏移后验不出现系统性双边贴界，才可进入拟合比较和后验解释。

该 M1 是用户批准的针对性扩展，活动参数由 41 增至 48；不对 `PODUR`、`WTPSD`、
`SDPDV`、`SIZLF` 等混杂更强或缺少直接观测的参数建立偏移。由于只有一个秋季试验，
所有偏移必须称为“季节适应性/结构不确定性参数”，不能宣称为稳定的秋季遗传参数；
也不得据此声称获得了普适的温度驯化机制。

## 运行失败修复与参数重构

T9 的 30 个失败全部发生在 25SP，且主要集中在 `SLAREF`、`SLAVR`、`TRIFL` 的耦合区域。DSSAT 内部使用 `SLAVR/SLAREF` 缩放有效 SLA，因此 T10 采用：

```text
SLAREF = 300       # fixed
SLAVR  = 240–330   # active; SLA ratio 0.80–1.10
TRIFL  = 0.40–0.65 # active but narrow; until main-stem leaf-count evidence exists
```

不把决策树切点 270.56、0.68、321.81 当作生理边界。运行时额外写出：

```text
sla_ratio = SLAVR / SLAREF
sla_trifl_index = sla_ratio / TRIFL
leaf_appearance_area = TRIFL * SIZLF
```

每个成员必须区分：

```text
failed_25SP_dssat
failed_25FA_dssat
failed_26SP_dssat
failed_output_extract
failed_merge
```

失败记录包含 DSSAT 返回码、WARNING/ERROR 摘要、缺失文件、缺失 token、季节、TN 和参数哈希。主率定前执行双季 200 成员 prior preflight；接纳条件为 DSSAT 非零退出 0、提取失败 0、合并失败 0。对单次原生 DSSAT 非零退出，调度器以完全相同的候选参数自动重试一次；重试成功则保留该成员并将事件写入 `dssat_retries`。正式 IES 中，两次均失败的成员必须标记为 `model_failed`，不得伪装成高 Phi 剔除；`ies_bad_phi_sigma` 保持禁用的极大值。工程门允许的缺失 Phi 槽比例最多为 2%，且末轮成员保留率仍须至少为 98%；超出任一上限即阻断后续分析。只有明确 `model_failed` 的成员才可从统计分析中排除。运行器不得以历史经验安全阈值或参数关系启发式覆盖已经冻结的 T10 参数范围；这类情况必须写入 `RUNNER_ADVISORY`，仍将原始候选值交由 DSSAT 实际判定。例如 `XFINT=0.08–0.50` 均应被注入，低于历史提示值 0.12 时只记录告警。

## T10 参数规模与边界策略

200 个成员不适合继续无审计地释放 T9 的 55 个参数和 12 个温度曲线参数。T10 M0
为 41 个活动共享参数；已批准的 T10 M1 在此基础上增加 7 个预先登记的秋季偏移，
共 **48 个活动参数**，约 4.2 个成员/参数。该规模只用于本次已限定的结构检验，不能
继续静默增加季节自由度。

建议活动候选池：

```text
# 冠层与生长
LFMAX SIZLF SLAVR KCAN KC_SLOPE PARMAX PHTMAX FINREF SIZREF VSSINK
RHGHT RWDTH TRIFL

# 果实形成与连续采收
XFRT FL-SD FL-SH PODUR SDPDV SFDUR JU-R0 LNGSH
PM06 PM09 XFINT XFPHT XMAGE

# 水氮过程
ATOP FRLFF FRSTMF PORPT WTFSD
RTNO3 RTNH4 RTEXF NSTFAC NMOBMX NVSMOB NRCVR

# 三阶段共享基温
TB1 TB2 TB3
```

共 41 个。`SLAREF`、`EM-FL`、`EM-V1`、`FL-VS`、`PL-EM`、`TO11–TO23`、`TM1–TM3` 在 M0 固定。若新的 CHFPW/CHPDT 定向敏感性筛查表明某候选在所有核心目标上稳定低影响，可固定；若需增加候选，活动数超过 45 前必须重新审核集合规模，不能静默突破。

边界处置原则：

- XFRT、PM06、PM09 等比例参数不得突破物理区间；
- PODUR 保留 T9 范围；`XFPHT` 根据其 54.7% 近下界率放宽为 31–70，但始终保持 `upper(XMAGE)=30 < lower(XFPHT)=31`；
- T10 prior 不以 realization 164 为中心收缩；旧 25SP 极佳参数集、T9 realization 164 和共享基线只作为三个确定性比较点；
- 每个边界变更记录生理依据、数值稳定依据和影响的目标变量；
- 后验贴边但敏感度低时优先固定/收窄，而非扩边；贴边且敏感、残差方向一致、又有外部依据时才提出 T10.1 边界修订。

## 正式运行设计

### 阶段 0：收获契约与确定性基线

用共享基线、旧 25SP 最佳参数、T9 realization 164 各跑一次 25SP＋25FA。每次均在本地 FileX 副本注入虚拟末次采收事件，生成逐事件 CHFPW/CHPDT 原始尺度对照、log-token 对照和日期映射审计。任何季节近零、虚拟事件未隔离、日期错位、单位不一致或 token 缺失都阻塞后续。

### 阶段 1：T10 prior preflight

- 200 个固定种子先验成员；
- 25SP＋25FA 全处理；
- 仅前向运行，不做 IES 更新；
- 目标：200/200 双季成功、活动观测全有限、两种收获变量均有变化；
- prior ensemble、seed、bounds hash、input bundle hash 全部冻结。

### 阶段 2：M0 正式联合率定

建议冻结启动参数：

```text
ies_num_reals       = 200
noptmax             = 4
ies_bad_phi_sigma   = 1e300
pwtadj1             = disabled
calibration seasons = 25SP,25FA
validation season   = 26SP (sealed)
```

PEST++ 的 lambda 试算会使实际 DSSAT 调用数高于简单的 `200*(4+1)`；启动器应报告预算估计、worker 数和预计磁盘占用，不承诺固定为 1000 次运行。

每一轮保存参数、模拟观测、实际 Phi、组 Phi、成员状态和失败类型。停止条件只使用预先登记的 PEST++ 规则；不得观察结果后临时加轮、改权重或剔除高 Phi 成员。

### 阶段 3：M0 审核后才决定 M1

先按季节—变量报告残差。只有残差模式符合前述机制表时，才构建一个受约束 M1。M1 先做小规模前向/短 IES 工程诊断；若用户批准其科学假设，再用独立 seed 的 200×4 正式运行。不得从多个 M1 中挑最优后只报告胜者。

### 阶段 4：冻结后解封 26SP

模型结构、参数边界、权重和最佳成员选择规则冻结后，才运行 XXQL2601。26SP 不参与 M0/M1 参数更新；一旦用它选择模型结构，应明确其已从纯独立验证转为模型选择数据，不能继续声称完全独立验证。

## 拟合、后验、共线性与异参同效交付

### 拟合能力

不得跨不同单位计算一个 OVERALL RMSE。分别按季节、变量和处理报告：

```text
n, RMSE, MAE, RRMSE, NSE, R², bias, d-index
```

核心变量为 CHFPW、CHPDT、LAID、LWAD、SWAD；CNAM 在有观测的季节报告；ADAP 低优先级；LAIX、HIAM、HWAM、PWAD、PWAI 只允许诊断或完全移除。CHFPW/CHPDT 还需报告最终累计量误差和逐采收日期轨迹误差。

### 条件后验与共线性

基于未进行高 Phi 筛选的末轮成功成员，输出：

- prior/末轮中位数、2.5%–97.5%区间、标准差收缩比；
- 2% 边界邻近率；
- Pearson 与 Spearman 参数相关矩阵；
- 标准化参数 PCA、主补偿轴载荷；
- 按季节和变量组计算的参数—响应相关性；
- 明确区分 prior 结构、全部成功末轮结构和近优成员结构。

### 异参同效

预先定义近优集合为 `Phi <= 1.10 * Phi_min` 且每个核心家庭组 Phi 不超过该家庭末轮中位数的 1.5 倍。若少于 20 个成员，补充报告最低 Phi 的 20 个成员，但必须标记为敏感性定义，不能冒充预登记近优集合。

对近优集合报告参数范围、相关性、PCA、预测包络和不同参数组合下的季节残差。边界调整规则为：

- 多个近优分支都能拟合：保留宽范围并报告不可辨识性；
- 参数贴边但跨分支预测几乎不变：下一版固定或收窄；
- 参数贴边且控制同一方向的系统残差：查找外部证据后再扩边或增加约束；
- 季节偏移与共享参数高度相关：拒绝把偏移解释为稳定遗传差异。

## Smoke 与正式接纳标准

Smoke 先使用 3–5 个手工成员、双季各 2 个处理：

- DSSAT 返回码全为 0；
- 两季 CHFPW/CHPDT 均非缺失、非陈旧、可随参数改变；
- 每个真实 FileT 事件与输出事件一一对应，最后真实事件通过虚拟末次事件后可读；
- PEST token 为 log 尺度，配对表和图表数据仍为原始 kg ha⁻¹；
- 手算 Phi 与 PEST++ Phi 一致；
- worker 串行和至少 2 worker 并行结果哈希一致；
- 清理旧输出后仍得到相同结果。

正式 preflight 接纳标准：

```text
prior members                     200
DSSAT/model failures                0
extract/merge failures               0
active observation finite rate    100%
CHFPW/CHPDT non-degenerate          yes
season mapping mismatches             0
family budget audit mismatches        0
```

正式 M0 完成不等于科学通过。还需满足：末轮成功成员完整、没有高 Phi 自动剔除、各核心变量指标可解释、25FA 不再结构性近零、后验/共线性/异参同效报告齐全。若任一门禁失败，状态保持 `engineering_failed` 或 `science_pending`，不得生成可引用的论文结论。

## 本轮明确不做

- 不实现 7–14 天连续温度驯化模型；
- 不引入完整时序协方差或复杂层次贝叶斯框架；

- 不把 HWAM、HIAM、LAIX、PWAD、PWAI 放入正式 Phi；
