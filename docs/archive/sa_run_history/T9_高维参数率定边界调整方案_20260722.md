# T9 高维参数率定边界调整方案（2026-07-22）

## 技术摘要

建议下一轮不再沿用 T8 的 17 参数窄空间，而采用 **55 个共享作物/生理参数**开展一次高维诊断率定；诊断通过后，再用独立先验开展正式后验率定。物候仅保留低优先级约束，核心评价转向 LAI/叶茎生物量、植株氮和连续采收序列。旧 `stage4_full_v12_best_parameters_fixed.csv` 可用于构造一个有名称、可追踪的诊断起点，但不能直接作为正式先验中心，也不能整套注入当前模板。

核心理由如下：

1. T8 的末轮最低 Phi 确为 realization 53 的 976.022，协作者给出的分变量指标可被独立复现。
2. T8 的 17 个活动参数中，9 个参数有至少 75% 的成员落在上下界 2% 范围内；`XFINT`、`TB2` 已完全坍缩到边界。这不是可直接解释的后验。
3. 旧单季结果的 108 个值中有 26 个是逐层初始水氮或土壤容重；它是“作物参数＋环境补偿”的联合解，不是纯遗传参数解。
4. 按用户决定，T9 的 `EM-V1` 恢复旧版基线 22，并采用 10–40 的诊断范围。原“38–40 才有有限 ADAPS”的检查降级为物候诊断，不再据此排除低值；但低值仍必须保证连续采收和过程输出有效。
5. 高参数反演的价值是让观测信息在受约束的参数空间中流动，而不是无约束地增加自由度。PESTPP-IES 的运行量主要由 ensemble 大小而非参数个数决定，但有限 ensemble 会产生伪相关，因此必须同时提供合理先验、足够 realization 和参数—观测局部化。[White (2018)](https://doi.org/10.1016/j.envsoft.2018.06.009)、[PEST++ Version 5 manual](https://pubs.usgs.gov/tm/07/c26/tm7c26.pdf)

T9 D1 候选边界已冻结为 `eggplant_t9_highdim_v1_20260722`；这并不等同于正式后验结果。D2 仍须在 D1 审核通过后，以独立先验另行冻结并运行。

## 2. 对协作者结论的核验与修正

### 2.1 可以接受的部分

realization 53 的 448 条非零权重观测指标已独立复现，包括总体 Phi、各季节和各变量族的 RMSE、RRMSE、NSE、R² 与 bias。LAI、叶生物量和春季采收量确有明显量级偏差；T8 的 17 参数空间不足以同时调整冠层形成、光合能力、源库关系、果实动态分配和水氮过程。

### 2.2 必须纠正的部分

1. **混合单位总体指标不可作为科学结论。** “总体 RMSE=853.6、RRMSE=103.7%、NSE=0.342”混合了天、LAI 和 kg/ha，只能作为程序复算校验。论文和率定验收必须按季节×变量族报告。
2. **ADAP 偏差方向写反。** 本项目 residual/bias 定义为 `simulated - observed`；bias=-19 d 表示模拟开花约早 19 d，而不是晚 19 d。
3. **不能笼统断言 25SP 比 25FA 更难拟合。** 25SP 的 SWAD 很好、25FA 的 PWAD 较好，而另一些变量方向相反；应按变量族判断。
4. **旧单季结果在可用目标上具有重要参考价值。** 累计采收、LAI 和过程生物量表现较好；旧档案中的 HWAM/HIAM 不适用于连续采收茄子，不能用来否定旧参数集。其主要限制是没有植株氮观测，且混入了初始水氮和土壤容重补偿。

## 3. 旧版数万 Phi 与当前千量级 Phi 不能直接比较

PEST 的 Phi 定义始终是 `Σ(weight × residual)²`，但两版的观测、残差尺度和权重完全不同。

| 对账项 | Phi | 说明 |
|---|---:|---|
| 旧版报告最低值 | 21,552.8 | 246 个活动观测，包含归一化/调整尺度和旧权重 |
| 旧版 HIAM 贡献 | 19,292.2 | 占旧版最低 Phi 的 89.5%；模拟约 0.001–0.004、观测约 0.53–0.61、权重 100 |
| 旧版扣除 HIAM | 2,260.7 | 数量级已降至数千 |
| 再扣除重复进入的 HWAM | 2,115.2 | HWAM 与最终 PWAD 在旧 PST 中使用相同模拟/观测值，形成重复证据 |
| T8 realization 53 | 976.0 | 448 个活动观测，使用原尺度 sigma 和组预算 |

因此，当前 Phi 较小主要是删除不适用的 HIAM/HWAM 目标、改用 `1/sigma` 和组预算后的尺度结果，不表示当前拟合比旧版好一个数量级。Phi 的绝对大小本身不会损害 IES；真正会影响率定的是权重比例错误、重复观测、遗漏重要目标或 sigma 不合理。后续只能在同一冻结观测合同下比较 Phi，并同时报告分季×变量族残差。

## 6. 旧参数集的正确使用方式

### 5.1 可以迁移

旧值可用于以下目的：

- 检查新范围是否遗漏单季可行区域；
- 为诊断运行增加一个 `legacy_compatible_seed`；
- 比较旧解、T8 最优解和宽先验解在两个训练季的残差结构；
- 识别哪些过程参数帮助改善 LAI、生物量和采收曲线。

### 5.2 不可迁移

- `XFPHT` 等仍存在模板语义差异的值；`EM-V1` 已按用户决定恢复旧版基线和宽域，但要先通过 D0 过程/采收有效性检查；
- 逐层 `IC_SH2O/IC_SNO3/IC_SNH4` 作为跨季共同参数；
- 11 层 `SOIL_SBDM` 作为靠产量反推的自由参数；
- `FRCNOD`；
- 将旧单季最优当作正式先验均值。

旧解和 T8 解都使用了当前训练数据中的 XXQL2501。把它们直接当作正式先验中心后再用同一批数据更新，会重复使用证据。PEST 的正式后验解释应从独立于本次观测的先验 ensemble 开始；PEST 官方也建议显式提供先验不确定性/协方差，而不是仅让程序从上下界推导。[PESTPP-IES help](https://help.pesthomepage.org/pestpp-ies.html)

## 7. 观测合同：以连续采收过程为核心

参数扩展之前应完成以下最小修正，否则更大的参数空间只会更有效地拟合错误目标：

1. **ADAP**：保留为低优先级校验，T9 的 PHENO family budget 从 1.0 降至 0.25。即使25SP的8个45 d值继续存在，也不得让它们主导参数更新；若能确认是同一个季节均值，后续再合并为 season-level 观测。
2. **PWAI/PWAD**：它们是当前最贴合连续采收实际的收获指标，但累计序列由增量序列确定，不能把两套完整序列当作独立证据。T9 以全部 PWAI 为主要观测，只让每季最后一个 PWAD 作为累计锚点，其余 PWAD 为 diagnostic。
3. **HWAM**：完全排除率定。builder 已删除 HWAM 目标和 `--hwamm-sigma`，并增加运行时拒绝与回归测试；runner 仍可保留 HWAMS 输出供历史诊断。
4. **地上部总重/含果实总重**：凡算法把已采果实、植株存量或季末总量混合计算的指标，默认不进入 Phi。只有经过逐事件质量守恒核验、能与实测定义一一对应时才允许加入。
5. **LAID/LAIX**：LAID 时间序列参与率定；LAIX 强制为 diagnostic-only，即使 policy 误设为 calibration 也会被代码置零权重。
6. **标准差**：FileA/FileT 中已有均值时，若原始重复仍可获得，应在不破坏 DSSAT 默认格式的伴随 uncertainty 表中记录 `sd`、`n_rep` 和来源。不能把均值的标准误与个体/地块尺度观测误差混用。
7. **25FA ADAP**：当前为 -99/零权重，保持缺测，不用模拟值填补。

T9 新增 `assumption_based_sigma_v3.csv` 和 `t9_multiseason_group_policy_v1.csv`：LAIX诊断化、无HWAM、仅最终PWAD入Phi、PHENO预算0.25。

## 8. 下一次率定的执行设计

### 阶段 D0：兼容性探针

只运行少量确定性参数集：当前基线、T8 realization 53、旧版 `EM-V1=22` 基线、旧最佳兼容参数和混合解。D0 不以 ADAPS 是否有限作为主要通过条件；必须检查所有季节的 DSSAT 成功状态以及 LAID、LWAD、SWAD、CNAM、PWAI、PWAD 是否有限且收获事件数量正确。

### 阶段 D1：高维诊断 IES

- 55 个活动参数；
- 600 realizations；
- `noptmax=2`；
- 显式先验 ensemble，范围约对应截断分布的 ±3 sigma；
- 加入 T8/旧解只作为命名诊断 realization，不用它们重心化整个 ensemble；
- `ies_bad_phi_sigma=1e300`，只剔除真正的模型失败；
- 使用简洁的过程局部化矩阵，阻止明显无关的参数—观测更新，但不做逐观测手工微调；
- XXQL2601 继续封存。
- 使用 `assumption_based_sigma_v3` 与 `t9_multiseason_group_policy_v1`。

建议局部化映射：物候/温度→物候与采收时序；冠层/光合→LAI 与生物量；源库/果实分配→生物量与采收；根水/根氮→水氮处理下的 CNAM、生物量和采收。有限 ensemble 中的伪相关是高维 ensemble 方法的已知风险，局部化应作为必要控制而非装饰。[Khare et al. (2008)](https://doi.org/10.1111/j.1600-0870.2007.00281.x)

诊断门槛：

- DSSAT/解析成功率不低于 95%；
- 不得再出现大批参数完全坍缩到人为边界；
- 分季×变量族残差方向得到改善，不能只看总 Phi；
- LAID、叶/茎生物量、采收和 CNAM 不得由单一组独占改善；物候仅作为低优先级诊断；
- 输出 prior、iteration 1、iteration 2 的完整 ensemble，保留所有模型成功成员。

### 阶段 D2：正式后验率定

D1 审核通过后：

- 使用独立、文档化的先验 ensemble；
- 建议 800 realizations、4 次更新；
- 不使用 T8 posterior 或旧单季 optimum 重心化先验；
- 继续区分 `model_failed` 与 `phi_outlier`；
- 率定结束后才开启 XXQL2601 独立验证。

## 9. 后验、共线性与异参同效分析

正式结果不得只报告“最佳 realization”。最小交付包括：

1. 每个参数 prior/posterior 的中位数、2.5%–97.5% 区间、标准差收缩和边界占比；
2. 每个季节×变量族的 posterior predictive 区间与确定性代表解；
3. prior 与 posterior 的 Spearman 相关矩阵，报告强相关对及其稳定性；
4. 标准化 posterior 参数 PCA，仅用于描述主要补偿方向；
5. 对满足预注册分组表现门槛的行为可接受成员进行聚类，比较不同参数簇是否产生近似相同预测；
6. 分别报告“完整 prior 结构”“仅排除模型失败后的更新结构”“最终行为可接受集合结构”，不能只看筛选后相关性。

范围调整规则应预注册：只有当参数靠边、对应观测组持续改善、模型稳定且方向具有生理合理性时才外扩；若参数靠边但对目标组无稳定改善，应加强先验或固定，而不是继续追边；若多个参数形成稳定补偿簇，应保留异参同效不确定性，或用新的独立观测增加约束。

## 10. 土壤和环境参数策略

采纳附件中的主要原则：可靠实测天气、灌溉、施肥、土壤剖面和每季初始水氮保持固定；三个季节使用各自实测剖面和初始状态。当前没有足够土壤水分/矿质氮动态证据时，不将 SLLL、SDUL、SSAT、SSKS 或逐层初始状态加入本次共同率定。

以后若有分层土壤水分时间序列，可以单独增加少量地块特异 nuisance multiplier，并通过局部化使其只受本地块观测更新，同时强制 `SLLL < SDUL < SSAT`。这应是后续独立任务，不阻塞 T9 作物参数率定。
