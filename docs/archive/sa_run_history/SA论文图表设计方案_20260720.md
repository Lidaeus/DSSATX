## Fig. 1（正文）：SA证据总览

**尺寸：** 双栏183×170mm  
**布局：** 3面板水平排列 (a) Morris跨季共识 (b) Sobol S1/ST (c) 跨季参数一致性

### 面板 (a)：Morris 跨季共识排名

**数据源：** `morris_consensus_ranking.csv`（每季一份）

**图形类型：** 水平条形图，参数为y轴，mu*为x轴，三季用不同颜色

**配色（来自 publication.json）：**
- XXQL2501（春2025）：`#0072B2`（模拟蓝）
- XXQL2502（秋2025）：`#D55E00`（验证橙）
- XXQL2601（春2026）：`#009E73`（绿，需新增）

**展示参数：** Top-15 参数（按三季平均mu*排序），分 general_genetic 和 water_nitrogen_response 两个子面板

**R实现：** 新文件 `paper/R/fig_sa_morris_consensus.R`
- 输入：`morris_consensus.csv`（三季合并，含 season 列）
- 输出：双面板条形图 → `Fig1a_morris_consensus.{pdf,svg,png}`

### 面板 (b)：Sobol 一阶/总效应指数

**数据源：** `sobol_bootstrap_indices.csv`（含 S1, ST, 95% CI）

**图形类型：** 点+误差棒图，S1（实心）和 ST（空心）分别显示，95% CI 为误差棒

**展示参数：** Top-12 参数（按 ST 排序），取三季中 bootstrap_valid_fraction ≥ 0.95 的观测

**R实现：** 新文件 `paper/R/fig_sa_sobol_indices.R`
- 输入：`sobol_indices.csv`（含 S1, ST, S1_ci_low, S1_ci_high, ST_ci_low, ST_ci_high）
- 输出：`Fig1b_sobol_indices.{pdf,svg,png}`

### 面板 (c)：跨季参数一致性

**数据源：** 同上两份数据，交叉计算

**图形类型：** 散点图，x=春季mu*（2501+2601均值），y=秋季mu*（2502），点标注参数名

**辅助线：** 1:1线 + 2x/0.5x封套（用于识别春季/秋季主导参数）

**R实现：** 新文件 `paper/R/fig_sa_cross_season.R`
- 输出：`Fig1c_cross_season.{pdf,svg,png}`

## Fig. S1（补充）：Morris 排名稳定性详情

**尺寸：** 单栏89×170mm  
**布局：** 2面板垂直排列

### 面板 (a)：种子间 Spearman/Jaccard 稳定性矩阵

**数据源：** `morris_seed_pairwise_stability.csv`

**图形类型：** 热力图矩阵（下三角 Spearman r，上三角 Jaccard）

**数据源：** `morris_seed_rankings.csv`（每季每seed）

**图形类型：** mu*（x轴）vs sigma（y轴）散点图，高 mu*/sigma 参数标注名称

**分面：** 三季 × 2域 = 6个子面板（或合并为一个面板，用颜色区分季节）

**R实现：** 同一R文件
- 输出：`FigS1b_mustar_sigma.{pdf,svg,png}`

## 数据合约设计（Python→R）

### 新增 Python 导出字段（`export_paper_data.py`）

在 `export_paper_data.py` 的 `--scenario-type controlled_counterfactual_sa` 模式下，需导出一个额外的 `sa_evidence/` 子目录：

```
paper_data/sa_evidence/
├── morris_consensus.csv         # 合并三季的共识排名
├── morris_seed_rankings.csv     # 合并三季三seed的排名
├── morris_seed_pairwise_stability.csv  # 合并三季的稳定性矩阵
├── sobol_indices.csv            # 合并三季的Sobol S1/ST/CI
├── sobol_convergence_comparisons.csv  # 合并三季的收敛比较
└── sa_data_manifest.json        # SA数据的SHA-256清单
```

### CSV 列规范

**`morris_consensus.csv`**（每行=参数×季节×域）：
```
season, parameter, ranking_domain, mean_score, mean_rank, consensus_rank
```

**`sobol_indices.csv`**（每行=参数×季节×观测）：
```
season, observation, parameter, base_samples, S1, S1_ci_low, S1_ci_high, ST, ST_ci_low, ST_ci_high, bootstrap_valid_fraction
```

### R 端新增文件

| 文件 | 功能 |
|------|------|
| `paper/R/fig_sa_common.R` | SA共享主题：季节配色、参数标签映射、Morris/Sobol数据加载+校验 |
| `paper/R/fig_sa_morris_consensus.R` | Fig1a + FigS1b |
| `paper/R/fig_sa_sobol_indices.R` | Fig1b |
| `paper/R/fig_sa_cross_season.R` | Fig1c |
| `paper/R/fig_sa_morris_stability.R` | FigS1a |
| `paper/R/fig_sa_sobol_convergence.R` | FigS2a + FigS2b |

### `make_all.R` 更新

在 `make_all.R` 中为 `fig1_sa`、`figs1`、`figs2` 添加源码引用：
```r
if (any(c("fig1_sa", "figs1", "figs2") %in% figure_ids)) {
  source("fig_sa_common.R")
}
if ("fig1_sa" %in% figure_ids) {
  source("fig_sa_morris_consensus.R")
  source("fig_sa_sobol_indices.R")
  source("fig_sa_cross_season.R")
}
if ("figs1" %in% figure_ids) {
  source("fig_sa_morris_stability.R")
}
if ("figs2" %in% figure_ids) {
  source("fig_sa_sobol_convergence.R")
}
```
