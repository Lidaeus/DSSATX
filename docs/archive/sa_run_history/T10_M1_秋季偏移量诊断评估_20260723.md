# T10 M1 秋季偏移量诊断评估（2026-07-23）

## 技术摘要

M1 采用“25SP 共享参数 + 25FA 预登记偏移量”的方式，对 LFMAX、SLAVR、XFRT、SFDUR 和三基点温度 TB1/TB2/TB3 加入秋季有效修正。以最终 ensemble 中加权 Phi 最低的可用成员（realization 98）比较，M1 的同口径加权 Phi 为 **2163.98**，低于 M0 最佳成员的 **3342.27**（降低 **35.3%**）。最大改善来自 25FA 连续采收鲜重；25FA 干重反而变差。

这只是诊断性结果，不能作为正式后验或论文结论。M1 原运行有 23 个非有限 Phi、177/200 个末轮成员留存，`engineering_status=engineering_failed`；同时 TB1–TB3 的上界从 14 收窄至 13 °C、XFRT 的初值/上界也被调整。因此，拟合改善不能被严格归因于“偏移量本身”。

## 最佳成员的秋季有效参数

25SP 使用共享值；25FA 使用下表的变换后值。`log_multiplier` 表示共享值乘以 `exp(offset)`；`logit_additive` 在 logit 尺度加偏移，保证比例落在 (0,1)。

| 秋季偏移 | 参数 | 最佳偏移 | 25SP 共享值 | 25FA 有效值 | 直接解释 |
|---|---|---:|---:|---:|---|
| DLFMAX_AUT | LFMAX | +0.1398 | 1.500 | 1.725 | 秋季有效最大叶光合能力 +15% |
| DSLAVR_AUT | SLAVR | +0.1398 | 240.0 | 276.0 | 秋季有效 SLA +15% |
| DXFRT_AUT | XFRT | +0.3500 | 0.9800 | 0.9858 | 秋季最大果实分配比例轻微升高 |
| DSFDUR_AUT | SFDUR | -0.0422 | 30.00 | 28.76 | 秋季有效果实充实持续量约 -4% |
| DTB1_AUT | TB1 | +2.000 | 6.00 °C | 8.00 °C | 营养阶段有效基温上调 |
| DTB2_AUT | TB2 | +2.000 | 6.00 °C | 8.00 °C | 早生殖阶段有效基温上调 |
| DTB3_AUT | TB3 | -2.000 | 8.95 °C | 6.95 °C | 晚生殖阶段有效基温下调 |

这里的“有效”表示对当前 DSSAT × 管理 × 气象输入组合的经验修正，并不是第二套遗传系数，更不能直接等同于叶片气体交换、真实 SLA 或温度阈值发生了同幅度生理改变。

## 生理合理性：哪些是可接受的，哪些仍不可解释

- **LFMAX +15%、SLAVR +15%**：作为秋季低辐射环境下的有效冠层/叶片修正具有一定表观合理性；较低光环境常与较高 SLA 的叶片策略相容。但 LFMAX 定义于标准温度、CO₂ 和高光条件，不能据此宣称秋季叶片固有最大光合能力真实提高 15%。
- **XFRT 0.9800 → 0.9858**：方向可理解为模型试图将更多同化物输送至连续采收果实，但共享值已非常接近上界，增加的绝对幅度很小。这更像对结构误差的补偿，不能作为强生理证据。
- **SFDUR -4%**：其单位是光热时间，不应按日历天数直译。秋季温度较低时，日历充实期通常可能延长；得到较短的光热持续量并非必然不合理，但没有独立果实发育观测不能验证。
- **TB1/TB2 +2 °C、TB3 -2 °C**：阶段性温度适应在理论上可能存在，但基温应主要是品种/发育过程参数。三个阶段方向相反且都处于允许范围边缘，更合理的解释是对温室微气候、辐射响应、发育阶段划分或模型结构误差的有效校正，而不是已证实的季节性遗传适应。

## 偏移量不确定性显示其尚未被可靠识别

M1 末轮可用成员中，七个偏移量约 41%–57% 位于各自上下界；5%–95% 区间普遍覆盖整个先验范围。例如：

- DLFMAX_AUT：5% = -0.1625，95% = +0.1398；
- DSLAVR_AUT：5% = -0.1625，95% = +0.1398；
- DXFRT_AUT：5% = -0.3500，95% = +0.3500；
- DTB3_AUT：5% = -2.0 °C，95% = +2.0 °C。

这不是可信的收敛后验，而是典型的边界堆积和多解信号。特别是 DSLAVR 的 ensemble 中位数接近 -0.159（约 -15%），而最佳成员为 +15%；所以不能把单个最佳成员的 SLA 增加作为稳定结论。

## 是否改善拟合

下表以 M0 最佳成员（realization 183）为基线，和 M1 可用最低 Phi 成员（realization 98）比较。两者均使用 432 个有效观测、完全相同的观测值、权重和对连续采收数据的 `ln(y+1)` 内部目标函数；表中 RMSE/RRMSE/NSE/R²/Bias 则在反变换后的原始尺度计算。

| 季节 | 变量 | M0 NSE / R² | M1 NSE / R² | 主要变化 |
|---|---|---|---|---|
| 25SP | CHFPW | 0.664 / 0.875 | 0.685 / 0.928 | 小幅改善；Bias 11,170 → 8,085 kg ha⁻¹ |
| 25SP | CHPDT | 0.053 / 0.529 | 0.296 / 0.702 | 明显改善但仍有限 |
| 25FA | CHFPW | -1.914 / 0.857 | 0.543 / 0.858 | **显著改善**；RMSE 7,464 → 2,957 kg ha⁻¹ |
| 25FA | CHPDT | 0.737 / 0.864 | 0.329 / 0.872 | NSE 下降，出现低估（Bias 52 → -201 kg ha⁻¹） |

因此，偏移模型对“秋季鲜重高估”这一主要问题有很强的诊断性改善，但并未同时改善秋季干重。鲜、干重之间的折衷说明模型仍存在干物质/含水量分配或连续采收表示方面的结构限制。

## 方法、范围与限制

- 来源：`workspace/runs/eggplant_t10_joint_20260723_000453`（M0）和 `workspace/runs/eggplant_t10_m1_offsets_20260723_071148`（M1）。
- 比较对象是每个 ensemble 最低可用 Phi 的成员，而不是预测验证或后验均值。
- M1 比 M0 除增加 7 个偏移量外，还改变了 TB1–TB3 与 XFRT 的冻结范围；这是归因的混杂因素。
- M1 运行发生了 DSSAT 原生数值失败，导致 ensemble 成员缺失；其偏移量分布不可用于正式后验、共线性或异参同效结论。
- 25FA 样本量较小（CHFPW 与 CHPDT 各 24 项），应避免从单季拟合提升推断普遍适应性。

## 建议的下一步

1. 保持“共享参数 + 少量预登记秋季有效偏移”的框架，但仅在已修复的保守 IES 数值配置下重新正式运行。
2. 首轮不要根据此诊断结果收窄偏移边界；先确认完整 ensemble 的工程稳定性、边界占用率和独立 26SP 验证表现。
3. 优先保留 LFMAX、SLAVR、XFRT、SFDUR 和 TB1–TB3 的当前 7 个偏移，不再增加更多季节项；现有数据尚不足以支持更复杂的季节适应模型。
4. 若后续要作生理解释，应补充叶面积/比叶重、叶片气体交换、果实含水率或果实生长历期等独立证据；否则在论文中称其为“season-specific effective corrections”。
