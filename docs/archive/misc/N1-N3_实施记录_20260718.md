# N1–N3 实施记录（2026-07-18）

本记录对应 P2 计划第 7 节的第一轮开发。目标是让批准的 D1 设计真正控制率定构建、阻止 IES 自动门误报科研有效，并把现有 SA 结果冻结为可追溯证据；本轮不启动任何正式 S1/S2/S3。

## 已实现

1. `src/calibration/design_config.py` 读取 design JSON 与 validation split，校验处理角色和阶段参数。`build_pest.py` 要求 `--design-config` 与 `--stage` 成对出现；对当前 `eggplant_stage2`，构建的 PST 只释放阶段声明参数，且只让 calibration treatments 与阶段声明观测组进入非零 Phi。validation/diagnostic 行仍可由模型输出产生，但不会进入目标函数。
2. S4 的旧文本“improved validation”已改为“calibration-only”；动态参数选择会在构建时失败，避免将 validation 用于模型选择。
3. IES 自动检查在 `tools/parallel/run_parallel.py` 中降级为 `engineering_validated/engineering_failed`。`src/calibration/finalize_calibration.py` 是科研升级的唯一入口；没有显式 group-Phi、确定性复跑、冻结 split 和来源哈希清单时，状态保持 `science_pending`。
4. `tools/package_sa_evidence.py` 复制现有 Morris/Sobol 审计产物、运行清单和文档，并写入逐文件 SHA-256。该工具不执行 DSSAT/PEST++，产物默认 `citation_status=pending_scientific_review`。
5. `assumption_based_sigma_v2.csv` 修正显式 sigma 与 model discrepancy/floor 的合成；累计采收是 diagnostic-only，增量采收使用预注册 1.25 multiplier；CNAMM 的单位说明改为百分点评价。
