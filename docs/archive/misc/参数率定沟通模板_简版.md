# 参数率定沟通模板（简版）

> 直接复制填写。没有修改的项目按下面的默认值执行。

```text
【本次目的】
例如：改善三季产量拟合和水氮响应。

【参与率定的数据】
季节：25春 + 25秋 + 26春
处理：各季全部有效处理
如需排除季节或处理：

【观测指标】
默认进入率定：
物候、LAI、叶干重、茎干重、株高、SNAM、LNAM、
土壤水分、累积干产量 CHPDT、单次干产量 HPODW。

默认不进入率定：
ADAP、MDAP、CNAM、鲜重产量。

数据变换：
CHPDT、HPODW 使用 ln(y+1)，其他指标保持原尺度。

【目标族权重】
物候：0.10
冠层：1.00
器官生物量：1.00
植株氮：1.00
土壤水分：1.00
绝对干产量：1.75
氮响应：0.75
干产量相关总预算：2.50

如需修改权重：

【参数设置】
默认沿用当前正式 frozen bounds。
FL-VS 固定为 100。
SLPF 参与率定，范围 0.90–0.96。
25秋使用 7 个秋季偏移量。

需要调整的参数边界：
参数：旧范围 → 新范围；原因：

【FileX 设置】
初始硝态氮 SNO3：1.0
初始铵态氮 SNH4：0.5
PAGE：25 天
SPRL：-99
其他管理条件保持 FileX 不变。

如需修改：

【运行规模】
默认：150×5，6 个并行 agents
如需修改：

【本次重点报告】
默认报告最佳成员的分季和总体 RRMSE、NSE、R²、Bias，
参数后验触边比例，以及高、低水下 N3−N0、N2−N0、N1−N0。

其他要求：

【启动方式】
请选择：由 Codex 启动 / 生成脚本后由我启动
```

## 更短的写法

如果只修改少量设置，可以直接发送：

```text
沿用当前正式基线，进行以下调整：
1. 参与季节/处理：
2. 参数边界：
3. 观测或权重：
4. 运行规模：
5. 由 Codex 启动 / 由我启动。
其他设置全部保持默认。
```
