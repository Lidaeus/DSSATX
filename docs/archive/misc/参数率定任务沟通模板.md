# 参数率定任务沟通模板

> 用途：在每次新建、重跑或对比参数率定前，统一说明输入、季节、处理、参数、
> 观测、变换、权重和验收要求。标有“必填”的项目未明确时，不启动正式率定。
>
> 使用方法：复制“填写区”到新的消息或任务文档，删除不适用的选项并填写值。

# 默认值建议

如果用户只说“沿用当前正式基线”，协作者应先回填并确认以下默认值，而不是静默猜测：

- ADAP、MDAP：diagnostic-only。
- `FL-VS=100`。
- 鲜重产量不进入 Phi，除非明确批准。
- SNAM、LNAM 可进入 PLANT_N；CNAM 不推算。
- CHPDT、HPODW 使用 `ln(y+1)` 时，所有衍生响应必须识别其已经变换，避免重复 `log1p`。
- 目标族预算静态、按有效观测数归一。
- 正式率定只允许使用 frozen bounds。
- 每个正式任务必须记录唯一输入 bundle、manifest 哈希和随机种子。
- 至少先做一次小规模工程烟雾测试，再启动正式 ensemble。
