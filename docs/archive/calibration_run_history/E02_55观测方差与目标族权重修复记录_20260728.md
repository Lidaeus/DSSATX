# E02_55 观测方差与目标族权重修复记录（2026-07-28）

## 技术结论

本轮修复解决了 E02_55 正式率定中三个会改变目标函数含义的问题：

1. `MDAP` 已从有效 Phi 中移除，仅作为诊断输出保留。无限生长型茄子不存在适合作为率定约束的真正生理成熟日期。
2. `CHTD` 观测值原以 cm 写入 DSSAT/PEST 链路，而 DSSAT `PlantGro.OUT` 的 `CHTD` 单位为 m。现已在观测包生成边界将均值和标准差统一换算为 m，并提高 FileT 序列化精度，避免 0.1 m 量化。
3. 活跃作物观测不再使用“一组一个固定 sigma”替代实测不确定性；PEST 权重现在优先读取逐观测有效标准差，并在其上施加静态目标族预算。

修复后，目标函数采用固定、可复现的两层权重：

\[
\sigma_{\mathrm{eff},i}
=
\sqrt{
\frac{s_i^2}{n_{\mathrm{eff},i}}
+\sigma_{\mathrm{model},g}^2
+\sigma_{\mathrm{floor},g}^2
}
\]

\[
w_i
=
\frac{1}{\sigma_{\mathrm{eff},i}}
\sqrt{\frac{B_f}{N_f}}
\]

其中，\(s_i\) 为实测重复标准差，\(n_{\mathrm{eff},i}\) 为有效重复数，
\(\sigma_{\mathrm{model},g}\) 和 \(\sigma_{\mathrm{floor},g}\) 是目标指标的静态模型误差项与下限，
\(B_f\) 为目标族预算，\(N_f\) 为该季该目标族的有效观测数。
因此每个有效目标族均满足：

\[
\sum_{i\in f}(w_i\sigma_{\mathrm{eff},i})^2=B_f
\]

该乘子只在构建 PST 时计算一次，率定全过程不进行动态重平衡。

## 目标族定义与静态预算

| 目标族 | 包含内容 | 预算 |
|---|---|---:|
| `PHENO` | `PDAP`、`ADAP`；不含 `MDAP` | 0.10 |
| `CANOPY` | `LAIX`、`LAID`、`CHTD` | 1.00 |
| `BIOMASS` | `LWAD`、`SWAD` | 1.00 |
| `PLANT_N` | `CNAM`（仅在存在有效实测值时启用） | 1.00 |
| `HARVEST_DRY` | 累积 `CHPDT` 与逐次 `HPODW` 事件 | 1.25 |
| `SOIL_WATER` | 土壤含水量过程观测 | 1.00 |

`CHPDT` 和全部 `HPODW` 事件共同使用一个 `HARVEST_DRY` 预算。增加采收次数只增加时间分辨率，
不会线性扩大采收数据在总目标函数中的占比。鲜重 `CHFPW` 仍为诊断项，不进入 Phi。

## 叶茎干重已参与，叶茎含氮量没有参与

| 数据 | 原始数据是否存在 | E02_55 是否进入 Phi | 实际证据 |
|---|---|---|---|
| 叶干重 `LWAD` | 是，三季均有 | 是 | 25SP 32、25FA 8、26SP 32 个正权重观测 |
| 茎干重 `SWAD` | 是，三季均有 | 是 | 25SP 32、25FA 8、26SP 32 个正权重观测 |
| 叶片含氮量/浓度 | 2025 春、秋原始 Excel 有 | 否 | TMT 的 `LNAM` 全为 `-99`，PST 无 `LNAM/LNAD` 观测 |
| 茎干含氮量/浓度 | 2025 春、秋原始 Excel 有 | 否 | TMT 的 `SNAM` 全为 `-99`，PST 无 `SNAM/SNAD` 观测 |
| 整株含氮量 `CNAM` | 当前三个率定包无有效值 | 否 | 配置声明“有观测时进入”，但三季正权重 `CNAM` 数均为 0 |

原始工作簿核查确认：

- 2025 春有 81 条植株样 NPK 记录，其中茎、叶、果各 27 条；茎叶全氮集中在 2025-07-13，
  单位为 mg/g，并包含重复和水氮处理。
- 2025 秋有 288 条记录，茎、叶、果各 96 条；日期为 2025-12-08 和 2026-01-09，
  全氮单位同为 mg/g。
- 当前观测构建器没有读取这两份 NPK 工作簿，而是在生成 FileT 时将 `CNAM/SNAM/LNAM`
  写为缺失值。因此 `PLANT_N=1.0` 预算在三季均未激活，也没有转移给其他目标族。

这里还存在一个定义问题：原始 Excel 的“全氮（mg/g）”是器官氮浓度，而 DSSAT FileT 的
`SNAM/LNAM` 通常需要器官氮数量。正式纳入率定前，应按同处理、同日期的器官干重换算为
kg N/ha，并核对 DSSAT 输出字段的确切定义、日期匹配和单位；不能把浓度直接写入 `SNAM/LNAM`，
也不能把茎氮与叶氮静默相加为 `CNAM`。

## 限制与后续判读

- 当前没有 `CNAM` 实测值，因而本轮不能用结果判断植株含氮量拟合质量。
- 方差下限和模型误差项是静态稳健化假设，不等同于额外的实测重复方差；后续报告应分别保留
  `raw_sd`、`n_replicates`、`model_sigma`、`sigma_floor` 和 `sigma_eff` 以便审计。
- 最终参数组应在三季分别完成工程门、目标族贡献、RRMSE/NSE、触边情况和参数代偿检查后，
  再决定是否推进下一阶段。
