# E02 联合率定末轮触边审查与 M1 秋季偏移正式启动

日期：2026-07-29

## 决策摘要

共享参数联合率定末轮 300 个成员全部保留。边界调整以末轮 ensemble 的 2% 和 5% 边界邻近率为依据，不因单个最优成员触边而自动扩边。

本轮采用论文“材料与方法”中已经定义的七个 25FA 有效偏移：

- `DLFMAX_AUT`：`LFMAX` 的 log 乘性偏移；
- `DSLAVR_AUT`：`SLAVR` 的 log 乘性偏移；
- `DXFRT_AUT`：`XFRT` 的 logit 加性偏移；
- `DSFDUR_AUT`：`SFDUR` 的 log 乘性偏移；
- `DTB1_AUT`、`DTB2_AUT`、`DTB3_AUT`：三个阶段基温的加性偏移。

这些偏移只作用于 25FA。25SP 使用共享参数。偏移解释为 2025 秋季条件下的有效过程修正，不解释为第二套遗传参数。

## M1 冻结边界

在上述数据驱动调整外，为安全接入文档定义的偏移，还进行了两项约束性变更：

- `TB1/TB2/TB3` 的共享上界由 14 收至 13，使 `+2°C` 秋季偏移后不超过物理上限 15°C；
- `XFRT` 的共享上界由 1.0 收至 0.98，保证 logit 偏移所需的开放区间。

温度矩形范围同时满足：

TB2 < TO12 < TO22 < TM2
TB3 < TO13 < TO23 < TM3
