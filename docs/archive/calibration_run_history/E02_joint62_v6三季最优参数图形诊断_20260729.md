## 3. 逐季节结果

### 25SP

- 累积干重采收：RRMSE 32.79%，NSE 0.699；曲线后段整体低于实测，最高处理的末期低估最明显（残差随观测量增大而变负）。
- 单次干重采收：RRMSE 62.47%，NSE −0.827；曲线表现为采收事件时序/幅度不能同时匹配，不能仅靠总量修正。
- LAID：RRMSE 61.45%，NSE 0.161，平均偏差 +0.763；LAI 动态图显示中后期多数处理模拟高于实测。
- LAIX：RRMSE 73.04%，NSE −33.47，平均偏差 +2.418；峰值阶段明显过高，是当前春季冠层扩张最突出的异常。
- LWAD / SWAD：LWAD NSE 0.732、偏差 −11.9，整体尚可；SWAD 偏差 +304.5，呈系统高估。
- CHTD：NSE −0.017、偏差 −0.230 m，但 R² 0.949，说明处理间排序被捕捉，存在近似统一的高度偏移/阶段偏差。
- ADAP 模拟比实测早 21 d，说明共享物候参数使 25SP 的发育节律过快。
- SNAM / LNAM：SNAM NSE −0.308（偏差 +8.0），LNAM NSE −1.330（偏差 +8.8）；植株氮质量并非完全失配，但叶氮质量的趋势和水平仍不足以约束叶片氮过程。

### 25FA

- 累积干重采收：RRMSE 15.11%，NSE 0.857；是三季中拟合最好的一项，说明秋季最终累积产量量级已基本正确。
- 单次干重采收：RRMSE 18.77%，但 NSE 0.060；总量较好并不代表逐批次分配节律正确。
- LAID / LAIX：LAID NSE 0.559、偏差 −0.421；LAIX NSE −1.735、偏差 −0.387，峰值和平台阶段仍偏低。
- LWAD / SWAD：LWAD NSE −0.921、偏差 −669.9；SWAD NSE −0.014、偏差 −436.4。两者均明显低估，说明产量拟合存在由果实库/分配参数对冠层生物量的补偿。
- CHTD：偏差 +0.248 m，R² 0.919；与 25SP 的负偏差方向相反，提示高度问题不能用单一全局平移修复。
- ADAP 比实测早 11 d。
- SNAM / LNAM：SNAM NSE −7.328（偏差 −9.6），LNAM NSE −16.553（偏差 −31.8），是当前最强的氮过程警报：秋季叶氮质量严重低估，需先检查氮吸收/迁移和观测口径，再调整参数。

### 26SP（外部季节诊断）

- 累积干重采收：RRMSE 25.53%，NSE 0.811；总量和处理间排序尚可，但各处理动态曲线在后期普遍低于实测。
- 单次干重采收：RRMSE 42.45%，NSE −0.589，R² 0.014；采收节律和单次分配明显失配。
- LAID：RRMSE 142.51%，NSE −3.381，平均偏差 +1.430；LAIX：RRMSE 133.15%，NSE −87.75，平均偏差 +3.569。所有处理的后期模拟 LAI 均显著高于实测，是最需要优先解释的外推失败。
- LWAD / SWAD 的 NSE 分别为 0.707 / 0.649，但 SWAD 偏差 +221.1；这表明干物质规模尚可时，LAI 仍会因 SLA/叶面积转换而失真。
- CHTD NSE 0.008、偏差 +0.228 m；处理排序好但存在明显系统偏移。
- ADAP 比实测早 22 d。由于未加 26SP 偏移量，这同时提示春季间物候适应性尚未被共享参数充分表达。

## 4. 对参数和模型结构的判断

1. **LAI 问题不是单纯的总干物质问题。** 26SP 中 LWAD/SWAD 的 NSE 尚可而 LAID/LAIX 极差，优先怀疑 SLAVR、SIZLF、LFMAX/PHTMAX 与冠层结构的耦合，而不是继续整体放大光合能力。25SP 的 SLAVR 后验上触上界，说明参数正在用较高的叶面积转换率补偿其他过程。
2. **产量总量与逐批次采收节律分离。** 三季 DRY_CUM 相对较好，但 DRY_INC 的 NSE 很低或接近零，说明 XFRT、VSSINK、DXFRT/采收间隔以及物候转换参数共同造成时序错位；只调整产量总量参数会继续掩盖问题。
3. **季节性物候偏移仍未消除。** 25SP、25FA、26SP 的 ADAP 偏差分别为 −21、−11、−22 d；PODUR、TB3 等参数的后验触边与该现象一致。不能把这一问题归结为单一 LAI 参数。
4. **秋季氮质量是新的硬约束。** 25FA 的 SNAM/LNAM 系统低估与 LWAD/SWAD 低估同向，说明需要检查秋季 FileX 氮初始条件、氮吸收/根系参数和器官氮迁移，而不是只放宽冠层参数。
5. **CHTD 的 R² 高而 NSE 低。** 这是“处理间排序正确、绝对水平偏移”的典型形态，应先检查高度观测单位、移栽苗龄、PAGE/初始状态和季节偏移口径，再决定是否调整 RHGHT；RHGHT 后验已接近下界，不建议直接继续大幅放宽。

## 5. 建议的下一步顺序

1. 先保留本次三季图形作为 v6 诊断基线，核查 25FA 的 SNAM/LNAM 实测单位、日期映射、FileX 氮初始条件及 `PlantN.OUT/SoilNi.OUT` 的吸氮过程；建立氮持续时间和土壤氮消耗门。
2. 对 LAI 做受控敏感性试验：固定产量/分配参数，单独比较 SLAVR、SIZLF、LFMAX 与 26SP 季节偏移的组合；不要把所有过程变量统一变换或同时放宽全部边界。
3. 对采收过程单独检查 `DXFRT_AUT`、`XFINT`、`VSSINK` 和 `PODUR` 的后验触边与采收事件日期，再做小规模子空间率定；先解决 DRY_INC，再评价 DRY_CUM。
4. 物候方面先核实 ADAP、TB/TO1/TO2/TM 的观测日期和移栽口径；如数据无误，再采用季节偏移或阶段参数的受控扩展，而不是全局放宽。
5. 继续保持 SOIL_SLPF 在当前范围；v6 后验已集中在高值区且无触边证据，不建议以降低土壤肥力指数来补偿上述冠层和氮过程问题。
