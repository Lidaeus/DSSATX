### 2.1 运行是否“严重影响”

- `organ_25SP/25FA` 的 DSSAT 集合大体运行完成，失败来自当前观测有限性门（NaN/缺失模拟值仍被统计），所以不是“所有率定都没有信息”；但工程状态为 failed，不能称为合格率定。
- 物候和所有产量子试验存在较高缺失或模型失败比例。尤其 25FA full-yield 的 EOF 是输入接口错误，结果完全不可用；25SP strict 的 Phi 和保留率也已越过门槛。
- 因此，本轮不报告正式 R²、NSE、RRMSE、后验或共线性结论。正式指标必须来自修复后的 deterministic best-parameter replay，并通过工程门。

## 4. 已确认的技术修复

本轮之后已修复构建层的两个问题：

1. 观测有效性判断排除 NaN，避免多季节拼接后未对应季节的土壤 token 被写入观测集；
2. 土壤水分 token 在按季节筛选处理后再编号，避免 token 间隙导致 `.ins` 与输出列错位。

25FA full-yield 的 SoilWat EOF 仍应在新构建中作为硬性 smoke 检查：每个 agent 必须确认 `PestSoilWat.OUT` 的观测行数和 `.ins` 行号一致。

## 5. 下一步正式率定前流程

1. 用当前修复后的代码重新 build：25SP/25FA organ、25SP/25FA yield-full、strict；物候只做接口诊断，不进入边界决策。
2. 先运行 `noptmax=0`、少量成员的接口 smoke，再运行正式预率定（200 members、4 iterations）。
3. 只有满足 `observation_finite=0`、Phi 非有限比例不超过 0.02、最终保留率 ≥0.95 且无 SoilWat EOF，才提取边界命中率。
4. 对确认后的候选写入 `bounds_proposals`，由人工审核后再用 `freeze_bounds.py` 生成新的 frozen bounds；本报告不改变 frozen bounds。
5. 通过后才进行正式率定和 deterministic best-parameter replay，计算 RRMSE、NRMSE、MAE、NSE、R²、bias、MSE_s/MSE_u，并进入后验/共线性分析。
