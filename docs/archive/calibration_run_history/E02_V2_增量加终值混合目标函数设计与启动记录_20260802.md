# E02 V2 增量＋终值混合目标函数设计与启动记录

## 目的

以 `e02_v2_formal25sp_nreleased_200x5_20260802` 为严格配置基线，仅改变时序目标函数的表达方式，检验减少累积/状态序列重复计权后，PEST-IES 对产量形成过程、冠层发展和器官生物量过程的拟合是否改善。

遗传参数、土壤参数、参数边界、25SP FileX、处理筛选、NRESP、PLANT_N、SOIL_WATER、Sobol 初始集合及 200×5 规模均保持不变。

## 统计设计

### 累积干重采收

- 事件增量：观测使用已审计的高精度 HPODW；模拟由 Python 对 DSSAT CHPDT 相邻采收值作差。
- 末期总量：每个处理仅最后一个 CHPDT 进入 Phi。
- 中间 CHPDT：保留在 PEST 接口和观测注册表中，但权重为零，仅用于诊断。
- HPODW 与终值 CHPDT 均在原尺度上率定，使用实测重复方差、模型误差和误差下限计算有效 sigma。
- 不采用 `1/y` 权重。项目已有观测方差模型，`1/y` 会在接近零的早期观测处放大噪声。

绝对干重采收预算仍为 1.75：HPODW 增量 1.25，末期 CHPDT 0.50。N_RESPONSE 预算仍为 0.75，因此产量与氮响应合计预算仍为原约定的 2.50。

### LAI、叶干重和茎干重

- 对 LAID、LWAD、SWAD 计算相邻观测日期之间的有符号差分。
- 第一个观测日期没有可靠的前一状态，因此不构造“相对零值”的人为增量。
- 负差分原样保留，用于表达衰老、落叶、干物质转运等过程。
- 每个处理最后一次 LAID、LWAD、SWAD 作为终值约束。
- 原始状态序列继续保留为诊断，权重为零。
- 差分误差在缺少重复测量协方差时按独立误差近似：`sigma_delta = sqrt(sigma_t^2 + sigma_t-1^2)`。这是保守处理；如果以后得到日期间协方差，可替换为完整协方差模型。

冠层原预算 1.00 被拆分为：LAIX 0.20、LAID 差分 0.60、LAID 终值 0.20。器官生物量原预算 1.00 被拆分为：LWAD/SWAD 差分 0.75、终值 0.25。没有提高这两个目标族的总权重。

## 解释限制

“增量＋终值”降低了完整累积/状态序列被重复计权的问题，但终值仍由各增量共同决定，两者并非严格统计独立。本版本通过静态预算把终值作为弱锚点，而不是把它当作额外一整组独立信息。后续比较必须在原尺度上同时报告完整状态/累积轨迹、增量指标、终值指标、NRESP 和参数后验触边比例，不能只比较 actual Phi。
