# NSTFAC 水氮响应剖面试验

> **2026-07-30 追补说明：**基准四角率定的 N-response 目标曾发生双重
> `log1p` 尺度错误，因此本剖面只能支持“在该最佳参数邻域，单独改变 NSTFAC
> 对 DSSAT 产量响应影响很小”这一确定性敏感度结论；不能用于证明错误目标函数
> 下的后验参数具有科学有效性。

基线：`e02_spring_pair_histbest_4corner_150x5_20260730_v4` 末轮最优成员74。

## 试验设计

固定其余54个参数，仅将 `NSTFAC` 在冻结范围 0.20–1.00 内含端点均匀取10个值：

`0.2000, 0.2889, 0.3778, 0.4667, 0.5556, 0.6444, 0.7333, 0.8222, 0.9111, 1.0000`。

每组均使用25SP和26SP四个角点处理，计算末次采收累积干重的 `N3−N0` 差异。共完成80个DSSAT处理运行，全部成功。

## 结论

1. `NSTFAC` 在当前最优参数组附近对氮响应几乎不敏感。0.20–0.82区间内四个水氮组合的响应基本不变，只有25SP-W3在高值端从231降至约212 kg ha⁻¹。
2. 当前响应方向存在结构性问题：25SP-W3为正，但25SP-W1接近零；26SP-W1为正，而26SP-W3为负。单独调整 `NSTFAC` 无法同时修复这些方向。
3. 因此，继续放宽或收紧 `NSTFAC` 边界预计不能建立正确的N3−N0响应。下一步应进行氮过程参数的联合剖面，重点包括 `RTNO3、RTNH4、NMOBMX、NRCVR、RTEXF`，并同时检查水分×氮交互和根层氮供给过程。
