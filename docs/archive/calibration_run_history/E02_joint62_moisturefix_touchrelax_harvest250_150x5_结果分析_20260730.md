# E02 joint62 水分率修正、触边放宽与采收权重 2.5 的 150×5 结果分析

## 1. 结论先行

本轮正式率定已完成并通过工程门。最佳末轮成员为 realization 78，`actual Phi = 203.742`。

本轮必须保留的科研修正包括：

1. 25SP 果实含水率录入错误已经在不可变派生数据包中修正；原始工作簿未被覆盖。
2. ADAP 已在代码层永久设为 `diagnostic_only`，不会再进入率定目标函数。
3. SLPF 使用 0.90–0.96，后验未触边，当前范围足够。
4. 累积干重及单次采收共享的 `HARVEST_DRY` 目标族预算已由 1.25 提高到 2.50。

边界放宽明显解决了 PODUR、RTNH4、TB3、VSSINK、SLAVR、NSTFAC 的原有触边问题，并改善了修正数据口径下的 25SP 累积干产量、单次采收、茎干重和茎含氮量拟合。但它没有带来全目标、全季节的同步改善：25SP 叶面积和叶干重、叶含氮量，以及 26SP 采收过程预测有所退化。

因此，本轮应作为当前“修正数据后的正式基线”保留，但不能简单解释为对旧 v6 的全面替代或全面提升。

## 6. 下一步工作决策

为快速推进，建议按以下顺序执行，不再同时扩大多项试验：

1. 将本轮固定为“修正数据基线”。旧 v6 参数可继续作为对照，但旧 v6 的正式目标函数使用了错误的 25SP 干产量数据，不能作为最终科研结果。
2. 永久沿用修正后的 v8 观测数据包和 ADAP 排除规则。
3. 保留已证明有效的新边界：PODUR、RTNH4、TB3、VSSINK、SLAVR、NSTFAC，以及 SLPF 0.90–0.96。
4. 暂不继续放宽 RHGHT；它已经达到项目登记的物理下界。
5. 暂不继续放宽 DXFRT_AUT。先检查其与 DSLAVR_AUT、秋季 LAI、LWAD、SNAM/LNAM 的后验相关和成员级响应，避免用秋季偏移掩盖共同遗传参数问题。
6. 下一轮只调整目标函数张力：建议将 HARVEST_DRY 从 2.50 回调至 2.00，或在保持总预算 2.50 时提高 CHPDT 在采收族内的份额、降低 HPODW 份额。原因是 2.50 对累积产量改善很小，却明显损害 26SP 单次采收和多个叶片过程指标。
7. 针对 TN13，下一轮重点应是增强低水、低氮处理的减产响应约束，而不是继续提高共同产量潜力。应检查 TN13 的 NSTD 持续时间、植株吸氮、土壤矿质氮消耗以及同水分水平下 N0 与 N2/N3 的差值残差。

最小可行的下一轮是：保持本轮参数边界和正确数据不变，只修改采收族内部权重分配，并运行 150×5。这样可以快速判断当前退化主要来自权重张力还是参数边界。
