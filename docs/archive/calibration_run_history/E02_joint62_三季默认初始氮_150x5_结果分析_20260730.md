# E02 joint62 三季默认初始氮 150×5 结果分析

## 技术摘要

`e02_joint62_three_season_defaultn_150x5_20260730` 已完整结束并通过工程质量门。率定规模为 150×5，包含 62 个可调参数和 1334 个有效观测，25SP、25FA、26SP 均进入率定。三季 FileX 的全部初始条件层统一使用 `SNO3=1`、`SNH4=0.5`。

末轮 `actual Phi` 最小成员为 **68**，`Phi=1558.10`。Phi 从初始最小值 6040.18 持续下降，说明 PEST++ 数值收敛有效；但最优参数的原尺度确定性重跑表明拟合能力总体较差：

- 累积干产量总体 RRMSE 为 **58.54%**，NSE 为 **0.096**。
- 单次干重采收总体 RRMSE 为 **70.00%**，NSE 为 **-0.544**。
- LAID 总体 RRMSE 为 **138.34%**，NSE 为 **-3.477**。
- 植株茎干重总体 RRMSE 为 **63.23%**，NSE 为 **0.208**。
- SNAM、LNAM 的总体 RRMSE 分别为 **59.84%**、**78.21%**。

统一低初始矿质氮没有改善拟合，反而导致明显参数代偿：RTNO3 后验 100% 靠近上界，NSTFAC 97.3% 靠近上界，NVSMOB 78.7% 靠近下界。这说明模型试图通过最大化硝态氮吸收能力、减弱氮胁迫和限制营养器官氮再转运，补偿被统一降低的初始土壤氮。

本版本适合作为“低初始氮反事实压力测试”，不应替代使用实测初始氮的正式率定基线。

## 4. 参数后验暴露出强烈代偿

采用距边界 5% 范围作为“靠近边界”的判定。

| 参数 | 方向 | 触边比例 | 后验中位数 | 最优值 | 解释 |
|---|---|---:|---:|---:|---|
| RTNO3 | 上界 | 100.0% | 0.0500 | 0.0500 | 最大化根系硝态氮吸收 |
| RHGHT | 下界 | 98.0% | 0.5251 | 0.5000 | 继续压低冠层形态参数 |
| NSTFAC | 上界 | 97.3% | 0.9994 | 0.9918 | 极力减弱氮胁迫作用 |
| SLAREF | 下界 | 94.7% | 250.0 | 250.0 | 压低参考比叶面积 |
| PODUR | 下界 | 93.3% | 12.0 | 12.0 | 缩短果荚/果实阶段持续时间 |
| DXFRT_AUT | 上界 | 88.0% | 0.3441 | 0.3500 | 秋季果实分配强烈向上修正 |
| NVSMOB | 下界 | 78.7% | 0.1500 | 0.1500 | 限制营养器官氮再转运 |
| RTNH4 | 下界 | 26.0% | 0.0090 | 0.0081 | 铵态氮吸收能力仍偏低 |
| SOIL_SLPF | 无 | 0% | 0.9433 | 0.9445 | 未承担主要代偿 |

RTNO3、NSTFAC、NVSMOB 的组合方向尤其关键：在初始硝态氮被固定为极低值后，率定没有恢复合理的氮胁迫响应，而是把吸氮能力推至极限并削弱氮胁迫。这种参数组合难以作为可信的作物遗传参数解释。

秋季偏移量也发生方向翻转：DXFRT_AUT 由上一版本大量靠近下界变为 88% 靠近上界，说明初始氮假设改变后，秋季果实分配偏移量被用于吸收季节性系统误差。

## 5. 结论与下一步

1. **不将本版本晋升为正式参数基线。** 它应保留为低初始氮反事实试验。
2. **恢复三季实测或FileX权威初始氮。** 当前结果支持此前判断：初始土壤氮并非可随意设为统一默认值的弱影响输入。
3. **不要基于本版本继续放宽 RTNO3、NSTFAC、NVSMOB。** 其触边主要是错误环境假设引起的代偿，不是合理生理范围不足。
4. **下一轮应回到实测初始氮基线，并单独率定季节特异的环境修正。** 若要检验初始氮不确定性，建议将每季初始 NO3/NH4 使用有依据的倍率或分层修正参数，而不是把所有季节、处理和土层设成同一个绝对值。
5. **26SP 应重新保留为独立预测季。** 三季都进入率定后无法继续评价真正的外部预测能力。
