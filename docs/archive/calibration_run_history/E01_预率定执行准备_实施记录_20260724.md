## 4. 关键审计发现

### 4.1 观测 profile 与策略 CSV 的语义不一致（已知，非阻塞）

**现象**：`direct_chpdt_log_v1.json` 声明 `active_phi_targets: ["CHPDT"]`、`diagnostic_targets: ["CHFPW", "LAID", "LWAD", "SWAD", "LAIX", "CNAM"]`。但既有 `assumption_based_sigma_v5_dryonly.csv` 将 ADAPM/LAIDM/LWADM/SWADM/CNAMM 全部标为 `calibration`（非零权重）。

**根因**：observation profile JSON 是**论文正式合同**（CHPDT 是唯一正式 Phi 目标）；observation policy CSV 是**实现层**（预率定可启用过程观测作为约束）。二者服务于不同目的，但命名容易混淆。

**影响**：既有 E01-Y spec（`E01_pre_calibration_25sp_yield`）实际激活了所有域，不是矩阵 §3 定义的严格 Y-only 子试验。

**处理**：
- 保留既有 E01-Y spec 不变（向后兼容，作为"全域预率定"参考）
- 新增 `E01_pre_calibration_*_yield_strict` spec 实现矩阵定义的严格 Y-only（CHPDT 唯一活跃）
- 在 `experiment_spec.py` 中，profile 的 `active_phi_targets` 仅强制 CHPDT 必须存在（通过合同门），不强制 CHPDT 是唯一活跃目标——这是设计选择，允许预率定启用额外过程约束

**建议**（P0-A 范围，不在本包）：让 observation profile JSON 显式声明其对应的 sigma CSV 路径，消除 `_resolve_observation_policy_csv()` 的隐式映射。

### 4.2 25FA 物候缺失（矩阵一致性确认）

矩阵 §3 E01-P 行注明"25FA 缺少有效 ADAP，默认不运行"。Smoke 确认 25FA:PHENO 组 n_obs=0。本包按矩阵要求跳过 E01-P 25FA，不创建对应 spec。

### 4.3 `_resolve_observation_policy_csv()` 硬编码修复

**原实现**：硬编码 `assumption_based_sigma_v5_dryonly.csv`，无法支持域特定策略。
**修复**：从 spec 的 `multiseason_design_path` 读取 JSON，提取 `observation_policy` 字段。保留向后兼容回退（design 无该字段时回退到 dry-only CSV）。
**回归验证**：既有 E01-Y spec 仍解析到 `assumption_based_sigma_v5_dryonly.csv`（7 个策略解析测试含 2 个回归断言）。
