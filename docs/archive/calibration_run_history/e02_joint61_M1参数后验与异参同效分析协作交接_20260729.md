## 1. 交接目标

本任务需要交付两条相互关联但不能混为一谈的证据链：

1. 参数条件集合分析：比较 IES 初始参数集合与末轮条件参数集合，回答哪些参数被数据约束、向何处移动、是否贴近边界，以及七个秋季偏移是否获得可辨识支持。
2. 异参同效分析：先识别“拟合相近但参数相距较远”的候选解，再通过隔离的确定性复跑判断这些解在预先冻结的验证或诊断域中是否仍给出相似预测。

最终应形成可复核的数据包、补充表、Fig. S5–S7 正式替换数据，以及在证据充分时才进入主文的 Fig. 5。分析不得把最低 Phi 参数组解释为唯一真实参数，也不得把 IES 条件集合称为严格 Bayesian posterior。

## 2. 术语和结论边界

全文统一使用以下术语：

| 推荐术语 | 含义 | 禁止替换为 |
|---|---|---|
| 初始参数集合 / prior ensemble | `.0.par.csv` 中实际生成的 150 个初始成员 | 仅由上下界假定出的均匀先验 |
| 末轮条件参数集合 / final conditional ensemble | 最高持久化迭代的参数集合 | 精确 Bayesian posterior |
| 条件集合区间 | 末轮成员的分位数区间 | 可信区间、置信区间 |
| 参数补偿候选 | 参数相关、收缩或边界行为提示冗余 | 已证明的异参同效 |
| 远距离近优候选对 | Phi 接近且参数距离较大 | 功能等效解 |
| 功能预测相似/分化 | 确定性复跑后按冻结阈值分类 | 生理参数相同/不同 |
| 秋季有效修正 | M1 对 25FA 的有效参数偏移 | 第二套秋季遗传系数 |

IES 成员不是 MCMC 样本，因此不计算或报告 R-hat、MCMC ESS、Bayesian credible interval。对 150 个成员进行的重抽样只能描述有限集合统计量的稳定性，不能包装成严格后验推断。

当前 `src/calibration/finalize_calibration.py` 中 `SCIENCE_PROMOTION_ENABLED = False`，因此即使完成工程 finalize，也只能得到 `science_pending`。协作者不得修改一个布尔值就把结果升级为科学验证；应先补齐机器可审计的科学证据和审批流程。带 `--allow-unvalidated-demo` 的输出仅供接口与绘图 QA，必须保持 DEMO 标记和水印。

要求初始与末轮参数集合一一可读、列名与 PST 活动参数一致、无非有限值、边界和变换可解析。通过后才能生成 Fig. S5 和参数补充表。

### Gate C：近优远距离候选

候选选择只能使用率定 Phi 和参数空间，不能看验证误差后再挑候选。采用现有冻结主规则：

- 两个成员的末轮 Phi 均不超过 `1.05 × best_phi`；
- 参数距离大于全体末轮成员两两距离的中位数；
- 最多选择 3 对；
- 同一 realization 不得在多对中复用；
- 排序和并列处理必须确定性。

2% 和 10% Phi 带只作阈值敏感性审计，不替代 5% 主规则。

### Gate D：功能预测证据

每个候选成员在隔离目录中使用完全相同的 DSSAT 输入、管理和输出提取规则进行确定性复跑。只有在预先冻结的 `validation` 和/或 `diagnostic` 域中完成一一对齐，才可计算预测距离。

当前目标设计没有 validation/diagnostic 处理，因此 Gate D 暂不具备条件。可选补充路径：

1. 若 26SP 从未参与参数数目、偏移结构、边界、权重、迭代停止和候选选择，则可在独立审计后冻结为 `validation`。

3. 对秋季偏移的外部验证需要第二个独立秋季或受控温光/叶片生理数据。26SP 只能主要检验共享参数迁移性，不能验证 25FA 专属偏移的跨秋季普适性。

## 5. 参数条件集合分析方案

### 5.1 核心问题

1. 哪些参数从初始集合到末轮集合明显收缩？
2. 哪些参数发生了相对于初始集合宽度而言较大的位置移动？
3. 哪些参数靠近物理/率定边界，提示边界截断或未建模补偿？
4. 哪些参数仍基本保持初始宽度，提示当前观测约束不足？
5. 七个秋季偏移是否离开 0，并且在实际 25FA 参数尺度上有稳定、可解释的修正？
6. 条件集合变化是否与总 Phi、分组 Phi、变量级拟合改善一致？

### 5.2 分析总体

主总体为：

- prior：`.0.par.csv` 的全部工程有效成员；
- final：最高实际持久化迭代的全部工程有效成员；
- 成员身份：保留 `real_name`；
- 参数清单：以 PST 中 61 个 `none` 参数为权威，不以方差筛列；
- 相关、VIF 等矩阵分析：只对末轮方差大于 `1e-12` 的活动参数进行，但塌缩参数必须留在边缘分布表中并标记。

不得根据最终 Phi 先筛成“好成员”再计算主后验/条件集合，因为这会把优化结果二次截断。可增加一个近优成员敏感性表，但必须与全体末轮集合并列呈现。

### 5.3 每参数统计量

每个参数至少输出：

| 类别 | 字段 |
|---|---|
| 身份 | `parameter`、`pargp`、`physiology_group`、`parameter_role`、`base_parameter`、`transform` |
| 初始集合 | `prior_n`、mean、median、q05、q25、q75、q95、IQR、variance |
| 末轮集合 | `final_n`、mean、median、q05、q25、q75、q95、IQR、variance |
| 更新 | `iqr_shrinkage = 1 - IQR_final/IQR_prior`、`var_shrinkage` |
| 位移 | `median_shift_prior_iqr = (median_final - median_prior)/IQR_prior` |
| 分布距离 | `wasserstein_prior_iqr = W1(prior,final)/IQR_prior` |
| 边界 | 精确下/上界比例；距边界不超过参数范围 2% 的比例 |
| 稳定性 | `collapsed`、非有限值数、启发式多峰提示 |

说明：

- 主区间继续使用 q05–q95，与现有 Fig. S5 契约一致；q025–q975 可进入补充表，但不要混称 95% 可信区间。
- “贴边”同时报告精确边界和 2% 范围邻近比例。现有 `1e-6 × range` 只适合发现数值上精确贴边，无法反映实际边界压力。
- 多峰检测仅是筛查，不是正式显著性结论。当前 150 个成员不宜建立复杂通用混合模型平台；先用启发式标记、分布图和成员轨迹核查。
- Wasserstein 距离和标准化中位数位移用于区分“只收缩”与“整体迁移”；它们进入表格和 QA，不必新增论文图。

### 5.4 季节偏移专项统计

对七组 `base + offset` 额外输出：

1. 偏移 q05、median、q95；
2. 偏移为正/负的成员比例；
3. 区间是否跨 0；
4. 基础参数与偏移的 Spearman 相关；
5. 25SP 基础参数的 q05/median/q95；
6. 由冻结变换计算的 25FA 有效参数 q05/median/q95；
7. 25FA 有效值与基础值的相对或绝对变化；
8. 基础参数、偏移、25FA 有效值分别靠近边界的比例；
9. 对应目标族的分组 Phi、原尺度 RMSE/Bias/NSE 变化。

判断顺序为：

`偏移离开 0` → `未由边界少数成员驱动` → `与基础参数补偿可接受` → `实际季节参数变化合理` → `相关目标族确有改善` → `独立证据可复现`。

任何一步不通过，都只能称为“季节有效修正候选”。

### 5.5 Phi 与参数关系

除总 Phi 外，必须接入分组 Phi。至少输出：

- 每个参数与末轮总 Phi 的 Spearman；
- 每个参数与各目标族 Phi 的 Spearman；
- 七个偏移与其预期目标族 Phi 的关系；
- 参数值分位组对应的原尺度变量指标。

注意：Phi 是带权目标函数，RRMSE/NSE/Bias 是解释层指标。不得用低总 Phi 自动替代变量级拟合证据。

## 6. 参数补偿与异参同效分析方案

### 6.1 四层证据链

#### 第一层：边缘可辨识性

使用收缩、位移、边界和偏移离零情况识别“受到约束”“未受约束”“可能被边界截断”的参数。此层不判断异参同效。

#### 第二层：参数补偿

计算并冻结：

- Pearson 和 Spearman 长表；
- VIF、条件数；
- 标准化参数空间 PCA 指标及 loadings；
- 跨生理组相关边表。

正式解释以 Spearman 为主，Pearson 作线性敏感性补充。VIF、条件数和 PCA 当前只进入审计表或方法补充，不新增主论文图；遵守项目 V3 的最小图族约束，不建设 t-SNE、聚类或通用后验探索平台。

相关网络仅保留满足下列条件的审计边：

- `|Spearman| >= 0.60` 为中等候选边；
- `|Spearman| >= 0.80` 为强补偿警告；
- 同时报告参数生理组和是否跨组。

若目标运行仍保持当前最大 `|rho|≈0.59`，则应明确报告“未出现预设的中强相关边”，而不是下调阈值制造网络。

#### 第三层：远距离近优候选

沿用 `src/reporting/posterior_summary.py` 的确定性候选规则，最多 3 对。主参数距离使用现有末轮 z-score 欧氏距离，以保持接口兼容。

增加但不改变主选择的稳健性审计：

- 先验范围 RMS 距离；
- 先验标准差标准化距离；
- 排除季节偏移后的共享参数距离；
- 仅七个偏移参数的距离；
- 2%、5%、10% Phi 带下的候选数量与排序稳定性。

若候选排序对尺度或 Phi 带高度敏感，必须标记 `candidate_selection_unstable`，不得只展示最有戏剧性的参数对。

#### 第四层：功能预测相似或分化

沿用 `src/reporting/candidate_predictions.py` 的冻结定义：

\[
d_{r,v} =
\sqrt{\frac{1}{n_{r,v}}\sum_i
\left(\frac{\hat y_{A,i}-\hat y_{B,i}}{\sigma_{\mathrm{eff},v}}\right)^2}
\]

其中：

\[
\sigma_{\mathrm{eff},v} =
\sqrt{\sigma_v^2+\sigma_{\mathrm{model},v}^2+\sigma_{\mathrm{floor},v}^2}
\]

每个数据角色内先对变量等权平均，validation 与 diagnostic 同时存在时再对两个角色等权平均。现有分类阈值为：

- `max(d_validation, d_diagnostic) <= 1.0`：`prediction_similar`；
- 任一角色大于 1.0：`prediction_divergent`；
- 任一角色缺失或复跑失败：`prediction_incomplete`。

该阈值表示两套预测平均差异是否小于冻结观测误差尺度，不表示参数具有相同生理含义。

### 6.2 必须同时检查“相似但都错”

候选对的预测距离只比较 A 与 B，不能判断它们是否接近观测。因此每对还必须输出：

- A、B 各自在 calibration、validation、diagnostic 的 RMSE、RRMSE、Bias、NSE；
- 按季节和变量拆分的指标；
- A 与 B 的预测距离；
- 与观测的误差方向是否一致；
- 确定性复跑是否成功且输出键完全对齐。

若 A 与 B 很相似但两者验证性能均差，分类应写为：

`prediction_similar_but_inaccurate`

而不是“功能异参同效得到支持”。

### 6.3 建议结果状态机

| 状态 | 条件 | 可用表述 |
|---|---|---|
| `compensation_candidate` | 收缩/边界/相关提示参数补偿 | 存在补偿候选 |
| `near_optimal_distant_pair` | 通过 Gate C | 率定域内有远距离近优解 |
| `prediction_incomplete` | 缺验证角色或复跑失败 | 功能等效未判定 |
| `prediction_similar_but_inaccurate` | A/B 距离小但两者准确度差 | 共同结构误差可能主导 |
| `functional_similarity_supported` | 参数远、Phi 近、验证/诊断距离≤1，且至少验证表现可接受 | 在冻结评价域内支持功能预测相似 |
| `predictive_divergence` | 参数远、Phi 近，但验证或诊断距离>1 | 率定等效不代表外推等效 |

项目现有生产代码输出 `prediction_similar`/`prediction_divergent`。若实现扩展状态机，必须保留原始距离与原始分类字段，新增解释字段而不是覆盖冻结合同。

## 7. 结果呈现方案

### 7.1 Fig. S5：先验与末轮条件集合

科学问题：哪些参数被数据约束、移动或推向边界？

建议保留现有 prior 灰色、final 蓝色的 q05–q95 区间和中位数设计，并作以下优化：

- 61 个参数按 `pargp` 和生理过程排序，分为多页或多个面板，禁止挤在单页小字体中；
- 每个参数保持自身原始尺度，不把不同单位参数画在同一数值轴上；

- 季节偏移使用独立面板并画出 0 参考线；
- 同步生成一张“基础参数 vs 25FA 有效参数”的七参数区间图；
- 图注使用“conditional ensemble interval”，明确不是 Bayesian posterior。

输出：PDF、SVG、600 dpi PNG、source CSV、summary CSV、figure manifest。

### 7.2 Fig. S6：参数补偿矩阵

科学问题：末轮集合中哪些参数存在协同变化？

建议：

- 使用生理组固定排序的 Spearman 下三角热图；
- 颜色使用以 0 为中心的色盲安全发散色；
- 全矩阵保留颜色，不在 61×61 矩阵中打印所有数字；

若没有 `|rho| >= 0.60` 的边，图注应如实说明当前未观察到预设的中强参数补偿。

### 7.3 Fig. S7：远距离候选对及预测距离

科学问题：参数相距较远的近优解，在冻结评价域是否给出相似预测？

建议面板：

- A：每对的总参数距离，以及共享参数/季节偏移距离分解；
- B：按 validation/diagnostic × 变量展示 `rms_normalized`，绘制 `d=1` 参考线；
- C：每对 A/B 的验证 RRMSE 或 NSE，防止“相似但都错”；
- D（证据足够时）：关键变量的 A/B 确定性轨迹或事件点对比。

最多展示三对，保持当前 R 核心接口。缺少 validation/diagnostic 时只允许 DEMO QA，不输出空壳正式图。

### 7.4 Fig. 5：主文可辨识性/异参同效综合图

只有满足以下条件才制作：

1. Fig. S5–S7 数据全部 `science_validated`；
2. 有至少一个冻结且可解释的验证域；
3. 候选对确定性复跑全部成功；
4. 变量级拟合指标足以支持预测解释；
5. 结论不是由单一偏移参数贴边驱动。

建议只整合三个最有解释力的面板：

- A：参数收缩率与标准化中位数位移散点，标出边界参数和七个偏移；
- B：1–3 对近优远距离候选的参数距离；
- C：同一候选对在验证/诊断域的预测距离与 `d=1` 阈值。

不把 PCA、VIF、全相关矩阵塞入主图。

## 13. 交付判定

本交接完成后的理想结论不是“找到唯一最佳参数”，而是以下三类之一：

1. 某些参数明显收缩且不贴边，季节偏移在实际尺度上稳定，并得到目标变量和独立数据支持；
2. 多个远距离参数组合在率定域近优，但在验证/诊断域发生预测分化，说明参数不唯一且外推不确定性重要；
3. 多个远距离参数组合在冻结评价域仍预测相似，但两者准确度需单独判断，说明在当前观测分辨率下存在功能预测相似。

若当前数据只能支持“远距离近优候选存在、功能判定不完整”，这也是合格且科学上诚实的交付结果。
