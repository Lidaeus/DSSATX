# E02 三季参数边界复盘与 25SP–25FA 联合遗传参数率定准备

日期：2026-07-29

## 结论

建议进入 25SP 与 25FA 共享作物遗传参数的联合率定，但不直接沿用单季 E02_55 的全部宽边界。

三季单季率定显示，当前范围的主体是可用的；需要有证据地放宽 `RHGHT`、`XFPHT`、`TO11`，同时收紧在 PAGE=25 联合抽样中暴露出运行不稳定或明显代偿尾部的参数。按项目不变量将 `FL-VS` 固定为 100 后，联合率定使用 54 个活动参数。

第二版 20×1 联合烟雾试验已通过工程门：20/20 成员保留、DSSAT 模型失败为 0、所有 Phi 有限，平均 actual Phi 从 1304.66 降至 408.07，最小 actual Phi 从 677.37 降至 356.73。正式 300×6 方案已经具备启动条件。

## 最新 25SP 结果的含义

最新 25SP 含水率修正运行的最优成员为 92，actual Phi 为 78.0732。累计干采收量 `CHPDT` 的拟合已经较好（RRMSE 18.77%，NSE 0.884），`LAID`、`LWAD` 和 `SWAD` 具有正 NSE，说明当前参数空间能够描述主要的冠层、生物量和累计产量动态。

需要注意：

- `HPODW` 的 RRMSE 为 106.04%、NSE 为 -5.976，而 `CHPDT` 已较好。这种组合更像单次采收分配/时序仍有偏差，不等同于作物总产量形成能力不足，不能据此继续无方向地扩大全部产量参数范围。
- `LAIX` 的 NSE 为 -6.146，说明峰值/季末摘要仍有偏差；但 `LAID` NSE 为 0.770，不能仅依据 `LAIX` 再次放宽叶面积相关参数并承担 LAI 失控风险。
- `CHTD` 的 R² 为 0.912、NSE 仅 0.104，表明处理间排序较好但绝对尺度存在系统偏差；`RHGHT` 三季持续触及下界，因此小幅向下放宽有直接证据。
- `ADAP` 误差 16 d 的该次运行仍使用 PAGE=60。联合输入已经权威化为 PAGE=25、SPRL=-99，故不根据旧输入下的 ADAP 偏差继续放宽 `PL-EM`。

## 输入与目标函数契约

- 25SP：含水率修正输入，ADAP=21 d，PAGE=25 d，SPRL=-99。
- 25FA：PAGE=25 d，SPRL=-99。
- 两季共用同一组 54 个遗传参数，不引入季节参数偏移。
- `PDAP`、`ADAP`、冠层、器官生物量、植株含氮量、累计干采收 `CHPDT`、单次干采收 `HPODW` 和土壤水分按现有契约进入 Phi。
- `CHPDT` 使用原尺度；`HPODW` 使用 `ln(y+1)`。
- `MDAP` 和鲜重采收变量只作诊断，不进入 Phi。
- 多次采收观测共享采收目标族预算，增加采收次数不线性增加该目标族总权重。
