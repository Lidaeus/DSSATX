# 两春季器官氮浓度敏感性分析方案（审核稿）

## 范围

- 仅使用 25 年春季 `xxql2501` 与 26 年春季 `xxql2601`；明确不开展任何秋季研究，也不使用 `xxql2502`。
- 输入优先采用 `data/user/experiments/xxql2501_layermean_ic_valid_n012_v1_20260801` 和 `xxql2601_layermean_ic_valid_n012_v1_20260801`（按土层平均 SH2O/SNO3/SNH4）。
- 旧正式宽科研域作为基线；新增参数全部进入独立 proposal，审核通过后才可冻结。

## 参数域

旧域保持原 bounds。新增/重启参数见 `data/parameter_registry/bounds_proposals/eggplant/eggplant_two_spring_organ_n_v1_20260803.csv`：

- `FL-VS` 固定为 120；不作为随机参数。
- `FRCNOD` 0.04–0.06；结构开关 `SD-PM`、`FL-LF` 360–440（窄域）。
- 器官氮组成：`PROL*`、`PROST*`、`PRORT*`、`PROSH*`。根（`PRORT*`）与 shell（`PROSH*`）没有直接观测，先采用窄域并在结果中单独标记为弱可识别参数；不得把整果氮观测当作 shell 观测。
- 目标变量为 `PlantN.OUT` 的叶、茎、根、果氮浓度（优先 `LN%D/SN%D/RN%D/CN%D`；缺失时只报告可审计代理，不用整果值替代 shell）。

## 方法与门禁

1. 先执行逐参数 baseline/lower/upper 注入、SPE 精确读回、文件 SHA-256 变化审计；任何失败均阻止正式 SA。
2. Morris 作为筛选（3 seeds，重复数沿用旧方案），仅在两春季共同可用的 FileX/处理上运行；报告每季及跨季聚合的 μ*, σ、方向一致性和失败率。
3. 通过 Morris 稳定性门禁后，才创建两春季 IES 率定；率定不得引入秋季数据。
4. SPE 白名单由冻结 bounds 的声明名动态并入，并增加标签驱动兜底注入；构建后必须核对 PST 参数集合与 proposal 的 active 集合完全一致。

## 审核点

- 是否接受根/shell 参数仅作敏感性候选、而非直接观测率定参数；
- `SD-PM/FL-LF` 的 360–440 窄域是否合适；
- 是否在通过注入审计后冻结本 proposal。
