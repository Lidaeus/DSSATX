# E02 joint54 25SP+26SP“拟合变差”诊断

## 结论

`e02_joint54_25sp_26sp_chpdtlog_150x5_20260729` 并未出现先前报告所称的全面拟合恶化。主要问题是一次性原尺度指标复算代码错误：代码使用 `x.transform` 读取观测变换类型，但 `transform` 与 pandas `Series.transform` 方法同名，实际取得方法对象，导致 CHPDT 和 HPODW 的 `ln(y+1)` 模拟值没有执行 `exp(x)-1` 反变换。

显式改为 `x["transform"]` 后，最优成员仍为 59，actual Phi 仍为 131.376；纠正后的总体 CHPDT RRMSE 为 18.63%、NSE 为 0.892，而不是此前错误报告的 114.32% 和 -3.116。

仓库正式率定、权重构建和 DSSAT 模拟代码未发现同类属性访问写法；错误局限于本次临时指标复算与由此产生的聊天报告。

## 输入与权重核查

- 运行工程状态为 `engineering_validated`，54 个共享活动参数，854 个正权重观测。
- 25SP 有 510 个正权重观测，26SP 有 344 个。
- MDAP、CHFPW、PWAD、PWAI 和 HWAM 均未进入 active Phi。
- 两季均按静态目标族预算构建权重：PHENO 0.1、CANOPY 1.0、BIOMASS 1.0、HARVEST_DRY 1.25、SOIL_WATER 1.0。
- 25SP 和 26SP 的 CHPDT 分别有 110 和 40 个观测；每个处理最终 CHPDT 与 HPODW 累加值一致，未发现累计干重构建错误。
- 最优成员 Phi 分解中，两季目标族均有贡献，不存在某一季完全未进入优化的问题。

## 仍然真实存在的问题

1. 25SP ADAP 观测为 21 d，而最优成员模拟约为 36 d；26SP ADAP 35 d则能够准确拟合。这是两个春季之间真实的物候响应冲突，被较小的 PHENO 预算弱化。
2. 26SP LAID 呈明显正偏，RRMSE 77.37%、NSE -0.291，但 R² 0.930，说明时序形状较一致、尺度偏高。
3. LAIX 两季总体 NSE -4.970，仍是当前最弱的冠层指标。
4. 最终 ensemble 中 PODUR 有 64.0% 位于下界 25，RTNH4 有 28.7% 位于下界，TO21 有 25.3% 位于下界，FL-SH 有 20.7% 位于下界。这些边界信号可能限制进一步改善，但不是此前“全面变差”的根因。
5. 联合率定提高的是两季共享目标的总体表现，并不保证 25SP 每个变量都优于 25SP 单季率定；例如 25SP LWAD 和 LAID 存在一定折衷。

## 后续修复建议

1. 将原尺度指标导出固化为正式脚本，变换字段只允许使用 `row["transform"]` 或等价的显式列索引。
2. 增加回归测试：输入已知 `ln(y+1)` 值，要求导出结果严格恢复为 `y`；同时验证最优 realization 名称与 obs/par ensemble 行的映射。
3. 在指标报告中同时输出原尺度观测均值、模拟均值、MBE 和最大值，快速发现“未反变换但被标为原尺度”的异常。
4. 下一轮模型改进应聚焦 25SP/26SP 的 ADAP 差异、26SP LAID 尺度偏差和 LAIX，而不是因为本次错误报告而否定两个春季联合率定。
