# E02 V2 权重与观测映射审计及 25SP+26SP 无土壤水分/无 NRESP 率定配置

## 1. 审计结论

本次审计没有发现“模拟值与观测值错位”的工程性错误。旧版 `e02_v2_formal25sp_nreleased_200x5_20260802` 的观测注册表包含 586 行、586 个唯一观测名，指令文件中也解析出 586 个 token，未发现缺失或多余 token。新建 25SP+26SP smoke 构建同样通过一对一检查。

权重算法的核心公式是：

\[
w_i = \frac{1}{\sigma_i}\sqrt{\frac{B_{s,g}}{n_{s,g}}},
\qquad
\sum_{i\in(s,g)}(w_i\sigma_i)^2=B_{s,g}
\]

其中 `s` 是季节、`g` 是目标族、`B` 是该季节目标族预算。因而在统计预算意义上，样本数较多的目标族不会仅因观测点多而线性放大；不同观测的测量误差仍通过 `sigma` 保留差异。

## 2. 需要注意的设计风险

1. 旧版 NRESP 以每个采收期、每个氮水平对同一 N0 基准重复构造差值。虽然 T8 预算归一化是正确的，但这些差值在统计上并非独立，且和 CHPDT/HPODW 共享同一收获序列，容易形成重复约束。
2. 旧版 soil-water 观测有独立的 SOIL_WATER 预算；若目标是只识别遗传参数，土壤水分目标会把土壤参数和作物参数共同推向后验，不能与“排除土壤水分权重”混用。
3. 旧版 25SP 物候目标在当前策略中本来就是诊断项；本轮保持 ADAP/MDAP/PDAP 诊断口径，不将其误计为活跃 Phi。

## 3. 新率定配置

运行批次：`e02_v2_joint25sp26sp_nosoil_nresp_200x4_20260802`

- 25SP：TN2、3、4、5、10、11、12、13，共 8 个处理
- 26SP：TN1–12，共 12 个处理
- 激活参数：99 个，边界完全继承 `eggplant_e02_v2_formal25sp_nreleased_20260802`
- 器官氮相关参数：保持 active，包括 NSTFAC、NMOBMX、NVSMOB、NRCVR、RTNO3、RTNH4、LNREF、NSLOPE、CMOBMX 等
- 目标函数：保留 LAI、叶干重、茎干重、SNAM、LNAM、CHPDT、HPODW
- SOIL_WATER：保留诊断输出，但全部零权重
- NRESP：不生成派生观测，全部不进入 Phi
- ADAP、MDAP、PDAP：诊断项，不进入 Phi
- 初始集合：Sobol
- 规模：200 个成员 × 4 次 IES 更新
