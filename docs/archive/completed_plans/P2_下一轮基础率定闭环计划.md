# P2 下一轮基础率定闭环计划

> 状态：待执行；目标是打通一个可信、可复核的 S2 基本闭环，不扩展通用框架。

## 1. 本轮唯一目标

完成：

```text
冻结设计和误差契约
→ prior-only 覆盖预检
→ 一次 no-cull S2 IES
→ 成员/分组Phi/边界审计
→ 代表参数确定性复跑
→ engineering_validated + science_pending
```

本轮不追求自动 `science_validated`，不运行 validation，不进入 S3/S4，不生成正式后验或论文图。

## 2. B1：关闭四个基础门禁缺口

只做以下四项：

1. 输出 `realization_status.csv`：`real_name, first_seen_iteration, last_seen_iteration, final_status, reason`；状态限定为 `retained/high_phi_screened/model_failed/other_dropped`。
2. IES 工程质量报告不得再写 `science_validated=true`；只有 `finalize_calibration` 可维护科学状态。本轮 finalize 最多输出 `science_pending`。
3. staged build 强制要求 `--observation-policy-csv`；缺失即失败。修正并绑定 `observation_ensemble_sha256`。
4. `NOPTMAX=-1` 使用 `engineering_preflight_completed`，不再因没有更新轮次被判工程失败。

最低测试：

- D0 fixture 能把已知 ID 分类为 `high_phi_screened`；
- 缺失成员且 REC 无筛除证据时分类为 `other_dropped`，不能臆测为模型失败；
- staged build 缺 observation policy 必须失败；
- engineering pass 的 quality JSON 仍为 `science_validated=false`；
- prior-only preflight 正常完成且不能升级科研状态。

## 3. B2：简化阶段观测设计

不增加新变量，只减少重复：

| 阶段 | 进入 Phi | 仅诊断 |
|---|---|---|
| S2 氮响应/营养生长 | `CNAM, LAIX, LAID, LWAD, SWAD` | `PWAI, PWAD` |
| S3 结实与采收 | `PWAI` | `PWAD` |
| S4 联合 | 暂不决定 | 等 S2/S3 通过后由用户审批 |

原则：

- 累计 `PWAD` 不与增量 `PWAI` 重复进入 Phi；
- S2 不再要求氮响应参数同时承担采收序列拟合；
- 不根据 validation 选择观测或参数；
- 不自动删除 prior-data conflict 观测；
- 不引入 pwtadj1、log、截断正态或相关噪声模型。

构建后只需一张设计审计表确认：非零权重均来自 calibration treatments，S2 没有 PWAI/PWAD，S3 没有 PWAD。

## 4. B3：只运行 S2 基本闭环

### 4.1 prior-only

使用批准的 S2 配置、frozen bounds、sigma v2、固定 S1 代表参数和 `NOPTMAX=-1`。输出：

- `prior_coverage_by_group.csv`；
- 每组 simulation SD、conflict fraction、signed residual；
- observation-noise 负值比例和 `sigma_eff / |observed|` 摘要；
- `engineering_preflight_completed`。

若所有关键组均全量冲突，或活动参数对所有目标都无模拟变化，则停止，不运行 IES。

### 4.2 正式 S2 工程运行

仅在预检可解释后运行一次：60 reals、4 iterations、`relative_phi_screening=false`。不再做阈值扫描或第二组 seed。

最低验收：

1. DSSAT/解析真实失败为 0；
2. 60/60 成员保留，参数/模拟/Phi 均有限；
3. observation ensemble、bounds、policy、input、design 均有 SHA-256；
4. `realization_status.csv` 与逐轮 ensemble 对齐；
5. 输出原始 group Phi、占比和观测数；
6. 无参数未经解释地 100% 堆积同一边界；若再次出现，停止并报告，不放宽 bounds；
7. 选“最低 Phi”和“参数中位数”各做一次确定性复跑，输出一致性检查。

完成状态仍为 `science_pending`，等待用户审核 S2 参数方向和边界后再决定是否进入 S3。

## 5. B4：交付给用户的最小材料

只交付四项：

1. 一页 S2 运行摘要；
2. `realization_status.csv`；
3. `group_phi_summary.csv`；
4. prior/final 参数范围、边界率和两次确定性复跑结果。

暂不制作后验密度图、PCA/VIF、异参同效配对和论文图。这些只有联合 S4 通过后才有科学含义。

## 6. 明确延期

- validation 自动调参；
- 一键工作流、GUI、dashboard；
- 正式论文图。

```text
B1 门禁小修和测试
→ 提交 code review
→ B2 配置差异交用户批准

```
