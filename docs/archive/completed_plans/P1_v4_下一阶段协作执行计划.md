## 3. 执行顺序与任务包

### W0：集成检查点与环境冻结

负责人：集成/QA 协作者。

任务：

1. 审查当前未提交改动，按 SA、率定、图表分组；先解决共享文件冲突，再形成可追溯提交。
2. 运行 `python -m pytest tests/ -q`，记录 Python、DSSAT、PEST++、R版本和 Git commit。
3. 从该提交创建独立工作树。正式运行期间禁止修改其代码、配置和输入；开发应在另一工作树进行。
4. 检查 v4 profile、SA input manifest、frozen bounds 三个 SHA-256 与案例 manifest 一致。
5. 合并前修复两项跨线用途门禁：
   - `src/calibration/build_pest.py` 必须读取 input manifest 的 `intended_use/prohibited_use`，对 `parameter_calibration` 被禁止的 SA 反事实包硬失败；增加“实际包可率定、SA包不可率定”的测试。
   - `src/reporting/export_paper_data.py` 的 `science_validated` 不能只相信 comparison CSV 自报状态；必须要求同一 run_id 的 run manifest 与质量报告通过，并拒绝 comparison/phi/trajectory 混合 run_id。DEMO 路径仍可显式放行并加水印。
6. 抽取统一的 input manifest 完整性检查：目录名与 bundle ID 一致、清单内每个文件存在且 SHA-256 匹配。SA、率定、确定性复跑入口都必须调用；只记录 manifest 自身哈希而不核对包内文件不算通过。

验收：干净工作树、全测试通过、版本和三个核心哈希可查；率定输入用途和论文数据来源各有正反回归测试。未达到时不得开始新的率定正式运行或导出 `science_validated` 论文包。W1 可在独立冻结工作树中执行，不受图表接口开发阻塞。

### W1：SA v4 `r=8` 扰动预检

负责人：SA 执行协作者。

从干净检查点重新构建预检，不复用脏工作树生成的控制文件：

```powershell
python src/sensitivity/sa_build_sen_case.py `
  --param-review data/parameter_registry/bounds_frozen/eggplant/eggplant_p1_xxql2501_v3_20260716.csv `
  --input-dir data/user/experiments/xxql2501_sa_counterfactual_v1_20260716 `
  --output-profile configs/sa/eggplant_p1_outputs.json `
  --case-dir workspace/runs/p1_wn_v4_preflight_r8 `
  --morris-r 8 --morris-p 6 --random-seed 20260716 `
  --run-type sensitivity_preflight_case

python tools/parallel/run_parallel.py `
  --run-dir workspace/runs/p1_wn_v4_preflight_r8 `
  --case sa_sen_morris --mode sen --n-agents 6 --wait

python src/sensitivity/morris_audit.py `
  --case-dir workspace/runs/p1_wn_v4_preflight_r8
```

必须验证：

- 464/464设计点完成，0模型失败、0运行时失败、8/8完整轨迹；
- 164项输出均有限、无 `-99`、无陈旧文件；
- 每个参数具有8个有效 elementary effects；
- 逐响应检查零方差和极小数值噪声；水差、氮斜率、交互项必须由同一参数向量的8处理成对模拟得到；
- `general_genetic` 和 `water_nitrogen_response` 均有有效响应覆盖。
- DAP50 只从原始 DSSAT 累计节点线性穿越计算，不从 R 平滑曲线反算；累计序列下降、最终值非正或节点缺失时标为不可估计并触发响应审计。

若某响应结构性零方差，不得降低门禁或静默删除。先判断提取错误、参数域内真实不敏感或定义冗余；只有需要改变164项契约时才暂停并提交新 profile proposal 供用户审核。

产物：`run_manifest.yaml`、运行/结果质量报告、零方差清单、失败重放（如有）和 `P1_v4_R1_预检报告.md`。预检结果不得用于论文排名。

### W2：正式多种子 Morris 与双域稳定性

负责人：SA 执行协作者；QA 协作者独立复核。

前置：W1全部通过且 profile 未改变。采用两个新的预声明 seed（建议 `20260923, 20261007`），每个 `r=30,p=6`、1740次运行；若任一域不稳定，再依次增加 `20261021, 20261104, 20261118`，最多5个 seed。

要求：

- 正式构建拒绝 dirty worktree，不使用 `--allow-dirty`；
- 每个 seed 必须1740/1740成功、30/30完整轨迹；任何失败使整个 seed 退出正式排名；
- 两个排名域分别计算 Spearman 和 Top-15 Jaccard，均达到0.90/0.80才停止扩展；
- 输出逐响应 `mu*`/`sigma`、特征族/过程组分数、逐 seed 排名和双域共识排名；禁止跨域平均。
- 多 seed 汇总必须拒绝 profile、input manifest、bounds 哈希或164项观测顺序不一致的案例；正式结果必须恰有两个排名域。
- `case_quality_validated` 与 `ranking_stable` 分开记录；只有所有案例通过且两个域均稳定，`science_validated` 才能为 true。

产物：双域稳定性报告，以及参数分类表：`两域共同重要`、`一般生长重要`、`水响应重要`、`氮响应重要`、`水×氮交互重要`、`低敏感/不稳定`。

### W4：参数率定协作者并行任务

率定开发和试运行可以与 W1/W2 并行，但必须遵守：

1. 只使用 `xxql2501_20260716` 的实测处理特异 IC，禁止使用 SA 反事实包。
   率定构建器的用途门禁测试通过前，只允许已有工程案例诊断，不允许新建正式率定案例。
2. 在 v4 Top-K 未批准前，接口开发、工程 smoke 和已有批准参数的试运行标记为 `engineering_preflight`；不得宣称最终参数选择已由新 SA 支持。
3. 不把 SA 的水差、氮斜率或交互量直接加入 PEST 目标函数；如需关系约束，另行提出并审核误差模型。
4. 保持已批准观测策略：PEST weight=`1/sigma`；处理均值 sigma 依据可追溯重复/SE规则；log 双侧同尺度；pwtadj1 保持关闭。
5. 正式 P2 前冻结参数清单、bounds ID、实际输入 manifest、观测/权重 profile、校准/验证处理划分、随机种子、集合规模和停止规则。
6. 每次 IES 输出 Phi集合分布、分组 Phi、有效/失败成员、参数更新幅度、边界命中和确定性复跑；Phi下降但参数未更新或某组支配时不得通过。
7. 后验分布、相关性和异参同效只使用通过 P2 质量门的集合；不得从失败/DEMO运行产生科研结论。

率定协作者交付给图表线的冻结接口包括：`phi_ensemble.csv`、后续 `group_phi.csv`、`comparison.csv`、`simulation_trajectory.csv`、参数 prior/posterior 表、质量报告和哈希 manifest。图表协作者不得从 `.par.csv`、临时 agent 目录或 DSSAT临时输出反向猜测这些数据。

### W5：论文图表协作者并行任务

图表开发可以使用 DEMO 数据继续，但必须遵守：

1. R 是唯一论文图渲染器；Python只导出冻结数据和运行诊断，不创建第二套 Fig/FigS 实现。
2. 非 `science_validated` 数据必须显式 `--allow-unvalidated-demo`、`DEMO_` 前缀和水印，不能改 figure registry 为正式完成。
   `science_validated` 导出必须绑定同一 run_id 的质量报告和 run manifest；仅在 CSV 中写入该字符串不构成科研验证。
3. Fig.1/Fig.S1/Fig.S2 等待 W2/W3 和正式 Sobol；Fig.2 等待 P2 IES 质量门；Fig.3/4/S3/S4 等待校准/验证角色及正式数据冻结。
4. R 不计算 SA 排名、响应归一化、Sobol指数或处理映射，只消费 Python 冻结的数据包和 SHA-256 manifest。
5. SA 图表数据契约至少分为：
   - `morris_effects.csv`：seed、ranking_domain、response_group、feature_family、parameter、mu_star、sigma、有效effects数；
   - `morris_rank_stability.csv`：domain、parameter、seed rank、consensus rank、稳定性状态；
   - `sobol_indices.csv`：domain/response、parameter、S1/ST、CI、样本量、estimable；
   - `sa_data_manifest.json`：输入/profile/bounds/代码哈希和质量状态。
6. 水氮颜色/点型编码只用于处理比较图；参数敏感性和后验图不套用处理颜色语义。
7. `make_all.R` 增加 `--figure-ids` 或等效的单入口模块选择；生成 Fig.1/S1/S2 时不应被迫提供率定轨迹，生成率定图时也不应被迫提供 SA 数据。
8. `paper_data_manifest.json` 增加 `scenario_type`、上游 run manifest/质量报告/input manifest/bounds/weights/validation split 哈希。SA 图只接受 `controlled_counterfactual_sa`；Fig.2–5 只接受 `actual_trial_calibration`。
9. figure registry 的 Fig.1 required data 和科学问题应明确包含两个排名域；状态仍保持 `pending_P1`，直到 v4 正式数据通过门禁。
