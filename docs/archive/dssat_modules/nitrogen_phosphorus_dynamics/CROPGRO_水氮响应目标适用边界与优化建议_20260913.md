# 当前CROPGRO配置下的水氮响应目标：适用边界与优化建议

> 日期：2026-09-13。补充[项目评审](CROPGRO_Eggplant_项目评审与后续工作建议_20260913.md)。适用于本项目官方4.8.5二进制、TMGRO048茄子参数化和PHOTO=L路径。
>
> 本文区分通用源码能力、当前配置已验证能力与尚未识别的机制。没有修改目标函数、冻结边界或运行配置；下面的目标调整均为下一轮建议。

## 1. 核心判断

合适的率定目标应同时满足：**观测差异可靠、模型存在对应机制、当前输入确实激活该机制、参数能够被相关过程资料约束。**

“模型能产生一条下降曲线”与“模型正确模拟过量氮造成的减产机制”不同。当前工程适合优先解决缺氮/缺水减产及接近充足后的边际收益下降；不能为了重现高投入处理的低产，任意改动光合、分配或初始N制造曲线。

反过来，也不能因为模型目前模拟不出实测梯度，就把这些观测删除、改成平台或视为噪声。结构不匹配应成为公开评价结果；如果关键处理超出模型经验证的适用域，应收窄模型应用范围，或增补机制和独立观测。

## 2. 对“过量氮减产无法模拟”的准确表述

官方VEGGR中的一个氮胁迫途径以供氮与需求之比形成0–1限制因子，充足后达到1；它不是施氮超过阈值就增加的毒害项。NUPTAK受需氮、根分布、土壤矿质N和水分等约束。因此“缺氮→充足→产量趋于饱和”有明确机制基础。[VEGGR源码](https://github.com/DSSAT/dssat-csm-os/blob/develop/Plant/CROPGRO/VEGGR.for)、[NUPTAK源码](https://github.com/DSSAT/dssat-csm-os/blob/develop/Plant/CROPGRO/NUPTAK.for)。

但不能宣称整个CROPGRO结构数学上绝不允许高氮处理减产。冠层、碳氮成本、用水和分配的耦合可能产生间接下降；PHOTO=L中叶N通过四节点FNPGN响应函数影响光合，并不是直接用施肥量预测产量。当前A47实际SPE为`1.39,2.79,20.0,20.0,QDR`，v51观察到非N0正午叶N落在平台范围内，不能把它解释为已经建立真实过氮损伤关系。[ETPHR源码](https://github.com/DSSAT/dssat-csm-os/blob/develop/SPAM/ETPHR.for)、[本地v51证据](E02_v51_photo_branch_and_carbon_diagnostics_20260902.md)。

本项目目前没有验收通过的“施氮量/根区盐分或铵态氮暴露→毒害/离子失衡/生殖损伤→产量下降”证据链。因此对盐害、铵毒、营养失衡、病害或倒伏造成的过量氮减产，**不宜把下降幅度作为当前参数率定必须实现的目标**。不是宣称所有DSSAT版本及扩展均没有这些能力，而是本地生产配置尚未证明能模拟这些机制。

也不建议仅降低FNPGN高端节点，迫使叶N略高的处理减产：需要独立叶N—光合曲线证据、实际运行响应和跨季验证。施肥量高不一定叶片结构N高；根区毒害也不能随意用叶片光合抑制替代。

## 3. 哪些目标合适，哪些需要条件，哪些不宜强拟合

| 响应目标 | 当前建议 | 理由与前提 |
|---|---|---|
| 经观测证实的缺氮相对充足N的产量/生物量差 | 优先率定 | 有供需、吸收、组织N和光合限制机制；须核对初始N与矿化，不以N0标签代替缺氮证据 |
| 缺氮→充足的响应幅度、转折区与边际增益下降 | 条件合适 | 必须有覆盖转折区的剂量/状态资料；若只有几个已经充足的处理，转折点不可识别 |
| 充足N区的产量平台，同时吸氮或组织N仍变化 | 合适 | 允许新增N主要表现为营养存量；产量和吸氮不要求同比增长 |
| N1/N2/N3每一级、每个采收日期都严格递增 | 不适合作为统一硬目标 | 原始差异可能接近测量误差、非单调或已处于平台；各级施肥不等于各级胁迫 |
| 有可靠观测支持的非N0正梯度 | 保留待解释目标 | 当前模型平台不能使该目标自动失效；先定位N状态、有效光合或分配在哪一环丢失差异 |
| 过量N导致明显、可重复的减产 | 当前以结构诊断为主 | 必须识别损伤机制；不能仅凭N3<N2宣布氮毒，也不能通过任意扩界强拟合 |
| 缺水相对适宜水分的生长、结实与产量损失 | 优先率定 | 前提是有效根区水分/吸水限制确实不同；需约束土壤水分和灌溉实际入量 |
| 水分充足后的产量平台与水生产力下降 | 合适 | 产量可不再增加而投入继续上升；需明确指标是产量/灌溉量还是产量/ET |
| 过量灌溉导致减产 | 条件合适，不能笼统说模型不支持 | CROPGRO ROOTS含过湿影响；还可能通过N淋失耦合。须有饱和时长、根系/通气或氮损失证据，并验证本地版本实际通道 |
| 轻度亏水提高产量、适量N最优的任意峰形 | 不作为预设硬形状 | 可能有真实耦合，但必须由过程与跨季数据支持，不能因一组均值而人为指定峰位 |
| 水×氮交互及“干旱时施N增益受限” | 条件合适 | 用同条件成对试验与过程资料判断；不要求各季、各阶段都出现相同方向/强度 |
| 所有水氮层具有相同CV、相同百分比差或固定排序 | 不合适 | 不同季节的基础供给和限制因素不同；CV不含方向，且不能证明机制正确 |

缺水可影响叶片光合、水分供需和结实；根系过湿机制也确实存在，不能将“过量水”和“过量氮毒害”视为同样不存在的路径。实际能力仍须用本地输入与可执行文件验证。[ETPHR](https://github.com/DSSAT/dssat-csm-os/blob/develop/SPAM/ETPHR.for)、[PODS](https://github.com/DSSAT/dssat-csm-os/blob/develop/Plant/CROPGRO/PODS.for)、[ROOTS](https://github.com/DSSAT/dssat-csm-os/blob/develop/Plant/CROPGRO/ROOTS.for)。引用的develop源码并非本地EXE同版本证明。

## 4. 针对现有目标函数的具体取舍

### 4.1 N0不一定是“低氮基线”，N3不一定是“过氮”

重新建立处理状态分类表：施肥N、初始矿质N、矿化假设、根区矿质N、植株/叶N、实测响应及不确定性。分类为“有证据缺氮”“接近充足”“已充足”“疑似过量损伤”“证据不足”。水分也按有效根区状态分类，不按W编号直接贴胁迫标签。

若各处理初始土壤N或水分不同，实际处理产量差是综合环境响应；不能全部归于施肥或灌溉。真实试验回放保留实测差异；另设统一IC的模拟对照用于机制归因，两者分开报告。**目标入选不能随某个候选模拟出的胁迫状态动态变化**，否则优化器能靠制造平台逃避目标；分组应在优化前由冻结观测与机制审查决定。

### 4.2 调整现有非N0梯度族，而不是继续增权

当前 `nitrogen_response.py::build_observed_n_dose_gradient_rows` 的 `monotone_plateau` 实际用前向最大值抬高观测目标；它既不是误差加权的单调估计，也不约束边际增益必须递减。26SP W1末次产量N1/N2/N3为65245/58484/70060，直接抬高N2会改变本来需要解释的负差。[实现](../../src/calibration/nitrogen_response.py)。

下一轮建议：

1. **不覆盖历史合同。** 保留原模式作历史对照，新方案使用未经抬高的观测与显式适用域。
2. `NGCV`先退出机制成功/晋级判据，建议从新轮主率定目标中移到诊断表；原始CV可以继续公开。
3. `NG12/NG23`使用原始有符号差或已声明的log差。只有有测量支持、对应机制可用的对比进入主目标；平台区允许差异在误差范围内接近零。
4. 疑似过量损伤的下降段单列结构检验，不通过抬高观测或忽略评价来“消除”。若它是研究核心且可靠，模型在这部分应判为能力不足，需要机制扩展或限定应用域。
5. 非N0存在可靠正差时继续作为待解决问题；不能因为现有模型处于平台，就将全部N1–N3降为平台目标。

### 4.3 建议的目标层次

| 层次 | 建议内容 | 防止的错误 |
|---|---|---|
| 基础拟合 | 各季/处理真实产量、LAI、器官生物量、单次采收；明确适用域 | 只改善相对差值却破坏绝对尺度 |
| 水氮过程 | 土壤水分、可用矿质N、器官N及有测量支持的吸氮 | 用错误供水供氮补偿遗传参数 |
| 有效响应 | 少量可靠的缺乏—充足对比、非N0有证据的梯度、同N水对比 | 将平台、噪声或不支持的损伤段强制拉开 |
| 结构检验 | 过量投入减产、不可解释的交互及独立季节偏差 | 删除难拟合数据造成虚假有效性 |

响应误差以处理均值差的不确定性为基础：`Var(差)=Var(均值高)+Var(均值低)−2Cov(均值高,均值低)`。有区组/重复配对时保留协方差；没有时披露近似假设。不要用两条共用N2的相邻差当两个独立重复。

可选择标准化残差，或预声明测量误差容许带的损失；容许带不能事后扩大至包住模型误差。累计采收日期彼此相关，不再同时对所有日期的增量、累计、差值和CV反复赋予强权重。优先少数有机制意义的阶段与末期，完整过程留在公开评价中。

## 5. 下一步优化顺序

**第一步：统一输入与冻结状态分类。** 完成26SP观测0.90数值系、0.34初始N、LAI补齐和实际土层的既有审查。真实数据无法支撑“过氮损伤”归因时标为未知，不猜测原因。固定版191先通过复现验收。

**第二步：做小型结构能力探针。** 每季在共同IC和既定参数下，设置覆盖缺乏—充足—高投入的4–5个N水平与缺水—适宜—高供水的3个W水平，形成约12–15个处理情景；初始氮、水分及管理时序逐项冻结。它们是模拟机制试验，不是额外实测点或独立验证。真实田间输入另作回放对照，不将反事实结果直接与不同IC的观测差混合计分。

记录土壤供给、吸氮/叶N、SWFAC/TURFAC、根系过湿状态、PHAD、器官分配、采收与水氮平衡；关键阶段效应存在疑问时，追加少量事件时机对照。目的不是画出好看的响应面，而是判断响应在哪一步消失。

**第三步：只对可激活、可约束的过程做低维率定。** 先校准缺乏—充足区，再检查平台区。N机制臂固定产量—冠层锚点；冠层臂固定已审计水氮环境。保留绝对产量、单次采收、两季LAI和茎重保护。当前PHOTO=L不因PHTMAX/PARMAX边界压力继续扩界；不继续依赖只压低N0的组合；PGEFF提高不能替代N梯度修复。

**第四步：设置决策分流。**

- 对可靠的正向梯度，若土壤/组织N本身就无差异，先查供给和需求；不要强拉产量。
- 组织N分离而光合无差异，检验真实作物是否也处于光合平台；没有相应观测，不随意改变FNPGN形状。
- 光合分离但果实产量不分离，再研究源库、果数/果重、衰老和采收过程。
- 可靠过量投入减产若需盐害、铵毒、病害等现有未验收机制解释，选独立模块/模型扩展；依据EC、NH4暴露或生理指标建模，而非直接乘以按施肥量设定的任意钟形惩罚。
- 若暂时缺乏扩展所需数据，正式结论限定为缺乏—充足区及经验证平台区，公开高投入损伤段的误差，不声称整个W×N域已验证。

**第五步：验证后再做资源优化。** 不一定要模拟出高N减产峰值，才有节氮意义。若平台预测经独立数据验证，可优化“达到预声明可接受产量水平时的最小施氮/灌溉量”，并报告参数与输入不确定性。但不能把模拟平台起点宣称为已验证的真实农艺最优量，也不能声称模型已排除过量投入风险。

## 6. 对前一份评审建议的细化

前一份报告提出以非N0梯度改善作为候选门，是为了避免“只压低N0”假装修好了N响应。该原则仍成立，但**不应对所有相邻处理、所有日期、所有季节统一强加15%改善或正向排序**。

应先冻结哪些对比可靠、哪些有机制支持、哪些属于结构检验，再对主目标制定改善门；不可靠近零差和平台允许近零，可靠正向梯度仍要解释，可靠下降段按其机制评价。目标降权/移出主优化不等于从性能评价或论文中消失。

验收交付物建议为 `response_target_contract.csv`：season、water/nitrogen contrast、日期/阶段、原始差值、单位、重复误差、IC可比性、机制、证据级别、calibration/diagnostic/structural_test角色、weight及冻结理由。后续每次运行都绑定其哈希，防止看过候选结果后临时换目标。
