# 茄子 DSSAT 参数率定试验矩阵与论文逻辑（v2，基于 2026-08 契约）

**状态：** 待审核的可复用试验设计；本文档只更新设计契约，不自动启动率定。  
**适用对象：** CROPGRO/TMGRO048 茄子模拟、遗传参数敏感性分析、PEST++ IES 率定及自定义 DSSAT 版本比较。  
**核心原则：** 先冻结输入、观测、目标函数、权重和可执行文件，再比较参数集；任何结果都必须能由 `run_manifest.yaml`、输入 bundle、frozen bounds、observation policy 和 executable/SPE 哈希复现。

## 0. 相对 v1 的关键修订

以下内容取代 v1 中的旧约定：

| 主题 | v1 旧约定 | 当前可复用约定 |
|---|---|---|
| 研究季节 | 25SP、25FA、26SP 混合推进 | 当前敏感性分析和主率定先使用 **25SP**；暂不开展25FA/秋季研究；26SP只能作为已冻结结构后的开发诊断或独立验证，不能冒充秋季数据 |
| 25SP 处理 | 可混用 8/10/14 个处理 | 主契约使用六处理：TN13、12、11（W1N0/N1/N2）和 TN5、4、3（W3N0/N1/N2）；扩展处理必须另建 design，不得静默加入 |
| 产量变换 | `ln(CHPDT+1)` | 当前主契约取消观测变换，使用原始单位的 signed difference；仅在另行批准的 policy 中才可启用变换 |
| 采收目标 | 累计 CHPDT 可按多个日期进入 Phi | `HPODW` 的实测增量 + 每处理一个最终真实累计 `CHPDT` 终值；虚拟终末采收不进入 Phi |
| 连续状态 | 原始 LAID/LWAD/SWAD 可整体进入 Phi | 原始状态序列主要作诊断；率定使用相邻观测差值和终值，避免累计序列伪重复 |
| 氮响应 | 旧的 log N-response、高预算方案 | 当前为同一水分水平内的原始 `N2-N0` 响应差，N_RESPONSE Phi 预算 0.10，`sigma_floor=50` |
| 土壤水分 | 可作为普通观测组处理 | 审计后的土壤水分进入 SOIL_WATER，Phi 预算 0.20；初始条件层均值是输入政策，不得与自由初始条件重复率定 |
| 权重 | 旧的 log/Min–Max/pwtadj1 方案 | `transform=raw`、`w=1/sigma_eff`；禁止动态 Min–Max 和 `pwtadj1`；组预算通过固定的 family/season/cell 分配实现 |
| 自定义 DSSAT | 将自定义参数当作普通遗传参数 | EXE、对应 SPE、参数行格式和注入白名单必须成套冻结；A3/A4/NR/NR-ZP 不能混用 SPE |
| FileX/FileT | 允许沿用历史复制品 | 25SP 必须以 `D:\Tomato_Cal\data\user\ref\XXQL2501.TMX` 为管理事件权威源；FileT/TMA 不得保留 `25203` 的估算收获观测 |
| 预率定流程 | v1 的分域/单季预率定逻辑在 v2 中被压缩 | 恢复 S1–S3：冠层形态建成 → 收获过程和终值 → 后验驱动的边界调整与联合正式率定 |

旧 v1 结果可以放入 `docs/archive/` 作为历史方法，但不得作为当前率定的 policy、输入或权重来源。

## 1. 当前不可变的输入与模型契约

### 1.1 25SP 权威输入

当前主率定 bundle 应使用修正后的 25SP 输入包，例如：

```text
data/user/experiments/xxql2501_layermean_ic_valid_n012_v1_20260801/
```

正式使用前必须重新确认该 bundle 的 `input_manifest.json` 已绑定最新权威 TMX；若 manifest 仍指向旧的 `data/user/experiments/XXQL2501/XXQL2501.TMX`，应先重建 bundle，不能把旧 bundle 当作修正后的输入。

每个 bundle 必须记录：

- 权威 `XXQL2501.TMX` 的路径和 SHA-256；
- `XXQL2501.TMT`、`XXQL2501.TMA`、`SOIL.SOL`、天气、`DSSBatch.v48` 的 SHA-256；
- 生成脚本和源观测表的 SHA-256；
- 处理排除清单、初始条件政策和观测不确定性来源。

### 1.2 FileX/FileT 对齐规则

`XXQL2501.TMX` 的施肥次数、施肥日期、施肥量、真实收获事件和处理编号是唯一管理事件来源。任何派生 FileX 必须逐字段对齐，不得从旧 batch 或旧 TMT 反推事件。

`XXQL2501.TMT`/`XXQL2501.TMA` 只保留真实观测事件：

- 删除所有对应 `25203` 的估算收获事件及其估算产量；
- `25203` 可以在审计注释中说明被排除，但不得作为观测行进入 registry、权重或 Phi；
- FileX 截止日、最后真实收获日、虚拟延长模拟终点必须分别记录；虚拟终点只服务于 DSSAT 完整运行，不生成观测和权重。

每次运行前执行 FileX/FileT 对齐审计，至少检查：施肥事件序列、真实收获日期、处理号、FileT 列单位、最后真实 `CHPDT` 事件和 `25203` 禁止项。

### 1.3 初始条件和土壤

当前 25SP layer-mean IC bundle 的初始 `SH2O/SNH4/SNO3` 使用有效 IC 子集的分层均值；排除没有可靠管理/初始条件定义的 TN1、TN6、TN7、TN8。初始条件不是遗传参数，除非另有独立观测和批准的 nuisance-parameter proposal，否则固定在输入 bundle 中。

土壤水分观测必须保持处理特异性，不得把不同处理池化成反事实观测。土壤层匹配、观测日期和初始层均值必须由 `soil_water_match_audit.csv` 与 manifest 固定。

## 2. 当前目标函数与权重契约

### 2.1 残差和变换

当前正式 policy：

```text
transform = raw
residual_i = simulated_i - observed_i
Phi = sum((w_i * residual_i)^2)
w_i = 1 / sigma_eff_i
```

不得使用候选模拟值动态计算 Min–Max、不得把 `1/sigma^2` 直接写成 PEST weight，也不得在 IES 运行中使用 `pwtadj1` 改写权重。所有原始值、sigma、最终 weight、组预算和 Phi 贡献必须进入审计表。

### 2.2 当前观测口径

当前主 policy 文件：

```text
configs/runs/e02_v2_rawdiff_terminal_nresp01_soil02_policy_20260805.csv
configs/runs/t10_rawdiff_terminal_nresp01_soil02_group_policy_20260805.csv
```

| 观测族 | 当前 Phi 状态 | 说明 |
|---|---|---|
| `LAIX` 最大 LAI | 活跃 | 原始尺度，`sigma_floor=0.1` |
| `LAID`、`LWAD`、`SWAD` 原始状态序列 | 诊断 | 不与差值序列重复计权 |
| `LAIDDM` | 活跃 | 相邻有效 LAI 观测的 signed difference |
| `LWADDM`、`SWADDM` | 活跃 | 相邻叶/茎干物质观测的 signed difference |
| `LAIETM`、`LWETM`、`SWETM` | 活跃 | 每处理终值 |
| `SNAM`、`LNAM` | 活跃 | 叶/茎氮质量；若研究氮浓度，必须另建审计过的 concentration token，不能把质量和由质量/干重反推的浓度重复计权 |
| `CNAM` | 诊断 | 合并氮质量不再与 SNAM/LNAM 重复进入 Phi |
| `HPODW` | 活跃 | 真实采收事件的干果重增量 |
| `CHPDT` | 活跃但仅终值 | 每处理最终真实累计干果重；中间累计节点只作诊断/图形 |
| `CHFPW` | 诊断 | 鲜果重和鲜干比解释，不进入当前 Phi |
| `PWAD`、`PWAI`、`HWAM` | 禁止 | 与当前连续采收观测定义不匹配 |
| `NRESP` | 活跃 | 同一 water 内的原始 `N2-N0` CHPDT 响应差；N1 用于响应形状诊断，不自动新增一套目标 |
| `SOIL_WATER` | 活跃 | 审计后的非初始土壤水分观测，预算 0.20 |
| `PDAP/ADAP/MDAP`、`CHTD` 等 | 诊断或低权重辅助 | 只有观测有效且在 policy 中明确启用时才可进入 Phi |

当前正式比较应区分 `calibration`、`diagnostic`、`validation` 和 `sensitivity_only`。诊断数据可以生成图和残差，但不能影响 Phi。

### 2.3 Phi 预算

当前 group policy 的核心预算如下。预算是预先冻结的 family/season/cell 分配，不是率定后反向调权：

| 组 | Phi 预算/倍数 | 当前含义 |
|---|---:|---|
| PHENO | 0.10 | 仅在有效物候观测存在时使用 |
| LAI 差值/终值 | 0.60 / 0.20 | 差值约束过程，终值约束末态 |
| 叶/茎干物质差值/终值 | 0.75 / 0.25 | 避免整段状态序列伪重复 |
| PLANT_N | 1.00 | SNAM + LNAM |
| HARVEST_DRY_INCREMENT | 1.25 | HPODW 真实事件增量 |
| HARVEST_DRY_TOTAL | 0.50 | 每处理一个最终真实 CHPDT |
| N_RESPONSE | 0.10 | 原始 N-response，明确降权 |
| SOIL_WATER | 0.20 | 审计土壤水分 |
| HARVEST_FRESH | 0 | CHFPW 仅诊断 |

每个实验必须输出 group-weight audit，说明每个 cell 的 `sigma_eff`、`n_eff`、budget、最终 weight 和 Phi 贡献。任何新权重方案都必须新建 policy/group-policy 文件和新的 experiment ID。

## 3. 自定义 DSSAT 版本契约

### 3.1 版本必须成套使用

当前可比较的版本包括：

| 版本 | 氮吸收结构 | 配套 SPE/参数注意事项 |
|---|---|---|
| A3 | `C*=max(C-NUPCMN,0)`，Hill/Michaelis–Menten 曲率 | A3 三参数版本使用 `NUPK50,NUPQ,NUPCMN`；具体 SPE 行必须与 EXE 匹配 |
| A4 | `Ceff=NUPAV*C`，Hill/Michaelis–Menten 曲率 | 使用 `NUPK50,NUPQ,NUPAV`，不把 A3 的 NUPCMN 塞入 A4 |
| A3_NR / A4_NR | A3/A4 + 连续 `NSTRES` | `NREXP`、`NRMIN` 的含义和 SPE 行由对应版本定义 |
| A3_NR-ZP / A4_NR-ZP | A3/A4 + zero-preserving 连续响应 | 使用对应 NR-ZP SPE；NR-ZP 的 `NRMIN` 是曲率混合权重，不解释为零氮最低响应因子 |

连续响应版本均需记录 `X=clamp(SUPPN/(NDMNEW*NSTFAC),0,1)`、日尺度平滑和响应公式。NR/NR-ZP 的当前候选范围为 `NREXP=0.05–2.00`、`NRMIN=0.05–0.80`；若某一版本固定它们，必须在 bounds/profile 中明确标记 fixed。

注意：最近的 A3 NR-ZP 33/83 参数域运行中，`NREXP` 和 `NRMIN` 是按该次 profile 固定写入的；上面的范围是后续释放这两个参数时的候选范围，不代表它们会自动进入所有率定。

当前 A3 NR-ZP 率定使用的自定义 Windows 程序为：

```text
D:\Tomato_Cal\windows\windows_a3_nr_zp_20260805\dscsm048_a3_nr_zp.exe
D:\Tomato_Cal\windows\windows_a3_nr_zp_20260805\Genotype\TMGRO048.SPE
```

该 EXE 的 SHA-256 为：

```text
2D1BB35912EFDEAB4E936F9A8A41684F519E45C2AF773A61BAA49264EEEE2276
```

`FL-VS` 当前固定为 `120`。自定义参数注入必须通过 SPE 白名单；每个 active/fixed 参数都要完成 baseline/lower/upper 注入、SPE 精确读回和文件哈希变化检查。不能因为参数未出现在旧白名单而静默丢弃。

### 3.2 参数集和边界生命周期

参数层级仍为：

```text
physical bounds → baseline → bounds_proposal → bounds_frozen → PST
```

率定只能读取 `bounds_frozen/<crop>/`。SA 排名只是候选证据，不自动决定 active 参数。

当前可复用的两个比较域为：

- **SA-top95/33 参数域：** 敏感性分析参与参数中经人工审核的 top95/33 active 参数；
- **SA-all/83 参数域：** 参与敏感性分析的全部 80+ 参数；不是只把 Morris 排名靠前的31个参数扩大。

具体名称、范围、status、pargp、file、cultivar、ecotype 和 bounds ID 必须由 profile 与 frozen CSV 冻结。后验触边后的 `keep/narrow/widen/fix` 必须新建 proposal，经审核后生成新 bounds ID；不能覆盖原冻结边界。

## 4. 更新后的试验矩阵

### E00：输入、SPE、白名单和观测契约审计（所有试验前置）

**目的：** 确保同一比较中只有参数集或 DSSAT 结构发生变化。

**必须完成：**

1. 校验最新权威 TMX、FileT/TMA、SOIL、天气、batch 和 input manifest 哈希；
2. 校验六处理映射和 FileX/FileT 施肥、真实收获、`25203` 排除；
3. 校验 observation policy 与 group policy 的 SHA-256；
4. 对每个 SPE 注入参数做 baseline/lower/upper round-trip、精确读回和哈希检查；
5. 校验 PST adjustable 集合与 frozen bounds active 集合完全一致；
6. 使用对应 EXE/SPE 完成六处理 smoke，并归类模型失败成员。

**停止条件：** 任一哈希不一致、白名单漏参、SPE 读回不精确、FileT 含估算事件、目标函数混入禁用变量或非有限输出，均不得进入正式 IES。

### E01：25SP Morris 敏感性分析

**目的：** 在固定 25SP 六处理、固定初始条件和固定目标函数下，识别器官氮/氮响应及过程输出对参数的响应稳定性。

**当前设置：**

- 只使用 25SP；不使用 25FA；没有“26秋季 FileX”这一输入；
- 以 corrected 25SP bundle 和最新 FileX/FileT 对齐审计为基础；
- 主响应包括 SNAM/LNAM（或另行冻结的器官氮浓度 token）、LAI/干物质终值、HPODW/CHPDT 终值、NRESP 和 SOIL_WATER；
- 每个参数/每个自定义参数都执行 SPE round-trip；
- Morris 结果只作为候选敏感度证据，不等于可识别性或因果证明。

**通过门：** 多 seed 稳定性、有效轨迹比例、响应非退化、Top-K 一致性、无结构性全零/非有限响应，并由用户审核 active profile。

### E02：分阶段 25SP 预率定（恢复 v1 的 staged pre-calibration）

**目的：** 在正式 33/83 参数 IES 之前，按过程域逐步释放参数，形成经验初始化、参数冲突诊断和边界 proposal。预率定不是独立验证，也不产生可直接拼接的“最终基因型”。

**共同设置：**

- 只使用 25SP 六处理和同一修正输入 bundle；不使用 25FA；
- 使用与正式率定相同的 raw-difference/terminal 目标函数契约；阶段未启用的观测族设为 diagnostic 或零 Phi，而不是改写观测定义；
- 每个阶段只从 frozen bounds 读取参数，使用 `--fixed-from` 绑定上一阶段的代表参数或固定 ensemble；
- 每个阶段均保存 active/fixed profile、PST、best/representative 参数、SPE round-trip、Phi/group audit 和边界诊断；
- S1–S2 的规模可以小于正式 IES（默认 100 members × 3 updates），但必须在 manifest 中记录；
- 阶段结果只能用于下一阶段初始化、后验诊断和边界调整，不能把各阶段的最优值逐参数拼接成最终参数组。

#### S1：冠层形态建成预率定

先释放冠层形态建成相关参数，例如 LFMAX、SIZLF、SLAVR、FL-SD、FL-SH、RHGHT、RWDTH、冠层结构开关以及经 profile 审核的早期建成参数。活跃观测以 LAIX、LAI 相邻差值和 LAI 终值为主，必要时加入经审计的冠层高度诊断；物候观测仅在真实有效时启用，不虚构 ADAP 目标。氮吸收、收获过程和土壤 nuisance 参数固定。

#### S2：收获过程和终值预率定

以 S1 代表参数为固定起点，释放收获过程、干物质终值和末期状态相关参数。活跃观测为真实 HPODW 增量、每处理最终真实 CHPDT、LWAD/SWAD 终值以及必要的 LAI 终值；中间累计 CHPDT、CHFPW、PWAD/PWAI 仍不新增 Phi。虚拟终末采收只用于完成 DSSAT 模拟，不进入目标函数。自定义氮参数和器官氮参数在 S2 固定，除非某一候选收获参数必须通过独立的 N-response smoke 才能确认其可读回性。

#### S3：后验驱动的边界调整与联合正式率定

S3 不再是单独的第三个分域预率定。首先联合检查 S1、S2 的后验 Q05/Q50/Q95、IQR/variance shrinkage、近下/上界比例、最佳成员触边、参数相关性和过程残差；然后为每个参数形成 `keep/narrow/widen/fix` 决议，生成 proposal，经审核后冻结新的 bounds ID。随后使用调整后的边界、S1/S2 代表初始化和完整当前 observation/group policy，开展联合正式率定。联合率定才是第一个允许同时释放已批准参数集并报告正式最佳成员的步骤。

**阶段通过门：** S1/S2 必须通过模型完成率、Phi 有限性、活动参数有变化、SPE 读回精确和失败成员分类；S3 还必须通过边界调整审计、物理/顺序约束、proposal 审核和联合正式率定的工程质量门。S1/S2 的结果不能作为独立验证或严格贝叶斯先验。

### E03：S3 联合正式率定执行（调整边界后）

**目的：** 执行 S3 已批准的联合正式率定：在 S1/S2 后验驱动的 frozen bounds 下，使用完整批准参数集和新目标函数契约获得可审计的联合正式率定基线。

**默认正式规模：** 200 members × 4 updates，Sobol 初始 ensemble；若资源或试验设计改变，必须生成新的 experiment ID。

**固定内容：** 六处理、同一 bundle、同一 policy、同一 group policy、S3 新 frozen bounds、S1/S2 代表初始化、同一随机种子和同一失败成员分类规则。最佳成员按最终迭代 active Phi 最小值选择，但同时保留 final ensemble 的 Q05/Q50/Q95。

### E04：33 参数与 83 参数 active-set 比较

**目的：** 检验放开全部 SA 参与参数是否改善拟合、氮响应和器官氮约束，而不是只看 Phi。

**比较规则：**

- 33 参数和 83 参数使用完全相同的 25SP 六处理、数据、权重、EXE/SPE 结构和 IES 规模；
- 83 参数必须是“SA-all”，不能误写成 Morris top31；
- 同时报告 overall、处理级、观测族级 RMSE/MAE/Bias/NSE/d-index/R²、NRESP 响应误差、器官氮误差、后验收缩、相关性和触边率；
- 只有在原始尺度误差、处理响应方向和边界质量均不恶化时，才可声称新增参数改善模型。

### E05：A3/A4/NR/NR-ZP 自定义 DSSAT 结构比较

**目的：** 区分遗传参数释放带来的改善和氮吸收方程结构带来的改善。

每个版本必须单独建立 EXE/SPE/profile/design/run 目录；除自定义 DSSAT 结构和对应参数外，其他输入、观测、权重、IES 设置保持一致。结果必须绑定 executable/SPE SHA-256，不能用 A3 的 SPE 运行 A4 或用普通 NR 的 SPE 运行 NR-ZP。

### E06：后验触边后的边界重跑

**目的：** 判断初始边界是否主动截断后验，而不是用更多迭代掩盖边界问题。

边界调整流程：

1. 用最终 `.par.csv` 计算每个参数的近下界/近上界比例、Q05/Q50/Q95 和最佳成员触边；
2. 为每个参数形成 `keep/narrow/widen/fix` 决议；
3. 记录物理边界、参数顺序约束、文献理由和审批信息；
4. 生成新 proposal，审核后 freeze 新 bounds ID；
5. 用同一 policy、EXE/SPE 和 IES 规模重跑；旧 run 保留不覆盖。

历史上采用过“触边比例 >5% 时向触边方向扩展旧范围15%”的工程规则；该规则只能作为明确标记的 proposal 生成器，不能绕过人工审核，也不能突破 physical bounds 或参数顺序约束。

### E07：26SP 开发诊断或独立验证

26SP 可以使用 W1N0/W1N1/W1N2/W2N0/W2N1/W2N2 观测，但必须先冻结其 FileX、FileT、初始条件和 treatment mapping。26SP 若参与参数调整，只能标记为 `development-calibration` 或 `exploratory pooled calibration`；若要作为论文外部验证，必须在结构和边界冻结后完全隔离，不能回流调参。

当前矩阵不包含 25FA 研究，也不定义 26FA/26秋季试验。

### E08：未参与结构选择的新季节/地点外部验证

论文的最终预测主张需要独立的新季节或地点。验证输入不得重新率定参数，至少包含水氮处理、连续干果重、过程观测、实际初始条件和完整管理事件。除绝对产量误差外，报告：

```text
ΔW = Y(Whigh,N) - Y(Wlow,N)
ΔN = Y(W,Nhigh) - Y(W,Nlow)
交互差 = [Y(Whigh,Nhigh)-Y(Wlow,Nhigh)]
       - [Y(Whigh,Nlow)-Y(Wlow,Nlow)]
```

只有绝对产量和响应方向均通过预登记门槛，才支持管理优化或论文预测性表述。

## 5. 统一指标和残差证据

主表使用原始物理尺度，定义：

```text
e = simulated - observed
MBE  = mean(e)
RMSE = sqrt(mean(e^2))
MAE  = mean(abs(e))
NSE  = 1 - sum(e^2) / sum((observed - mean(observed))^2)
```

同时输出 NRMSE、d-index、R²、Pearson 斜率/截距和 treatment-block bias。Phi 只作为目标函数诊断，不替代原始尺度指标。

累计采收曲线可画事件阶梯线和单调平滑线，但插值节点不参与 RMSE、NSE、d-index 或 Phi。增量采收必须按真实事件比较；虚拟终末采收只用于模型结束，不生成数据点。

每个实验至少输出：

- overall、season、treatment、观测族和 dataset_role 分层指标；
- raw observation/simulation/residual 对照表；
- 处理级水氮响应差值；
- 残差轨迹、1:1 图、残差-观测值图；
- posterior Q05/Q50/Q95、边界比例、IQR/variance shrinkage、Spearman/Pearson 和 PCA；
- final ensemble、最佳成员和至少两个近 Phi 异参同效成员的确定性前向结果。

## 6. 运行产物和审核门

每个 run 必须包含并哈希绑定：

```text
run_manifest.yaml
input_manifest.json
experiment/design config
observation policy + group policy
frozen bounds CSV/YAML
PST/TPL/INS
prior/final parameter ensemble
prior/final observation ensemble
phi.actual / phi.group / weights audit
member-status and engineering/science quality reports
best-member deterministic rerun and metrics
EXE/SPE path and SHA-256
```

`engineering_validated` 只表示运行完成、文件完整、参数和模拟有变化；不等于 `science_validated`。只有正式输入、设计、验证分割、确定性复跑、group-Phi 审计和来源哈希均齐全，才能升级科学状态。

## 7. 执行顺序和停止规则

```text
E00 输入/白名单/SPE round-trip smoke
 → E01 25SP Morris
 → 用户审核 SA active profile 与初始 bounds proposal
 → E02-S1 冠层形态建成预率定
 → E02-S2 收获过程和终值预率定
 → E02-S3 后验驱动的边界调整
 → E03 调整边界后的联合正式率定
 → E04 33 vs 83 active-set 比较
 → E05 A3/A4/NR/NR-ZP 结构比较
 → E06 后验触边边界重跑
 → E07 26SP 开发诊断或冻结后验证
 → E08 独立外部验证
``` 

在以下任一情形停止并修复原因，不以“多跑几轮”替代审计：

- 输入、FileX/FileT、policy、bounds、EXE/SPE 哈希不一致；
- `25203` 或其他估算收获进入观测/Phi；
- SPE 注入未精确读回或白名单漏参；
- transform、signed difference、terminal-only 规则与 registry 不一致；
- 权重使用动态 Min–Max、`1/sigma²` 或 `pwtadj1`；
- PST adjustable 集合与 frozen bounds/profile 不一致；
- 模型失败、非有限值或高 Phi 成员未分类；
- 大量参数触边而没有独立物理理由；
- 26SP/验证数据被回流用于参数结构选择；
- 指标、数据角色或目标函数改变但没有新 experiment ID 和 manifest。
