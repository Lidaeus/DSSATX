# 敏感性分析相关图表优化设计方案

> 日期：2026-08-02  
> 适用范围：三季茄子/番茄模型遗传参数 Morris、Sobol 及其论文/补充材料图表  
> 设计依据：项目产品定义、科研图表设计与开发计划、绘图工作交接文档、敏感性分析方案与图表优化实施计划、`nature-figure` 图形契约  
> 本文状态：设计交接；不改变冻结边界、不新增 DSSAT 运行、不将当前 `science_pending/DEMO` 证据升级为正式论文结论

## 1. 结论先行

当前敏感性分析图表的统计逻辑总体正确，主要问题不是“缺少更多图种”，而是不同证据层级在同一张图中竞争空间，导致读者不容易区分：

1. 跨季反复重要性是什么；
2. Morris 的非线性/交互参与提示是什么；
3. Sobol 的定量主效应和总效应是什么；
4. 数值证据在哪些季节通过质量门；
5. 这些结果对率定候选池有什么含义。

建议保留现有 Fig. 1、Fig. S1、Fig. S2 的总体证据链，但做“层级化改版”：

- Fig. 1 只讲跨季核心和过程指纹，并接入一个极简、明确标注证据范围的 Sobol 摘要；
- Fig. S1 只讲 Morris 的效应几何与多种子稳定性；
- Fig. S2 只讲 Sobol 的效应分解、响应尺度和数值支持；
- `mu*–sigma`、参数选择漏斗、完整 55 参数图和响应方向剖面进入补充/诊断层，不再挤占主图。

正式论文图仍由 `paper/R/` 唯一渲染；本方案采用 `nature-figure` 的“结论—证据链—图形原型—审查风险”流程，不建立第二套 Python 论文绘图实现。

## 2. 敏感性分析图表契约

### 2.1 论文主张

建议敏感性分析部分围绕以下中心句组织：

> 在冻结且生理可解释的参数空间内，多季 Morris 识别了跨环境反复重要的过程控制参数；响应级 Sobol 分解进一步区分了主效应与交互参与，但这些证据依赖季节、响应定义和采样规模，因此敏感性结果用于构建受观测约束的率定候选池，而不是直接证明可辨识性、因果性或模型有效性。

### 2.2 证据层级

| 层级 | 要回答的问题 | 允许的图形表达 | 禁止的表达 |
|---|---|---|---|
| 跨季筛选 | 哪些参数在多个季节/域重复出现？ | 季节点、范围线、等权均值、稳定核心标记 | “绝对主导”“必需率定” |
| 过程归属 | 参数主要关联物候、冠层、生物量、收获还是水氮响应？ | 参数×响应组指纹矩阵 | 把不同量纲原始分数相加后称为综合生理效应 |
| Morris 几何 | 高 `mu*` 是否伴随较大 `sigma`？ | 响应级 `mu*–sigma` 小多图 | 把 `sigma` 直接称为参数对交互强度 |
| Sobol 分解 | 主效应与总效应分别多大？ | `S1/ST` 配对点区间图 | 双层堆叠条形图、跨季合并未通过指数 |
| 数值可信度 | 哪些季节/域通过 bootstrap、收敛和名次门？ | 状态矩阵、阈值点图、源表 | 用红绿灯色块替代状态定义 |
| 率定含义 | 如何进入率定候选池？ | 精简决策表或图注 | 由敏感性直接推出“可辨识”或“必须率定” |

### 2.3 统一命名

正式图和图注统一使用：

- `first-order sensitivity index (S1)`；
- `total-effect sensitivity index (ST)`；
- `interaction-involving remainder (ST-S1)`；
- `season-end cumulative harvested dry mass`，不要继续使用含义不完整的 `Fruit dry mass`；
- `water contrast`；
- `nitrogen-response slope`；
- `difference in nitrogen-response slopes between water levels`；
- `conditional parameter importance`。

## 3. 当前图表审查

### 3.1 当前 Fig. 1：保留骨架，降低过度结论和视觉拥挤

当前优点：

- 上部使用季节点、季节范围和等权均值，能避免只呈现一个 pooled 排名；
- 下部过程组指纹没有把不同响应的原始量纲直接相加；
- 已保留稳定/需要更多 seed 的形状信息；
- 水氮域与通用遗传效应域分开显示。

主要问题：

1. 标题 `identifies dominant process controls` 过强，容易把条件敏感性写成生理因果；
2. `Hierarchy-normalised Morris score` 对读者不够自解释，缺少“响应内归一化、仅用于同一响应/域内比较”的说明；
3. 过程指纹的颜色强度容易被读成跨响应可加的绝对效应；
4. 稳定性点、季节图例、形状图例和两个域条带分散了阅读路径；
5. 版面下部留白较多，但主图没有明确把“筛选结果”连接到“率定候选池”的证据边界。

改版建议：

- 标题改为：`Cross-season conditional sensitivity identifies a stable core of process-relevant parameters`；
- 副标题明确：`Scores are conditional on the frozen parameter ranges and season-specific water–nitrogen scenarios`；
- 上部只保留 6–8 个覆盖物候—冠层—收获—水氮链条的代表参数；
- 将稳定性从空心/实心点改为“外圈描边/无描边”或直接加 `stable`/`boundary` 标签，避免依赖点填充；
- 下部热图改用 `within-response-group relative contribution`，色条标题写明 `relative Morris importance within response group`，并在图注披露不能跨响应比较原始颜色深浅；
- 如接入 Sobol，采用右下角小型 `S1/ST` forest plot，只显示通过数值门的 XXQL2502、3 个核心响应、每个响应 Top 2–3 参数；不把完整 Sobol 审查压进主图；
- 取消单独的大型季节/稳定性图例，使用一个横向共享图例和简短 panel note。

### 3.2 当前 Fig. S1：由“排名轨迹板”改成“效应几何 + 稳定性证据”

当前优点：

- 三季、多 seed、两个域均有显示；
- Spearman、Top-15 Jaccard 和阈值线都被保留；
- 对 XXQL2502 水氮域边界不稳定没有隐藏。

主要问题：

1. 排名轨迹采用多条彩色折线，关注参数一多就形成 spaghetti plot；
2. 轨迹排名只回答“名次怎么动”，不能回答“效应量是否大、`sigma` 是否大”；
3. 现有 `FigS1b/FigS1c` 的功能定义和实际冻结数据并不完全对齐，尤其响应级 `morris_response_effects.csv` 尚未成为当前 v4 纸图包的稳定输入；
4. `mu*–sigma` 聚合若采用跨观测中位数，需要明确它是描述性汇总，不应被写成固定标量响应的 Morris 结果。

改版建议：

**Panel a：响应级 Morris `mu*–sigma` 小多图（主证据）**

- 选择 4 个核心响应：开花期、LAI 积分、季末地上部生物量、季末累计收获干物质量；
- 每个小图只对应一个响应，`x=mu*`、`y=sigma`；
- 每个响应内独立标准化/排序，禁止跨响应平均原始 `mu*` 和 `sigma`；
- Top 5 参数直接标注，其余参数低饱和度显示；
- 颜色最多表示两个科学域，形状/描边表示稳定状态；
- 图注写 `sigma indicates nonlinearity and/or interaction involvement; it is not a pairwise interaction estimate`；
- 不画未经定义的四象限阈值。

**Panel b：多 seed 稳定性矩阵**

- 行：season × ranking domain；
- 列：Spearman、Top-15 Jaccard、最大 Top-15 名次变化；
- 每个格子显示实际值、阈值和 `Pass`/`Not met`；
- 通过/未通过用点形与描边共同编码，颜色只作弱辅助；
- 该面板比当前三个单独小图更快回答“哪一域的边界仍不稳定”。

**Panel c：可选的排名轨迹**

- 只保留 4–6 个跨季核心参数，作为背景证据；
- 不再用 8 个参数全部进入显眼彩色图例；
- 轨迹颜色按参数族而非季节，季节改用小分面；
- 若篇幅紧张，Panel c 降为 `diagnostic_*`，不进入正式 Fig. S1。

### 3.3 当前 Fig. S2：拆分“效应大小”和“证据状态”

当前优点：

- 同时展示 `S1`、`ST`、paired-bootstrap 区间和 `ST-S1` 是否支持交互参与；
- 明确 XXQL2502 通过、XXQL2501 bootstrap 失败、XXQL2601 rank gate 未通过；
- 没有把未通过季节的指数伪装成精确跨季结论。

主要问题：

1. 上部状态色块、中央效应面板、下部收敛图在一页中同时争夺注意力；
2. 状态色块采用接近红/绿/橙的强填充，容易把质量状态读成结果好坏；
3. 当前中央面板只显示每个响应 Top 3 by `ST`，读者不容易知道遗漏项是“低效应”还是“未通过显示筛选”；
4. 响应尺度信息只在 source CSV 中，不在图内可见；
5. `Fruit dry mass` 术语会掩盖它实际是季末累计采收干物质量；
6. `ST-S1` 用紫色线段标记有用，但需要在每个响应面板中与数值/区间对应，避免被误读成独立指数。

改版建议：

**Panel a：数值证据状态矩阵**

- 行：XXQL2501、XXQL2502、XXQL2601；
- 列：bootstrap、rank convergence、response variance；
- 单元格显示 `0.665/0.95`、`Pass`、`Not met` 等短文本；
- 不用大面积交通灯色块，采用灰底 + 蓝/金描边 + 符号；
- 把详细阈值与失败原因放入 source/metrics 表，图中只保留可读短语。

**Panel b：定量效应 forest plot（英雄面板）**

- 仅显示通过全部门的 season/domain；当前即 XXQL2502；
- 每个响应一个小分面，参数按 `ST` 降序；
- `S1` 空心圆，`ST` 实心圆；两者均有各自 95% paired-bootstrap 区间；
- 用浅灰连接线表示同一参数的 `S1→ST`，若 `ST-S1` 区间下限大于 0，再以紫色描边提示“interaction-involving remainder supported”；
- 保留 0 和 1 参考线；不裁剪超出 `[0,1]` 的有限样本区间；
- 响应标题使用：`Anthesis`、`Seasonal LAI integral`、`End-of-season aboveground biomass`、`Season-end cumulative harvested dry mass`、`Water contrast`、`Nitrogen-response slope`、`Difference in N-response slopes between water levels`。

**Panel c：响应尺度与收敛证据**

- 左侧为响应标准差/范围的紧凑点图或表格条，单位随响应显示；
- 右侧为 N=128→256 的 Spearman、Top-8 Jaccard、最大名次变化点图；
- 将“相对方差份额”和“绝对响应变异量”并列，但不放在同一坐标轴；
- 对水氮交互斜率差的低 `response_sd` 做直接脚注，防止读者把高 `ST` 误读为大的农学效应。

## 4. 推荐的新图表

### 4.1 新增/正式化候选：Fig. S1b“响应级 Morris 效应几何”

**科学问题**：哪些参数在特定响应上同时具有较大平均绝对效应和较大的非线性/交互参与提示？

**图形原型**：4 个响应小多图的 `mu*–sigma` scatter；参数 Top 5 直接标注，完整参数保留为 source CSV。

**数据要求**：

- 新增并冻结 `morris_response_effects.csv`；
- 粒度至少为 `season × seed × ranking_domain × response_id × parameter`；
- 字段包括 `mu`、`mu_star`、`sigma`、有效轨迹数、失败率、响应内标准化值；
- 若只有观测级 elementary effects，图注明确“response-level descriptive aggregation”，不得称为固定标量响应估计；
- 保留零效应和低效应参数，不只导出 Top-K。

**不应做的事**：不画 SHAP，不加四象限阈值，不把 `sigma/mu*` 写成某一对参数的交互系数。

### 4.2 新增诊断图：`diagnostic_sa_response_profiles`

**科学问题**：关键参数变化时，DSSAT 输出的方向和非线性形状是什么？

**图形原型**：参数分位数分箱后的条件响应曲线；显示中位数、10–90% 条件带和每箱样本数。

**推荐对象**：TRIFL、RTNO3、XFRT、LFMAX、RTNH4、XFINT；响应选择 LAI 积分、季末累计收获干物质量、水分效应、氮响应斜率。

**解释边界**：这是在其他参数同时变化条件下的描述性边际 profile，不是单因素因果曲线；任何视觉拐点必须再用定向 DSSAT 运行确认，未确认时不得写“阈值”。

**状态**：先作为 Python 运行诊断，不新增正式 Fig/FigS；待 W1–W5 审查完成后再决定是否转入 R 补充图。

### 4.3 可选新图：`Fig. S1c`参数—响应角色矩阵

如果读者需要从“参数排名”转向“过程决策”，建议用参数×响应组的点阵/矩阵替代当前部分热图：

- 点的横向位置：响应内相对 Morris 重要性；
- 点大小：跨季出现次数或有效季节数；
- 点形：通用遗传域/水氮域；
- 描边：稳定/边界不稳定；
- 颜色：只区分过程族，保持低饱和度。

该图不显示原始量纲，能直接表达“哪个参数覆盖哪些过程、证据在哪些季节重复出现”。若 Fig. 1 已包含过程指纹，则该图只进入补充材料，避免重复。

## 5. 不建议使用的图形

- **雷达图**：不同响应和不同参数域的尺度不自然，读者难以比较局部差异；
- **全 55 参数单一条形榜**：会把条件敏感性误导成全局固定排序，且无法呈现季节异质性；
- **跨响应原始 `mu*`/`sigma` 叠加面积图**：量纲和响应数量会共同制造视觉总量；
- **双层堆叠 Sobol 条形图**：当 `S1<0`、`ST<S1` 或区间较宽时会伪造非负可加结构；
- **t-SNE/PCA 作为异参同效主证据**：只能辅助显示，不替代目标距离、参数距离和确定性复跑；
- **SHAP 主图**：当前没有独立 DSSAT holdout 和代理精度门，不能把代理解释写成 DSSAT 机理归因；
- **红绿灯质量图**：会把“证据是否通过”误读成“模型好坏”，应改为状态矩阵和短文本。

## 7. 最终 QA 清单

### 科学表达

- [ ] 标题使用 `conditional sensitivity`，不使用 `dominant process control`；
- [ ] 每个 panel 只回答一个科学问题；
- [ ] Morris `sigma` 被解释为非线性和/或交互参与提示；
- [ ] `ST-S1` 被解释为 interaction-involving remainder，不被写成具体参数对；
- [ ] 只对通过门的季节报告定量 Sobol 指数；
- [ ] 响应尺度与相对 Sobol 份额同时可见；
- [ ] 水氮交互斜率差的低绝对变异量被明确披露；
- [ ] 敏感性结果不被写成可辨识性、因果性或模型验证。

### 视觉表达

- [ ] S1/ST 用空心/实心和线型共同编码，灰度打印可区分；
- [ ] 通过/未通过不只依赖红绿颜色；
- [ ] 轴线、参考线、误差区间和标签在双栏最终尺寸可读；
- [ ] 参数名和响应名不裁切、不重叠；
- [ ] 不使用彩虹色图；
- [ ] 共享图例不重复，稳定类别优先直接标注；
- [ ] 7 pt 正文、8 pt panel label、183 mm 双栏宽度和 170 mm 高度约束通过。

### 可复现性

- [ ] R 是正式渲染器；
- [ ] R 只读取冻结数据包，不直接读取 DSSAT/PEST 临时输出；
- [ ] 观测/模拟、参数、响应、质量状态与上游 `run_id` 可追溯；
- [ ] source CSV、manifest、SHA-256 和 QA 记录齐全；
- [ ] `science_pending/DEMO` 状态不会被误写成正式论文证据。

## 8. 交接结论

本轮不建议继续增加新的敏感性算法或复杂图种。优先级应为：

1. 把 Fig. 1 从“汇总板”改成“跨季核心—过程指纹—精简定量效应”的证据链；
2. 把 Fig. S1 的排名轨迹降为辅助，把响应级 `mu*–sigma` 和稳定性矩阵提升为主证据；
3. 把 Fig. S2 的状态、效应大小、响应尺度和收敛结果分层，避免一页内过载；
4. 先补齐响应级 Morris 数据字段，再讨论新图；
5. 以 `diagnostic_sa_response_profiles` 作为最有价值的新图形方向，但暂不升级为正式 Fig/FigS；
6. 继续保留现有失败季节和 `science_pending/DEMO` 标识，不用视觉优化掩盖科研质量门未完成的事实。
