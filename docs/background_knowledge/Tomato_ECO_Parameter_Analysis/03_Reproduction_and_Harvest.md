# 番茄 ECO 参数解析 (三)：繁殖分配与多次采收逻辑

本报告解析了 `TMGRO048.ECO` 中控制番茄繁殖器官生长、鲜重计算及多次采收机制的关键参数。

## 1. 果实生长时序与分配

### LNGSH (Time for Individual Shell Growth)
- **定义**：单枚果实（果皮/荚）生长所需的光温时。
- **逻辑**：在 `PODS.for` 中，`LNGSH` 决定了果实外壳发育的时间窗口。
- **公式影响**：
  `SHVAR = WTPSD * SDPDVR * ((100.-THRESH)/THRESH) / ((LNGSH-.85*LNGPEG)*((1.-PROSHI)/(1.-PROSHF)))`
- **番茄特性**：番茄的果实发育周期较长且连续，`LNGSH` 的设定需与实际品种的果实膨大期匹配。

---

## 2. 鲜重与干物质浓度 (DMC)

番茄模型中一个显著的特点是集成了鲜重计算模块 (`FreshWt.for`)。

### 干物质浓度 (DMC) 公式
在 `FreshWt.for` 中，番茄果实的累计干物质百分比（DMC）是随生理龄（PAGE）动态变化的：

```fortran
! Tomato (TM) DMC calculation
DMC(NPP) = (5. + 7.2 * EXP(-7.5 * PAGE / 40.)) / 100.
```

- **5.0%**：番茄果实成熟时的典型基准干物质含量（约 95% 为水）。
- **7.2%**：描述了幼果期到成熟期 DMC 下降的幅度（幼果 DMC 较高，随着水分充盈而稀释）。

---

## 3. 多次采收触发：XMAGE

### XMAGE (Photothermal Time for Multi-harvest)
- **定义**：单个果实达到可采收状态所需的最小光温龄（PAGE）。
- **关键机制**：
  1. 模型每日检查所有果实队列的生理龄。
  2. 若 `PAGE >= XMAGE`，该队列的果实被标记为“成熟中的果实”。
  3. 成熟果实会被计入 `MTFPW` (成熟鲜重) 和 `MTDPW` (成熟干重)。
  4. 一旦发生采收事件 (`HARVF = 1`)，所有满足 `PAGE >= XMAGE` 条件的果实干重和鲜重将从植物体移出，转入产量计数。

---

## 4. 极端温度对发育的影响：OPTBI 与 SLOBI

虽然这两个参数在物候文档中有所提及，但它们对繁殖期的成功至关重要。

- **逻辑偏移**：如果外界最低气温低于 `OPTBI`，向开花和座果的发育进度会按 `SLOBI` 比例减缓。
- **意义**：这模拟了番茄在早春或晚秋由于低温导致的“落花落果”或座果延迟现象，尽管模型本身不直接计算花粉活力，但通过减缓发育阶段转换达到了类似效果。

---

## 5. 繁殖分配的动态修正 (Potential Parameters)

### XFPHT 与 XFINT
> [!NOTE]
> 虽然在 `TMGRO048.ECO` 的标准表头中未显式列出，但 `DEMAND.for` 源代码中保留了读取这两个参数的逻辑。

- **XFINT**：初期分配给果实的比例。
- **XFPHT**：达到最大分配比例所需的时间。
- **设计初衷**：用于更精细地控制无限生长型作物在第一穗果坐住时的资源截留压力，防止因第一批果实过强拉动产物而导致植株早衰。

---

> [!TIP]
> **校准建议**：
> 如果模拟的鲜重产量持续偏高，优先检查 `FreshWt.for` 中的 DMC 参数而非 ECO 中的干重参数；如果采收批次分布不均，应调整 `XMAGE`。
