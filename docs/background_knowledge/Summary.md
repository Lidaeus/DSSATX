# 参数对比汇总

本目录 `Eggplant_Parameter_Calibration_Docs` 包含了茄子（Eggplant）基于番茄（Tomato）模板修改后的遗传参数文件与原始番茄参数文件的详细对比。

## 1. 关键改动概览

- **CUL 文件**：
  - 权重种子最大重量（WTPSD）字段名称更改。
  - 校准标记从 `N`/`G` 调整，部分参数从 `N`（未校准）改为 `G`（已校准）。
  - `MINIMA` 与 `MAXIMA` 行的数值整体缩小，表明对生长阶段的阈值做了显著下调。
  - 新增 `TM0008 Brilliance` 株系记录。

- **ECO 文件**：
  - 增加了 `XFPHT`、`XFINT` 两列，扩展了生态型描述。
  - 校准标记整体从 `N` 变为 `P`（已校准），并对 `TM0001` 的生态型参数做了大幅调整（如 PL-EM、EM-V1 等）。

- **SPE 文件**：
  - `PARMAX`、`PHTMAX` 的光合参数第四列从 `0.10` 调整为 `0.03`，光合上限更保守。
  - `WTFSD` 系列系数第二列从 `0.21` 改为 `0.61`，提升根系对水分的利用效率。
  - `VSSINK`（源限制因子）从 `4.1` 降至 `1.1`，将导致早期 LAI 增长更快，符合对茄子早熟的需求。
  - 表型阶段（VEGETATIVE/REPRODUCTIVE）的温度阈值整体上升，说明茄子在更高温度下仍保持相同的发育进度。

## 2. 对敏感性分析的建议

1. **VSSINK**：该参数变化幅度最大（4.1 → 1.1），建议在敏感性分析中重点考察其对早期 LAI、光合产量以及最终产量的影响。
2. **WTPSD** 与 **WTPSD**：种子重量的微调可能影响种子数目和质量，建议在种子产量模型中进行局部灵敏度测试。
3. **PARMAX / PHTMAX**：光合上限的降低可能限制光合效率，建议评估不同光照条件下的产量响应。
4. **WTFSD 系列**：根系水分利用效率提升，可能改变土壤水分限制情形下的生长，建议在干旱情景下进行敏感性分析。
5. **生态型参数（PL-EM、EM-V1、V1-JU 等）**：这些参数在 ECO 文件中有显著变化，建议在不同播种期和温度情景下评估其对发育进度的影响。

4. 将实验结果归档到 `Eggplant_Parameter_Calibration_Docs`，并在后续报告中给出参数优化建议。
