## 可直接改写进论文的正文

### 2.X.1 作物模型与敏感性分析目的

本研究采用 Decision Support System for Agrotechnology Transfer（DSSAT）4.8.5 中的 CROPGRO 作物模型进行茄子生长模拟。由于该版本 DSSAT 未提供独立的茄子模型，本研究以 CROPGRO-Tomato 模型代码 `CRGRO048` 及番茄品种、生态型和物种参数文件 `TMGRO048.CUL`、`TMGRO048.ECO` 和 `TMGRO048.SPE` 为基础，依据茄子试验资料、DSSAT 官方茄科作物参数、已发表文献和模型结构约束建立茄子候选遗传参数域。该处理表示在 CROPGRO-Tomato 框架内对茄子进行参数化，并不表示番茄与茄子的遗传参数可以直接等同。DSSAT-Cropping System Model 的总体结构见 Jones 等和 Hoogenboom 等的说明\[1–3]。

敏感性分析的目的，是识别在预先限定的参数范围、三季气象条件和水氮管理组合下，对物候、冠层、生物量、采收以及水氮响应具有稳定影响的遗传参数，为后续参数率定缩减维度。敏感性结果只表示“参数不确定性对所选模型输出的传播”，不直接证明参数可辨识性、因果关系或参数率定的必要性。

### 2.X.2 试验季节与模型输入

敏感性分析使用位于【试验地点，经纬度】的三季设施茄子试验，包括两个春季和一个秋季。三季使用相同的遗传参数域和随机设计，分别运行和质控，之后再进行跨季汇总。各季输入与纳入处理如下。

| 试验编号     | 季节       |                                纳入处理 | 水氮设计说明                     |
| -------- | -------- | ----------------------------------: | -------------------------- |
| XXQL2501 | 2025 年春季 | TN2、TN3、TN4、TN5、TN10、TN11、TN12、TN13 | 2 个水分水平 × 4 个氮水平，共 8 个唯一组合 |
| XXQL2502 | 2025 年秋季 |   TN1、TN3、TN4、TN6、TN7、TN9、TN10、TN12 | 2 个水分水平 × 4 个氮水平，共 8 个唯一组合 |
| XXQL2601 | 2026 年春季 |   TN1、TN3、TN4、TN6、TN7、TN9、TN10、TN12 | 2 个水分水平 × 4 个氮水平，共 8 个唯一组合 |

经原始试验记录复核，XXQL2601 的 TN12 为低水分、零氮处理（`MI1/MF4`）；早期 FileX 中误录为 `MI3/MF4`。本研究依据用户于 2026 年 7 月 21 日确认的信息更正该字段，并建立带独立 bundle ID 和文件哈希的修正输入包。修正后 TN9 为 W3/N0、TN12 为 W1/N0，XXQL2601 构成完整的 2 水分 × 4 氮水平析因设计。除 TN12 的 MI 字段外，其余处理因子不因该项更正而改变。

气象、土壤、种植、灌溉和施肥信息均来自相应季节的 FileX、气象文件和土壤文件。用于敏感性分析的 FileX 不需要 FileA 或 FileT，因为本阶段分析模型输出对遗传参数扰动的响应，而不计算观测—模拟残差。FileA 和 FileT 仅在后续参数率定、模型评价与独立验证中使用。

### 2.X.3 初始条件和环境参数的控制

为避免不同处理的初始土壤含水量和矿质氮差异与遗传参数效应混杂，本研究为每一季建立独立的受控敏感性分析输入包。对该季所有保留处理，在每一土层分别计算实测初始土壤含水量（SH2O）、铵态氮（SNH4）和硝态氮（SNO3）的中位数，并将所得共同剖面赋给该季全部处理。三季之间不共用初始剖面，用户原始 FileX 保持只读。该受控输入仅用于遗传参数敏感性分析，不用于参数率定或观测验证。

FileX 和 SOIL.SOL 中的实测土壤属性在主遗传参数分析中固定，不作为遗传参数共同采样。这一做法将主分析限定为遗传参数筛选，并避免测量误差较小的环境参数扩大参数空间。必要时，可在主遗传参数筛选完成后另设窄范围环境参数扰动试验，用于评价结论对土壤测量误差的稳健性；该试验不得与主遗传参数排名混合。

茄子属于非豆科作物，正式输入将 FileX 的 `SYMBI` 设为 `N`，同时将 CRGRO048 不支持的钾模型选项 `POTAS` 设为 `N`。物种参数 `FRCNOD` 固定并排除在敏感性分析与率定之外；本文不把某个 FRCNOD 数值解释为生物固氮的关闭开关。固定宽度 OPTIONS 行在写入后按列位置重新解析，以确认 `SYMBI=N、POTAS=N` 均被 DSSAT 正确读取。

### 2.X.5 模型响应变量

敏感性分析不以单一产量指标代表全部模型过程，而是预先声明物候、冠层、生物量、采收及水氮响应五类输出。响应值直接从每次 DSSAT 模拟的 Summary.OUT、PlantGro.OUT 和 FreshWt.OUT 等输出中提取；任何 `-99`、非有限值或缺失值均按失败处理，不作统计插补。

| 响应类别 | 指标                                                                          |
| ---- | --------------------------------------------------------------------------- |
| 物候   | ADAPS、PDFPS                                                                 |
| 冠层   | LAIXS、LAI\_AUC、LAI\_PEAK、LAI\_END，以及移栽后 45、67、95 和 119 d 的 LAI              |
| 生物量  | CWAMS、末期叶重（LEAF\_END\_LWAD）、末期茎重（STEM\_END\_SWAD）和末期地上部生物量（AGB\_END\_CWAD）  |
| 采收   | YIELD\_HWAMS、末期果实干物质量（FRUITD\_END）、累计采收达到最终值 50% 时的移栽后日数（CUMHARVEST\_DAP50） |
| 水氮响应 | 四个核心过程指标的同氮水平水分差、不同水分水平下的氮响应斜率及二者斜率差                                        |

LAI\_AUC 采用相邻 DSSAT 日尺度节点之间的梯形积分计算。CUMHARVEST\_DAP50 只在非递减且终值大于 0 的累计采收序列上，通过相邻原始节点之间的线性插值计算；论文绘图中使用的平滑曲线不参与该指标、敏感性指数或后续目标函数的计算。

对响应变量 (Y)，同一氮水平 (n) 下的水分效应定义为：

\[
D\_{W,n}=Y\_{W3,n}-Y\_{W1,n}.
]

在水分水平 (w) 下，以 FileX 中各施肥事件的 FAMN 总和作为季节施氮量 (N)（kg N ha(^{-1})），用普通最小二乘回归计算氮响应斜率：

\[
\beta\_{N,w}=\frac{\sum\_j (N\_j-\bar N)(Y\_{w,j}-\bar Y\_w)}
{\sum\_j (N\_j-\bar N)^2}.
]

水氮交互的描述性指标定义为：

\[
I\_{W\times N}=\beta\_{N,W3}-\beta\_{N,W1}.
]

这些派生量用于评价参数对水氮响应形态的影响，不等同于基于观测数据的方差分析交互效应，也不作因果解释。

### 2.X.6 Morris 全局筛选设计

采用 Morris elementary-effects 方法进行全局筛选\[4,5]，并使用 PEST++-SEN 5.2.16 调用 DSSAT 前向模型\[6]。对第 (i) 个参数，将原参数值 (x\_i) 线性映射到单位区间，并在 (p=4) 级网格上构建随机单因素轨迹；步长设为 PEST++ 对应设置的 (\Delta=2/3)。第 (j) 条轨迹中参数 (i) 对响应 (Y) 的 elementary effect 为：

\[
EE\_{i,j}=\frac{Y(\mathbf{x}\_j+\Delta\mathbf{e}\_i)-Y(\mathbf{x}\_j)}{\Delta},
]

其中 (\mathbf{e}\_i) 为第 (i) 个参数方向的单位向量。对每个参数—响应组合计算：

\[
\mu\_i^\*=\frac{1}{r}\sum\_{j=1}^{r}|EE\_{i,j}|,
]

\[
\sigma\_i=\sqrt{\frac{1}{r-1}\sum\_{j=1}^{r}(EE\_{i,j}-\bar{EE}\_i)^2}.
]

(\mu^\*) 表示参数在给定范围内对该响应的总体影响强度，(\sigma) 较大通常提示非线性效应、与其他参数的交互作用，或二者同时存在；本研究不根据 (\sigma) 单独判定具体交互参数。

初始设计采用 3 个预先固定的随机种子，每个种子包含 10 条完整 Morris 轨迹。对于 (k=55) 个参数，一个种子在一个季节需要 (r(k+1)=560) 次批量前向模型调用；初始三种子、三季共 5,040 次批量调用，每次调用运行该季全部保留处理。为便于逐季比较，同一个随机种子在三季使用相同的归一化参数轨迹。正式论文应以运行清单记录的实际种子、最终轨迹数和前向调用数替换本段数字：随机种子为【待填】，最终每个种子的轨迹数为【待填】，有效批量模型调用数为【待填】。

若初始轨迹不能达到预声明的排名稳定性标准，则按预先登记的完整轨迹块增加样本，不在查看参数排名后修改参数范围、响应指标、稳定性阈值或随机种子。Morris 是本研究的主筛选方法；Sobol 分析不自动启动。

### 2.X.7 不同响应和季节之间的等权汇总

由于各响应的量纲和数值范围不同，不直接对原始 (\mu^*) 求平均。对季节 (s) 中的每一个响应 (o)，先将参数 (i) 的 (\mu^*) 归一化为：

\[
R\_{i,o,s}=\frac{\mu^_{i,o,s}}{\sum_{h=1}^{k}\mu^\_{h,o,s}}.
]

若某响应的所有参数 (\mu^\*) 总和为 0，则该响应被判为退化，所在正式案例不能进入排名。随后依次对同一特征族中的处理或时间点取算术平均、对同一过程组中的特征族取算术平均，并在排名域内对过程组等权平均。该层级结构避免某个过程仅因包含更多处理或更多时间点而获得更高权重。

一般遗传响应域由物候、冠层、生物量和采收 4 个过程组构成；水氮响应域由水分响应、氮响应和水氮交互 3 个过程组构成。两个排名域独立报告，不把水氮响应与一般遗传响应压缩成一个总排名。每季通过质量门后，使用等季节权重计算三季综合得分：

\[
R\_{i,\mathrm{multi}}=\frac{1}{S}\sum\_{s=1}^{S}R\_{i,s}, \qquad S=3.
]

因此，两季 8 个处理和一季 7 个处理不会因处理数量差异而被赋予不同的季节权重。论文应同时报告三季综合排名和逐季结果，以识别对季节条件敏感的参数。

### 2.X.8 运行质量控制与重复种子稳定性

正式分析前，对 55 个候选参数分别在下界、初始值和上界进行确定性单参数扰动检查，核对 DSSAT 固定宽度文件中的实际写入值、模拟返回码和全部响应。参数值不得被静默裁剪，输出不得来自旧文件，且基线和扰动运行均须产生完整、有限的当次输出。

每个 Morris 种子作为独立案例接受质量审查。可进入科研排名的案例必须满足：PEST++ 管理进程完整结束；计划运行全部具有终态；无运行时、未知或 DSSAT 模型失败；每一条轨迹完整；每个参数具有相同数量的有效 elementary effects；`.mio` 中全部预声明响应和参数组合均存在且为有限值；各响应均非退化。任一模型点失败将使其整条轨迹失效；本研究不插补 elementary effect，也不把不完整种子混入正式排名。

在每一季、每一个排名域内，计算不同随机种子参数排名的 Spearman 相关系数以及 Top-15 参数集合的 Jaccard 相似系数：

\[
J(A,B)=\frac{|A\cap B|}{|A\cup B|}.
]

只有所有种子对均满足 Spearman (\rho\ge 0.90) 且 Top-15 Jaccard (J\ge 0.80)，才认为该季该排名域达到稳定。若任一季或任一排名域未达标，则增加预声明的完整轨迹块并重新评价。最终论文应报告各季最小的两两 Spearman、Top-15 Jaccard、有效轨迹数和排除案例及原因，而不能只报告一个综合排名。

### 2.X.9 从敏感性结果到率定参数的筛选

后续率定参数不由综合排名自动产生。首先分别形成各排名域、各季和各随机种子的稳定 Top-K 核心及边界候选并集；随后根据参数对应过程是否具有观测资料、参数是否可能辨识、参数间结构关系、边界合理性及文献依据进行人工审核。只有通过该审核的参数才进入率定边界冻结流程。低敏感参数在当前范围和响应定义下可优先固定，但不能据此宣称其在所有环境或所有模型输出中不重要。

如在人工审核后对缩减参数集开展 Sobol 分析，应另行报告参数数目、基础样本量、总模型调用数、采样矩阵、随机种子、一级指数 (S\_1)、总效应指数 (S\_T)、bootstrap 置信区间及至少两个样本尺度的收敛比较\[7]。单一样本尺度只能称为该尺度下的估计，不得称为已经收敛。若本研究最终未开展 Sobol 分析，应从论文中删除本段，不以 Morris 的 (\sigma) 替代 Sobol 交互贡献。

### 2.X.10 软件与可重复性

模型运行使用 DSSAT 4.8.5.0 和 PEST++-SEN 5.2.16；案例构建、输入校验、输出提取、质量审查和跨种子汇总使用 Python 【待填实际版本】。正式运行采用相互隔离的工作目录，每个 worker 仅读取其版本化输入包，不修改 DSSAT 共享安装目录。每个案例保存参数边界 ID、输入包和输出契约的 SHA-256、DSSAT 可执行文件哈希、随机种子、Git 提交号、完整命令行、运行状态、失败审计和 PEST++ 原始结果。

论文敏感性图由 R 【待填实际版本】根据通过科研质量门的冻结数据包绘制；Python 图仅用于运行诊断。图表不得读取临时 DSSAT/PEST++ 文件或未通过质量门的案例。未验证数据只能生成带 `DEMO` 标识的布局预览，不能用于论文结论。

- 不写“(\sigma) 证明参数存在交互”；应写“较大的 (\sigma) 提示非线性和/或交互作用”。
- 不写“3 个季节是 3 个独立重复”；它们代表不同季节环境，用于评价跨季稳健性。
- 不写“XXQL2601 为完整 2×4 析因设计”，除非 TN12 经原始记录确认并创建可追溯修正版。
