## 1. 一句话概括

对 2026 春季 12 个水氮处理（26SP，全部参与率定）构建 **511 项目标**、
**11 个活跃目标族 + 4 个仅诊断族**、**总 Phi 预算 97** 的加权目标函数；
每项目标为"标准化残差经伪 Huber 压缩后乘族权重"，即 PEST++ 最小化的
Phi = Σ (w_i · e_i)²，其中 e_i = ρ((sim−obs)/σ_eff)，w_i² 之和按族精确等于族预算。

## 4. σ 与权重的精确公式

对每项目标 i（实现于 `objectives()`，编码于 `src/calibration/sa98_joint40.py::encode`）：

```
σ_eff,i = sqrt( raw_sd_i²/n_eff + floor_family² + (cv_family·|obs_i|)² )     # n_eff=1（不按重复缩放）
w_i     = sqrt( budget_family / n_family )                                   # 族内均匀
r_i     = (sim_i − obs_i) / σ_eff,i                                          # 标准化残差
e_i     = r_i                                  （二次族）
        = r_i·sqrt(2/(hypot(1, r_i/δ)+1))     （伪Huber族，δ=1.5）
Phi     = Σ_i (w_i·e_i)²
```

PEST++ 侧契约（`make_case`）：`obsval=0`、`weight=w_i`、指令文件读回的正是 e_i，
因此 PEST 的 Phi 与上式严格一致；模型命令为
`python -X utf8 tools\calibration\run_water_stress_expansion_40x3_20261107.py --forward <运行目录>`。

伪 Huber 的大残差渐近为线性（|r|≫δ 时 e≈δ·sign(r)·√2·...），用于抑制个别
极端收获事件对整族预算的支配；季末产量与水氮对比保持纯二次，保证响应幅度
不被压缩。

## 5. 水氮响应目标的定义（本批核心）

- 观测值：`obs = fresh(W2,Nk) − fresh(W1,Nk)`（4 项，k=0..3）与
  `obs = fresh(Wj,N2) − fresh(Wj,N0)`（3 项，j=W1..W3），fresh 取各处理末次 CHFPW；
  σ 由两处理 raw_sd 的 hypot 合成，再加 floor 1500 kg/ha 与 cv 0.20。
- 模拟值：`src/calibration/sa98_joint40.py::extract` 从 `FreshWt.OUT` 同日期对
  直接作差（配对处理、同收获日，缺失即该成员本轮失败）。
- 方向约束：观测水/氮差为正，若模拟差为负或近零，二次残差直接大额计入 Phi——
  即"符号错误的响应是有效模拟、产生残差"，而不是运行失败。
- 水对比预算 10 为全表第三大族（仅次于两产量族），是"水响应优先"评审的体现。

- 58 个自由参数 + 固定参数见

  蛋白质下限序 PROxF ≤ PROxG ≤ PROxI（叶/茎/根）、壳 PROSHF≤PROSHI、
  温度曲线 TB1<TO11<TO21<TM1 与 TB2<TO12<TO22<TM2、氮曲线 FNPGN1<2<3、
  XMAGE<XFPHT、FRSTMF+FRLFF≤1；另有 LNREF>FNPGN(1)、YLEAF(4)+YSTEM(4)≤1、
  PROSHG≤PROSHI（本批 PROSHG 固定 0.145、PROSHF 固定 0.1095）。

## 7. 前向运行流水线（目标函数的执行路径）

`trial.forward`（同文件 445 行起）→ `evaluate → simulate + encode(extract(...))`：

1. 哈希门：design 密封校验 + 81 个源文件逐一 SHA-256；
2. `<运行目录>\26SP_inputs` 载荷复制到临时工作目录（TMX/TMT/TMA/WTH/SOIL/
   CUL/ECO/SPE/DSSBatch/DSSATPRO/INP/INH）；
3. 基因型参数按 `field_map` 偏移量切片注入 CUL/ECO/SPE，并做**逐参数读回校验**；
4. `C:\DSSAT48\DSCSM048.EXE CRGRO048 B DSSBatch.v48`（150 秒超时，ERROR.OUT 非空即失败，
   PlantGro 出现负 LAID 即失败）；
5. `extract`：ADAP←Evaluate.OUT 的 ADAPS；对比族←FreshWt.OUT；其余←
   PlantGro/PlantN/FreshWt/SoilWat.OUT（`single_season_n.extract_observations`），
   含 VWC 实测深度×输出层重叠几何校验（`check_water_geometry`）；
6. `encode` 计算 e_i 写 `FormalObjectives.OUT`（12 位有效数字）；
   失败写入 `forward_failures.jsonl`（不吞错）。

## 8. 验收与后处理口径（`trial.finalize`，468 行起）

- 每轮保留率 = 有效成员数/40，≥98% 才允许该轮参与选优（`round_quality.csv`）；
- 候选 = 通过门槛的轮次中 Phi 最小的成员；对其实施确定性单跑，Phi 必须与
  集合值一致（rtol 1e-6）方可采纳（`selection.json`，`validation_used=False`）；
- 25SP 验证季（`locked_validation_observations.csv`）只在选优后评估
  （`validation_comparison.csv`）；果氮浓度作为诊断
  （`calibration_fruit_n_diagnostic.csv`）；
- 参数边界占用统计 `parameter_boundary_round3_4.csv`；水/氮梯度诊断由
  `run_final_spring_gradient_trial_20261106.py::save_gradient_diagnostics` 生成
  （`gradient_comparison.csv` / `gradient_metrics.csv`）。
