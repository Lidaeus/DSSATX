# 敏感性分析与率定用户指南

> 状态：当前用户指南
> 更新：2026-07-22

## 1. 先理解三个状态

| 状态 | 含义 | 可否用于论文结论 |
|---|---|---|
| `engineering_validated` | 程序完成、产物完整、参数/模拟/Phi 有变化 | 否 |
| `science_pending` | 尚未完成或尚未批准科学审核 | 否 |
| `science_validated` | finalize 明确授权，且正式输入、设计、验证证据齐全 | 是 |

退出码 0 和质量报告 pass 都不等于科研有效。率定只有 `calibration_finalize/calibration_finalize.json` 可以授权正式下游。

## 2. 准备实验文件与两季土壤氮环境

FileX、FileA、FileT、SOIL、天气和 batch 必须组成一个版本化输入包。文件位置和导入命令见 [目录与输入资产规范](目录与输入资产规范.md)。输入包一旦生成 `input_manifest.json` 就不再覆盖；修订数据应创建新 bundle。

### 2.1 两季初始土壤矿质氮基准与试验背景

本项目春季两茬试验具有显著不同的田间土壤历史背景：
- **2025 春季 (25SP)**：属于连续多年高肥栽培设施大棚，具有极高的历史残留矿质氮背景，基准采用 Scheme 4 的 `double_n` 矿质氮环境；
- **2026 春季 (26SP)**：属于新置换土/低初始氮基质环境，**正式基准统一更正为 0.34 倍率测定值（基于 `26SP硝态氮铵态氮校准值.xlsx`）**，彻底废弃早期探索阶段的“26SP 翻倍氮”旧表述。

**25SP `double_n` 批次相对于实测参考（`25SP硝态氮铵态氮参考.xlsx`）的全层倍率核算**：
- **0–20 cm 土层**：`double_n` 批次硝态氮与铵态氮含量设定为实测参考值的 **0.70 倍 (0.700x)**（硝态氮均值 $20.44\text{ mg/kg}$ vs 实测参考 $29.23\text{ mg/kg}$；铵态氮均值 $1.08\text{ mg/kg}$ vs 实测参考 $1.54\text{ mg/kg}$）；
- **20–40 cm 土层**：`double_n` 批次硝态氮与铵态氮含量设定为实测参考值的 **0.80 倍 (0.800x)**（硝态氮均值 $10.31\text{ mg/kg}$ vs 实测参考 $12.93\text{ mg/kg}$；铵态氮均值 $0.64\text{ mg/kg}$ vs 实测参考 $0.80\text{ mg/kg}$）；
- **40–60 cm 土层**：`double_n` 批次硝态氮与铵态氮含量设定为实测参考值的 **2.00 倍 (2.000x，翻倍层)**（硝态氮均值 $12.11\text{ mg/kg}$ vs 实测参考 $6.05\text{ mg/kg}$；铵态氮均值 $1.67\text{ mg/kg}$ vs 实测参考 $0.84\text{ mg/kg}$）；
- **0–60 cm 剖面总和**：硝态氮剖面总和为 $42.87\text{ mg/kg}$（为实测参考总和 $48.21\text{ mg/kg}$ 的 **0.889 倍**），铵态氮剖面总和为 $3.39\text{ mg/kg}$（为实测参考总和 $3.17\text{ mg/kg}$ 的 **1.069 倍**）；深层 60–180 cm 保持背景值（$\text{SNO3}=2.0, \text{SNH4}=1.0\text{ mg/kg}$）。

FileA/FileT 建议继续保存处理均值。各重复的原始数据另存长表，用于计算 `replicate_sd`、`n_effective` 和 `sigma_eff`，不要把共享同一模拟值的重复当作独立 PEST 观测。

## 3. 管理参数范围与种苗参数定位

参数范围分四层：

1. `src/common/param_registry.py`：物理硬边界；
2. `data/parameter_registry/baseline/`：基线建议；
3. `bounds_proposals/`：待审核建议；
4. `bounds_frozen/<crop>/`：获批版本，也是率定唯一可读取的层。

### 3.1 定植苗龄（PAGE）与苗温（PENV）参数定位

定植苗龄（`PAGE`，24~60 d）与育苗环境温度（`PENV`，10~20 °C）属于**田间农艺管理与环境状态参数**：
- **参数性质**：**不定义为常规可率定遗传参数，仅参与敏感性分析与机理对照，不进入主遗传参数率定流程**；
- **建议取值范围（参考 v47 / v48 率定与敏感性分析结果）**：
  - **2025 春季 (25SP)**：`PAGE` 建议范围 **45 ~ 60 天**（基准参考值 ~50d），`PENV` 建议范围 **10 ~ 20 °C**（基准参考值 ~19°C）；
  - **2026 春季 (26SP)**：`PAGE` 建议范围 **30 ~ 45 天**（基准参考值 ~34~41d），`PENV` 建议范围 **10 ~ 20 °C**（基准参考值 ~19~20°C）；
- **机理对照说明（适龄商品苗）**：
  - 若模拟现代化设施 25–28 天商品穴盘苗标准（`PAGE = 28d / 25d`, `PENV = 25°C`），移栽当天不带大量老龄叶，株高呈自然平滑 S 型曲线伸长；
  - 历史老龄苗配置（`PAGE = 60d`, `PENV = 25°C`, `PLPH=1`）定植当天带 18.3 片叶，导致定植首日株高直接跳升至 0.88m 并过早封顶，需注意区分。

### 3.2 多季遗传参数与物种氮素机制

主遗传率定固定实测土壤与初始条件，集成 **Dias et al. (2026)** 物种器官蛋白质分配与吸收转运机制：
- 物种蛋白质参数：`PROLFF/PROLFG/PROLFI`（叶）、`PROSTF/PROSTG/PROSTI`（茎）、`PRORTF/PRORTG/PRORTI`（根）、`PROSHF/PROSHG/PROSHI`（果）；
- 根系吸氮通量：`RTNO3`、`RTNH4`、吸氮敏感因子 `NSTFAC`；
- 氮素再分配与衰老：`NMOBMX`、`NVSMOB`、`SENRTE`、`NSLOPE`；
- 光合与源库参数：`FNPGN1/FNPGN2`、`LNREF`、果实分配上限 `XFRT`（0.85~0.95）、初花热时间 `EM-FL`（21~26°C·d）、比叶面积 `SLAVR`（180~210 cm²/g）。

当前候选温度范围为 `TB*=8–12`、`TO1*=20–27.5`、`TO2*=28–33`、`TM*=34–45 °C`；`FL-VS` 只以 100–140 作为结构敏感性探针，缺少末叶/终止生长观测时不进入率定；`XMAGE=8–30` 与 `XFPHT=31–70` 在参数域层面保证顺序。完整历史依据见 [正式多季参数域设计报告](archive/sa_run_history/正式多季遗传参数敏感性分析参数域设计_20260719.md)。

## 4. 敏感性分析

Morris 回答“哪些参数在当前输入、范围和响应定义下稳定影响模型输出”。它不是参数可辨识性或因果结论。

每个 seed 使用独立目录；正式运行必须保留参数范围、输入包、输出 profile 和 Git 哈希。运行后至少检查：

- 模型完成率和有效轨迹数；
- 是否出现全零或结构性零方差响应；
- 每个预声明排名域的跨 seed Spearman 和 Top-K Jaccard；
- 单个处理或输出是否异常支配排名。

只有稳定 Morris 结果可以进入 Top-K 人工审核。Sobol 应在获批 Top-K 上运行，并用至少两个通过质量门的正式尺度判断收敛；单个样本尺度只能称为单尺度估计。

标准命令见根 [README](../README.md)。具体参数以各 CLI `--help` 为准。

## 5. 分阶段 IES 率定

推荐阶段：

- S1：物候与冠层时序；
- S2：氮响应与营养生长；
- S3：结实与增量采收；
- S4：仅重新释放前阶段中确有更新、边界行为可解释的少量参数。

每阶段必须：

- 只读取获批 frozen bounds、输入 bundle、design 和 observation policy；
- 在新 `workspace/runs/<run_id>/` 中构建；
- S2–S4 用 `--fixed-from` 绑定紧邻上游代表参数；
- 保留 `run_manifest.yaml`、质量报告、成员状态、参数 ensemble、Phi 和确定性复跑；
- 先完成工程检查，再由 finalize 决定科研状态。

不建议同时释放大量遗传参数。土壤和初始条件默认固定，除非有独立观测和单独批准。

对实测土壤和初始水分，不要把文献中的宽泛 ±20%–30% 直接当成本场试验先验。优先使用重复测量 SD/SE 或检测方法误差；没有误差记录时，较窄百分比只能用于单独稳健性预检，不能与遗传参数同时率定并据此解释遗传系数。

## 6. 观测误差与权重

目标函数采用：

```text
Phi = Σ (w_i × residual_i)²
w_i = 1 / sigma_eff_i
```

`sigma_eff` 应记录重复测量、模型尺度误差和下限的来源。组倍率默认 1.0；任何调整都必须预声明并有倍率 1.0 对照。当前 pwtadj1 关闭。

默认使用原始物理尺度。log 变换只有在 observation policy 完整声明并保证观测与模拟使用相同定义时才允许。T10 的例外是累计连续采收 `CHFPW/CHPDT`：在 PEST 专用表中使用 `ln((y+1 kg ha-1)/(1 kg ha-1))` 及相应 `sigma_log`，而 FileT、FreshWt.OUT、常规指标、论文图仍保留 kg ha-1。动态 Min–Max 禁止进入目标函数。

对 T10 的最后真实采收事件，模型本地 FileX 副本须在最后真实模型采收之后添加一次虚拟采收并延长模拟结束日；真实采收日对应的模型管理事件提前 1 天。输出仅允许在真实观测日 ±1 天内有界就近读取，选择日期、虚拟事件和源文件哈希均应进入 registry/manifest；虚拟事件本身不进入 Phi。

完整定义见 [观测误差与权重规范](权重设计方案改进提案.md)。

## 7. 验证与条件参数集合

validation 按完整处理留出，不能把同一处理的日期行随机拆到 calibration 和 validation。diagnostic 不进入 Phi。

正式 finalize 通过后才运行：

- 处理级 RMSE、MAE、bias 等验证指标；
- prior 与 IES conditional ensemble 的收缩和边界诊断；
- Spearman 参数相关；
- 最多 2–3 对“Phi 相近、参数距离较远”的候选解；
- 候选解在 validation/diagnostic 上的确定性预测距离。

只有参数距离和预测距离都满足预声明条件时，才能讨论功能异参同效。

## 8. 图表与成果包

Python 的 `diagnostic_*` 只用于运行诊断。论文图由 R 渲染，必须读取 hash-gated `paper_data_manifest.json`。

正式图需要 `science_validated`、`scenario_type=actual_trial_calibration`，并携带输入、bounds、observation policy 和 validation split 哈希。未验证数据只能通过 `--allow-unvalidated-demo` 生成带水印的布局预览。

图表规范见 [科研图表设计与开发计划](科研图表设计与开发计划.md)。

## 9. 常见错误

- 把退出码 0 当作科研通过；
- 在 `workspace/` 根目录手工放输入并依赖默认查找；
- 覆盖旧输入包或 frozen bounds；
- 将 `1/sigma²` 写入 PEST weight；
- 把累计采收的每个日期当作独立观测重复计权，或把虚拟末次采收事件当成真实观测；
- 根据 validation 结果反复挑参数；
- 把 IES ensemble 称为严格贝叶斯后验；
- 用 DEMO 图或历史失败运行支持论文结论。
