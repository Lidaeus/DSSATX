# 参数聚类分析设计文档

## 1. 目标
对前 100 个后验参数集（Ensemble 12）进行聚类，以分析率定参数的“异方同效性”（equifinality）。这有助于识别出能够产生相似优良模型性能的不同参数组合。
我们将从每个聚类中选择一个具有代表性的参数集，用于进一步的详细分析或情景测试。

## 2. 输入数据
- **源文件**: `c:\DSSAT48\Tomato_Cal\Workspace\Calibration_Results\tomato_cal.12.par.csv`
- **内容**: 100 个率定后的参数实现（后验分布）。
- **结构**: CSV 格式，参数名称为列，实现 ID 为行。

## 3. 方法论

### 3.1. 预处理
1.  **加载**: 使用 Pandas 读取 CSV 文件。
2.  **过滤**: 移除非参数列（例如 `real_name` 索引）。
3.  **标准化**: 由于参数具有不同的单位（例如天数 vs. 系数），我们必须使用 Z-score 标准化 (`StandardScaler`) 对其进行归一化，以确保 K-Means 中的距离计算不会受到量级偏差的影响。

### 3.2. 聚类算法
- **算法**: K-Means 聚类。
- **聚类数量 (k)**: 我们将默认使用 **k=4**。这在选择“代表性”情景时，在粒度和可解释性之间提供了合理的平衡。
    - *可选*: 在完整的科学研究中，我们可能会使用肘部法则（Elbow Method），但对于此自动化任务，4 是一个实用的选择。

### 3.3. 代表性样本选择
对于每个聚类，我们需要从集合中挑选 *一个* 真实的参数集来代表该聚类。
- **方法**: 在高维标准化空间中，找到聚类中距离聚类质心最近（欧几里得距离）的样本。
- **理由**: 质心本身是一个数学平均值，可能不对应于物理上有效或已测试的参数集。选择最近的真实样本可以确保参数组合的有效性。

### 3.4. 可视化
为了将 12 维参数空间可视化到 2D：
- **技术**: t-Distributed Stochastic Neighbor Embedding (t-SNE)。
- **过程**:
    1.  使用 t-SNE 将标准化数据投影到二维嵌入空间（Dim1, Dim2）。
    2.  创建散点图。
    3.  根据聚类 ID 对点进行着色。
    4.  用独特的标记（例如星号）标记“代表性样本”。

## 4. 输出规范
1.  **代表性参数文件**:
    - **格式**: CSV (`Representative_Parameters.csv`)
    - **内容**: 选定代表性样本的原始（未缩放）参数值，加上一列指示其聚类 ID。
2.  **可视化图表**:
    - **格式**: SVG (`Cluster_Visualization.svg`)
    - **内容**: 展示聚类和选定代表性样本的 t-SNE 散点图。

## 5. 实施步骤
1.  导入 `pandas`, `sklearn.preprocessing`, `sklearn.cluster`, `sklearn.manifold`, `matplotlib.pyplot`, `seaborn`。
2.  加载 `tomato_cal.12.par.csv`。
3.  数据缩放。
4.  拟合 K-Means (k=9)。
5.  识别代表性样本。
