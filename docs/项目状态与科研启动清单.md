## 正式重新分析前需要用户批准

### 敏感性分析

- 新的候选遗传参数清单及每个参数的物理/研究范围；
- SA 输入包与预声明 DSSAT 输出指标；
- Morris seed、轨迹数和稳定性门；
- 是否运行 Sobol，以及 Top-K、样本预算和收敛尺度。

### 参数率定

- 参与率定的参数清单与新的 frozen bounds ID；SA 排名只提供候选证据，不能自动决定率定参数；
- calibration/validation/diagnostic 完整处理划分；
- observation policy：sigma 来源、组倍率、采收变量、是否使用变换；
- S1–S4 active/fixed 参数、ensemble 规模、迭代数和随机种子；
- 正式 approval ID 与 `approval_scope=science_run`（或项目最终采用的等价状态）。

## 建议启动顺序

```text
新输入包与模板审计
  → 新 SA proposal/frozen bounds
  → baseline + 扰动预检
  → 多 seed Morris
  → 用户审核 Top-K
  → 必要时 Sobol 多尺度
  → 新率定 bounds/design/policy 冻结
  → S1 → S2 → S3 → S4
  → 独立 validation
  → 条件参数集合与候选解预测复跑
  → 正式 R 论文数据与图
```

每一步失败都停在本阶段处理原因；不自动增加参数、不把 validation 调回 calibration、不用 pwtadj1 或事后调权掩盖问题。

## 当前不需要继续开发的内容

MVP 不需要代理模型、自动聚类、t-SNE、PCA/VIF 平台、通用工作流框架、管理优化或更多占位论文图。下一轮工作的重点是用户审核后的正式输入与运行，而不是扩充算法。
