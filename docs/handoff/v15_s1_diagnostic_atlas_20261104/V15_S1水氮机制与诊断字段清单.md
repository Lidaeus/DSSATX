- **W2 的氮梯度在净吸收阶段已较窄。** N1—N3 累计净吸氮最大同日范围为 6.03 kg N/ha，W1 和 W3 分别为 17.93 和 10.87。W2 施氮组的冠层氮浓度、LAI 和产量差异也较小。N2 和 N3 在 W2 的最终鲜产相差约 0.02 t/ha。
- **碳限与终结算应分开查。** 1512 个处理日中，38 个处理日的同化碳缩放低于 0.99999，638 个处理日出现大于 0.000001 kg N/ha 的终结算退回。Dmax 在 584 个处理日小于或等于已裁剪的根潜力，其余 928 天的前置上限来自已裁剪潜力。这些是逐步约束的命中统计，涉及多个约束时仍需查看日账。
- **低氮的冠层总光合与叶级能力有不同响应。** N1—N3 的光合氮因子在同一日最多相差约 0.0065。LAI、光合氮因子、PHAD 和扩展水胁迫分别绘制，便于辨认面积变化与叶级响应。
- **根深与回显上限有实质差异。** 原生根深最大为 1.00 m。40 cm 以下贡献各处理全季净吸氮的 11.7%–34.4%。深度取 `OVERVIEW.OUT` 的运行时 13 层，土壤输入表使用不同分层。

这些幅度来自同一参数组的处理比较。各参数的贡献仍需要控制输入后的逐项扰动来区分。

## 各过程需要回显的参数

| 过程 | 优先回显的参数与本组值 | 诊断用途 |
|---|---|---|
| 水分供给、吸水与根长 | `RWUMX=0.014`、`KEP=0.869`、`ATOP=0.609`、`RTDEPI=10 cm`、`RLDSM=0.1`、`RTEXF=0.1`。按运行层保存厚度、LL／DUL／SAT、SRGF、土壤体积质量及初始水、NO3、NH4 | 水分通过逐层吸水、孔隙水浓度、根长及水分因子同时改变根供氮。ATOP 通过水氮状态改变根分配，宜与根长和根深配对看 |
| 质量流和双亲和吸收 | `RTNO3=0.0027`、`RTNH4=0.0069`，共用 `V_MAX_H=0.003, K_M_H=0.28, V_MAX_L=0.015, K_M_L=35`。K 用 mg N/L。质量流 `sigma_NO3=0.70, sigma_NH4=0.30`。`F_DIFF` 的 LL 到 DUL 区间指数 1.8，温度因子固定 1 | 按氮形态记录有效 Vmax，包括 RT 缩放。质量流与膜动力学候选在本版相加，随后只把最终净量入账。两条候选贡献必须分列，才能检查同一供应的潜在重复计入 |
| 系统氮反馈及吸收上限 | `NB_ALPHA_H=4.582, NB_ALPHA_L=2.393, DELTA=0.100`，富氮屏障指数 6。Dmax 同时依赖新生长需氮、上下界余量、修复和库容 | 低于临界的带宽 ψ 对 HATS／LATS 的反馈保持 1。富氮时才下调，屏障同时乘质量流和主动候选。归档反馈因子可用当日决策态 ψ 重算 |
| 器官临界浓度、最低新组织浓度 | `CNC_A=4.4462%, CNC_B=0.2012, CNC_W0=1.1246 t DM/ha, CNC_NC_INF=2.1782%, NB_STEM_BMULT=0.548`。叶 `PROLFI/FG/FF=0.261/0.240/0.154`，茎 `PROSTI/G/F=0.159/0.103/0.064` | 茎参照乘 PROSTI／PROLFI，并用不同的稀释指数。站存下界比例取 FF／FI 或 F／I，新生组织最低浓度用 FG／FI 或 G／I，两类下限需分列。上界为临界加固定干重基准的可容储备浓度 |
| 有机储备与再转运 | `KMOB=0.034 d⁻¹, KFILL=0.322 d⁻¹, PROTECT=0.020, TARGET=0.080, STEM_TARGET=0.089, CAPACITY=0.101`。保留 `NMOBMX=0.084, NVSMOB=0.282, CMOBMX=0.0108` | 快速储备和慢速结合氮分别计量。速率常数经 `1 − exp(−k)` 转为每日比例。储备容量按现存器官干重，储备是叶茎总氮的子库 |
| 同化与碳成本 | `RNO3C=2.556, RNH4C=2.478, RPRO=0.280`，氮转蛋白当量分数 0.16，额外转运碳成本回显为 0 | CROPGRO 用 `(U_NO3×RNO3C+U_NH4×RNH4C)/0.16` 估算碳需求，并按 PGAVL 缩放。终结算退回未接受的氮和对应碳。此版用同日蛋白当量结算，液泡无机氮库及独立同化动力学均属后续版本的状态量 |
| 生长、光合、果实与衰老 | `NB_BETA_GROW=1.793`、即时生长氮因子下限 0.5、两日权重 0.5/0.5、叶层光合亏缺指数 2.5。联查 `LFMAX, SLWREF, NSLOPE, PGEFF, KCAN, SLAVR, XFRT, ICMP, TCMP` 及果壳／籽氮组成 | 生长用带宽 ψ，光合用扣除显式储备后的非糖叶干重浓度代理并对比动态参照，坐果另用功能氮响应。保留实际使用的分支、叶层和过程因子，避免把单一 NSTRES 解释成所有过程的限制 |

**回显与生效要分开。** 冻结 S1 的根动力学由 `NBUF_ACT` 选择。虽然原生回显有 `UPTAKE_MODE=1`、`NB_SOIL_ALPHA=0.028`、`NB_ROOT_DEPTH=40 cm`，在这条根调用链中，经验土壤响应、模式枚举切换和 40 cm 上限均缺少实际接线。新增诊断应记录实际分支及该参数的使用位置。类似地，`NSTFAC=0.917` 是旧供需分支阈值，S1 VEGGR 使用 ψ 分支。 `LNREF` 有原生输入，S1 叶层 AGEMXL 的直接临界参照来自动态 CNC。
