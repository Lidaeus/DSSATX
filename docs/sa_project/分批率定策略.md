# 分批率定策略（旧结果停用说明）

> 文档状态：历史策略已停用
> 更新日期：2026-07-15

旧版文件依据历史 Morris/Sobol 排名直接给出了参数清单和率定顺序。现有审计表明，对应 Morris 结果存在全零退化，IES 结果也存在目标函数近似恒定和参数不更新，因此其中的排名、参数重要性和具体阶段清单均不得继续使用。

当前只保留“先物候、再冠层/生长、后结实/产量，最后小规模联合更新”的过程分阶段原则。正式策略见 [产品定义与系统设计](../../项目重构规划.md#8-参数率定设计)。

新的分批率定清单必须在以下条件满足后产生：

1. P0 科研可信性修复通过；
2. 新 Morris 和 Top-K Sobol 运行通过质量门；
3. 参数具有直接或明确的间接观测支撑；
4. 参数边界及跨参数关系经领域审核；
5. 用户批准各阶段参数和观测组。

在此之前，不应依据旧文件中的 `TRIFL`、`XFRT`、温度参数或其他排名启动率定。
