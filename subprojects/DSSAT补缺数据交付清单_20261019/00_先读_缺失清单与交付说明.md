## 4. 标准数据表如何填

### 4.1 通用规则

- 键：`season + run_id + date`；器官表再加`state_timing + organ`，水分剖面表再加`state_timing + layer_top_cm + layer_bottom_cm`。不得只靠小区号跨季连接。
- `date`为公历`YYYY-MM-DD`；DAT由定植日重新计算，定植DAT0。不要直接假定DSSAT的DAP、DAS等于本研究DAT。
- 水平：2026 W1/W2/W3×N0—N3，2025 W1/W3×N0—N3；2025不补W2。实际施氮/灌水剂量见运行对应表，DSSAT使用的**施用量、有效入渗量和灌溉效率**还需区分。
- 面积量统一kg/ha；N/P/K均为元素量，不是P₂O₅/K₂O。浓度可提供g/kg干物质，和mg/g数值相同；若原输出为%，请在变量表写明，不能原样当g/kg。
- 挂果必须给干物质；鲜重、个数为辅助。果实口径需涵盖整个果实，包括果皮、果肉及种子；只有种子量不可当整果量。
- 缺测值留空或写`NA`，不写0。不支持的变量在字段表标`UNSUPPORTED`；“0”仅用于确认的数值零。
- `block_id`仅在确有对应区组输入和模拟时填写1/2/3；`ensemble_id`是参数/情景编号，与区组重复不同。
- 状态值与流量分表：在株存量可升可降；累计采出一般不降；当天采出不可再次叠加到已含当天的累计值。

### 6.2 养分计算遵循收支，不反复相加站存量

```text
时点所计地上部累计量
 = 当时茎＋叶＋全部在株果实养分
 + 截至当时累计采收果实移出
 + 截至当时已知整枝/脱落移出（若纳入且有依据）

阶段所计净增量 = 末时点上述累计量 − 初时点上述累计量
定植后累计净增量 = 时点累计量 − 定植苗初始量
```

边界采收事件只计一次，可统一采用采收前状态＋此前已采量，或采收后状态＋含当日已采量，二者在收支闭合时应一致。根另列，未纳入根/整枝/脱落时仍说明器官范围；地上部量的变化也不直接等于根系总吸收通量。若模型有直接N吸收累计量，可单独交付并核实是否含初始苗N、固氮等。

若只给干物质及干基浓度：`器官养分kg/ha = 干物质kg/ha × 浓度g/kg ÷ 1000`。若给干重g/株：先乘27换为kg/ha；不要再次使用0.027乘面积干重。

### 6.3 显著性与不确定性

模型运行、日期和参数集合都不是新增生物重复。每处理一条模拟不能产生3个独立重复，不套用原实测ANOVA字母。若确有真实副区对应模拟，可在原裂区层级下进行模型辅助分析，仍需区分观测变异与模型共享误差；各子阶段分配也彼此相关。后续正式统计和图表继续用R处理，模拟结果与原实测主证据分层呈现。
