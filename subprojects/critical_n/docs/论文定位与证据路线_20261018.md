# 从器官氮缓冲扩展到品质研究：论文定位与证据路线

日期：2026-10-18。基于已冻结的capacity_a生理执行体与V13双春季率定结果。本文件是论文准备路线及可用措辞，不代表新增实验、独立验证或品质模型已经完成。

## 1. 建议的主论文问题

核心问题是：在多次采收的设施茄子中，如何使作物模型同时描述生长、器官总氮、可再动员缓冲和供氮响应，并避免通过不受约束的储备或错误结算换取良好产量拟合？

可用工作标题：

**面向多次采收设施茄子的DSSAT-CROPGRO器官氮缓冲扩展：严格碳氮结算与双春季联合率定。**

**An organ-resolved nitrogen-buffering extension of DSSAT-CROPGRO for multi-harvest greenhouse eggplant: constrained carbon–nitrogen accounting and joint calibration across two spring seasons.**

标题使用joint calibration而不是independent validation；使用extension而不是new universal nitrogen theory。现有证据不足以把fruit quality prediction作为主论文已验证结果写进标题。最终发表层次取决于机制对照、观测独立性和证据强度，不能由单一拟合指标保证。

## 2. 建议凝练的贡献

| 拟写贡献 | 当前能支持的具体内容 | 尚需的区分性证据 |
| --- | --- | --- |
| 多次采收条件下的器官氮状态框架 | 营养体稀释基准、器官总N内的缓冲子集、功能N代理、亏缺/富余状态 | 明确相对STICS/APSIM及已有CROPGRO储备的差异；不能声称首次提出氮储备 |
| 受约束的日尺度碳氮协调 | 偏好目标、真实容量、日充填通量分开；未接受预留取消、种子返回及对应C结算 | 分离质量缺陷修复与日内接受策略影响；用消融说明收益和代价 |
| 面向多过程的模型评价 | 两春20处理、末产量/过程/器官N/水氮差分联合约束 | 原版同预算重率定、留出环境检验；完整报告末期LAI和器官N不足 |
| 可复现的高维率定证据链 | 可行坐标、真实PEST-IES、完整参数—输出对检查点、失败透明及确定性重放 | 与连续IES的效率和稳定性作专门对照；不把它称新后验采样理论 |

前三项适合作为方法与模型论文的主线；第四项是可信度和计算实现贡献。不要将全部工作拆成很多“首创”点，弱化真正有区分度的机制问题。

## 3. 证据叙事顺序

1. 先用原版代表解说明研究问题：产量可以接近，但不同N水平的器官状态和边际响应可能不充分；不以原版错误光合路径的极差结果作靶子。
2. 给出最小状态/通量图和精确方程：哪些量由原生DSSAT持有，哪些是新增子集；参照Nc与实际TN的关系；真实库存、计划、预留、实际接受和退款的时序。
3. 显示约束正确性：质量账本、名义容量、日速率、种子返回、关闭模块回归、源码冷重建及极端原生探针。
4. 展示模型能力及其代价：分季产量、逐次/累计采收、分日期冠层、器官N及水氮差分，保留负NSE和未达标项。
5. 用嵌套消融讨论哪些改善来自机制、参数机会或补偿；最后讨论品质研究接口和未测组分。

历史上“实际器官N浓度没有单调下降，因此违反临界氮稀释定律”的说法不宜进入论文。临界氮是充足阈值，实际器官N还受供给、稀释、再富集、采收及管理影响，两者不是同一对象。[Gastal与Lemaire，2002](https://academic.oup.com/jxb/article/53/370/789/537168)

## 4. 将论点变成可检验假设

| 假设 | 需要比较什么 | 主要结果量 | 已有证据与待补内容 |
| --- | --- | --- | --- |
| H1：储备与功能响应分离能改善N梯度而不把富余N直接奖励为光合 | 原生、仅目标稀释、仅缓冲、目标+缓冲；相同参数与分别重率定两层对照 | 同日器官N量/浓度、N1→N2差、叶片功能响应、产量 | 历史固定参数消融可作先导；当前尚缺完整同预算嵌套重率定 |
| H2：严格库容与接受结算可在物理成立条件下保留拟合 | 旧结算、仅物理缺陷修复、完整接受策略 | 容量超限、N/C残差、退款比例、产量/器官误差 | V11/V12已有交叉消融与严格候选；不能把所有轨迹变化归为越界修复 |
| H3：状态相关根供给能恢复对不同N供给的响应 | 相同植株模块下旧根核/当前根核；先固定参数，再分别识别 | 层输入、全季输入、土壤矿质N、N梯度 | 已有旧根核反事实；缺少根和矿质N动态独立测量，不能唯一识别通道 |
| H4：机制具备跨环境可迁移性 | 预先冻结后在未参与开发/选择的环境预测 | 产量、过程、器官N与梯度，预测区间 | 两春均已率定，现阶段尚未完成 |

这些是假设，不是已经通过的结论。只增加自由参数后拟合更好，不能独自证明机制解释更真实。

## 5. 原版及近期版本对照应怎样写

可直接使用的事实：历史原版MEPHO=L代表解在2026春最终鲜产NRMSE为7.6557%，当前为5.6019%；叶氮NRMSE由12.6782%降至8.3383%。这些指标由本次脚本从原生输出按当前观测重算。见[原版对照表](../reports/milestone_20261018/historical_vanilla_comparison.csv)。

必须同时呈现：当前叶/茎DM和株高并未优于该历史代表解；单次干采收误差略大；原版并未按当前双季1123目标重新获得相同预算优化机会。不能把26.8%或34.2%的下降全部归因于某一个新机理，也不能称“全部指标全面领先”。

真正用于归因的比较应冻结天气、土壤、管理、观测算子、光合路径、目标口径与物理规则，报告每种模型实际有效参数数、支持域、初始集合、完整成功调用数及失败分母。每个模型应获得合理且可比的参数识别机会；模型专属参数和无效参数不能机械按同一数量充数。

总Phi只在同目标、同尺度、同权重条件下直接比较。当前127.1914与原79维127.2416可直接比较；不能与689目标的119.88等数值直接排名。

## 6. 创新措辞清单

| 建议使用 | 避免使用 |
| --- | --- |
| 本研究在DSSAT-CROPGRO中实现并评价了一套器官氮缓冲扩展 | 首次发现/首次模拟植物奢侈吸收 |
| 借鉴临界氮、器官边界与储备思想，针对多次采收接口进行适配 | 首创临界氮稀释理论或HATS/LATS |
| 在本试验范围改善了关键产量和叶N指标，并恢复了非零供氮响应 | 器官N在所有条件下均准确、全部指标远优于DSSAT |
| 当前有效根核加入水流、浓度和体内反馈依赖 | 已经求解真实根际对流扩散或验证转运蛋白机制 |
| 功能光合响应连续，整体施氮响应在已测处理间有所改善 | 当前全部根响应处处连续光滑 |
| 实现严格名义库容和日尺度碳氮结算 | 守恒闭合证明了生理过程真实且日内联立精确 |
| 双春季联合率定，为独立预测与品质扩展建立基础 | 两季独立验证通过或品质预测已经可靠 |
| 本项目的集成和实现贡献具有进一步验证的价值 | 已经完成全球首创性或高水平期刊录用证明 |

特别是原版CROPGRO已有luxury组成与吸收概念，相关原始论文明确说明了这一点。[Jing等，2024，表4及试验I讨论](https://acsess.onlinelibrary.wiley.com/doi/10.1002/agj2.21654)

## 7. 品质研究如何接续

建议将下一阶段定义为“冻结生长氮机制底座，开发独立品质状态与观测接口”，不要因已有良好末产量就直接训练一个质量输出映射并宣称机制成立。

| 品质目标 | 当前可用基础 | 必须新增的观测/机制 |
| --- | --- | --- |
| 果实总N浓度与采收N移出 | 原生总N、成熟队列、干鲜采收质量 | 采样对象、果龄、同日果实N量与含水率配对，解决指定日成熟果缺失 |
| 干物率 | 原干鲜转换、逐次采收干鲜比 | 成熟度—含水率动态；避用F8.1低精度PDMCD作为精确采收观测算子 |
| 蛋白/氨基酸 | N/C预算可提供边界 | 蛋白N与非蛋白N测量、组分形成/周转；不可默认总N×6.25等于真实蛋白品质 |
| 果实硝酸盐 | 根NO3输入可作供给信息 | 果实/植株内硝态储存与还原转运、硝酸盐独立测量；当前有机储备代理不能替代 |
| 糖酸、可溶性固形物、花青素等 | 果实C分配、环境与成熟度可作驱动 | 专门组分状态与形成/降解模型、品质重复测量、独立留出环境 |

优先确立总N和干物率的同口径评价，再依据已有实验数据选择一个明确品质终点。质量属性的参数应与生长参数分组，先检验新增模块是否仅利用生物量/含水率就能解释变化，再证明更复杂机制带来的增量价值。

## 8. 投稿前证据优先级

| 优先级 | 具体交付物 | 决策价值 |
| --- | --- | --- |
| 1 | 同数据、合理同预算的原版与最小嵌套版本率定比较 | 分离模型贡献和参数机会，建立主论文对照 |
| 1 | 同日器官N量/浓度与DM拆分、末期LAI、逐次采收及剩余N2水分差分诊断 | 避免总体误差掩盖管理响应错误 |
| 1 | 留出环境/独立试验预测方案，冻结日期早于观测揭示 | 支持论文的预测性和可迁移性主张 |
| 2 | 当前冠军附近密集施N及psi边界审查，区分根反馈跳变与采收事件 | 明确数值性质和对管理预测的影响 |
| 2 | 精确系数来源、编码单位、可辨识性与多起点剖面 | 防止把工作常数写成生理真值，落实可复算方法 |
| 2 | 一个品质终点的独立状态、观测契约与外部检验 | 为后续品质论文建立新增贡献，而非重复生长率定 |

以上为后续研究路线，本轮不启动新模拟、率定或试验。报告中的现有事实已经归档；未来论文可以据新增证据升级主张，不必把阶段里程碑等同于完成全部外推验证。
