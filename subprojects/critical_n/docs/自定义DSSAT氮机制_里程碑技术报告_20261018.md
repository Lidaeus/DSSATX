# 自定义DSSAT器官氮缓冲与双春季率定：里程碑技术报告

版本：2026-10-18。研究对象：设施茄子，采用DSSAT番茄TMGRO048/CROPGRO通道。本文为当前项目技术总报告；历史方案、失败候选和原始验收合同继续保留。

## 1. 里程碑定位

本项目达到“可复现的器官氮机制研究平台与双春季受约束联合率定”里程碑。已经具备可运行的缺氮—充足—富余状态表达、器官氮缓冲、状态相关有效根吸收、严格名义库容与碳氮结算、真实并行率定、全精度独立重放及审计证据。可据此进入果实品质机制及管理响应研究。

目前最有证据支撑的成果是：在本研究处理范围内，模型能够表达非零施氮响应与储备周转；两季末产量误差较低；相对现存历史原版代表解，2026春鲜产与叶N误差明显下降；库容与账本约束得到落实。这不等于全部器官浓度和所有过程已准确、根际机制已独立验证或品质预测已完成。

**阶段里程碑达成与原科研验收门槛是两个状态。** 用户确认将本平台作为后续研究基础；原16项共同护栏仍为15/16，正式科学晋升标志保持false，不改变旧门槛或旧运行收据。2025/2026春均参与率定，后续留出环境的预测检验另列。

## 3. 实际采用的模型框架

### 3.1 保留DSSAT主框架，扩展氮状态与过程接口

天气、土壤水氮、物候、原生器官生物量/总N、光合基础、果实队列及采收框架来自DSSAT。叶/茎储备N是器官总N的子集，不在全株总N上重复加一次。非储备部分作为功能N代理，不把它直接等同特定蛋白或纯结构氮。当前没有独立硝态—铵态—氨基态生化库。

### 3.2 营养体基准与有序氮边界

NBUF开启时使用Wveg=(WTLF+STMWT)/100，单位t DM/ha，不包含在株和累计果实；旧非NBUF路径仍可保留历史有效生物量口径。叶参照质量分数为：

`cL=[Cinf+(A−Cinf)×max(1,Wveg/W0)^(−b)]/100`。

茎参照使用相同营养体基准、指数乘STEM_BMULT并乘PROSTI/PROLFI。它是经典稀释思想的器官经验映射，不能把营养体/叶/茎曲线直接称为已实测建立的通用全株Nc曲线。

以器官DM、参照组成、最低比例和容量密度构造Nmin、Ncrit和Nmax。psi在亏缺/富余侧分别除以Ncrit−Nmin和Nmax−Ncrit，用于表示有向状态；无有效边界时显式处理。Nc参照描述充足阈值，不能要求任一器官的实际TN浓度必须全季单调下降。

### 3.3 有限储备、功能修复与真实受体

叶/茎容量Qmax_j=DM_j×qcap_j；偏好目标Qtarget_j=min(Qmax_j,theta_j×Ncrit_j)。两者不是同一个量。日最大新入库量按已存在空位乘[1−exp(−kfill×1日)]计算，新生长产生的空位不提前当作日初已有库存。修复、回补、内源动员与新生长分别计划，实际动员/接受受真实受体、库存和C预算限制。

NB_TARGET_RATIO是搜索坐标，实际卡值theta=.02+r×(NB_CAPACITY−.02)，不能将其当作快库的直接容量占比。当前叶/茎目标写入约.076/.091，容量系数.100。

### 3.4 功能叶N与光合

功能光合入口扣除储备N；不足侧采用1−(−psi)^2.5、充足侧平台为1的经验响应。其作用是让总N富余与功能修复状态能够区分，而不是证明储备氮没有生理作用。响应曲线的数值性质与叶片气体交换生理验证分开；本项目尚无足够独立功能N组成或气体交换证据。

### 3.5 根吸氮是有效动力学扩展

当前根潜力包含水流—孔隙浓度相关项和HATS/LATS形式的主动有效项，后者受根长、水分与体内状态反馈影响。随后执行层可提取库存、全株Dmax、预付同化C及真实受体接受/取消。**当前capacity_a使用Dmax而非把偏好root_request作为额外硬上限。**Dmax自身含生长与受日速率限制的可接受空间，精确表达以冻结源码nb_plan为准。

这是半经验的供给—状态反馈近似。它不是DAISY径向对流扩散求解器，也没有显式转运蛋白表达、NH4吸附分配或完整温度响应；质流运达与跨膜项直接相加的解释仍有待独立验证。日志中的潜在通道份额不能当作实测吸收途径份额。

**当前冠军根核并非处处平滑。**它保留psi≤0时反馈1、psi>0时1/(1+exp(alpha×psi))的旧主动项，右极限为.5。功能光合函数连续不等于全部根过程连续；离散处理的总体响应改善不等于完成密集剂量连续性证明。局部平滑、delivery/carrier协调等保留在历史消融分支，未自动进入本冠军。

### 3.6 积分前的碳氮协调

吸收先作为预留；实际生长确定后撤销未用内源动员，按修复和当日充库预算接受剩余量。无法接受的外源预留在土壤积分前按形态比例取消，种子未用N返回种子库，根N同化费用相应退款至现有CH2O储备。不得以无界充库或删除N余额掩盖超限。

这不是植株把已同化N真实排回土壤。退款不追算当天生长，仍是日尺度顺序算子分裂；“严格守恒”不等于精确的连续日内联立C–N解。

## 6. 氮响应改善与仍待验证的部分

当前模拟的平均全季根输入（kg N/ha），2026春N0/N1/N2/N3为146.637/195.903/210.295/211.815；2025春为165.416/202.712/221.223/228.819。它显示已不锁定为相同总吸收，并能表示边际趋缓；这些是模型内部量，不是根吸收独立实测验证。

当前26春全日期/水平均叶N的N1→N2差为+0.1075个百分点，实测+0.2293；N0→N1差为+0.4325，实测+0.1432。方向与幅度必须分开：响应并非消失，但部分梯度过度集中于低氮段。25春部分观测相邻浓度差为负，也不应把“每个器官随施氮单调上升”作为无条件正确标准。

原护栏剩余失败为2026春N2 W2−W1鲜产差分：模拟3384.6、实测10801.8 kg/ha，误差7417.2，超过登记容差5345.2157。末次LAI和器官N的负NSE、逐次采收错位、成熟果采样可用性及14个活动参数贴界仍保留为明确问题。这些限定本里程碑的外推范围，不否定平台已经可用于下一阶段研究。

## 8. 后续品质研究的合理起点

当前可输出果实/采收总N、干鲜质量、器官N状态、根输入与C分配等状态/通量，可为品质模型提供驱动。先选择可测的总N浓度、逐次干物率或含氮品质指标，并对齐成熟度、器官、采样日期、鲜/干基准和管理移除。总N不直接等于硝酸盐、真实蛋白或氨基酸；原生蛋白等价记账常数也不是品质测量。

糖酸、可溶性固形物、花青素、维生素C和果实硝酸盐需要额外组分状态/形成损耗模型与独立观测。不能只将psi代入经验式后宣称机制预测完成。阶段一宜保持当前生长底座冻结，单独开发品质模块；新环境留出数据用于最终检验，避免反复使用已参与选择的两春数据作为“独立验证”。

参数归属维持[上轮处置建议](../reports/best79_metrics_parameter_review_20261018/parameter_disposition_proposal.csv)：13个有效自定义氮参数保留SPE入口、按证据控制固定/活动；未连接的NB_ROOT_DEPTH和当前无效NB_SOIL_ALPHA不作为有效率定维度；SLPF/SLDR保留土壤/环境语义。果实模块按当前研究决定保留。
