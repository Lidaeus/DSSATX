# 双春官方 DSSAT 与 V15 协调时序＋5 日窗口主对照

## 实施顺序

1. 锁定官方最佳参数和严格 1043 最佳组，从对应确定性复跑提取已经注入的 CUL、ECO、SPE。核对二进制、参数文件、数据包清单和实际输入哈希。
2. 2025 春采用 xxql2501_refreshed_lwad_20261108，2026 春采用 xxql2601_final_20261105。两版按季节共用原始 TMX、TMA、TMT、天气和 SOIL.SOL。土壤参数采用数据包的固定值。按批次首末处理预检后运行 8＋12 个实有处理，两版共 40 个处理运行。
3. 比较实际吸氮及根长、土壤矿质氮及水分、叶茎氮库和含氮率、冠层、胁迫和分批产量。V15 专有的氮状态和协调通量按本版定义展示。
4. 用共同成功配对点计算分季指标。2026 春第四次叶茎氮留在图和配对表，另行标识。按实际处理矩阵计算产量差分。复跑用于比较完整率定配置，差异同时包含模型与各自品种参数的作用。

## 输出与证据边界

- replay.py 执行确定性复跑并写入每组 receipt.json。render.py 采用 S1 图集的水分分面和氮梯度颜色，叠加两版和观测，输出诊断图、日值、配对、指标和产量差分。
- 官方二进制原生文件未提供需求截断前 TRNU、ANDEM 或 FNO3/FNH4/SMDFR。本轮无需替换官方执行体即可比较共同的 NUPC，日值为其相邻日期差分。潜在吸氮实现率和通道级归因需要同源只读日志及原执行体输出等价性验证。
- V15 RootNSupply、NDecision、NFlux、OrganNState 和 NCBalance 原始日志随复跑保留。V15 原生 vegetative_nni 使用本版定义。跨版统一 NNI 需要锁定共同的临界曲线及生物量、器官氮和采收计量口径。
- 产量差分使用 kg/ha。边际产量按施肥事件汇总的实际氮量归一化，2025 春为 0、122、254、364 kg N/ha，2026 春为 0、120、240、361 kg N/ha。summarize.py 同时输出 V15 原生氮平衡残差。附件的 12 个处理和示例氮梯度是设计示意，实际处理与剂量以数据包为准。
