## 已实施

- `v15_s1_interface`：实际 HATS/LATS 反馈接通原有 C1 `nb_feedback_response`。高正 ψ 区间恢复原函数，不将整个正分支乘二。
- `v15_s2_weighted`：只对根系供氮信号，扣除被功能氮缺口占用、且当日不可动员的储备；物理总氮、生长胁迫信号保持原定义。
- `v15_s2_joint`：比较外部供氮与快速储备在增长/修复需求间按需求比例分配；缓慢结构氮不作为修复的供给来源。
- `v15_s2_weighted_joint`：组合后两项。上述方案不增加可率定参数。
- 所有版本新增只读 `NDecision.csv`，明确日初总氮、储备、当日最大可动员量、功能氮缺口、总氮信号、根反馈信号和实际 Dmax。

原生 Fortran 单元测试、两季回归及降低根吸氮能力后的受限供氮试验已完成，见 `evidence/`。各方案均有单独执行体和构建哈希，不能仅凭 V15 文件夹名判断所用机制。

## 日步长与计量处理

完成移动储备目标的受控收敛试验（1–128 子步），严格保持一日新增生物量及外部氮供给预算，不重复内部转运、灌溉、施肥或土壤扣氮。该试验是子系统测试，不冒充整个 DSSAT 的子步长复跑。

当前 DSSAT 根吸氮结算早于当天衰老/冻害存活量计算，故尚不采用预测新生物量扩容的正式补丁。正确实现需要联立日末存活干重、氮/蛋白质量、土层氮接受量和同化碳退款；现有名义库容断言不放宽。

EM-V1、TRIFL、VSSINK、SIZLF 均正确活跃；TRIFL 上限仍为 0.85。现有生长测量最早为 2025 春 DAP 45、2026 春 DAP 49，未覆盖早期波谷，未因图形外观扩展边界。快速储备继续明确为有机氮的蛋白当量假设；未在缺乏氮形态数据时更改质量系数。

## 小规模率定

`configs/registered_pilots.json` 注册两组 100 成员 × 2 次更新的约束 PEST-IES：仅修接口组、储备加权＋共同分配组。两组相同随机种子、相同起始最佳参数、相同目标和边界；各自预检最多 300 次。当前模型的 1079 项目标、2026 春第四次叶/茎氮排除规则、商品成熟果同日采样定义及鲜果重量目标全部沿用。

检查点保留失败提议之前的真实参数/输出配对，不将失败参数配上旧模拟值；保留成员数不等于有效更新数或后验样本量。最终需报告原始 PEST 存活数、冻结成员数、有效参数唯一数及所有失败原因。

没有分季/关键日期生长护栏，也不强制叶氮单调下降。候选只依据完整目标和全周期物理预算审查；局部波谷统计仅解释。
