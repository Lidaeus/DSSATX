# CROPGRO A2 土壤氮吸收响应（本机验证记录）

## 目的

本分支 `feat-cropgro-n-uptake-hill-a2` 只改动 CROPGRO 土壤无机氮潜在吸收因子，不改动 `NSTRES`、`NREXP`、`NRMIN` 或冠层/产量胁迫传递。原来的

\[
F(C)=1-\exp(-0.08C)
\]

替换为二参数 Hill 函数：

\[
F(C)=\frac{C^{q}}{K_{50}^{q}+C^{q}}.
\]

其中 `C` 是 DSSAT `NUPTAK` 中每个有根土层的内部无机氮浓度变量；`K50` 是使潜在响应达到 0.5 的同单位浓度；`q` 是无量纲曲率参数。`q<1` 使低浓度段更平缓，`q>1` 使响应更陡。原有 `F<0.04` 置零、`0≤F≤1` 限幅和根长/水分/吸收系数计算均保留。

## 源码和 SPE 参数

- Fortran 实现：`Plant/CROPGRO/NUPTAK.for`
- 物种参数：`Data/Genotype/TMGRO048.SPE`
- 新增 SPE 段（位于 `!*ROOT PARAMETERS` 之后）：

  ```text
  !*NUPT HILL SOIL N UPTAKE RESPONSE PARAMETERS
   40.0   1.00                           NUPK50,NUPQ
  ```

`NUPTAK` 在 `RUNINIT` 读取这两个参数。没有该段的旧 SPE 文件使用兼容回退 `K50=ln(2)/0.08=8.66434`、`q=1`，因此旧输入仍可运行；率定时应显式提供新段。模型只检查二者为正值，建议率定工作域为 `NUPK50=20–80`、`NUPQ=0.7–1.3`。

## 本机验证

```bash
cmake -S . -B build-hill-a2 -DCMAKE_BUILD_TYPE=Release
cmake --build build-hill-a2 -j4
```

生成：`build-hill-a2/bin/dscsm048`。同一官方基线（`origin/develop`，未修改 `NUPTAK`）也在独立临时目录成功编译，用于回归对照。Windows 可执行文件尚未生成。

率定运行器已增加 `NUPK50`、`NUPQ` 的 SPE 标签注入和宽安全边界；注入单元测试确认 `20,0.7` 等值会写入 `NUPK50,NUPQ` 行。测试工作区的可执行文件链接已恢复到 A2 本机版本。

## 小范围网格结果

对 25SP、26SP 共 20 个处理运行 9 个组合：`K50={20,40,60,80}`、`q={0.7,1.0,1.3}`（仅测试用户建议范围内的组合）。终端产量按每季每处理的最后一次累计采收计算；累计采收序列按相同处理和采收序号合并。计算时显式重置索引，避免跨季节 `idxmax` 重复选行。

终端 RMSE 最小的是 `K50=20,q=0.7`：RMSE 911.7、RRMSE 25.58%、MBE −457.9；累计序列 NSE=0.716、Willmott `d`=0.927。该结果仍不能称为最终率定，误差显示当前试验/土壤/管理输入仍有明显系统偏差。网格内增大 K50 或 q 会使模拟产量整体下降，说明该数据集对 A2 参数有方向性敏感性，但尚不足以单独确定唯一最优值。

26SP 按 FileX 施氮总量映射的处理均值（`K50=20,q=0.7`）为：

| 施氮量（kg N ha⁻¹） | 模拟终产量 | 观测终产量 |
|---:|---:|---:|
| 0 | 1,738 | 2,978 |
| 120 | 3,674 | 3,168 |
| 240 | 3,474 | 3,262 |
| 361 | 3,470 | 3,632 |

因此在 240 与约 360 kg N ha⁻¹ 间，A2 已表现为平台并略降；但 0 kg 处理仍明显偏低，后续应先核查初始土壤氮、土壤氮单位/深度和处理对应关系，再决定是否继续率定，而不是立即扩展模型复杂度。

## 与官方基线的回归

在同一 `K50=20,q=0.7` 参数文件下，A2 与官方指数函数版本的终端产量不同：25SP 最大绝对差约 265 kg ha⁻¹，26SP 最大绝对差约 242 kg ha⁻¹；说明新函数确实被执行，而不是停留在 SPE 注释层面。

## 后续率定建议

1. 保持方程和参数数量不变，先用 `K50=20–80`、`q=0.7–1.3` 做正式 PEST++ 或更细网格率定。
2. 终端产量以 RMSE/RRMSE 为主；累计采收序列同时报告 NSE、Willmott `d` 和采收日期偏差。
3. 只有在输入核查完成、且低氮—240—约360 kg N ha⁻¹排序仍不能改善时，才考虑扩大 K50 工作域；暂不增加高氮毒害项或新的 `NSTRES` 方程。
