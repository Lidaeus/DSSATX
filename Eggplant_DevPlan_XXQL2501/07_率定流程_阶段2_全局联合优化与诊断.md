## 1. 参数集（联合优化的“可识别”最小集合）

联合优化不追求“参数越多越好”。推荐以阶段 1 的敏感性输出为依据，选择 8–15 个参数进入联合。

敏感性结果来源：

- Morris：`Workspace\Sensitivity_Analyze\SA_Project_Output\morris_results_compact\morris_overall_parameter_ranking.csv`
- Sobol（总效应 STi）：`Workspace\Sensitivity_Analyze\SA_Project_Output\sobol_results_compact\sobol_overall_parameter_ranking_STi.csv`

默认候选（对齐当前工程实现）：

- `CUL`：`SLAVR, SIZLF, LFMAX, XFRT, PODUR, SFDUR`（以及当前模板中为 `fixed` 的 `WTPSD/SDPDV` 若后续解锁）
- `ECO`：`XMAGE, TRIFL, RWDTH, RHGHT`（按敏感性筛选进入联合；`FL-VS` 固定不释放）
- `SPE`：`TB, TO1, TO2, TM`（若阶段 1 未充分确定，或存在系统性物候偏差时纳入）

基于本轮敏感性排序的“推荐进入联合”的优先级（面向 XXQL2501）：

- 第一梯队（必须优先考虑）：`TRIFL`（ECO）、`XFRT`（CUL）
- 第二梯队（按诊断需要选择）：Thermal time（`TB2/TO22/TO11/TB1` 等 SPE）、`RWDTH`（ECO）、`KCAN`（SPE）、`PM06`（ECO）
- 第三梯队（用于解释水-氮处理差异与胁迫时序）：`FRLFF/FRSTMF/ATOP/PORPT`（SPE）

为避免多解性，建议在联合率定中显式拆分“品种参数 vs 处理响应”角色：

- `CUL` 以表达品种层面的固有库强/分配上限为主（`XFRT/PODUR/SFDUR`）。
- 水-氮梯度的处理差异优先由管理/初始条件与根系-水分过程参数解释，避免把处理差异挤压进 `CUL`。

针对“无限生长型 + 前期去花 + 不以生理成熟为目标”的场景：

- 不建议把 `MDAPM` 作为目标观测进入 WLS。
\- 若加入物候参数，只把 `ADAPM` 当作弱约束（低权重），用于排除极端早花/极端晚花（建议 `σ=15–30 天`；工程默认 `σ=25 天`）。

## 2. 目标函数（WLS）与权重

目标函数采用加权最小二乘：

`J(θ) = Σ_i ( (obs_i - sim_i(θ))^2 / σ_i^2 )`

权重实现：`weight_i = 1 / σ_i^2`。

σ 的建议来源优先级：

1. 试验重复的标准差（最佳）
2. 多日期序列的 MAD/SD（次优）
3. 目标精度假设（保底）

当前工程实现补充说明（与本章公式一致）：

- `build_pest.py --mode eggplant_stage2` 会把多次采收观测写入 `PestHarvest.OUT`，并按分次采收编号 `HNO` 设置 `PWADM_H{hno}` 分组权重。
- `PWADM` 的 σ 采用可解释的“截距 + 变异系数”形式（以采收分次的中位数为尺度）：
  - `sigma = sqrt(sigma0^2 + (cv * |median|)^2) * sigma_factor`
  - 对应 CLI 参数：`--pwadm-sigma0/--pwadm-cv/--pwadm-sigma-factor`

## 3. 敏感性筛选与信息准则（AICc）

为了满足“避免多解性”的审稿要求：

1. 先做 Morris/Sobol：识别对物候/LAI/产量敏感的参数，并以 Sobol STi 优先识别强交互参数。
2. 每次只新增 1 个参数进入联合优化，比较 ΔAICc（或用等价的复杂度惩罚准则）。
3. 只有 ΔAICc 显著改进（例如 < -2）才保留该参数。

推荐的“增参顺序”（从最小可识别集到论文级集）：

1) `TRIFL` → 2) `XFRT` → 3) `TB2/TO22` → 4) `RWDTH` → 5) `KCAN` → 6) `PM06` → 7) `FRLFF/FRSTMF`（按处理差异需要）

## 4. 不确定性分析

项目已采用 `PEST++ IES`（集合平滑），建议：

- `ies_num_reals ≥ 100`（论文级不确定性统计）
- 输出参数后验分布、置信区间与参数相关矩阵

必要输出：

- 参数后验分布（均值、标准差、2.5%–97.5%）
- 观测残差分布与正态性检验（至少提供 QQ 图）

## 5. 标准化诊断指标网格（Metrics Grid）

按类别输出（至少）：

- 精度：RMSE、NRMSE、MAE
- 一致性：d-index、EF
- 偏差：PBIAS
- 趋势：R²（或 Pearson r）

并补充两个更贴近“生产意义”的指标：

- RRMSE（相对均方根误差）：用于不同量纲目标的可比性
- 分解诊断（如 SB/SDSD/LCS）：用于区分系统偏差与动态形状偏差

并对产量/LAI/物候分别给出阈值判断（例如产量 NRMSE < 15%）。

建议以观测组为单位输出 RMSE、NRMSE 与 d-index，并在结果汇总表中同时提供“全体处理”和“分处理（TRNO）”两类统计，以显式呈现 Genotype-by-environment interaction。

## 6. 独立验证（可扩展设计）

当后续加入多年份/多地点时，采用：

- 留一年法（Leave-one-year-out）或留站点法（Leave-one-site-out）
- 校准集与验证集 NRMSE 差异不超过 5–10% 作为稳定性判据
