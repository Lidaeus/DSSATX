# 02 观测-参数映射与权重设计

本章回答四个问题：

1. **每一类观测指标由哪些参数主导？**
2. **这些参数位于哪个文件（CUL/ECO/SPE）？**
3. **在校准中，这些观测的权重如何设置？**
4. **如何避免权重和参数选择导致的“多解性”？**

---

## 1. 物候类观测（日期/天数）

### 1.1 观测指标

- 播种/定植日期：`PDAT`
- 出苗/移栽缓苗结束：`EDAPM`（若有）
- 始花期：`ADAPM` 或等价字段
- 生理成熟：`MDAPM`
- 多次采收触发：`TMT` 中首次采收日期序列

### 1.2 主控参数与文件位置

- `CUL`（`TMGRO048.CUL.base` `39-46`）：
  - `EM-FL, FL-SH, FL-SD, SD-PM, FL-LF`
- `ECO`（`TMGRO048.ECO:45-48`）：
  - `PL-EM, EM-V1, V1-JU, JU-R0, FL-VS, TRIFL, XMAGE`
- `SPE`（`TMGRO048.SPE:99-120`）：
  - 各阶段的 `TB/TO1/TO2/TM` 与阶段连线定义

敏感性分析提示：在 `XXQL2501` 上，Thermal time（尤其 `TB2/TO22/TO11`）对“发育节奏”具有高总效应（Sobol STi），实际优先级不低于 `CUL` 的阶段热时参数；因此物候类观测不应仅用 `CUL` 去吸收温度响应误差。

### 1.3 权重与阶段划分

为避免物候主导所有优化，并考虑 `XXQL2501` 的前期去花/坐果管理导致“始花定义偏移”，建议采用弱约束口径：

1. 阶段 1（物候弱约束）：
   - 仅保留 `ADAPM`（对应 `TMA:ADAT`）作为弱约束；
   - 建议 `σ = 15–30 天`（工程默认 `σ = 25 天`），仅用于排除极端早花/极端晚花；
   - 工程实现可用 `build_pest.py --adapm-sigma <days>` 直接覆盖；
   - 其他物候（如 `MDAPM`）默认不纳入目标函数。
2. 阶段 2（联合）：
   - 若纳入物候，仍只将 `ADAPM` 作为弱约束组：`w = 1 / σ^2`，且建议 `σ` 不小于 25 天；
   - 不建议采用 “σ=3 天” 的目标精度假设，以免把管理噪声与定义偏差放大为主导约束。

## 2. 冠层和生物量类观测（LAI/TDM/器官干重）

### 2.1 观测指标

- LAI：
  - 季末最大 LAI：`LAIX`（FileA）
  - 过程中 LAI 序列：`LAID`（FileT）
- 器官干重：
  - `LWAM/LWAD`：叶干重
  - `SWAM/SWAD`：茎干重
  - `RWAD`：根干重（若有）

### 2.2 主控参数与文件位置

- `CUL`：
  - `LFMAX`：最大叶光合速率（源端上限）；
  - `SLAVR`：比叶面积（叶面积–叶重关系）；
  - `SIZLF`：单叶最大面积；
  - `FL-LF`：从始花到叶生长停止的热时长度。
- `SPE`：
  - 光合：`KCAN, KC_SLOPE, CCMP, CCMAX, CCEFF, PGEFF` 等；
  - SLA 动态：`SLAMAX, SLAMIN, SLAPAR, TURSLA, XSLATM, YSLATM`；
  - 叶生长曲线：`FINREF, SLAREF, SIZREF, VSSINK, XVGROW, YVREF`；
  - 叶/茎分配：`XLEAF, YLEAF, YSTEM, WTFSD`。

敏感性分析提示：冠层侧最强参数为 `TRIFL`（ECO），其次才是 `LFMAX`（CUL）与 `KCAN`（SPE）。因此 LAI 早期斜率与“达峰时间”的系统偏差，应优先从 `TRIFL` 与 Thermal time 的配合关系诊断，而不是直接放大 `LFMAX`。

### 2.3 权重设计

为避免 LAI 单独支配优化，建议：

- 将 **LAI 和 TDM** 视为同等级核心指标，但在目标函数中按单位标准差归一化：
  - `w_LAI = 1 / σ_LAI^2`；
  - `w_TDM = 1 / σ_TDM^2`；
- 若缺乏重复观测，可以采用目标相对精度：
  - 设定 LAI 期望 NRMSE ≈ 20%，则取 `σ_LAI = 0.2 * mean(LAI_obs)`；
  - 生物量（TDM/器官干重）目标 NRMSE ≈ 15%，并据此定义 `σ`。

在当前工程实现中，`TMT` 的 `LAID/LWAD/SWAD` 过程点可直接接入 PEST：

- 观测（`LAIDM/LWADM/SWADM`）：来自 `XXQL2501.TMT` 按 `DATE` 的采样点
- 模拟（`LAIDS/LWADS/SWADS`）：来自 `PlantGro.OUT` 同名日值，按“同日或向前最近日”取值
- 入口文件：`PestTmtGrow.OUT`（标签列：`@LAIDS@/@LWADS@/@SWADS@`）
- 构建方式：`build_pest.py --mode eggplant_process`

由于该类指标采样误差可能较大，建议采用“低权重、按日期分组”的权重策略：

`σ_D = sqrt(σ0^2 + (cv * |median(obs_D)|)^2)`，`weight = 1/σ_D^2`

- `LAIDM`：`σ0=1.6`，`cv=0.50`
- `LWADM`：`σ0=80`，`cv=0.25`
- `SWADM`：`σ0=100`，`cv=0.25`

## 3. 产量与多次采收类观测

### 3.1 观测指标

- 季末总产量：`HWAM`（干重），必要时推导鲜重；
- 多次采收：
  - 单次采收干/鲜重：`PWAD` 与由 `PDMCD` 反推的鲜重；
  - 累积采收干/鲜重：`CHFPW/CHPDT` 等累积字段；
  - 采收频率：采收日期间隔。

### 3.2 主控参数与文件位置

- `CUL`：
  - `XFRT`：每日生长物分配到种子+荚壳的最大比例；
  - `WTPSD`：最大单粒种子质量；
  - `SFDUR`：单荚群的灌浆持续时间；
  - `SDPDV`：单荚平均粒数；
  - `PODUR`：达到最终荚数所需光热日；
  - `THRSH`：脱粒比（种子/(种子+荚壳)）；
  - `SDPRO/SDLIP`：种子蛋白与油分比例（影响氮/碳分配）。
- `ECO`：
  - `XMAGE`：多次采收触发热时（多收作物特征参数）。
- `SPE`：
  - DMC 动态（鲜重/干重关系）由源代码 `FreshWt` 决定，视需要微调。

敏感性分析提示：产量/多次采收侧的第一控制参数为 `XFRT`（CUL），并与 `TRIFL`（冠层供源能力）和 Thermal time（发育节奏）共同决定累计采收曲线形状；在水-氮梯度下，`FRLFF/FRSTMF/ATOP/PORPT` 等根系与水分过程参数也会显著影响处理间差异（G×E）。

### 3.3 权重设计

建议将产量相关指标划分为两个等级：

1. **一级（结构性）约束**：
   - 累积干重 / 季末干重（`HWAM` 与累积 `PWAD` 等价）
   - 目标：NRMSE ≈ 10–15%；
   - 权重基于 `σ_Yield = 0.1–0.15 * mean(Yield_obs)`。
2. **二级（动态）约束**：
   - 单次采收量、采收频率、DMC 序列；
   - 目标：拟合趋势而非每一点数值；
   - 可将这些观测分组，对组内均值/斜率构造合成指标，权重略低于一级指标。

在当前工程实现中，多次采收以“累计采收干重曲线”为主目标接入：

- 观测（`PWADM`）：`XXQL2501.TMT` 中优先取 `CHPDT`（累计采收干重）；若缺失则对 `PWAD` 做累加补足。
- 模拟（`PWADS`）：`PlantGro.OUT` 的 `PWAD`（累计采收干重），按“采收日期当日或之前最近一天”取值。
- 观测分组：按采收次数（`HNO`）分组，分组名为 `PWADM_H{hno}`。
- 权重：`build_pest.py` 在 `eggplant_harvest` 模式下为每个 `HNO` 构造一组 `σ`，默认形式：
  - `σ_H = sqrt(σ0^2 + (cv * median(PWADM_H))^2)`
  - 推荐 `σ0 = 250 g`，`cv = 0.08`

## 4. 权重在 PEST 中的实现原则

在 `build_pest.py` 中，观测权重实现为两档：

- 若未提供 `group_sigmas`：有效观测（非 -99）使用 `weight = 1.0`，缺失观测（-99）使用 `weight = 0.0`。
- 若提供 `group_sigmas`（当前 `eggplant_pheno/growth/joint` 模式已使用）：按观测列名（`xxxM`）查找 `σ`，并设置 `weight = 1 / σ^2`；缺失观测仍为 0 权重。

多次采收模式（`eggplant_harvest`）沿用同一权重机制，但观测列名会带采收次数后缀：

- `obsnme`：`PWADS_R{run}_H{hno}`
- `obgnme`：`PWADM_H{hno}`
- `group_sigmas`：优先查找 `PWADM_H{hno}`，查不到则回退到 `PWADM`

因此本计划中的“目标精度 σ”可以直接落到 `build_pest.py` 的 `group_sigmas` 字典中，不需要额外的 `target_sigma` 列。

过程点模式（`eggplant_process`）同理：观测列名会带日期后缀，分组名形如 `LAIDM_D{date}`，`group_sigmas` 优先查找 `LAIDM_D{date}`，查不到则回退到 `LAIDM`。

## 5. 避免多解性的参数-观测配对策略

为避免参数间补偿效应，本计划明确“一个物理过程优先对应的一组参数”：

- 物候：优先确定 `SPE` 的 Thermal time 响应（`TB/TO/ TM`），再用 `CUL/ECO` 的阶段长度做微调；避免用 `CUL` 阶段热时去“补偿”温度函数错误。
- 冠层和 TDM：优先调整 `LFMAX/SLAVR/FL-LF` 与 `SPE` 中的 SLA/分配曲线，不随意动 `XFRT/WTPSD`。
- 产量：
  - 单果大小：`WTPSD`；
  - 粒数/果数：`SDPDV/PODUR` 与 `XMAGE`；
  - 品质：`SDPRO/SDLIP` 与 DMC 公式参数。

补充：对水-氮处理差异的解释，优先使用“管理/土壤/根系与水分过程”相关参数与初始条件；除非有跨环境的独立证据，否则不建议把处理差异强行归因到 `CUL`。

## 6. 批次率定的停止准则（RMSE/NRMSE/d-index）

每一批次结束时，至少对目标组输出 RMSE、NRMSE 与 d-index（Willmott d），并以“趋势稳定且可解释”为优先。

- 产量（`HWAM` 或累计采收）：NRMSE 目标 `≤ 15%`，d-index 目标 `≥ 0.85`。
- LAI（`LAIX/LAID`）：NRMSE 目标 `≤ 20%`，d-index 目标 `≥ 0.80`。
- 物候（`ADAPM`）：以 RMSE 为主（弱约束不设硬阈值，通常 RMSE `10–20 天` 可接受；关键是不牺牲产量与 LAI 组）。
- 物候（`ADAPM`）：弱约束不设硬阈值；以 RMSE 作为“合理性检查”即可（通常 RMSE `10–20 天` 可接受；关键是不牺牲产量与 LAI 组）。
