# Historical research workflows

The `archive/pre-standalone-main` tag preserves the original scripts for
A-budget feedback, P0b, integration, C3/C4, and the V4–V7 experiment series.
Those scripts were coupled to Windows run trees, frozen design records and
application-side Python modules. Their original outputs and receipts retain
their source paths for provenance.

The current tree retains the Fortran implementations, fixtures, native tests
and research documentation. For new runs use the standalone entry points
in [RESEARCH.md](../RESEARCH.md). The full historical calibration designs
need their original sealed assets and adapters for an exact rerun.
