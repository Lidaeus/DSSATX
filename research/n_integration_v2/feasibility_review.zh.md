# DSSAT 4.8.6.4 氮吸收—储存—同化一体化方案 v2：可行性评估与执行准备

日期：2026-11-02。范围：评估v2原文、核查官方源码接口、准备独立分支与基线；尚未实施生理机制修改。

## 1. 判断与建议

**总体可行，适合分阶段实现；不宜按文中伪代码直接整体接入。** 最有价值的改变是把土壤净吸收 `U`、体内未同化氮 `Q`、实际同化 `A` 和器官有机氮分配分开，同时保留官方土壤过程与器官再转运。该抽象有理论依据，也能针对既有模型中“当天吸收即有机可用”的近似做可检验的改进。

但可编程、可辨识和预测有效是三个不同问题。现有产量、生物量、器官氮观测可以检验整体行为，**不足以保证同时识别根系米氏参数、有效扩散、无机氮库容和有限同化参数**。先开发少参数、能回退的研究版本，再决定增加复杂度，不能预先承诺比V15 s1拟合更好。

建议采用的主线：

**官方4.8.6.4独立基线 → P0真实时序与预算追踪 → 原根系下新增氮库及有限同化 → R1/R2独立根吸收 → 器官三氮曲线与软状态诊断 → 对实际光合路线实施替换式反馈 → 受控消融 → 同等条件率定。**

R2核函数可以提前独立开发验证；整株接入必须等无机氮接收端、实际有机氮接受能力和收支闭环建立。文中末章“根系优先”与P1/P2先建库并不矛盾，前者适用于独立核函数，后者是整株集成的依赖关系。

当前准备状态是：**P0的版本冻结、独立构建和行为回放已完成；P0的新增运行时诊断尚未实施。** 新根系、新库、新同化、新NNI反馈均尚未实现，不把此次基线回归当作新机制验收。

## 3. 方案中值得保留的部分

| 设计 | 评价与保留方式 |
|---|---|
| 吸收、无机储存、同化、器官分配分别记账 | 是本方案的核心收益，能表达富氮储存与断氮后的同化延续 |
| 质流/有效扩散供给与膜运输能力联立，而非“质流+主动吸收”相加 | 避免将同一股氮重复计算；仅最终UNO3/UNH4作为土壤扣除依据 |
| 先单支米氏式，延后双HATS/LATS | 降低参数补偿；双支动力学不应仅凭产量率定启用 |
| 区分NO3和NH4，NH4不照搬NO3质流分支 | 正确；铵态可用性和有限缓冲必须单独处理 |
| 复用DEMAND/MOBIL/PODS/VEGGR/GROW | 保留官方多年积累及上游修复，降低跨模块改写风险 |
| 先诊断NNI，再替换反馈 | 便于区分同化延迟与新胁迫函数各自的效应 |
| 实际浓度允许偏离参考曲线 | 符合用户的软约束目标；限制真实物质库存不等于强制器官浓度夹在曲线带内 |
| Mode 0严格回归、全氮守恒、可回退 | 应保持为工程验收条件；不能因拟合收益而放宽 |

文献支持这些过程的存在，不等于支持任一具体的茄子参数组合。NiCoLet的储存/结构区分可借鉴，但其对象是生菜；不能把生菜的液泡、渗透与碳参数直接移植到无限生长型果菜。[Seginer, 2003](https://pubmed.ncbi.nlm.nih.gov/12714361/)

根表运输与吸收动力学耦合有成熟理论基础；质流的贡献随根间距、运输能力与土壤过程变化，并无通用固定百分比。v2的R2应称为日尺度有效近似，不能宣称复现了完整径向对流—扩散或滴灌二维空间分布。[McMurtrie & Näsholm, 2018](https://doi.org/10.1111/nph.14927)

## 4. 实施前必须补齐的设计问题

### A01：土壤扣除实际滞后一轮，原文的同日交接表述不成立（P0阻断项）

官方代码事实：

1. [LAND.for:311](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/CSM_Main/LAND.for:311) 的RATE顺序为SOIL → SPAM → PLANT。
2. [SoilNi.for:349](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Soil/Inorganic_N/SoilNi.for:349) 明写 `Update with yesterday's plant N uptake`，随后从SNO3/SNH4扣除UNO3/UNH4，并累计土壤侧WTNUP。
3. [LAND.for:359](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/CSM_Main/LAND.for:359) 的INTEGR也先SOIL后PLANT；当日新吸氮是在后面的 [CROPGRO.for:992](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/CROPGRO.for:992) 产生。

因此原文R.9第7步“从PLANT(INTEGR)返回给SoilNi(INTEGR)”以及“同日扣除核对”的描述需要修订。**这是方案接口假设不准确，不是据此认定官方模型漏氮。**

首选保留官方时序，增加带日期的待结算吸氮账本 `P_pending`，冻结最终逐层通量，下一次RATE核对实际扣除。不要为追求字面同日而全局重排SOIL/SPAM/PLANT，也不要再手工扣一次土壤。

在“植株已入账、土壤尚未扣除”的日末，联合库存应写成：

`N_combined = N_soil_book + N_plant_org + QNO3 + QNH4 - P_pending`。

否则把同一批氮同时算在土壤与植株。季末未结算通量、最后一个生长日以及处理切换需要运行时追踪后确定最终结账办法；不能默默清零或只检查土壤自身打印的Balance。

### A02：实际吸水与土壤含水率必须取同一时间截面（P0阻断项）

[SPAM.for:435](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/SPAM/SPAM.for:435) 调用XTRACT得到实际RWU；[SPAM.for:454](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/SPAM/SPAM.for:454) 保存到 `SPAM/UH2O`，单位cm/d。这条接口可用。

但在PLANT(INTEGR)读取它时，SOIL(INTEGR)已经更新过SW。直接用此时SW计算 `NO3*BD/SW`，可能把RATE的吸水与积分后的水浓度组合。应在RATE保存对应SW、NO3_plant/NH4_plant、根长及日期快照，或明确定义并验证平均态近似。原方案要求“时序一致”是对的，现有伪代码尚未真正落实。

`SUM(RWU)=EP/10`需带运行、日期、模式标记，不能只检查数组非负。无水模拟、未出苗或缓存过期时，新根模式宜明确报错；若提供显式回退，必须在收据中标为回退，不能当作R2试验结果。

### A03：全株Q库还不能直接解释茎、叶NO3及总N（P1阻断项）

全株等效Q可用于整株吸收—同化预算，**不能独自给出叶片与茎的无机氮浓度**。同样一个Q，分布在根、茎或叶，会产生不同的器官观测结果。

需在接入器官N观测前选择并记录一种最低限度映射：全株Q附带守恒的器官分配权重，或根/茎/叶等效子库。前者参数更少，但必须标明是等效分配假设；不能把整株Q分别全量加到每个器官上。

此映射同时决定初始Q、打叶/衰老/采收外流和最终残体N。若尚不具备映射，阶段结果只能解释全株等效Q，不比较器官NO3，也不能宣称完整满足茎叶氮浓度目标。

### A04：动态库容缩小的处理尚未闭合（P1阻断项）

`Qmax=qmax*Wref`在落叶、根死亡或摘叶后下降。原文允许暂记潜在超额，适用于开发诊断，**不满足最终“零超库容”验收**。

建议根据明确的器官分配，将脱落组织携带的无机氮记入相应残体，采收带出计入外部移除；剩余库存再判断是否可同化。不能为了腾空间额外强迫同化，尤其在低碳情形。也不能用 `Q=min(Q,Qmax)` 丢弃超额。若选用短暂容量松弛，需作为显式新模型假设而非隐藏容差。

`Wref`与qmax的干重口径须统一。无机N对应的硝酸盐及伴随离子不应乘6.25冒充蛋白干物质；若首版干物质仍沿用原有组成近似，应报告这一近似对器官干重与浓度分母的潜在影响。不能只因N账平衡就宣称全部干物质/离子质量机制完备。

### A05：有机氮接纳容量不能仅由DEMAND预测值保证（P2阻断项）

DEMAND是在当日同化、再转运和实际生长碳消耗全部结算前预测需求。`Dnew+Dold+Dreserve`需要核查是否含有同一个回补空间，不能凭名称相加。

有限同化若先花完碳，后续生长量下降，真实器官接纳量也会变小；再转运又可能先填满该空间。只用DEMAND预测截断A，仍可能最终出现TNLEAK。需采用“候选同化—成本—实际分配接受量”的一致性求解/有限回调；未被接受的NO3应留在Q，而不是已付碳成本后丢弃或无记录退回。

原版 [VEGGR.for:441](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/VEGGR.for:441) 在NLEFT超过NDMOLD时累加TNLEAK。其 [SEASINIT清零](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/VEGGR.for:198)、日内 `TNLEAK=TNLEAK+NLEAK` 及 [PlantNBal最终使用方式](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/PlantNBal.for:111) 表明它是累计量，虽然变量注释写着日通量。**每日损失应取累计量差分，不能每天把整个TNLEAK加入新日预算。**

### A06：同化、再转运与后续生长成本需要一个共享碳预算（P2阻断项）

v2将RSPNO3/RSPNH4从吸收量改为同化量，方向正确；但不能只改这一处。

- [CROPGRO.for:1000](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/CROPGRO.for:1000) 是当日还原/合成相关成本。
- [CROPGRO.for:1047](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/CROPGRO.for:1047) 附近另扣再转运蛋白重合成成本。
- [CROPGRO.for:1229](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/CROPGRO.for:1229) 根据来源加权RPROAV，供下一日潜在组织生产成本使用。

更换来源分母为NASSIMD相关供给是必要条件；仍需核对种子N、固氮、实际动员量和使用时刻。不能把NO3与NH4各自都按完整PGAVL限额计算，也不能用MAX(0,PGAVL-cost)掩盖超支。若根膜主动运输仍使用有效Vmax而无显式能量账，就应声明其碳成本是隐含近似；不能再随意添加一笔与RNO3C重叠的ATP成本。

### A07：现有输入是MEPHO=L，只改PHOTO(C)不会覆盖实际工作配置（反馈阶段阻断项）

本次冻结26SP输入的原生输出写明 `PHOTO:L`，`WATER:Y`、`NITROGEN:Y`。实际配置从 [CROPGRO.for:748](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/Plant/CROPGRO/CROPGRO.for:748) 读取SPAM给出的AGEFAC和PG，而非调用PHOTO(C)。

[ETPHOT.for:205](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/SPAM/ETPHOT.for:205) 读取PLANT/RNITP；[ETPHR.for:537](D:/Tomato_Cal/subprojects/critical_n/dssat_csm_os_4864/SPAM/ETPHR.for:537) 已有叶氮响应。因此M1可沿用原L路线，新反馈阶段必须优先核查并覆盖L路线中光合能力、气孔/蒸腾与氮状态的相互作用。不能悄悄改成C来使补丁生效并把差异全部归因于氮机制。

有机氮也不全部等于功能光合蛋白N，尤其存在氨基酸等有机储备时。新Q分离能避免NO3直接增益，但不能据此宣称已精准模拟Rubisco-N。应保留功能叶氮/叶面积这一后续检验方向，先用现有实际路线诊断是否仍存在“缩叶保持高单位面积氮、光合不分离”。

### A08：器官三条参考曲线没有被v2自动实现（曲线阶段阻断项）

v2的 `Ncrit,leaf=g(Wleaf,LAI,s)` 尚是占位函数；也未给出茎对应的Nmin/Ncrit/Nmax及与有机库容的联系。因此仅完成R2+Q+有限同化，**还不能声称完成用户要求的茎、叶生物量相关参考浓度及上下参考带**。

建议单列曲线实施单元：

1. 叶、茎分别规定浓度分母、驱动生物量、N分析口径；不能将整株Nc直接当叶片有机Nc。
2. 优先比较简约幂律 `Nc=a*max(W,W0)^(-b)`，小生物量平台阈值若采用用户所述1 t/ha，必须说明是哪一种W。结构/残余参考与富余参考可与Nc联动，但先验证曲线顺序及可识别性。
3. `Nmin_ref<Ncrit_ref<Nmax_ref`是参照体系的顺序要求；实际器官N不投影回参考带。物质非负及已定义真实库存容量仍为硬边界。
4. 常规NNI=`N/Ncrit`、扣除最低参考后的功能指数 `(N-Nmin)/(Ncrit-Nmin)` 和无机池占用度是三个不同量，分别命名与输出；不继续混称“统一NNI”而改变刻度。
5. PROLFI/PROSTI还参与组织化学组成与生长碳成本，不能为获得动态曲线而全局覆盖这些参数。优先新增独立参考曲线变量，再按已验证的作用位置接入需求/储备。
6. 对连续采果、打叶，不能默认将历史累计采果与站存茎叶质量等价。至少比较站存营养器官质量与能维持采收连续性的代理量，并明确代理对应的生理假设。

曲线核函数和诊断可提前准备；曲线生理反馈应在Q/同化预算稳定后逐项启用。全株Nc的已有拟合常数不能直接搬作叶/茎“有机氮”曲线的已知参数。

### A09：NH4旧潜力分支需拆出，不能调用整套NUPTAK再丢弃NO3（根阶段阻断项）

官方NUPTAK对两种形态使用共同需求缩放。若新NO3模式仍调用旧NUPTAK，只保留其UNH4结果，NH4可能已经受到旧NO3竞争与ANDEM截断，违背新模式定义。

推荐在新模块内复用经过核对的**NH4物种潜在能力公式**，再统一结算实际NH4库容、同化能力与土壤库存。旧NUPTAK的Mode 0原分支保持不变，不通过全局修改旧函数来迎合新路线。

### A10：参数与验证范围必须服从当前数据和用户约束（进入率定前阻断项）

- 茄子继续使用TMGRO048；无需先做新的番茄/甜椒本地化项目。
- 当前只以26SP为拟合研究范围，不把25秋或跨季节适用性作为前置。可做同季处理留出及受控事件检验，但不能把它写成跨季节外部验证。
- 不加入分季/关键日期生长护栏。真实生理状态或连续物候函数与人为日期护栏必须区分。
- SPAD、LI-6400、荧光、茎粗等不新增为率定目标。可核查机理文献与诊断，不能仅为了“识别参数”就违反既有观测契约；是否存在可直接对应的观测另行核对。
- 7月17日茎叶N保留诊断；果实氮对照当天独立采摘的商品成熟果实；产量仍采用鲜重。
- 硫酸消煮观测不能未经方法核实当作纯有机N或完全全N。TKN对硝态N不保证定量回收。[UC Davis方法515](https://anlaborders.ucdavis.edu/analysis/Plant/515)

## 5. 已核对的量纲与R2求解边界

以下v2换算正确，可作为下一步原生核函数测试的手算标准：

| 项目 | 换算/例子 |
|---|---|
| 土壤NO3等效溶液浓度 | `Cbulk=NO3[mg/kg]*BD[kg/L]/SW`，得mg N/L |
| 质流候选供应 | `FMF=0.01*RWU[cm/d]*Cbulk[mg/L]`，得g N/m²/d |
| 手算质流 | `RWU=0.3,Cbulk=72.8 → FMF=0.2184 g N/m²/d` |
| 层NO3总质量 | `0.01*BD*DLAYR*NO3`，得g N/m²；1.3×20×14×0.01=3.64 |
| 土层根长 | `100*RLV*DLAYR`，得m root/m² ground |
| 返回土壤吸收 | `UNO3/UNH4[kg/ha]=U[g/m²]*10` |
| 膜供应和扩散 | Vmax必须按每米根长；KD是有效传质导度，不是自由水扩散系数 |

R2的分段解在单调米氏式、非负参数下可用有界二分法。只有当 `V(Cbulk)>FMF` 才进入根表浓度求解；另一分支的Cr=Cbulk是有效上限近似，不模拟根表富集。候选解之后仍需全株接纳限幅，此时Cr只代表限幅前潜在解，诊断不得再称其满足“最终实际吸收”根表平衡，除非重新求解。

需覆盖零根、零NO3、零RWU、KD=0、干土、库满、土层顺序互换，以及1/2/4子步收敛。内部子步不可让同一天的RWU或剩余土壤氮被各子步重复全量使用。
