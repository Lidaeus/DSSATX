# F5 现有组织氮回补方案执行报告

在 `research/root-n-4864` 上，从 `06c1429c` 开始实施。用与 80×4 归档 SHA-256 一致的私有 26SP 输入复跑 W1/W2/W3 × N0–N3，共 12 个处理。所有试验冻结归档最佳成员的 CUL、ECO 和 SPE。

## 实施取舍

| 指南建议 | 决定及理由 |
| --- | --- |
| 用日初无机库填充率调节现有叶、茎的回补目标 | 采用。开启 `refill_substrate_target=1` 后，叶和茎的回补目标在 `ccrit` 与 `cmax` 之间按归一化的米氏函数插值。空库端仍给临界氮修复留空间，满库端可达到原目标。根组织沿用原回补目标。 |

| 给全株同化附加有机氮富余反馈 | 未采用。同化同时供应新生组织和果实灌浆，第一轮只改现有组织回补的条件。 |

## 复跑方法

从仓库根目录运行。将 `f5_experiment` 指向 80×4 率定所用的原始私有试验包，并激活包含率定依赖的 Python 环境。以下命令使用新输出目录。

```sh
f5_trial=build/f5-trial
f5_engine=build/refill-f5/engine/bin/dscsm048
f5_archive_input=build/26sp-full-joint-80x4-input/inputs
f5_reference=build/26sp-full-joint-80x4-native

python research/calibration/f5_26sp.py prepare \
  --experiment "$f5_experiment" --inputs "$f5_archive_input" \
  --out "$f5_trial/stage"

python research/calibration/ies.py \
  --engine "$f5_engine" --inputs "$f5_trial/stage/inputs" \
  --template "$f5_trial/stage/NIntegration.nml.tpl" \
  --bounds "$f5_trial/stage/bounds.csv" \
  --observations "$f5_trial/stage/observations.csv" \
  --members 32 --updates 2 --workers 8 --seed 20261124 \
  --pestpp-ies pestpp-ies --out "$f5_trial/ies"

python research/calibration/replay.py \
  --case "$f5_trial/ies" --out "$f5_trial/replay"

python research/calibration/f5_26sp.py compare \
  --engine "$f5_engine" --stage "$f5_trial/stage" --reference "$f5_reference" \
  --posterior "$f5_trial/replay/configs/NIntegration.nml" --out "$f5_trial/complete"
```

如只需验证对照及 F5/F6，省略最后一条命令中的 `--posterior`。组合级数据写到 `treatment_summary.csv`，保留 12 个处理的季末鲜果、峰值 LAI、6 月 29 日茎叶氮、季节吸氮和花前 `psi=1` 天数。`receipt.json` 保存参数文件哈希、回归结果、守恒审计与门槛判定。各重跑目录的 `paired_holdout.csv` 和 `paired_stage2b_observations.csv` 保留独立核对所需的观测及模拟结果。
