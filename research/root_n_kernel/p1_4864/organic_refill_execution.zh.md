# 26SP 茎叶有机氮回补与根吸供给执行报告

基于 `790a5cec` 的 80×4 最优成员 4，新增两项默认关闭的 B4 有机氮回补设置。
11 组全季复跑均通过碳氮守恒审计。扩大回补空间能增加茎叶有机氮存量，
同时使花前 `day_psi` 饱和更早。根吸倍率与无机库容的联合对照能扩大实际吸氮差异，
鲜果梯度仍未达到基线验收要求。[80×4 冻结参数与诊断](../../calibration/results/26sp_80x4/README.md)

## 原实现核查

- 原田间输入的 W3，N1/N2/N3 季节硝态膜候选量为 739/1,627/2,317 kg N/ha，
  实际总吸氮为 265.2/278.2/278.7 kg N/ha，硝态氮同化为
  251.6/253.6/253.1 kg N/ha。差异主要在候选吸收进入持久无机库与实际同化的
  过程中缩小。候选量是模型潜力，单位可与实际吸收并列，不能直接当成可提取土壤库存。
- W3 季均硝态库为 3.84/5.19/5.32 kg N/ha。均值从 N1 到 N2 上升约 35%，
  N2 到 N3 仅增加约 2.5%。其季平均库容比例为 70%/81%/83%。膜反馈均值约
  0.84，三处理相差小于 0.004。以日末名义库容作分母，硝态候选量与库容比值
  ≥3 的日期占比为 33%/45%/87%。该比值是入口饱和程度的近似诊断。
- W3 三处理季均叶 NNI 为 1.245/1.261/1.265，`max_ratio=1.2267`。
  单器官叶 NNI 与茎叶加权后截断的 `day_psi` 属于不同口径。用原生开花日期
  `ADAT` 核对，三处理花前各有 27 天 `day_psi=1`。该现象说明原有
  状态信号发生截断。器官浓度受生长、分配和再转运影响，既有 `cmax`
  约束回补目标和状态归一化。

## 建议逐项决策

| 建议 | 执行决定与理由 |
| --- | --- |
| 固定叶、茎储氮密度，并把 `cmax` 从稀释曲线全局解耦 | **部分接受。** 试验配置 `org_reserve_cap=0.015,0.010` 只改变 `NI_REFILL` 的受体目标，按 `ccrit+org_reserve_cap` 计算。保留原始 `cmax`、新生组织目标和需求预测口径，避免同一次调整重标定 `day_psi`、根膜反馈及生殖前的同化碳预算。这个值表征回补空间，整个器官仍沿既有质量账动态演化。 |
| 以 `refill_tau` 对奢侈填充限速 | **接受为独立研究开关。** `4 d` 对应约 22.1% 的单日奢侈回补比例。启用时先分配叶茎功能修复及原有根修复，再用剩余氮渐进填充叶茎奢侈区。额外部分仍走既有退款和退库链。单开限速使 W3 N1 的正饱和日从 82 降到 74，但花前饱和从 27 升到 28 天，鲜果倒挂加深。 |
| 参数为零时保留基线及蛋白分母校验 | **接受。** 两项默认零。选项只开放给持久无机库 B4，拒绝和有机储备对照、共同接受及晚段奢侈路线叠加。检查最小生物量处的最大回补目标小于 0.12 g N/g DM，给蛋白质量分母 `1−target/0.16` 留出余量。 |
| 下调根吸倍率以打开根际供给梯度 | **接受为受控敏感性试验。** 从冻结点 1.56375 向下测试 0.6 和 0.9。0.6 明显缓解入口饱和，但放大鲜果倒挂。0.9 在 W2/W3 修正鲜果增量方向，绝对增量仍很小。当前数据支持保留 0.9 作为下一轮对照点，尚不足以重定物理参数范围。 |
| 将 `q_no3_max` 提高到约 0.008 | **接受 0.006 和 0.008 为扫描点。** 容量扩展缓解入口饱和并增加实际吸氮，也使 W3 的日初 `psi` 季均值提高。现有实验缺少组织硝态氮的独立库容测定，生产上限仍取冻结值 0.00499。 |
| 借 V15 S1 的 `D_max`、储备反馈和速率规则重接供给 | **本轮暂缓。** 保留当前 A 臂的膜动力学、库存接收函数和 `pool_beta=0.20754`。独立回补试验由当前 B4 受体方程实现。根吸、被接受供给和同化周转已能用同底盘对照单独归因，移植另一套反馈还需区分有机储备与无机持久库的贡献。 |
| 叶茎总氮算子加入 `r_NO3`、`r_NH4` | **接受为诊断，暂缓进入 IES。** `organ_n_diagnostics.csv` 输出有机氮、硝态 N、铵态 N 及全回收端点，分母用同期器官干重。`leaf_n_observation_envelope.csv` 对齐原观测日期。`PlantNIntegration.csv` 已含器官分摊量，因此复用现成字段。分摊值是模型代理，消煮的分形态回收率尚无独立证据。 |
| 维持原生有机账与 7 月 17 日诊断用途 | **接受。** 诊断算子放在复跑输出层，模型有机账、原生 `LN%D/SN%D`、IES 权重和留出划分沿用冻结口径。 |

## 统一土壤下的对照结果

统一采用 W2–N2 的土壤剖面和初始条件，水、氮管理沿各处理记录。下表每栏依次为
**N2−N1 总实吸、N3−N2 总实吸**（kg N/ha）及 **N2−N1 鲜果**（t/ha）。
回补量的观测效应与层账同化、季末浓度一起核对。

| 两开关为零 | +4.31 / +0.07 / −0.285 | +9.94 / +0.48 / −0.332 |
| 仅固定回补容量 | +5.23 / +0.04 / −0.204 | +12.24 / +0.30 / −0.272 |
| 仅 4 d 限速 | +2.98 / −0.17 / −0.662 | +7.68 / +0.14 / −0.850 |
| 固定容量 + 4 d | +5.21 / +0.13 / −0.383 | +12.25 / +0.33 / −0.452 |
| 根吸倍率 0.60 | +6.76 / +1.91 / −0.643 | +11.73 / +2.64 / −0.501 |
| 根吸倍率 0.90 | +5.63 / +0.66 / +0.323 | +10.96 / +1.32 / +0.244 |

W3 同时启用固定容量和限速时，季末叶有机氮由 3.94/4.08/4.10% 升至
4.23/4.36/4.37%，茎由 2.01/2.07/2.09% 升至 2.30/2.38/2.39%。
整体水平抬升，N2 到 N3 的差仍很小，花前饱和日由 27 增至 31 天。
根吸倍率 0.75 与库容 0.008 的组合把 W3 候选量/库容近似比值 ≥3 的日期占比
从 33%/44%/79% 压至 0%/4%/15%，花前饱和仍为 27 天。实测 W2/W3 的
N2−N1 鲜果增量为 7.240/6.561 t/ha，根吸倍率 0.90 的修正只达到
0.323/0.244 t/ha。保留这些对照用于定位生殖分配和营养生长的限制。

## 含氮观测口径与回归

| 叶氮观测集 | 数量 | 模拟无机氮贡献中位数（百分点） | 有机氮 RMSE | 全无机回收端点 RMSE |

| 零权重诊断 | 16 | 0.436 | 0.635 | 0.787 |
| N1 保留 | 8 | 0.312 | 0.409 | 0.648 |
| N3 保留 | 12 | 0.468 | 0.372 | 0.648 |

全无机回收端点在四组观测上均使 RMSE 上升，因此暂留两端诊断。原生植物氮目标
用打印浓度，表中有机氮来自双精度账本浓度。

11 组各含 12 个处理，逐组核对土壤实扣、库存和碳账。最大季节植株氮残差
为 3.38×10⁻⁶ g N/m²，最大每日实际碳残差为 4.84×10⁻⁶ g CH₂O/m²，
最小氮结算 `PGAVL` 为 0.00114 g CH₂O/m²。关闭两项时，7 个诊断账本及
P0 追踪逐字节一致，3 个原生输出仅有运行时间戳差异，剔除时间戳后逐字节一致。
整季 CTest 回归通过。负时标、超过 0.12 的受体浓度及不兼容路线均触发配置校验。
