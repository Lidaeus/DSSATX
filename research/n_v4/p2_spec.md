# P2：一次共同规划、受体执行一次、统一结算

用户授权：实施一次性碳氮共同接受及叶茎有机储备子库存。工程基础为3cfd2053，
不采用P1最低Phi但重现W2倒挂的曲线组合；原版4.8.6.4修复与C1—C4预算保留。

## 配置、单位与开关

| 字段 | 默认 | 定义 |
|---|---:|---|
| common_acceptance | 0 | 1启用共同C/N规划及缓存接受；0原C4/P1路径 |
| reserve_mode | 0 | 1为叶、茎各增加一个Norg内部R标签；可单独消融 |
| reserve_capacity | -1 | 开启R时显式提供，g N/g活体承载代理；不是Nc或硬限制总浓度 |
| reserve_fill_tau | -1 | R填充时标，d；速率为1-exp(-1/tau) |
| reserve_protect | -1 | R保护量相对Nc×存活DM的比例 |
| build_min_leaf / build_min_stem | -1 | -1沿用原新组织最低组成；显式(0,1]×相应Nc，与软Nmin独立 |

完整P2要求stage5、A/C4预算、C1状态、C2动员、C3有限奢侈同化及C4叶耦合已启用。
共同接受与P1额外缩叶消融开关不能叠加，防止误以为其同时生效。
新组成比例只能在共同接受下启用。机器合法域不是率定生理先验；本轮工程值
R容量.004、填充3 d、保护.02以及组成.85/.70均未成为正式冻结边界。

## 一次性规划的实际范围

1. DEMAND照常计算发育、水分、温度和潜在器官需求；有限同化与供体仍先提供
   可撤销候选供给。候选费用不能误当成已经提交并且不可用于当日生长的支出。
2. VEGGR的内部9001准备入口只更新一次原生根冠分配和CUMTUR，并输出新组织
   潜在DM及最低/临界N组成；准备入口不运行CANOPY、不改器官库存或果实队列。
3. 纯核函数统一考虑果实潜在C/N、叶茎根新组织、存活老组织功能修复、可用N及
   所需同化费用。先保留原生果实C潜在库偏好，并为营养潜力计入自身同化成本；
   N不足时按共同可接受比例分担，而不是让果实先拿走全部N。这里不是无优先级
   的数学最优化，也没有把所有原生队列改成代谢网络。
4. 同化费用按候选NO3/NH4实际组成的加权单价进入C预算。64次二分仅为纯核函数
   内部的标量求解，不反复调用有SAVE状态的生理过程。未接受的同化预留在受体
   执行前取消，底物留在Q；已提交有机N不逆向转成NO3。
5. PODS在已接受额度内执行一次。新花/果数量的潜在源指标保留原生发育含义，
   不把不存在的当前果实生长需求当成禁止第一次开花的条件；实际果实DM/N/C
   仍必须受当日共同额度限制，原生果实N组成函数未更改。
6. VEGGR的实际入口使用缓存DM/N及其组成成本，不再运行旧NRATIO与额外浓度
   门控的连乘。CSAVE仅能保留未被接受生长占用的C；CANOPY只执行一次。
7. 功能修复的实际接受上限由共同计划和C4实际存活受体共同限制。生长以后剩余
   碳可支持有机R填充，但不能再解一次生长或追加第二批功能修复。
8. 原生受体实际使用少于预测时，取消未用供体/同化预留，按C4实际支付结算。
   不事后裁剪果实队列或凭空恢复面积。供体候选再合成费用仍先预扣、最终按实际
   使用退款；本阶段未宣称完成所有内部源价格的全局最优选择。

新组织组成与器官软Nmin是不同量；新组织质量守恒不能保证整个老器官始终处于
参考带内。无日期生长护栏、固定产量排序或高N额外SLA/库强增幅。

## R子库存与亲本库存

器官总氮`Ntot=QNO3+QNH4+Norg`；叶、茎内部`Norg=R+Nnonreserve`。
R不额外加入Norg，不额外创建DM；其填充已包含在原生NAD和有限同化费用内。
沿用原生蛋白当量N/.16与相应成本，不能称为逐一化学定义的游离氨基酸池。

R从0开始、各处理重置。只有真实提交的、功能需求满足后的剩余同化N可填充。
新填充受名义容量、软目标空间及有限速率限制；软目标下降不投影已有R或Norg。
当日旧库被释放时不再同库补充。

先回收正常衰老材料，随后R按remob_tau有限释放；严重缺N时再允许保护量以上
的健康功能蛋白缓慢动员。健康功能蛋白只支撑实际新生长，不能为修复自身而
无意义抽提再合成。R和健康功能库存互斥，原有根/果壳供体路线保留。

正常衰老中R分为实际回收与随残体离开；新的填充进入存活受体，不二次损失。
`Rend=Rbegin-Rfast-Rsen_recovery-Rlitter+Rfill`逐日独立检查。未使用的候选释放
先取消，提交时才改变R。填充/修复受体使用C4损失和已回收蛋白校正后的真实存活质量。

生长软状态和RNITP使用Norg-R，实测对应的原生器官N浓度仍用Norg，Q与总氮另列。
冠层分层积分对应实际传入的非储备氮，储备不自动成为Rubisco或同比增加光合。
Nnonreserve仍是功能代理，不是真实蛋白组；非光合保护量仍需后续机制检验。

## 接口与验证

`PlantNP2.csv`公开共同请求/额度/实际使用、调用次数、组成、费用、R库存与全部去向。
同化预留和实际费用仍由PlantNIntegration/PlantNLuxury/PlantCCash联合审计。
所有预算使用既有容差；增加功能修复为合法N受体有明确的实际NAD证据，不是放宽容差。

运行入口：`p2_workflow.py prepare`，编译，`deliver --revision r5`，`units`，`all`，
`build-cases`，`guards`，`mode0`及`case --trace`；最后`analyze_p2.py r5`。
已经存在的案例/构建拒绝覆盖。r0—r4过程记录保留，不把调试结果混为最终r5。
无实际受体时所有可撤销供体明确归零，避免float32求和尾差变成微小的R输出。

R模块生命周期驱动是11个受控模块步，验证填充、给定外源有机供给缺口下的实际
快速释放、取消未用释放、正常衰老损失与重置。它不是全作物供氮中断试验；
当前田间回放没有出现快速R输出，不能据此宣称缓冲作用已被田间数据验证。

目标仍是26SP同612个直接观测；不改同日商品成熟果N采样对象。未进行新率定，
新参数未自动接入主PEST模板、活动注册或冻结边界。全元素化学C尚未完全闭合；
通过CH2O/N/蛋白当量DM预算不等于论文独立验证或管理适用性验证。
