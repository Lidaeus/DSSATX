>
> 适用季节：2025 春、2025 秋、2026 春（茄子）
> 对应自动生成脚本：`generate_dssat_all_seasons.py`
> 本文档把脚本里的计算口径，逐条翻译成可在 Excel 里手动复现的鼠标/公式操作，方便在没有 Python 环境时也能得到与脚本完全一致的 `*.TMA`（File A）与 `*.TMT`（File T）。

## 0. 先读懂：File A 与 File T 到底是什么

| 文件 | 文件后缀 | 每行含义 | 固定列 |
|------|----------|----------|--------|
| **File T**（时间序列观测） | `*.TMT` | **某小区（TRNO）在某天（DATE）的一次观测** | `@TRNO  DATE  LAID  SWAD  LWAD CHFPW CHPDT  SNAD  LNAD` |
| **File A**（最终汇总） | `*.TMA` | **某小区（TRNO）一季的收尾值** | `@TRNO  HWAH HWAHF  LAIX  LWAM  SNAM  HDAT` |

**DSSAT 列代码对照表（必须背下来）**

| 代码 | 含义 | 单位 | 取值规则 |
|------|------|------|----------|
| `TRNO` | 小区号（= 处理号） | — | 1, 2, 3 …，本数据集即小区号 |
| `DATE` | 观测日期 | `YYDDD`（年+儒略日） | 如 `2025-10-02` → `25275` |
| `LAID` | 当日叶面积指数 | m²/m² | 当日该小区各重复 LAI 的平均值 |
| `SWAD` | 当日**茎**干重 | kg/ha | 茎干重(g/株) × 密度 / 1000 |
| `LWAD` | 当日**叶**干重 | kg/ha | 叶干重(g/株) × 密度 / 1000 |
| `CHFPW` | 截至当日**累计鲜果产量** | kg/ha | 仅在**实际采收日**填，其它日 -99 |
| `CHPDT` | 截至当日**累计干果产量** | kg/ha | 仅在**实际采收日**填，其它日 -99 |
| `SNAD` | 当日**茎**含氮量 | kg N/ha | 茎干重 × 茎全氮(mg/g) / 1000 |
| `LNAD` | 当日**叶**含氮量 | kg N/ha | 叶干重 × 叶全氮(mg/g) / 1000 |
| `HWAH` | 最终累计**干**果产量 | kg/ha | = 该小区最后一次采收的 `CHPDT` |
| `HWAHF` | 最终累计**鲜**果产量 | kg/ha | = 该小区最后一次采收的 `CHFPW` |
| `LAIX` | 全季最大 LAI | m²/m² | = 该小区所有 `LAID` 的最大值 |
| `LWAM` | 最终一次观测的叶干重 | kg/ha | = 最后一个观测日的 `LWAD` |
| `SNAM` | 最终一次观测的茎含氮量 | kg N/ha | = 最后一次有 SNAD 的观测日值 |
| `HDAT` | 最后一次采收日期 | `YYDDD` | 该小区最晚的采收日 |

**核心约定（脚本里强制执行，Excel 里也要遵守）**

1. **小区内重复取平均**：同一 `日期 + 小区` 下若有多行（多株/多行重复），全部 `LAID/SWAD/LWAD/SNAD/LNAD` 先求平均再写一行。
2. **CHFPW / CHPDT 只能在采收日出现**，其它日必须留空（输出时填 `-99`）。
3. **累计产量只能递增**：相邻两次采收，鲜/干累计都必须比上一次大，不允许下降或相等。
4. **缺失值统一用 `-99`**，日期统一写成 `YYDDD`（2 位年 + 3 位儒略日）。
5. **不输出** `HWAD/FWAD/CWAD/FRNAD/CNAD/CWAM/CNAM/FRNAM`（留株果实取样误差太大，脚本里主动放弃）。
6. **种植密度统一 27000 株/ha**；换算公式：`kg/ha = g/株 × 27000 / 1000 = g/株 × 27`。

## 1. 通用准备工作（三季都要先做）

### 1.1 建一个总工作簿
新建一个 Excel 文件 `DSSAT手工整理.xlsx`，按季节建如下工作表标签：

```
2025春-生长 | 2025春-产量 | 2025春-FileT | 2025春-FileA
2025秋-生长 | 2025秋-养分 | 2025秋-产量 | 2025秋-DM筛选 | 2025秋-FileT | 2025秋-FileA
2026春-产量 | 2026春-品质 | 2026春-生长 | 2026春-FileT | 2026春-FileA
```

### 1.2 准备一个"日期转 YYDDD"辅助列
DSSAT 要求日期写成 `YYDDD`。在任意数据表的最后加一列 `DATE_YYDDD`，用公式：

```
=TEXT(A2,"yy") & TEXT(A2-DATE(YEAR(A2),1,0),"000")
```

> 解释：`TEXT(A2,"yy")` 取 2 位年；`A2-DATE(YEAR(A2),1,0)` 算出该天是当年的第几天（儒略日），再用 `"000"` 补成 3 位。
> 例：`2025-10-02` → 第 275 天 → `25275`。

### 1.3 准备"密度换算"参数
随便找个空白单元格（例如 `参数!B1`）写入 `27000`，命名其为 `密度`。后面所有 g/株 → kg/ha 换算都用 `=单元格 * 27`。

## 2. 2025 春季（数据已基本就绪，最简单）

源文件：`2025春/2025年春茄子DSSAT数据集_累积数据_含完整生物量含氮量和DSSAT格式.csv`。
特点：**源表里 `公顷产量`、`公顷成熟果干重`、`SWAD`、`LWAD`、`公顷茎含氮量`、`公顷叶含氮量` 已经是 kg/ha 单位，且产量已是累计值**，所以几乎不用换算。

### 2.1 导入 CSV
`数据` → `从文本/CSV` → 选上面的 CSV → 分隔符选逗号 → 加载到 `2025春-生长` 表。

### 2.2 整理"生长/养分"观测行（用于 File T 的 LAID/SWAD/LWAD/SNAD/LNAD）

1. 复制原表到一个新区域，只保留列：`日期、小区号、重复、LAI、SWAD、LWAD、公顷茎含氮量、公顷叶含氮量`。
2. 加筛选：`数据` → `筛选`。
3. **只保留至少有一个生长指标的行**：在 `SWAD/LWAD/LAI` 三列里，把三列都为空的行删掉（脚本里 `.notna().any(axis=1)`）。
4. **按"日期 + 小区号"汇总平均**：
   - 方法 A（推荐，用数据透视表）：行 = `日期` → `小区号`；值 = `LAI/SWAD/LWAD/公顷茎含氮量/公顷叶含氮量`（全部"平均值"）。
   - 方法 B（公式）：`=AVERAGEIFS(源!E:E, 源!A:A, 日期, 源!B:B, 小区号)`。
5. 把结果列名改为 DSSAT 名：`LAI→LAID`、`SWAD→SWAD`、`LWAD→LWAD`、`公顷茎含氮量→SNAD`、`公顷叶含氮量→LNAD`。

### 2.3 整理"产量"行（用于 File T 的 CHFPW/CHPDT）

1. 再复制原表到另一区域，只保留 `日期、小区号、公顷产量、公顷成熟果干重`。
2. 删除 `公顷产量` 与 `公顷成熟果干重` **同时为空** 的行。
3. 按 `日期 + 小区号` 透视，值取平均值，列名改为 `CHFPW`（鲜）、`CHHPDT`→`CHPDT`（干）。
4. **验证累计递增**：按 `小区号、日期` 升序排序，对每个小区检查 `CHFPW`、`CHPDT` 的相邻差必须 `>0`。可在旁边加辅助列：
   ```
   =IF(A2<>A1, "", IF(C2>C1, "OK", "⚠️下降"))
   ```
   若出现 ⚠️，需回源数据核对（脚本里遇到会直接报错）。

### 2.4 合成 2025 春 File T
在 `2025春-FileT` 表里：

1. 把第 2.2 节的生长行和第 2.3 节的产量行**上下拼起来**（列对齐成 9 列：`TRNO、DATE、LAID、SWAD、LWAD、CHFPW、CHPDT、SNAD、LNAD`）。
2. 关键：**同一 (TRNO, DATE) 要合并成一行**。
   - 用 `=SUMIFS`/`VLOOKUP` 或者再透视一次：行 = `日期+小区`，每个指标用 `平均值`，缺失的自动为空。
   - 脚本里用的是"取第一个非空值"，对这套数据等价于平均值（因为同一天同一指标只在一类行里出现）。
3. 按列顺序排好：`TRNO  DATE  LAID  SWAD  LWAD  CHFPW  CHPDT  SNAD  LNAD`。
4. **把所有空格填 -99**：选中数据区 → `Ctrl+H` → 查找留空、替换 `-99`（注意选项里勾"匹配整个单元格"）。或加公式 `=IF(单元格="","-99",单元格)`。
5. **DATE 列用 §1.2 的 YYDDD 公式转好**。
6. 排序：先按 `TRNO`，再按 `DATE`，都升序。

### 2.5 生成 2025 春 File A
在 `2025春-FileA` 表里，一行一个小区（TRNO 1…16）。逐列：

| 列 | Excel 公式思路 |
|----|----------------|
| `TRNO` | 手填 1, 2, …, 16 |
| `HWAH` | 该小区**最后一个采收日**的 `CHPDT`：`=LOOKUP(2,1/(FileT!$A:$A=A2),FileT!$G:$G)`（取该 TRNO 最后一行的 CHPDT） |
| `HWAHF` | 同上，取最后一行的 `CHFPW`：`=LOOKUP(2,1/(FileT!$A:$A=A2),FileT!$F:$F)` |
| `LAIX` | 该小区所有 `LAID` 的最大值：`=MAXIFS(FileT!$C:$C,FileT!$A:$A,A2)` |
| `LWAM` | 该小区**最后一次生长观测日**的 `LWAD`（= 排序后最后一行的 LWAD）：`=LOOKUP(2,1/((FileT!$A:$A=A2)*(FileT!$D:$D<>"")),FileT!$D:$D)` |
| `SNAM` | 该小区**最后一次含 SNAD 的观测日**的 `SNAD`：`=LOOKUP(2,1/((FileT!$A:$A=A2)*(FileT!$H:$H<>"")),FileT!$H:$H)` |
| `HDAT` | 该小区最后一次采收日的 YYDDD：`=LOOKUP(2,1/((FileT!$A:$A=A2)*(FileT!$F:$F<>"")),FileT!$B:$B)` |

> `LOOKUP(2, 1/(条件), 返回列)` 是经典的"取最后一个满足条件行"的写法，要求数据已按日期升序排好。

## 3. 2025 秋季（最复杂，需要 DM 筛选）

源文件（都在 `2025秋/`）：
- 生长：`2025年秋季茄子生长指标集.xlsx`（列：日期、小区、行号、茎干重、叶干重、果鲜重、果干重、LAI …）
- 养分：`2025年秋季茄子植株样氮磷钾测定.xlsx`（列：取样日期、取样部位、小区号、重复、全氮(mg/g) …）
- 产量：`2025秋季产量集.xlsx`（列：日期、小区号、重复、小区棵数、行果实总重、小区果实总重、小区产量 …）

### 3.1 导入三张表
分别加载到 `2025秋-生长`、`2025秋-养分`、`2025秋-产量`，只保留脚本里用到的列（见上）。

### 3.2 校验源数据一致性（脚本里强制做的）
1. **小区—处理映射要一致**：用三张表做"小区号、水处理、氮处理"的去重，三张结果必须完全相同。
2. **行果实总重之和 = 小区果实总重**：`=SUMIFS(产量!行果实总重, 产量!日期, D2, 产量!小区号, Q2)` 应等于同日期同小区的 `小区果实总重`。
3. **反算种植密度**：`=小区产量*1000/(小区果实总重/小区棵数)`，每个值都应 ≈ 27000（误差 ≤ 0.1%）。
4. **果鲜重/果干重成对**：两者要么都有、要么都空；不成对的要先修。

### 3.3 计算每个 (小区, 日期) 的茎/叶 kg/ha —— 用于 SWAD/LWAD
在 `2025秋-生长` 旁加列：

```
SWAD = 茎干重(g) * 27      ' 即 =密度/1000
LWAD = 叶干重(g) * 27
```

然后**按"小区+日期"透视**：`SWAD/LWAD/LAI` 取平均值，重命名 `LAI→LAID`。这给 File T 提供了所有生长日的 `LAID/SWAD/LWAD`。

### 3.4 筛选果实干物质率（DMFR）—— 最关键一步
脚本逻辑分四类样本，要在 `2025秋-DM筛选` 表里复现：

1. **候选样本**：从生长表里挑 `果鲜重>0 且 果干重非空` 的行。
2. 新增列 `DMFR = 果干重 / 果鲜重`。
3. **手动剔除 2 条已知异常**（脚本写死了这两条，必须排除）：
   - `2025-12-08，小区 2，行号 1`
   - `2026-01-10，小区 11，行号 1`
   - 加辅助列 `标记 = "user_outlier"` 标出，过滤掉。
4. **剔除果干重 < 10 g 的样本**（`min_fruit_dry_weight=10`）：加列 `标记 = "low_weight"`。
5. **按测量日期做 Tukey 1.5×IQR 离群剔除**（剩下样本内）：
   - 按 `日期` 分组，对 `DMFR` 求 `Q1`、`Q3`：
     ```
     Q1 = PERCENTILE.INC(该日所有DMFR, 0.25)
     Q3 = PERCENTILE.INC(该日所有DMFR, 0.75)
     IQR = Q3 - Q1
     下界 = Q1 - 1.5*IQR
     上界 = Q3 + 1.5*IQR
     ```
   - 不在 `[下界, 上界]` 内的标 `iqr_outlier`，剔除。
6. **聚合**（默认 `mean`）：对剩下的样本，按 `小区 + 日期` 分组，`DMFR` 取**平均值**。
   > 脚本支持 mean/median/pooled，默认 mean；如需其它，对应改成 `MEDIAN` 或 `SUM(果干重)/SUM(果鲜重)`。
7. **覆盖检查**：`2025-12-08` 与 `2026-01-10` 两个日期，筛选后必须 12 个小区全有，缺了要回查。

> 与脚本一致的结果：候选 117 条 → 剔除 user 2 条 + low_weight 49 条 + iqr 5 条 → 保留 61 条，DMFR 范围 7.02%–10.82%。

### 3.5 把采收日匹配到最近的 DMFR 测量日 —— 用于 CHFPW/CHPDT
1. 从产量表按 `日期 + 小区号` 聚合，取 `小区产量`（鲜产，kg/ha）作为该次采收的 `HARVEST_FRESH`。
2. 对每一条 (采收日, 小区)，在 DM 聚合表里找**同小区、日期最接近**的那条 `DMFR`（脚本 `nearest_by_plot`）。
   - Excel 里推荐用辅助列：
     ```
     MATCH_DAYS = ABS(采收日 - DM日)
     最近的 DMFR = INDEX(DMFR列, MATCH(MIN(MATCH_DAYS), MATCH_DAYS, 0))
     ```
   - 同小区内可能有多条 DM 日，对每条算 |差|，取最小那条。
3. 计算 `HARVEST_DRY = HARVEST_FRESH × DMFR`。
4. 按 `小区 + 采收日` 升序排，对每个小区做**累计求和**：
   ```
   CHFPW = SUMIFS(本小区及之前所有采收日的 HARVEST_FRESH)
   CHPDT = SUMIFS(本小区及之前所有采收日的 HARVEST_DRY)
   ```
   或用 `=SUM($X$2:X2)` 这种"按下拉、范围递增"的写法（数据先按 TRNO+DATE 排序）。

### 3.6 计算茎/叶含氮量 —— 用于 SNAD/LNAD
1. 把养分表（长表，按"取样部位"分茎/叶/果）**透视为宽表**：行 = `取样日期+小区号+重复`，列 = `取样部位`，值 = `全氮(mg/g)`。得到 `STEM_N`、`LEAF_N`（果的不要）。
2. 把养分表与生长表按 `小区 + 重复` 配对，养分日匹配到**最近**的生长日（拿当天的茎/叶干重）：
   ```
   SNAD = 茎干重(g) × 27 × STEM_N(mg/g) / 1000
   LNAD = 叶干重(g) × 27 × LEAF_N(mg/g) / 1000
   ```
3. 按 `小区 + 养分日` 求 `SNAD/LNAD` 的平均，得到 File T 里的氮行。

### 3.7 合成 2025 秋 File T
和 2025 春 §2.4 完全一样：
- 把"生长行"（§3.3）、"氮行"（§3.6）、"产量行"（§3.5）按列对齐（9 列）拼起来；
- 同 (TRNO, DATE) 合并取非空；
- 空格填 `-99`，DATE 转 YYDDD；
- 按 TRNO、DATE 升序排。

预期：12 小区 × 7 个观测日 = **84 行**（其中含采收数据 36 行）。

### 3.8 生成 2025 秋 File A
同 §2.5 的公式，逐列用 LOOKUP/MAXIFS 取该小区收尾值。预期 12 行。

## 4. 2026 春季（用品质表的"含水率"反推干物质率）

源文件（都在 `2026春/`）：
- 产量：`2026春产量集.xlsx → Sheet1`（列：日期、小区号、重复、小区测产棵数、小区产量、小区果实总重 …）
- 品质：`2026春品质指标集.xlsx`（3 个工作表 `20260272/20260624/20260603`，含 `半果含水率` 或 `含水率`）
- 生长：`2026春生长指标集.xlsx`（3 个工作表 `0502/0602/0629`，列名各不相同，要分别处理）

### 4.1 产量预处理 + 校验
1. 导入 `Sheet1`，把 `小区号` 转成数值（脚本里 `TRNO_NUM`），删掉非数字行。
2. **批次结构校验**：每个"采收批次"必须 12 小区 × 5 重复 = 60 行，且同一批次/小区的 `小区产量` 一致；每个批次只能对应一个日期、不同批次日期不重复。
3. 按 `日期+小区` 聚合，取 `小区产量`（鲜产）作 `HARVEST_FRESH`。
4. 反算密度校验：`=小区产量*1000/(小区果实总重/小区测产棵数)` ≈ 27000。

### 4.2 由品质表算 DMFR
1. 三个工作表都读进来合并，注意列名：
   - 有 `半果含水率` 的用 `半果含水率`；否则用 `含水率`。
2. 新增列：
   ```
   DMFR = 1 - 含水率列
   ```
3. 按 `小区 + 日期` 求 `DMFR` 平均，得到品质日的小区 DMFR。

### 4.3 配 DMFR → 算 CHFPW/CHPDT
同 §3.5：
- 每条 (采收日, 小区) 匹配最近品质日的 DMFR；
- `HARVEST_DRY = HARVEST_FRESH × DMFR`；
- 按小区对采收日累计求和得 `CHFPW/CHPDT`。

> 脚本测得：采收批次日 `20260526, 20260602, 20260609, 20260622, 20260701`；品质日 `20260603, 20260624, 20260702`，最大匹配间隔 5 天。

### 4.4 生长表（三个工作表，列名不同！）
脚本对三个工作表分别处理，Excel 里也要分开：

| 工作表 | 标识小区的列 | 含 LAI | 处理 |
|--------|--------------|--------|------|
| `0502` | `小区` | ✓ | 按 `小区+取样日期` 平均 `LAI/茎干重/叶干重` |
| `0602` | `处理` | ✓ | 按 `处理+取样日期` 平均 |
| `0629` | `处理 (Treatment)` | ✗（没测） | 按 `处理+取样日期` 平均 `茎干重/叶干重`，**LAID 留空 -99** |

1. 三张表都加列：`SWAD = 茎干重 × 27`，`LWAD = 叶干重 × 27`，`LAID = LAI`（0629 不填）。
2. 各自按"小区+日期"透视取平均。
3. 三张结果**上下拼起来**，列名统一为 `TRNO、DATE、LAID、SWAD、LWAD`。

### 4.5 2026 春没有氮数据
脚本里 `nitrogen` 为空，所以 **File T 的 SNAD/LNAD 列整列都是 `-99`**，File A 的 `SNAM` 也是 `-99`。直接整列填 `-99` 即可。

### 4.6 合成 File T / File A
同 §2.4 / §2.5。

预期：12 小区；File T 每小区约 7 个观测日（生长 2–3 个 + 采收 5 个）。

## 5. 最终输出成 DSSAT 文本格式

Excel 整理完只是"数值正确"，DSSAT 还需要固定宽度的文本文件。两种做法：

### 5.1 简单做法：导出 CSV 再手工修
1. 把 File T 数据区另存为 CSV。
2. 用记事本打开，把表头改成 DSSAT 格式（每列名固定 6 字符宽）：
   ```
   *EXP. DATA (T): 2025 FALL EGGPLANT; TRNO=PLOT NUMBER

   ! TRNO = plot number; within-plot replicates were averaged.
   ! Missing numeric values = -99; dates = YYDDD.
   ! CHFPW/CHPDT appear only on actual harvest dates.

   @TRNO  DATE  LAID  SWAD  LWAD CHFPW CHPDT  SNAD  LNAD
   ```
3. 文件名保存为 `2025FALL.TMT`（春 `2025SPR.TMT`、2026 春 `2026SPR.TMT`）。

### 5.2 推荐做法：用 Excel 公式拼出固定宽度文本
在 File T 数据区右侧加一列"输出行"，用 `TEXT` 函数把每个字段拼成 6 字符：

```
=TEXT(A2," 0")          ' TRNO，整数，占6字符右对齐
&B2_YYDDD               ' DATE 已是 5 位，前面补 1 空格
&TEXT(C2,"0.000")       ' LAID 3 位小数
&TEXT(D2,"0")           ' SWAD 整数
… 依此类推
```

> 每个字段宽度都是 6，可用 `=RIGHT("      "&值, 6)` 这种"左补空格到 6 位"的技巧。

### 5.3 文件命名对照表

| 季节 | File A 文件名 | File T 文件名 |
|------|---------------|---------------|
| 2025 春 | `2025SPR.TMA` | `2025SPR.TMT` |
| 2025 秋 | `2025FALL.TMA` | `2025FALL.TMT` |
| 2026 春 | `2026SPR.TMA` | `2026SPR.TMT` |

> `TM` 是 DSSAT 茄子（Tomato/Tomatillo 类）的两字符作物代码，可通过脚本 `--crop-code` 改。

## 附：常用 Excel 公式速查

| 目的 | 公式 |
|------|------|
| 日期转 YYDDD | `=TEXT(A2,"yy")&TEXT(A2-DATE(YEAR(A2),1,0),"000")` |
| g/株 → kg/ha（密度 27000） | `=单元格*27` |
| 同小区同日期取平均 | `=AVERAGEIFS(源!值列, 源!日期列, 条件日, 源!小区列, 条件号)` |
| 取该小区最后一行某列 | `=LOOKUP(2,1/(FileT!$A:$A=A2), FileT!$F:$F)` |
| 该小区 LAI 最大值 | `=MAXIFS(FileT!$C:$C, FileT!$A:$A, A2)` |
| 累计求和（按下拉） | `=SUM($X$2:X2)` |
| 空值替换为 -99 | `=IF(单元格="","-99",单元格)` |
| Tukey IQR 下/上界 | `=PERCENTILE.INC(范围,0.25)-1.5*(PERCENTILE.INC(范围,0.75)-PERCENTILE.INC(范围,0.25))` |
| 最近日期匹配 | 辅助列 `=ABS(目标日-候选日)` → `=INDEX(值, MATCH(MIN(辅助),辅助,0))` |
