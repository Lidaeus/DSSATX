# 果实干物质与采收养分核算：需要补充什么、为什么

更新：2026-10-09。本文件解释尚不能把鲜果产量直接换成全季N/P/K吸收量的原因，并提供可填写的补充表。茎叶干重、密度和对应重复已确认；2026年6月2日干重与6月3日NPK为同批样本，已用于站存量计算。

## 一、果实干物质依据指什么

产量表是**鲜果产量kg/ha**，NPK浓度是**mg/g果实干物质**，相乘前必须把鲜果量换成干物质量。

可以有两种依据：

1. 同批代表果实烘干前后的鲜重、干重，干物质比例`f_DM=干重/鲜重`。
2. 同批果实湿基含水率`w=水质量/鲜重`，则`f_DM=1-w`。您现有品质含水率以比例记录，换成百分数展示后，计算应使用`f_DM=1-含水率%/100`。

不要求把整批收获果实全部烘干。可以使用代表性果样的干物质比例，但需要说明它代表哪一次／哪一段采收，并能对应到处理和重复。

您的“半果”是去掉头尾后剩下的果实，属于去头尾果样，不是简单称为重量的一半。因此**不能把半果干重直接乘2**当整果干重。若剩余果肉的含水率和干基NPK可以代表整果，则可用其比例换算整果采收量，但须明确这是代表性假设；若头尾差异明显，应提供头尾比例或整果对照。现阶段半果可以作为已测果样的分析口径，不直接声称已验证整果代表性。

## 二、采收量对应的养分浓度依据指什么

不同日期采收果实的干物质比例和NPK浓度可能变化。要算每次带走多少养分，应把某次采收鲜重，与代表这批采收果实的干物质比例和浓度相配，而不是把三次浓度各自乘全季总产量后再相加。

对一次采收、一个处理和一个重复：

```text
采收干物质量（kg/ha）=当次鲜果产量（kg/ha）×f_DM
当次N/P/K移出量（kg/ha）=采收干物质量×干基浓度（mg/g）/1000
全季采收果实N/P/K移出量=各次采收移出量之和
```

例：一次鲜果产量1,000 kg/ha，含水率94%，果干基N浓度20 mg/g，则干物质量60 kg/ha，N移出量`1,000×0.06×20/1000=1.2 kg N/ha`。这是示例，不是本试验结果。P、K按相同公式，均是元素量，不再作氧化物换算。

您确认的有效采收株数和单株果数用于鲜产量及单果重的核算；它们本身不提供果实干物质比例或NPK浓度。

可采用的后续方法，由您说明真实采样设计后确定：

- **实际批次对应：** 每批采收有配套测定，直接对应，最清楚。
- **预设时期代表：** 样品代表一段采收期，把这段内的采收量乘该期果样系数，明确窗口及边界。
- **插值／最近样本：** 根据样本时间估计未测采收日，只能称模型或近似值；端点之外如何处理需另定义，不能把早期缺样自动补成可靠动态。
- **全季代表值：** 您认可少量成熟果样代表全季后，给出条件性估算与敏感性。2025只有一次果NPK，不能在这种条件下写成已测全季浓度过程。

若使用插值，应优先讨论直接插值`f_DM×C`这一单位鲜果养分系数，还是分别插值两项再相乘；两种方法并不严格相同。未决定窗口时，本轮只保留果样系数，不分配全部采收移出量。

## 四、如何汇总“全季吸收”

按您接受的近似，可以汇总：

```text
全季地上部养分累计吸收近似
 = 拉秧时茎站存量
 + 拉秧时叶站存量
 + 拉秧时仍未采果实的养分（若存在）
 + 全季已采果实累计养分移出量
```

整枝移出、脱落叶和根系暂无资料，按本次约定不补造，并在正文明确未计入。这是范围有界的估算，不是完整器官收支或直接根吸收通量。若拉秧时没有未采果，请明确填“无”；若存在而未测，不能把它记为0。

**不能把5月、6月、7月的茎叶站存量都相加。** 后一期往往包含前期仍在植株上的同一批养分，多次相加会重复计数。各期站存量可以描述过程；做末季汇总只使用末次站存量，再加已经离开植株的采收量。

该核算区分站存量、果实移出及近似累计量，与设施果菜研究中区分standing biomass和累计已采收／移出量的做法一致；本项目仍按您接受的缺项范围执行。[原始研究：站存量与累计收获量](https://pmc.ncbi.nlm.nih.gov/articles/PMC4755136/)
