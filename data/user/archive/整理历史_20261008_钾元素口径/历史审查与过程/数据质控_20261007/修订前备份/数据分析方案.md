# 五、N、P、K吸收和需肥规律

- 果实干物质量；
- 根干物质量——如果你的试验有根；

- 根TN、TP、TK含量。

计算：

\[
养分吸收量=器官干物质量\times养分含量
\]

\[
TN\ uptake(kg/ha)=Biomass\times TN/1000
\]

然后：

\[
全株TN=根TN+茎TN+叶TN+果TN
\]

P、K同理。

### 必须做的五组分析

**第一组：器官吸收动态**

分别画：

- 茎TN、叶TN、果TN、植株TN；
- 茎TP、叶TP、果TP、植株TP；
- 茎TK、叶TK、果TK、植株TK。

横轴建议用DAT，纵轴kg/ha。

**第二组：不同器官分配比例**

例如：

\[
果实N分配率=\frac{果实N吸收量}{全株N吸收量}\times100\%
\]

分析养分从营养器官向果实的转移。

**第三组：阶段需肥量**

\[
阶段需N=N_{阶段末}-N_{阶段初}

| 生育阶段 | 需N | 需P | 需K | N:P:K |
|---|---:|---:|---:|---:|
| 苗期 | | | | |
| 开花坐果期 | | | | |
| 盛果期 | | | | |
| 结果后期 | | | | |

**第四组：阶段吸收速率**

\[
N吸收速率=\frac{\Delta N}{阶段天数}
\]

这样你才能真正判断**需肥高峰期**。
