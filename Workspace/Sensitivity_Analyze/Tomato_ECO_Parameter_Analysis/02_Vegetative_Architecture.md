# 番茄 ECO 参数解析 (二)：冠层结构与营养生长动态

本报告解析了 `TMGRO048.ECO` 中用于修正番茄冠层高度和宽度的相对比例参数，以及它们如何与物种文件 (`.SPE`) 和环境因子协同工作。

## 1. 核心比例参数：RHGHT 与 RWDTH

番茄的冠层生长在模型中是高度依赖节点的。这两个参数作为**比例因子**，将物种级的标准生长速率转换为特定生态型的表现。

| 参数名称 | 定义 (Ecotype Parameter) | 对应源代码 (CANOPY.for) |
| :--- | :--- | :--- |
| **RHGHT** | **相对高度因子**。相对于标准品种单位节点的株高增加量。 | `RCANHT = ... * RHGHT * ...` |
| **RWDTH** | **相对宽度因子**。相对于标准品种单位节点的冠层宽度增加量。 | `RCANWH = ... * RWIDTH * ...` |

### 动力学公式解析
在 `CANOPY.for` 中，每日的高度增加量 (`RCANHT`) 和宽度增加量 (`RCANWH`) 计算如下：

```fortran
! 高度增加量计算示例
RCANHT = RVSTGE * TABEX(YVSHT,XVSHT,VSTAGE,10) * HWTEM * TURFAC * HPAR * RHGHT * CUMNHT
```

- **RVSTGE**: 节点的形成速率（由 `TRIFL` 决定）。
- **TABEX(YVSHT,...)**: 从 `.SPE` 文件中查询得到的当前阶段标准节间长度。
- **HWTEM / TURFAC / HPAR**: 分别代表温度、水分和光照对扩展生长的修正。
- **RHGHT**: **ECO 修正项**。若此值为 1.0，则表现为标准株高；若为 0.9，则株高缩减 10%。

---

## 2. 营养生长动态的驱动力：TRIFL

### TRIFL (Rate of Appearance of Leaves)
- **作用**：定义了主茎上叶片（节点）出现的速率（Leaves per Degree Day）。
- **连锁反应**：
    1. `TRIFL` 决定了 `RVSTGE` (节点/天)。
    2. `RVSTGE` 是 `RCANHT` 和 `RCANWH` 公式的第一个乘数。
    3. `VSTAGE` 的增加速度决定了叶面积指数 (LAI) 的扩展速度。

> [!IMPORTANT]
> 在番茄模型中，`TRIFL` 的细微变化会通过积温累积，显著改变植株的早期覆盖速度。对于半停心型 (Semi-determinate) 番茄，较高的 `TRIFL` 意味着更快的封垄速度。

---

## 3. 营养生长终点控制：FL-VS

### FL-VS (Flowering to Last Node)
- **定义**：从初花期到主茎停止生长（或达到最大节点数）所需的光温时。
- **无限生长习性模拟**：
    - 番茄通常具有无限生长潜力。在模型中，如果不设定 `FL-VS`，主茎节点会持续增加。
    - 该参数设定了一个生长期窗口：一旦开花后经过了 `FL-VS` 定义的时间，营养生长（节点增加）将趋于停止或转化为生殖生长为主。

---

## 4. 参数配置与表型关联

| 参数组合 | 对应的番茄植株表型 |
| :--- | :--- |
| **高 RHGHT + 低 RWDTH** | 植株高瘦，节间较长，适合高密度种植或温室吊蔓品种。 |
| **低 RHGHT + 高 RWDTH** | 植株矮壮，分枝性强，冠层平展。 |
| **高 TRIFL + 短 FL-VS** | 营养生长极快但生长期短，表现为早熟且紧凑的品种。 |

> [!TIP]
> **校准建议**：
> 如果野外观察到番茄株高明显高于模型模拟值，但 LAI 匹配，应优先调高 `RHGHT` 而非修改 `SPE` 中的全局表格；如果冠层封垄过早，应调低 `RWDTH` 或 `TRIFL`。
