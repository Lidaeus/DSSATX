# 测试与质量保障（SA 项目）

本项目在 `Workspace\Sensitivity_Analyze` 下提供统一的 lint、typecheck 与单元测试流程。

## 1. 环境准备

在 `C:\DSSAT48\Tomato_Cal\Workspace\Sensitivity_Analyze` 下执行：

```powershell
python -m pip install -r .\requirements-dev.txt
```

## 2. 质量检查命令

在 `C:\DSSAT48\Tomato_Cal\Workspace\Sensitivity_Analyze` 下执行：

```powershell
python -m ruff check .
python -m mypy .\SA_Project_Code
```

说明：

- lint 仅检查代码目录与测试目录，跳过 `SA_Project_Output` 与 `SA_Project_Docs`。
- typecheck 默认忽略第三方缺失类型，避免阻断主流程。

## 3. 单元测试

在 `C:\DSSAT48\Tomato_Cal\Workspace\Sensitivity_Analyze` 下执行：

```powershell
python -m pytest
```

## 4. 测试覆盖范围

- 指标命名与分组逻辑：`sa_postprocess_morris.py`、`sa_postprocess_sobol.py`
- DSSAT 输出解析：`sa_model.py`（Evaluate/PlantGro 解析与曲线面积）
- 参数范围默认值逻辑：`sa_generate_param_review_csv.py`

## 5. 常见问题

- 若 `pytest` 未找到模块，请确认从 `Sensitivity_Analyze` 目录运行。
- 若 lint 结果包含大量历史问题，可先从新增代码开始逐步收敛。
