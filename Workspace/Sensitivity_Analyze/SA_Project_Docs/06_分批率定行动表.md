# 分批率定行动表（Morris+Sobol 综合）

本行动表用于指导后续的参数分批率定。分批顺序综合了 Morris（筛选）与 Sobol（总效应 STi）的结论，并按模块与目标指标组织。

## 目标与原则

- 先时序后结构、先主效应后细节；每批次覆盖少量紧密相关参数，避免互相掩蔽。
- 每批次率定完成后，进行最小回归验证（LAI、果实干重、产量、HI）。
- 采用固定批次步长（≤6 个参数/批），并保留前批次的调整窗口以防回退。

## 第 1 批：Thermal time 与物候时间尺度（优先）

目标指标：ADAPS、LAI 时间结构（dap/auc）、FRUITD 时间结构（dap/auc/end）

- TB1、TB2（SPE_TempStages）：低温/适温阈值
- TO11、TO12、TO22（SPE_TempStages）：最适/上限温度
- EM-FL（CUL_PhenologyHarvest）：播种至开花
- EM-V1（ECO_Phenology）：早期发育进度

操作建议：以 ADAPS 和 LAI_DAP 的偏差作为主损失，联动 FRUITD_DAP 的时间结构；步长小、逐项微调。

## 第 2 批：冠层结构与叶面积形成

目标指标：LAI_AUC、LAI_PEAK、LAI_END、CWAMS/AGB_END_CWAD

- TRIFL（ECO_Architecture）：叶片形成速率
- LFMAX（CUL_Architecture）：最大叶面积上限
- RWDTH、RHGHT（ECO_Architecture）：冠层几何形态
- KCAN（SPE_Photosynthesis）：消光系数，影响冠层光分配

操作建议：以 LAI_AUC/PEAK 为主、CWAMS/AGB_END_CWAD 作为结构性约束，优先匹配峰值与面积。

## 第 3 批：果实分配与产量形成

目标指标：FRUITD_AUC、FRUITD_END、YIELD_HWAMS、HIAMS

- XFRT（CUL）：分配到果实的比例
- XFINT（CUL）：果实分配的起始强度
- PM06（CUL）：光周期敏感性
- ATOP（CUL）：冠层向果实的分配调节

操作建议：先分配强度（XFRT/XFINT），再调整光周期与分配调节（PM06/ATOP）；以 FRUITD_AUC/END 与 HIAMS 联合度量。

## 第 4 批：根系与水分相关参数（情景微调）

目标指标：在干旱/过湿试验或情景扩展中验证

- FRLFF、FRSTMF（SPE_RootWater）：根分配相关，对胁迫下 LAI/果实影响
- PORPT（SPE_RootWater）：根系孔隙度与吸水能力 proxy
- SOIL_SLLL_06、SOIL_SLLL_07（土壤）：中下层萎蔫点
- SOIL_SBDM_05、SOIL_SBDM_06（土壤）：中下层容重
- SOIL_SSAT_02（土壤）：第 2 层饱和含水量

操作建议：单独情景（干旱/灌溉）验证其影响，再决定是否纳入主校准流程。

## 每批次操作流程

1. 锁定批次参数及上下界（参考 sensitivity_param_review.csv/topk_params.csv）。
2. 采用小步长拟合（例如 L-BFGS 或手动迭代），每次只调整 2–3 个参数。
3. 校验输出：
   - LAI：AUC、PEAK、END、关键 DAP 点。
   - 果实：AUC、关键 DAP、末期值 END。
   - 产量/HI：终值一致性。
4. 记录变更与理由（文件级：ECO/CUL/SPE），并生成差异比对图。
5. 若出现交叉影响（前批次被新批次破坏），回退并缩小步长。

## 快速参考（来源文件 → 参数组）

- SPE_Photosynthesis：KCAN
- SPE_TempStages：TB1/TB2/TO11/TO12/TO22
- SPE_RootWater：PORPT、FRLFF、FRSTMF
- ECO_Phenology：EM-V1
- ECO_Architecture：TRIFL、RWDTH、RHGHT
- CUL_PhenologyHarvest：EM-FL
- CUL_Allocation：XFRT、XFINT、ATOP
- CUL_Photoperiod：PM06

## 里程碑与验收

- 里程碑 1（物候）：ADAPS/LAI_DAP/FRUITD_DAP 的时间误差显著下降。
- 里程碑 2（冠层）：LAI_PEAK 与 LAI_AUC 达到目标区间，CWAMS/AGB_END_CWAD 波动收敛。
- 里程碑 3（产量）：FRUITD_AUC/END 与 YIELD/HIAMS 的偏差可控，采收节律合理。

完成以上三步后，再进入土壤与根系水分的情景微调。
