# 输出结构与文件解读（SA 项目）

本文说明 `Workspace\Sensitivity_Analyze\SA_Project_Output` 下的主要输出结构与阅读顺序，覆盖 Morris 与 Sobol 两阶段，以及前向模型 `SA_Indicators.OUT` 的意义。

## 1. 总体目录结构

以默认输出目录为例：

- `SA_Project_Output\sensitivity_param_review.csv`：参数范围审核表（唯一真源）
- `SA_Project_Output\sen_case\`：敏感性 Case（PEST 控制文件、模板、输出）
- `SA_Project_Output\morris_results*\`：Morris 后处理结果（紧凑或全量）
- `SA_Project_Output\sobol_results*\`：Sobol 后处理结果（紧凑或全量）

说明：

- `*` 表示可自定义目录名，例如 `morris_results_compact2`。
- 运行不同规模的 Case 会产生多个 `sen_case_*` 目录（如 `sen_case_r10_big_fix2`），结构一致。

## 2. Case 目录（sen_case）结构

典型文件（以 `sen_case` 为例）：

- `sa_sen_morris.pst`：Morris 控制文件
- `sa_sen_sobol.pst`：Sobol 控制文件
- `sa_params.csv` / `sa_params.csv.tpl`：参数输入与模板
- `SA_Indicators.OUT.ins`：PEST 读取指标的指令文件
- `SA_Indicators.OUT`：前向模型输出（被 PEST 读取）
- `sa_obs_order.txt`：观测量行序（保证 `SA_Indicators.OUT` 行序稳定）
- `sa_sen_morris.*`：Morris 运行与结果文件
- `sa_sen_sobol.*`：Sobol 运行与结果文件
- `_sa_tmp_runs\`：前向模型临时运行目录（执行后会被清理）

### 2.1 `SA_Indicators.OUT` 如何理解

- 每一行对应一个指标（观测量）。
- 行序由 `sa_obs_order.txt` 决定，或由 `sa_model.py` 内置的默认顺序生成。
- 数值为浮点数，缺失或失败时为 `-99`。
- `TN2_` / `TN3_` 前缀表示不同处理或试验编号（由 `Evaluate.OUT` 的 TN 字段映射）。
- `MEAN_` 前缀表示对同一指标在多个 TN 之间的均值。

与之配套：

- `SA_Indicators.OUT.ins` 列出了所有指标的命名与顺序，Pest 读取时以此为准。

### 2.2 `sa_sen_morris.*` 关键文件

- `sa_sen_morris.rec`：运行记录，包含 finished 时间戳与运行命令
- `sa_sen_morris.mio`：核心敏感性表（按指标 × 参数）
- `sa_sen_morris.raw.csv`：原始 Morris 结果（更接近 PEST 输出）
- `sa_sen_morris.sen.par.csv`：按参数汇总的敏感性表

### 2.3 `sa_sen_sobol.*` 关键文件

- `sa_sen_sobol.rec`：运行记录与命令
- `sa_sen_sobol.sobol.si.csv`：一阶指数 Si
- `sa_sen_sobol.sobol.sti.csv`：总效应指数 STi
- `sa_sen_sobol.sobol.obs.csv` / `sa_sen_sobol.sobol.par.csv`：按观测或参数聚合的中间表

## 3. Morris 后处理输出（morris_results*）

核心文件与阅读顺序：

1. `morris_overall_parameter_ranking.csv`
   - 全局综合排序（推荐从这里锁定 Top 参数集合）
2. `morris_overall_top<top_n>.png/.svg`
   - Top-N 参数可视化
3. `morris_heatmap_param_x_indicator.png/.csv`
   - 参数 × 指标组热力图，用于快速定位“哪个参数影响哪些指标”
4. `morris_heatmap_<metric>.png/.csv`
   - 时序指标（如 LAI、果实干重）在不同 DAP 的敏感性分布
5. `morris_scatter_score_vs_sigma.png`
   - 非线性/交互迹象：高敏感且高波动的参数需重点关注
6. `morris_onepage_summary.tsv/.md`
   - 便于汇报的一页式摘要

补充：

- `morris_param_to_indicator_scores.csv` 可用于从“参数 → 指标”视角聚合。
- `morris_top20_<indicator>.csv` 为单个指标的 Top-N 明细表。

## 4. Sobol 后处理输出（sobol_results*）

核心文件与阅读顺序：

1. `sobol_quality_report.csv`
   - 质量报告，检查 Si/STi 是否大量 NaN
2. `sobol_raw.csv`
   - 标准化后的 Sobol 原始表（已统一指标名称）
3. `sobol_overall_parameter_ranking_<Si或STi>.csv`
   - 全局排序，默认优先使用 STi
4. `sobol_top<top_n>_<indicator>.png/.csv`
   - “指标 → 参数”视角
5. `sobol_param_top<top_n>_indicators_<par>.png/.csv`
   - “参数 → 指标”视角
6. `sobol_heatmap_<metric>_<Si或STi>.png/.csv`
   - 时序指标热力图

当 `sobol_quality_report.csv` 显示 Si/STi 均为 NaN 时，后处理会停止出图，仅保留质量报告与 `sobol_raw.csv` 以便排查前向模型是否输出异常。

## 5. 推荐的阅读路径（快速把握重点）

1. Morris：`morris_overall_parameter_ranking.csv` → `morris_heatmap_param_x_indicator.png`
2. Morris：时序热力图（`morris_heatmap_lai.png`、`morris_heatmap_fruitd.png`）
3. 选 Top-K：`topk_params.csv`（由 `sa_select_topk_from_morris.py` 生成）
4. Sobol：`sobol_quality_report.csv` → `sobol_overall_parameter_ranking_STi.csv`
5. Sobol：指标/参数双视角图与时序热力图

## 6. 常见输出异常与定位建议

- `SA_Indicators.OUT` 出现大量 `-99`
  - 先检查 `Evaluate.OUT`、`PlantGro.OUT`、`FreshWt.OUT` 是否在临时运行目录生成。
  - 检查 `sa_obs_order.txt` 与 `SA_Indicators.OUT.ins` 是否一致。

- `sobol_quality_report.csv` 中 Si/STi 全 NaN
  - 重点检查 `sa_sen_sobol.rec` 中的运行是否完成。
  - 检查 `sa_sen_sobol.sobol.si.csv` / `sa_sen_sobol.sobol.sti.csv` 是否包含有效数值。

- 图片或 CSV 缺失
  - 确认后处理脚本使用了正确的 `--out-dir` 与 `--case-dir`。
  - 若使用 `plot-mode compact`，部分图表会被精简为热力图与摘要表。
